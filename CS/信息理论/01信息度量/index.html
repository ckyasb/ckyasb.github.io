01 信息度量 🔴 考试核心（~40%）

余官定 | 2026-03-08 ~ 04-12 (4 讲) | 考试占比 ~40%

1. 知识框架

信息度量的核心问题：如何量化一个随机事件或随机变量含有的"信息量"？

度量体系的层次：

自信息 I(x) = -log p(x)      （单个事件的不确定性）
  ↓ 取期望
熵 H(X) = E[-log p(X)]       （随机变量的平均不确定性）
  ↓ 两个变量
联合熵 H(X,Y), 条件熵 H(X|Y)    （多变量扩展）
  ↓ 比较分布 / 互信息
KL散度 D(P||Q), 互信息 I(X;Y)   （分布差异 / 共享信息）
  ↓ 随机过程
熵率 H∞, 数据处理不等式, Fano不等式 （信息处理的约束）

老师强调："整个第一章讲了这么多概念，本质上来讲就是两个概念——自信息和互信息。自信息就是负的 log，互信息就是自信息减条件自信息（一个差值）。其他都是倒腾来倒腾去，要么加要么减。"（03-15 课堂原话）

2. 核心概念与定理

2.1 自信息 (Self-information) 🟡重点

定义：事件 \(\{X=x\}\) 的自信息

\[I(x) = -\log p(x)\]

含义：自信息度量一个具体事件发生时所携带的"信息量"——事件越罕见，信息量越大。"明天太阳东升"概率接近 1，信息量几乎为 0（你早知如此）；"六月杭州下雪"概率极低，若真发生就是爆炸性新闻。用对数是为了满足可加性：两件独立事件同时告诉你，总信息量等于各自信息量之和——对数恰好把概率的乘法变成信息的加法。自信息是信息度量体系的基石：对自信息求期望就得到熵，比较两个概率分布的自信息差就得到 KL 散度。

底 单位
2 bit
\(e\) nat
10 hartley

性质： - \(p(x)=1 \Rightarrow I(x)=0\)（必然事件无信息） - \(p(x) \to 0 \Rightarrow I(x) \to \infty\) - \(I(x) \geq 0\)

课堂补充细节

老师用大量生活例子解释自信息： - 男足夺冠：概率趋近于 0，若真发生则信息量无穷大，是"爆炸性新闻" - 明天下雨：概率 0.25 时，"明天会下雨"这句话的信息量是 \(-\log_2 0.25 = 2\) bit - 概率 1/2 vs 1/20：前者 1 bit，后者约 4.32 bit——概率越小信息量越大 - 成都 vs 北京：成都多雨，告诉成都人"明天要下雨"信息量小；北京冬天下雨概率极低，告诉北京人"明天要下雨"信息量大

两种理解角度（老师用能量类比）： 1. 事件发生后对外界提供的信息量（类比物体落下释放的势能） 2. 让该事件发生需要外界提供的信息量（类比把物体提升到一定高度需要的能量）

老师在黑板上特别强调："事件的自信息并不代表事件的不确定性——事件本身没有不确定性，只有随机变量才有不确定性。"

配套练习

题目 1：设某地明天下雨的概率为 0.125，晴天概率为 0.875。计算"明天会下雨"这句话的自信息。

??? note "答案" \(I = -\log_2 0.125 = 3\) bit

题目 2：证明自信息的可加性：对两个独立事件 \(A,B\)，有 \(I(A \cap B) = I(A) + I(B)\)。

??? note "答案" \(A,B\) 独立 \(\Rightarrow p(A \cap B) = p(A)p(B)\)，则 \(I(A \cap B) = -\log p(A)p(B) = -\log p(A) - \log p(B) = I(A) + I(B)\)。这正是老师讲的"独立事件的信息量是比特加比特，不是比特乘比特"。

易错点
  • 自信息是事件的函数，不是随机变量的函数——\(I(x)\) 取决于具体取值，不是平均量
  • 不要混淆"概率"和"信息量"：概率大的事件信息量小，概率小的事件信息量大
  • 单位问题：以 2 为底是 bit，以 \(e\) 为底是 nat，相差常数因子 \(\ln 2\)

2.2 熵 🔴必考

定义：

\[H(X) = -\sum_{x} p(x) \log p(x) = \mathbb{E}[-\log p(X)]\]

含义：熵是一个随机变量整体不确定性的度量——是自信息的期望。如果说自信息回答"这个具体值有多意外"，熵回答的是"这个变量平均有多难猜"。熵越大，你对结果越没把握。公平硬币熵为 1 bit（完全无法预测），两面相同的硬币熵为 0（100% 确定）。熵解决了信息论最根本的问题：如何用一个数来量化"不确定性"的大小。注意熵只依赖于概率分布，与变量的具体取值含义无关——不管你关心的是"猫"还是"狗"，概率分布相同，熵就相同。

性质：

  1. 非负性：\(H(X) \geq 0\)，等号当且仅当 \(X\) 是确定型变量。
  2. 上界：\(H(X) \leq \log |\mathcal{X}|\)，等号当且仅当 \(X \sim \text{Uniform}\)。
  3. 凹性：\(H(p)\) 是概率分布 \(p\) 的凹函数。

二元熵（Bernoulli）：

\[H_2(p) = -p\log p - (1-p)\log(1-p)\]

\(p=0.5\) 时最大（1 bit），\(p=0\) 或 \(1\) 时为 0。

课堂补充细节

熵的物理意义（老师重点讲解）：

  • 英文单词 entropy 直接借用热力学术语，代表"系统的混乱程度"
  • 越混乱的分布熵越大——均匀分布时系统最混乱，熵最大
  • 老师用莫斯科、北京、香港冬天下雪作类比：
  • 莫斯科冬天大概率下雪 \(p=0.8\)，熵较小（比较确定会下雪）
  • 北京冬天一半一半 \(p=0.5\)，熵最大（最不确定）
  • 香港几乎不下雪 \(p\approx 0.0001\)，熵接近 0（基本确定不会下雪）

熵与自信息的区别（老师反复强调）：

  • 自信息是单个事件的信息量；熵是随机变量的平均信息量（自信息的期望）
  • 老师举保研的例子：一个年级第一的同学"保不了研"这件事自信息无穷大（极不可能发生），但整个年级能不能保研这个随机变量的熵取决于保研率

为什么用对数（老师总结）： 1. 概率越小 → 信息量越大（直觉合理） 2. 对数可加性：独立事件的信息可叠加（比特加比特，不是比特乘比特） 3. 数学简单：好求导、好积分

老师说："如果你穿越回 80 年前，你能不能想到负的 log？"

配套练习

题目 1：三元信源 \(p = \{0.5, 0.3, 0.2\}\)，计算 \(H(X)\)。

??? note "答案" \(H(X) = -0.5\log_2 0.5 - 0.3\log_2 0.3 - 0.2\log_2 0.2 = 0.5 + 0.521 + 0.464 = 1.485\) bit

题目 2：证明 \(H(X) \leq \log |\mathcal{X}|\)（用 Jensen 不等式）。

??? note "答案" 由 Jensen 不等式：\(H(X) = \mathbb{E}[-\log p(X)] \leq -\log\mathbb{E}[p(X)]\)? 更准确的做法：令 \(q(x) = 1/|\mathcal{X}|\) 为均匀分布，则 \(D(p\|q) = \sum p\log\frac{p}{q} = \sum p\log p - \sum p\log(1/|\mathcal{X}|) = -H(X) + \log|\mathcal{X}| \geq 0\)，得 \(H(X) \leq \log|\mathcal{X}|\)。

题目 3：当 \(p=0.3\) 时计算二元熵 \(H_2(0.3)\)。\(p\) 为何值时 \(H_2(p)\) 最大？何时最小？

??? note "答案" \(H_2(0.3) = -0.3\log_2 0.3 - 0.7\log_2 0.7 \approx 0.881\) bit。最大值在 \(p=0.5\) 时取 1 bit，最小值在 \(p=0\) 或 \(p=1\) 时取 0。

易错点
  • 熵只依赖于概率分布，不依赖于随机变量的具体取值（老师强调："猫和狗在香农看来是一样的，都只是一个概率分布"）
  • 二元熵是 \(p\) 的凹函数（上凸），极大值在 \(p=0.5\)
  • 熵的单位取决于对数的底，bit 对应以 2 为底

2.3 联合熵与条件熵 🔴必考

联合熵：\(H(X,Y) = -\sum_{x,y} p(x,y) \log p(x,y)\)

含义：联合熵 \(H(X,Y)\) 是同时观测两个变量所需的总信息量；条件熵 \(H(X|Y)\) 是已知 \(Y\) 后 \(X\) 的剩余不确定性。两者的链式关系 \(H(X,Y)=H(X)+H(Y|X)\) 很容易理解：总不确定性 = 先搞懂 \(X\) 所需信息 + 搞懂 \(X\) 后再搞懂 \(Y\) 还需多少额外信息。关系 \(I(X;Y)=H(X)-H(X|Y)\) 则回答了"知道 \(Y\) 让 \(X\) 的不确定性减少了多少"——减少的量就是两个变量共享的信息。这就像一个拼图：联合熵是整幅图的信息量，条件熵是已知一部分后对剩下部分的不确定性。

条件熵（两种定义，老师重点区分）：

两种条件熵的区别

老师花了大量时间区分两种条件熵：

  1. 给定具体事件 \(Y=y\) 的条件熵： $\(H(X|Y=y) = -\sum_x p(x|y) \log p(x|y)\)$ 这是单个 \(Y=y\) 条件下的熵，与 \(H(X)\) 没有必然的大小关系（可大可小可相等）

  2. 给定随机变量 \(Y\) 的条件熵（常用）： $\(H(X|Y) = \sum_y p(y) H(X|Y=y) = -\sum_{x,y} p(x,y) \log p(x|y)\)$ 对 \(Y\) 的所有可能取统计平均，一定满足 \(H(X|Y) \leq H(X)\)

链式法则：

\[H(X_1, \ldots, X_n) = \sum_{i=1}^{n} H(X_i \mid X_1, \ldots, X_{i-1})\]

含义：链式法则说明联合不确定性可以一步步拆解：先确定 \(X_1\) 花 \(H(X_1)\) 的信息量，已知 \(X_1\) 后再确定 \(X_2\) 只需 \(H(X_2|X_1)\)，以此类推。这就像一个猜谜游戏：你可以先猜第一个字母，再根据第一个猜第二个，每一步都利用已猜到的信息减少后续的不确定性。链式法则也是许多更复杂证明的基础工具。

课堂补充细节

条件熵的物理意义（老师用杭州-上海下雨例子）：

  • \(X\)：杭州是否下雨（概率 0.5/0.5，\(H(X)=1\) bit）
  • \(Y\)：上海是否下雨
  • 若上海下雨了，杭州下雨概率升到 0.75，则 \(H(X|Y=\text{下雨}) < 1\) bit（不确定降低）
  • 若上海晴天，杭州下雨概率降到 0.25，则 \(H(X|Y=\text{晴天}) > 1\) bit（不确定反而升高）
  • 但 \(H(X|Y)\)（对 \(Y\) 的所有可能平均后）一定 ≤ \(H(X)\)，即平均而言，条件不会增加不确定性

老师用高考志愿选择类比：找不同人聊建议（\(Y\)），综合所有人意见后你的不确定性应该下降。"如果你综合了所有人的意见还是更不确定了，那大不了不听他的。"

条件熵与热力学的类比：外界的一个输入会使一个开放系统的熵减少——这是信息论熵与热力学熵的又一呼应。

配套练习

题目：已知联合分布 \(p(x,y)\) 如下表，求 \(H(X,Y)\), \(H(X|Y)\), \(H(Y|X)\)。

\(p(x,y)\) \(y=0\) \(y=1\)
\(x=0\) 0.4 0.1
\(x=1\) 0.2 0.3

??? note "答案" 边缘分布：\(p_X=(0.5,0.5)\)，\(p_Y=(0.6,0.4)\)

$H(X,Y) = -(0.4\log 0.4 + 0.1\log 0.1 + 0.2\log 0.2 + 0.3\log 0.3) \approx 1.846$ bit

$H(X) = 1$ bit，$H(Y) \approx 0.971$ bit

$H(X|Y) = H(X,Y) - H(Y) = 1.846 - 0.971 = 0.875$ bit

$H(Y|X) = H(X,Y) - H(X) = 1.846 - 1 = 0.846$ bit
易错点
  • \(H(X|Y=y)\) 与 \(H(X|Y)\) 是不同概念！前者是事件条件，后者对 \(Y\) 取平均
  • \(H(X|Y=y)\) 可以大于、小于或等于 \(H(X)\)，但 \(H(X|Y) \leq H(X)\) 恒成立
  • 链式法则的物理意义：联合不确定性 = 先确定第一个 + 已知第一个后确定第二个 + ...

2.4 相对熵 (KL 散度) 🟡重点

含义：KL 散度衡量用分布 \(Q\) 近似真实分布 \(P\) 时代价多大——或者说把 \(Q\) 误当成 \(P\) 来用，平均多花多少"信息费"。它不是数学上的距离（不对称），而是"额外代价"或"惊讶增量"。比如你把公平骰子（\(P\)）当成作弊骰子（\(Q\)）来预测，KL 散度就是这种误判导致的信息损失。在机器学习中，最小化 KL 散度就是让模型分布逼近真实数据分布——这正是交叉熵损失函数的本质：模型训练就是不断减少"用模型代替真实分布"的额外代价。

定义：

\[D(P \Vert Q) = \sum_x p(x) \log \frac{p(x)}{q(x)}\]

性质： - \(D(P \Vert Q) \geq 0\)（Gibbs 不等式），等号当且仅当 \(P=Q\) - 不对称：一般 \(D(P \Vert Q) \neq D(Q \Vert P)\) - 联合凸性

课堂补充细节

老师用 公平骰子 vs 作弊骰子 的例子引入 KL 散度：

  • \(P\)：公平骰子（每个面概率 1/6）
  • \(Q\)：被做过手脚的骰子（"比如 3 点的概率是 1/2，其他 5 个面各 1/10"）
  • KL 散度衡量这两个概率分布之间的"距离"

老师特别提到 KL 散度与机器学习中的交叉熵的紧密联系： - 交叉熵 = \(H(P) + D(P\|Q)\) - 机器学习训练的本质：让模型分布 \(Q\) 逼近真实分布 \(P\)，即最小化 \(D(P\|Q)\) - 老师强调："损失函数就是用交叉熵，为什么？因为我们要最小化两个分布之间的差异"

不对称性：老师现场演示——\(D(P\|Q)\) 和 \(D(Q\|P)\) 一般不同，这不满足数学上"距离"的定义。解决方法：定义对称 KL 散度 \(D_{\text{sym}} = D(P\|Q) + D(Q\|P)\)。

统一性（老师重点讲解）：三个核心概念可以用 KL 散度统一： - 互信息：\(I(X;Y) = D(p(x,y) \| p(x)p(y))\) - 熵：\(H(X) = \log|\mathcal{X}| - D(p(x) \| \text{Uniform})\) - 老师总结："H 和 I 都可以用 D 来表示，所以本质上只有一个概念"

配套练习

题目：设 \(P=(0.5,0.5)\), \(Q=(0.9,0.1)\)，求 \(D(P\|Q)\) 和 \(D(Q\|P)\)。

??? note "答案" \(D(P\|Q) = 0.5\log\frac{0.5}{0.9} + 0.5\log\frac{0.5}{0.1} \approx 0.5 \times (-0.848) + 0.5 \times 2.322 = 0.737\) bit

$D(Q\|P) = 0.9\log\frac{0.9}{0.5} + 0.1\log\frac{0.1}{0.5} \approx 0.9 \times 0.848 + 0.1 \times (-2.322) = 0.530$ bit

可见 $D(P\|Q) \neq D(Q\|P)$。
易错点
  • 定义中 \(q(x)=0\) 时必须要求 \(p(x)=0\)，否则 KL 散度无穷大——即 \(Q\) 的支撑集必须包含 \(P\) 的支撑集
  • KL 散度不是真正的"距离"（不满足对称性和三角不等式）

2.5 互信息 🔴必考

含义：互信息度量两个随机变量之间"共享"的信息量——知道 \(Y\) 后，\(X\) 的不确定性降低多少。公式 \(I(X;Y)=H(X)-H(X|Y)\) 的意义非常直观：\(H(X)\) 是你对 \(X\) 的原始不确定度，\(H(X|Y)\) 是已知 \(Y\) 后还剩的不确定度，差值就是 \(Y\) 告诉你的信息量。举例来说，你想知道明天是否下雨（\(X\)），看到夜空多云（\(Y\)）后你的不确定度从 1 bit 降到 0.4 bit——差值 0.6 bit 就是互信息。如果 \(X\) 和 \(Y\) 独立，互信息为 0（知道 \(Y\) 对 \(X\) 毫无帮助）；如果 \(Y\) 完全确定 \(X\)，互信息等于 \(H(X)\)（知道 \(Y\) 就知道 \(X\) 的一切）。

定义：

\[I(X;Y) = \sum_{x,y} p(x,y) \log \frac{p(x,y)}{p(x)p(y)} = D(p(x,y) \Vert p(x)p(y))\]

与熵的关系（教材式 2.1.46）：

\[I(X;Y) = H(X) - H(X|Y) = H(Y) - H(Y|X) = H(X) + H(Y) - H(X,Y)\]

性质（教材式 2.1.47）： - 对称：\(I(X;Y) = I(Y;X)\) - \(0 \leq I(X;Y) \leq \min\{H(X), H(Y)\}\)

条件互信息：

\[I(X;Y|Z) = \sum_{x,y,z} p(x,y,z) \log \frac{p(x,y|z)}{p(x|z)p(y|z)}\]

联合互信息链式法则：

\[I(X;Y,Z) = I(X;Z) + I(X;Y|Z) = I(X;Y) + I(X;Z|Y)\]
课堂补充细节

互信息的物理意义（老师重点讲解）：

互信息 = 自信息 - 条件自信息 = \(Y\) 发生后 \(X\) 不确定性的降低量

用杭州-上海下雨例子： - 杭州下雨的不确定性（自信息）= 1 bit - 已知上海下雨后，杭州下雨的条件自信息 = \(-\log_2(0.75) \approx 0.415\) bit - 所以上海下雨给杭州下雨提供的互信息 = \(1 - 0.415 = 0.585\) bit

老师用维恩图解释互信息与熵的关系： 

    H(X,Y)
    /   \
  H(X)   H(Y)
   \    /
  H(X|Y) I(X;Y) H(Y|X)
其中 \(I(X;Y)\) 是两个圆的交集，\(H(X|Y)\) 是 \(X\) 中不与 \(Y\) 重叠的部分。

极端情况： - \(X \perp Y\) 时：\(I(X;Y)=0\)，两圆无交集 - \(Y=f(X)\) 时：\(I(X;Y)=H(X)\)，\(Y\) 完全确定了 \(X\)，两圆重合

老师举掷骰子的例子： - \(X\)：骰子点数（1-6），\(H(X)=\log_2 6\) - \(Y\)：奇偶性，\(H(Y)=1\) bit - \(I(X;Y)=H(Y)-H(Y|X)=1-0=1\) bit（知道点数就知道奇偶） - 但反过来 \(I(Y;X)=H(X)-H(X|Y)=\log_2 6 - \log_2 3 = 1\) bit（知道奇偶只把点数范围缩到 3 种）

配套练习

题目：证明 \(I(X;Y) = H(X) - H(X|Y)\)。

??? note "答案" \(I(X;Y) = \sum p(x,y)\log\frac{p(x,y)}{p(x)p(y)} = \sum p(x,y)\log\frac{p(x|y)}{p(x)}\)

$= -\sum p(x,y)\log p(x) + \sum p(x,y)\log p(x|y) = H(X) - H(X|Y)$
易错点
  • 互信息符号是分号 \(I(X;Y)\)，不是逗号——逗号表示联合
  • 互信息总是非负的（\(I(X;Y) \geq 0\)），等号当且仅当 \(X \perp Y\)
  • 互信息对称但不具有三角不等式

2.6 熵与互信息关系图 🟡重点

含义：该维恩图直观展示了熵、联合熵、条件熵和互信息之间的数量关系。\(H(X)\) 和 \(H(Y)\) 两个圆的总面积是联合熵 \(H(X,Y)\)；两圆交叠的部分是互信息 \(I(X;Y)\)——两个变量共享的信息；\(X\) 圆中不与 \(Y\) 重叠的部分是 \(H(X|Y)\)——\(Y\) 无法告诉你的那部分 \(X\) 的不确定性。整个图的核心等式 \(H(X) = H(X|Y) + I(X;Y)\) 说明：\(X\) 的总不确定性 = \(Y\) 无法消除的部分 + \(Y\) 能消除的部分。这个可视化是理解整套信息度量关系的钥匙。

    H(X,Y)
    /   \
  H(X)   H(Y)
   \    /
  H(X|Y) I(X;Y) H(Y|X)
  • \(H(X,Y) = H(X) + H(Y|X) = H(Y) + H(X|Y)\)
  • \(H(X) = H(X|Y) + I(X;Y)\)
  • \(H(Y) = H(Y|X) + I(X;Y)\)

2.7 数据处理不等式 (DPI) 🟡重点

马尔可夫链 \(X \to Y \to Z\)（条件独立 \(X \perp Z \mid Y\)）：

\[I(X;Z) \leq I(X;Y)\]

含义：数据处理不等式（DPI）揭示了一个根本性的限制：你不可能通过对数据做任何后处理来凭空创造更多信息。一旦原始观测（\(Y\)）被采集，后续的所有加工——滤波降噪、PCA 降维、特征提取、甚至深度神经网络——都只能在信息不增加的前提下进行。你可能去掉噪声（让信息更容易提取），但信息总量只会保持或减少，绝不会增加。DPI 是信息论中最重要的基础定理之一：它划出了机器学习和信号处理的终极天花板——信息只能被提取和压缩，不能被制造。

证明：由链式法则 \(I(X;Y,Z) = I(X;Y) + I(X;Z|Y) = I(X;Z) + I(X;Y|Z)\)，利用条件独立性 \(I(X;Z|Y) = 0\)，得 \(I(X;Y) = I(X;Z) + I(X;Y|Z) \geq I(X;Z)\)。

课堂补充细节

DPI 的直观理解：老师用通信系统类比： - \(X\)：发送的信号 - \(Y\)：接收到的信号（经过信道可能有噪声） - \(Z\)：对 \(Y\) 做任何后处理（如去噪、特征提取） - DPI 告诉我们：\(Z\) 中包含的关于 \(X\) 的信息不可能超过 \(Y\) 中的 - 这就像一个"信息不可能无中生有"

老师特别强调："任何数据处理、任何特征提取、任何机器学习模型，都不可能创造出比原始数据更多的信息——这是信息论的一个根本限制。"

配套练习

题目：已知 \(X \to Y \to Z\) 是 Markov 链，且 \(Z = f(Y)\) 是确定性函数。证明 \(I(X;Z) \leq I(X;Y)\) 并给出取等条件。

??? note "答案" DPI 直接给出 \(I(X;Z) \leq I(X;Y)\)。取等条件：\(X \to Z \to Y\) 也成立（Z 是 Y 的充分统计量）。

典型反例：$Z = \text{sign}(Y)$ 丢失了 $Y$ 的幅度信息。
易错点
  • DPI 要求严格的 Markov 链 \(X \to Y \to Z\)，即 \(p(x,y,z) = p(x)p(y|x)p(z|y)\)
  • 如果 \(Z\) 依赖 \(X\) 和 \(Y\)（不止 \(Y\)），DPI 不一定成立

2.8 Fano 不等式 🔴必考

含义：Fano 不等式为任何基于 \(Y\) 猜测 \(X\) 的估计器设定了一个无法突破的错误率下界。简单来说：如果观测到 \(Y\) 后你对 \(X\) 仍然很不确定（\(H(X|Y)\) 很大），那么无论你用多聪明的算法来推断 \(X\)，都必然频繁出错。这就像考试时如果试卷信息严重不足（条件熵大），再厉害的学生也考不好——你没法靠"更好的处理"来弥补信息本身的亏空。Fano 不等式把这个直觉公式化，成为信息论与估计理论之间的重要桥梁。

\[\boxed{H(P_e) + P_e \log(|\mathcal{X} |-1) \geq H(X|Y)}\]

其中 \(P_e = P(\hat{X} \neq X)\)，\(\hat{X}\) 是基于 \(Y\) 的估计。等价于：

\[\boxed{P_e \geq \frac{H(X|Y) - 1} {\log(|\mathcal{X}|-1)}}\]
课堂补充细节

Fano 不等式给出了任何估计器（不论多复杂）的错误概率下界。老师说这是"信息论给估计理论的一个 fundamental limit"。

物理意义：如果 \(H(X|Y)\) 很大（即看了 \(Y\) 后仍然对 \(X\) 很不确定），那么任何基于 \(Y\) 的估计都会有很大错误率。这直观上很好理解——给定 \(Y\) 后不确定性越大，估计越容易错。

配套练习

题目：设 \(|\mathcal{X}| = 4\)，\(H(X|Y) = 1.2\) bit，求 \(P_e\) 的下界。

??? note "答案" \(P_e \geq \frac{H(X|Y)-1}{\log(|\mathcal{X}|-1)} = \frac{1.2-1}{\log_2 3} = \frac{0.2}{1.585} \approx 0.126\)

2.9 微分熵与熵功率（教材 §2.2） 🟢了解

含义：微分熵是离散熵到连续变量的推广——它衡量一个连续概率分布的"分散程度"。分布越平缓、越不确定，微分熵越大。与离散熵不同，微分熵可以是负数（概率密度可以大于 1），这意味着单个微分熵的绝对值没有意义，不同分布间的微分熵差才有意义。给定方差时正态分布微分熵最大——这说明在自然界的许多现象中，正态分布是最"随机"的分布，这也解释了为什么中心极限定理下误差会趋向正态分布。

微分熵定义 🟢了解

对于连续随机变量 \(X\)，概率密度为 \(f(x)\)：

\[h(X) = -\int f(x) \log f(x) \, dx\]

最大熵定理（教材定理 2.2.2） 🟢了解

给定方差 \(\sigma^2\)，正态分布 \(\mathcal{N}(0, \sigma^2)\) 达到最大微分熵：

\[h(X) \leq \frac{1}{2} \log(2\pi e \sigma^2)\]

等号当且仅当 \(X \sim \mathcal{N}(0, \sigma^2)\)。

熵功率（教材式 2.2.24） 🟢了解

定义熵功率为：

\[\bar{\sigma}^2 = \frac{1}{2\pi e} 2^{2h(X)}\]

由最大熵定理可知，\(\bar{\sigma}^2 \leq \sigma^2\)，当 \(X\) 服从正态分布时等号成立。

课堂补充细节

老师提到：连续随机变量和离散随机变量的熵有本质区别： - 离散熵 \(H(X) \geq 0\)，有明确的上界 - 微分熵 \(h(X)\) 可以是负数（因为概率密度可以大于 1） - 微分熵的对数底数也决定单位（bit/nat）

对于连续分布的最大熵，老师指出：给定方差时正态分布最大；给定取值范围时均匀分布最大（这与离散情况不同——老师特别指出这个区别）。

2.10 熵率与平稳随机过程 🟢了解

含义：熵率回答一个基本问题：一个平稳随机过程平均每个符号携带多少信息？以英文为例，单个字母的熵（考虑频率）约 4.0 bit，但相邻字母之间存在大量依赖——"q"后面几乎总是"u"——所以每新增一个字母实际提供的信息远小于 4 bit。随着考虑的序列越来越长，这种依赖累积起来，平均每字母的信息量最终收敛到熵率 \(H_\infty\)。英文的熵率约 1.4 bit/字母，意味着 27 个字母中有 71% 是冗余的——这正是我们能在拼写错误时仍能读懂文章、能有效压缩文本的原因。

课堂补充细节（04-12 讲重点内容）

老师用一整节课讲信源的熵率，这是第一章最"高级"的内容。

核心问题：一本书（如莎士比亚全集）到底有多少信息量？每个字母平均多少比特？

定义： - 平均每个符号的熵：\(H_n(X) = \frac{1}{n} H(X_1, X_2, \ldots, X_n)\) - 熵率：\(H_\infty(X) = \lim_{n\to\infty} H_n(X)\) - 平均条件熵：\(H'_n(X) = H(X_n | X_1, \ldots, X_{n-1})\)

四个重要定理（老师逐一证明）： 1. \(H'_n(X)\) 随 \(n\) 单调不增（条件越多，不确定性越少） 2. \(H_n(X)\) 随 \(n\) 单调不增 3. \(H_n(X) \geq H'_n(X)\) 4. \(\lim_{n\to\infty} H_n(X) = \lim_{n\to\infty} H'_n(X)\)（两极限相等）

实际应用：英文的熵率约 1.4 bit/字母，而 27 个字母（26+空格）若均匀分布最大熵为 \(\log_2 27 \approx 4.766\) bit。这意味着英文约有 71% 的冗余（由语法结构造成）。

马尔可夫信源： - 一阶 Markov：下一字母只与当前字母有关 - M 阶 Markov：下一字母与前面 M 个字母有关，状态空间 \(K^M\) - 熵率计算：\(H_\infty = \sum_{s} \pi(s) H(X|S=s)\)，其中 \(\pi(s)\) 是稳态分布

3. 典型例题

例题 1：二元信源熵

问题：随机变量 \(X \sim \text{Bernoulli}(0.3)\)，求 \(H(X)\)，以及当 \(p\) 为何值时 \(H(X)\) 最大？

解：

\[H(X) = -0.3 \log_2 0.3 - 0.7 \log_2 0.7 \approx 0.881 \text{ bit}\]

\(H_2(p)\) 是 \(p\) 的凹函数，在 \(p = 0.5\) 时取最大值 \(H_2(0.5) = 1\) bit。\(p=0.3\) 时 \(X\) 并非"最大不确定性"——0 比 1 更可能，降低了平均信息量。

例题 2：联合熵与条件熵

问题：\(X\) 与 \(Y\) 的联合分布如下：

\(p(x,y)\) \(Y=0\) \(Y=1\)
\(X=0\) 0.4 0.1
\(X=1\) 0.2 0.3

求 \(H(X)\)、\(H(Y)\)、\(H(X,Y)\)、\(H(X|Y)\)、\(H(Y|X)\)、\(I(X;Y)\)。

解：

边缘分布：\(p_X = (0.5, 0.5)\)，\(p_Y = (0.6, 0.4)\)

\[H(X) = H_2(0.5) = 1 \text{ bit}$$ $$H(Y) = -0.6\log_2 0.6 - 0.4\log_2 0.4 \approx 0.971 \text{ bit}$$ $$H(X,Y) = -(0.4\log_2 0.4 + 0.1\log_2 0.1 + 0.2\log_2 0.2 + 0.3\log_2 0.3) \approx 1.846 \text{ bit}\]

条件熵：

\[H(X|Y=0) = H_2(0.4/0.6) = H_2(2/3) \approx 0.918$$ $$H(X|Y=1) = H_2(0.1/0.4) = H_2(0.25) \approx 0.811$$ $$H(X|Y) = 0.6 \times 0.918 + 0.4 \times 0.811 \approx 0.875 \text{ bit}$$ $$H(Y|X) = H(X,Y) - H(X) \approx 0.846 \text{ bit}\]

互信息：

$\(I(X;Y) = H(X) - H(X|Y) = 1 - 0.875 = 0.125 \text{ bit}\)$ 或 \(I(X;Y) = H(X) + H(Y) - H(X,Y) = 1 + 0.971 - 1.846 = 0.125 \text{ bit}\)

例题 3：条件熵与独立性

问题：证明 \(H(X|Y) \leq H(X)\)，并举例说明等号何时成立。

解（Gibbs 不等式法）：

\[H(X|Y) - H(X) = -\sum_{x,y} p(x,y) \log \frac{p(x|y)}{p(x)} = -\sum_{x,y} p(x,y) \log \frac{p(x,y)}{p(x)p(y)}\]

令 \(Q = p(x)p(y)\)（独立），\(P = p(x,y)\)，则：

\[H(X|Y) - H(X) = -D(P \Vert Q) \leq 0\]

由 Gibbs 不等式 \(D(P\Vert Q) \geq 0\)，得 \(H(X|Y) \leq H(X)\)。等号当且仅当 \(X \perp Y\)（即 \(p(x,y) = p(x)p(y)\)）。

例题 4：DPI 的应用

问题：已知 \(X \to Y \to Z\) 是 Markov 链，且 \(Z = f(Y)\) 是确定性函数。证明 \(I(X;Z) \leq I(X;Y)\) 并给出取等的条件。

解：

由 DPI，\(I(X;Z) \leq I(X;Y)\) 直接成立。取等条件：\(X \to Z \to Y\) 也成立，即 \(Z\) 是 \(Y\) 的一个充分统计量——\(Z = f(Y)\) 保留了 \(Y\) 中关于 \(X\) 的全部信息。

典型反例：\(Z = \text{sign}(Y)\) 丢失了 \(Y\) 的幅度信息。

例题 5：英文熵率计算（课堂讨论）

问题：假设英文字母共 27 个（26 字母 + 空格），计算：(1) 均匀分布时最大熵 (2) 计入各字母概率分布后的一阶熵 (3) 熵率的实际值。

解（老师课堂上给出的数据）：

  1. \(H_0 = \log_2 27 \approx 4.766\) bit（均匀分布最大熵）
  2. \(H_1 \approx 4.036\) bit（考虑字母出现频率不等，但假设独立）
  3. \(H_2 \approx 3.326\) bit（考虑相邻字母相关性）
  4. \(H_\infty \approx 1.4\) bit（考虑全部语言结构后的熵率）

意义：熵的相对率 \(\eta = H_\infty / \log_2 27 \approx 0.29\)，冗余度 \(R = 1 - \eta \approx 71\%\)。这意味着英文中 71% 的内容是由语法结构决定的，只有 29% 是作者的"自由发挥"。

[例 2.1.7] 化验问题的互信息计算

问题：已知平均每 100 人中有 2 人患有某种病。为了查明病情，必须进行某项指标的化验。这种化验的结果对于有病的人总是阳性的，对于健康人来说有一半可能为阳性、一半可能为阴性。试问这项化验对于查明病情提供多少信息？如果先验分布变为等概率，化验又提供多少信息？

解：

用随机变量 \(X\) 取值 0,1 分别表示被抽查人是健康或有病，则 $\(p(X=0) = 0.98,\quad p(X=1) = 0.02\)$

用随机变量 \(Y\) 取值 0,1 分别表示化验结果为阴性或阳性，条件概率为： $\(p(Y=0|X=0) = 0.5,\quad p(Y=1|X=0) = 0.5\)$ $\(p(Y=0|X=1) = 0,\quad p(Y=1|X=1) = 1\)$

情形一：先验 \(p(X=0)=0.98, p(X=1)=0.02\)

计算边缘分布： $\(p(Y=0) = 0.98 \times 0.5 + 0.02 \times 0 = 0.49\)$ $\(p(Y=1) = 0.98 \times 0.5 + 0.02 \times 1 = 0.51\)$

源熵： $\(H(X) = -0.98\log_2 0.98 - 0.02\log_2 0.02 \approx 0.1414 \text{ bit}\)$

后验概率： $\(p(X=0|Y=0) = \frac{0.5 \times 0.98}{0.49} = 1,\quad p(X=1|Y=0) = 0\)$ $\(p(X=0|Y=1) = \frac{0.5 \times 0.98}{0.51} \approx 0.9608,\quad p(X=1|Y=1) \approx 0.0392\)$

条件熵： $\(H(X|Y=0) = 0\)$ $\(H(X|Y=1) = -0.9608\log_2 0.9608 - 0.0392\log_2 0.0392 \approx 0.2423 \text{ bit}\)$ $\(H(X|Y) = 0.49 \times 0 + 0.51 \times 0.2423 \approx 0.1236 \text{ bit}\)$

互信息： $\(I(X;Y) = H(X) - H(X|Y) = 0.1414 - 0.1236 \approx 0.0178 \text{ bit}\)$

情形二：先验 \(p(X=0)=0.5, p(X=1)=0.5\)

此时 \(H(X) = 1\) bit。

边缘分布： $\(p(Y=0) = 0.5 \times 0.5 + 0.5 \times 0 = 0.25\)$ $\(p(Y=1) = 0.5 \times 0.5 + 0.5 \times 1 = 0.75\)$

后验概率： $\(p(X=0|Y=0) = 1,\quad p(X=1|Y=0) = 0\)$ $\(p(X=0|Y=1) = \frac{1}{3},\quad p(X=1|Y=1) = \frac{2}{3}\)$

条件熵： $\(H(X|Y=1) = -\frac{1}{3}\log_2\frac{1}{3} - \frac{2}{3}\log_2\frac{2}{3} \approx 0.918 \text{ bit}\)$ $\(H(X|Y) = 0.25 \times 0 + 0.75 \times 0.918 \approx 0.6885 \text{ bit}\)$

互信息： $\(I(X;Y) = 1 - 0.6885 \approx 0.3115 \text{ bit}\)$

结论：同样的化验对于不同的先验分布，提供不同的信息量。发病率低时（1/50），化验只提供 0.0178 bit 信息；发病率高时（1/2），化验提供 0.3115 bit 信息。

老师的补充讨论

老师在课堂上特别提到核酸检测的例子："疫情防控的人应该学点信息论——检测不可能 100% 准确，总有假阳性假阴性。" 即使检测结果都是 0.5/0.5（完全随机），互信息为 0，检测毫无价值。

[例 2.1.8] 硬币识别问题

问题：有两个硬币，一个是正常的硬币（一面国徽，一面面值），另一个是不正常的硬币（两面都是面值）。现随机地抽取一个硬币，抛掷 2 次。问出现面值的次数对于硬币的识别提供多少信息？

解：

用 \(X\) 表示硬币类型：\(X=0\) 表示正常硬币，\(X=1\) 表示不正常硬币。

随机抽取，\(p(X=0) = p(X=1) = 0.5\)，\(H(X) = 1\) bit。

用 \(Y\) 表示抛掷两次中出现面值的次数，\(Y \in \{0,1,2\}\)。

条件概率（正常硬币每抛一次出现面值概率为 0.5）： $\(p(Y=0|X=0) = 0.25,\; p(Y=1|X=0) = 0.5,\; p(Y=2|X=0) = 0.25\)$ $\(p(Y=0|X=1) = 0,\; p(Y=1|X=1) = 0,\; p(Y=2|X=1) = 1\)$

计算边缘分布： $\(p(Y=0) = 0.5 \times 0.25 + 0.5 \times 0 = 0.125\)$ $\(p(Y=1) = 0.5 \times 0.5 + 0.5 \times 0 = 0.25\)$ $\(p(Y=2) = 0.5 \times 0.25 + 0.5 \times 1 = 0.625\)$

后验概率（以 \(Y=2\) 为例）： $\(p(X=0|Y=2) = \frac{0.5 \times 0.25}{0.625} = 0.2,\quad p(X=1|Y=2) = \frac{0.5 \times 1}{0.625} = 0.8\)$

条件熵： $\(H(X|Y=0) = H(X|Y=1) = 0 \text{（完全确定）}\)$ $\(H(X|Y=2) = -0.2\log_2 0.2 - 0.8\log_2 0.8 \approx 0.722 \text{ bit}\)$ $\(H(X|Y) = 0.125 \times 0 + 0.25 \times 0 + 0.625 \times 0.722 \approx 0.4513 \text{ bit}\)$

互信息： $\(I(X;Y) = H(X) - H(X|Y) = 1 - 0.4513 \approx 0.5487 \text{ bit}\)$

结论：抛掷两次出现面值的次数提供了约 0.55 bit 的信息，使我们对硬币类型的不确定性从 1 bit 降到了 0.45 bit。注意 \(Y=0\) 或 \(Y=1\) 时能完全确定是正常硬币，但 \(Y=2\) 时仍然有歧义（可能是正常硬币抛出了两个面值，也可能是不正常硬币）。

互信息的基本性质（教材式 2.1.46）

问题：证明互信息的三种等价表达式： $\(I(X;Y) = H(X) - H(X|Y) = H(Y) - H(Y|X) = H(X) + H(Y) - H(X,Y)\)$

证明：

由互信息定义： $\(I(X;Y) = \sum_{x,y} p(x,y) \log \frac{p(x,y)}{p(x)p(y)}\)$

展开为三项： $$ \begin{aligned} I(X;Y) &= \sum_{x,y} p(x,y) \log \frac{p(x|y)}{p(x)} \ &= -\sum_{x,y} p(x,y) \log p(x) + \sum_{x,y} p(x,y) \log p(x|y) \ &= H(X) - H(X|Y) \end{aligned} $$

同理可得 \(I(X;Y) = H(Y) - H(Y|X)\)。又： $$ \begin{aligned} I(X;Y) &= \sum_{x,y} p(x,y) \log \frac{p(x,y)}{p(x)p(y)} \ &= \sum_{x,y} p(x,y) [-\log p(x) - \log p(y) + \log p(x,y)] \ &= H(X) + H(Y) - H(X,Y) \end{aligned} $$

三种形式等价，在不同计算场景中灵活选用。

微分熵与熵功率（教材定理 2.2.2、式 2.2.24）

问题：设连续随机变量 \(X\) 的方差为 \(\sigma^2\)，证明其微分熵满足 \(h(X) \leq \frac{1}{2}\log(2\pi e\sigma^2)\)，并定义熵功率。

解：

最大熵定理：在给定方差 \(\sigma^2\) 的条件下，正态分布 \(\mathcal{N}(0,\sigma^2)\) 达到最大微分熵： $\(h(X) \leq \frac{1}{2}\log(2\pi e\sigma^2)\)$ 等号当且仅当 \(X \sim \mathcal{N}(0,\sigma^2)\) 时成立。

证明思想：设 \(g(x)\) 为正态分布密度，\(p(x)\) 为任意满足方差约束的密度。由 KL 散度非负： $\(0 \leq D(p \| g) = -h(p) - \int p(x) \log g(x) dx\)$ 代入 \(\log g(x) = -\frac{1}{2}\log(2\pi\sigma^2) - \frac{x^2}{2\sigma^2}\)，化简即得。

熵功率定义： $\(\bar{\sigma}^2 \triangleq \frac{1}{2\pi e} 2^{2h(X)}\)$ 由最大熵定理可知 \(\bar{\sigma}^2 \leq \sigma^2\)，当 \(X\) 服从正态分布时等号成立。熵功率可以理解为"随机变量的有效功率"——在相同熵值下等效的正态分布方差。

题型四：马尔可夫链 + DPI 综合

题目（教材习题 2.23）：二阶二元马尔科夫信源，条件概率 \(p(0|00)=p(1|11)=0.8\)，\(p(0|01)=p(0|10)=p(1|01)=p(1|10)=0.5\)。求熵率 \(H_\infty(X)\)。

解答要点：①将二阶 Markov 转化为一阶状态 Markov（4 个状态：00,01,10,11）②列稳态方程求解：\(\pi(00)=\pi(11)=5/14\)，\(\pi(01)=\pi(10)=1/7\) ③\(H_\infty = \sum_s \pi(s)H(X|S=s)\) ④\(H_\infty = \frac{5}{14}H_2(0.8)+\frac{1}{7}H_2(0.5)+\frac{1}{7}H_2(0.5)+\frac{5}{14}H_2(0.8) \approx 0.802\) bit。

题型五：微分熵与熵功率

题目：设连续随机变量 \(X\) 方差 \(\sigma^2 = 4\)，求最大微分熵和熵功率。

解答要点：①正态分布达到最大微分熵：\(h(X) = \frac12\log_2(2\pi e\sigma^2) = \frac12\log_2(2\pi e \times 4) \approx \frac12 \times 4.094 = 2.047\) bit ②熵功率 \(\bar{\sigma}^2 = \frac{1}{2\pi e}2^{2h(X)} = \sigma^2 = 4\)（正态时熵功率等于实际方差）。

8. 信息论的核心问题（老师课堂总结）

老师在第一节课（03-08）和第二节（03-15）反复强调信息论的三个核心问题：

  1. 无损压缩（信源编码第一定理）：给定一个信源，最少需要多少个比特来存储？（"一本书需要多少比特？"）
  2. 有噪信道传输（信道编码第二定理）：在有噪声的信道上，最大可靠传输速率是多少？（"传这本书需要多少信道容量？"）
  3. 有损压缩（率失真理论）：允许一定失真的前提下，最少需要多少个比特？（"微信发图片，如何用几十 K 传一张基本可辨认的图片？"）

这三个问题都建立在信息度量的基础之上——这就是第一章的全部内容。

9. 信息论的重要理念（课堂散记）

老师关于信息论本质的讨论

信息论是数学课（反复强调）： - "信息论是一门应用数学课，你可以理解成高级概率论" - 不需要通信背景，任何理工科学生都可学 - 与机器学习底层相通："机器学习的底层是统计，信息论的底层也是概率"

香农信息论的 Bug（03-08 和 03-22 都提到）： - 把所有事件的重要性等同对待——猫和狗、正面和反面在香农看来都一样 - 在通信领域没问题（传猫传狗都一样），但在机器学习中有问题（样本重要性不同） - 老师鼓励大家思考："如果你想推翻香农，先把 \(-\log p(x)\) 干掉"

信息论的未解问题： - 信息是否守恒？一条信息可以无限复制扩散，不像物质（守恒）和能量（守恒） - 语义信息如何处理？香农明确说"不考虑语义"，但这在 AI 时代越来越重要
