03 信道容量与信道编码（Channel Capacity & Channel Coding） 🔴 考试核心（~30%）

余官定 | 2026-05-10 ~ 05-24（3 讲） + 05-17 小测 | 考试占比 ~30%

香农第二定理的核心：\(R < C\) 即可实现无差错传输。这是香农 1948 年最惊人的发现——在有噪信道中以正速率实现零差错传输。

1. 知识框架

信道容量解决的核心问题：给定一个有噪声的信道，每次使用最多能可靠传输多少比特信息？

信道模型
 离散无记忆信道 (DMC): (𝒳, p(y|x), 𝒴)
    │
    ├── 无噪信道: C = log|𝒳|
    ├── BSC(f): C = 1 - H₂(f)
    ├── BEC(α): C = 1 - α
    ├── 对称信道: C = log|𝒴| - H(行)
    └── 一般DMC: 迭代算法
    │
    ▼
  信道容量 C = max_{p(x)} I(X;Y)
    │
    ├── 性质: 非负, 连续, 有上界
    ├── 计算: 对称→解析; 一般→BA算法
    └── 级联: C_cascade ≤ min(C₁, C₂)
    │
    ▼
  ┌────────────────────────────────────┐
  │ 香农第二定理 (信道编码定理)    │
  │ 正向: R < C ⇒ ∃码使 P_e → 0    │
  │ 逆向: P_e → 0 ⇒ R ≤ C       │
  │ 证明: 随机编码 + 联合典型译码   │
  └────────────────────────────────────┘
    │
    ▼
  实用意义: 通信系统的速率上限由 C 决定
  工程师目标: 提高 C (改进硬件/调制/编码)

2. 核心概念与定理

2.1 离散无记忆信道 (DMC) 🟡重点

定义

一个 DMC 由三个要素定义： $\(\boxed{(\mathcal{X} , p(y|x), \mathcal{Y})}\)$

  • 输入字母表 \(\mathcal{X}\)：发送方可选的符号
  • 输出字母表 \(\mathcal{Y}\)：接收方观测到的符号
  • 转移概率 \(p(y|x)\)：发送 \(x\) 时收到 \(y\) 的概率。对每个 \(x\)，\(\sum_y p(y|x) = 1\)

无记忆性： $\(p(y^n | x^n) = \prod_{i=1}^n p(y_i | x_i)\)$

课堂比喻："信道就像一条被污染的河流——你放进去清水（\(x\)），流出来的水可能有杂质（\(y\)）。\(p(y|x)\) 描述的就是这个污染过程的特征。"

课堂补充细节：香农的数学建模

香农 1948 年发表《通信的数学理论》，首次为通信建立了严格的数学模型。

历史背景（课堂）： - 1948 年以前通信已是工程现实（电报、电台在二战中广泛使用） - 奈奎斯特采样定理已在 1928 年提出，数字通信已有基础 - 但没有人从数学上理解"信道容量"——大家只知道"怎么传"，不知道"最多能传多少" - 香农的伟大在于：把工程问题转化为数学问题，建立抽象模型

"1948年以前的通信是一个工程，就跟现在做神经网络一样，纯工程没有数学。你只有把工程跟理论完全打通了之后，你的创新才会更大。"

模型的普适性： - 光纤信道 → 转移矩阵接近单位阵 - 无线信道 → BSC 模型或更复杂的衰落信道模型 - 水声信道 → 多径时变信道，但依然可以用概率转移矩阵建模 - 课堂："无论你的信道是什么，这个数学模型好像都能建模它——这就是香农比较厉害的地方。"

DMC 的两大假设： 1. 无记忆：\(p(y^n|x^n) = \prod_i p(y_i|x_i)\) 2. 平稳：不同时刻 \(t\) 的 \(p(y_t|x_t)\) 相同

"真正实际工程问题很复杂。如果你真的把所有东西都考虑进来，你做不出这么简单的一套理论。所以你一定是要做假设、做建模、再推理论。"

与当今 AI 的类比（课堂）： - 现在的机器学习 / 深度学习也处于"工程繁荣、理论匮乏"的阶段 - 就像 1948 年前的通信——大家都在用，但没人建立数学基础 - 课堂："如果你在自己的工程领域想做出一些比较扎实的基础贡献，你要看看你这个领域的数学到底是什么。"

配套练习

  1. 判断以下信道是否满足 DMC 假设： (a) 光纤信道，误码率 \(10^{-12}\)，前后符号独立 (b) WiFi 信道，受突发干扰（一次干扰影响连续多个符号） (c) 打字机信道：按 a 等概率打出 a 或 b，按 b 等概率打出 b 或 c

  2. 给定 DMC 转移矩阵 \(P = \begin{bmatrix}0.9 & 0.1 \\ 0.2 & 0.8\end{bmatrix}\)，输入分布 \(p(X=0)=0.3\)，\(p(X=1)=0.7\)，求输出分布 \(p(Y)\)。

  3. 香农为什么需要"无记忆"假设？这一假设在信道容量的推导中起到了什么关键作用？

答案

  1. (a) 是 DMC（符号独立，可近似无记忆） (b) 不是严格 DMC（突发错误意味着有记忆，前后相关） (c) 是 DMC（每次按键的结果独立于其他次）

  2. \(p(Y=0) = 0.3 \times 0.9 + 0.7 \times 0.2 = 0.27 + 0.14 = 0.41\) \(p(Y=1) = 0.3 \times 0.1 + 0.7 \times 0.8 = 0.03 + 0.56 = 0.59\)

  3. 无记忆性使 \(I(X^n;Y^n) \leq \sum_{i=1}^n I(X_i;Y_i)\)，从而信道容量可以简化为单次使用的 \(C = \max_{p(x)} I(X;Y)\)。否则需要处理无限长的序列相关性，无法得到简洁的理论结果。

易错点
  1. DMC 不等价于"无噪声"：DMC 允许任意噪声，只要是无记忆的
  2. 输入分布是我们可设计的：我们可以选择最优的 \(p(x)\) 来最大化互信息
  3. "离散"的含义：要求 \(\mathcal{X}, \mathcal{Y}\) 是有限集；连续信道先要通过采样和量化离散化

2.2 常见信道模型 🟡重点

三种基本信道

（1）无噪信道

$\(p(y|x) = \begin{cases} 1 & y = x \\ 0 & y \neq x \end{cases}\)$

$\(C = \log |\mathcal{X}|\)$

课堂：光纤信道接近于无噪信道，每次传输可用 4096-QAM（12 bit/use）甚至更高阶调制。

（2）二元对称信道 (BSC)

$\(\mathcal{X} = \mathcal{Y} = \{0,1\}, \quad p(y|x) = \begin{cases} 1-f & y=x \\ f & y \neq x \end{cases}\)$

转移矩阵： $\(P = \begin{bmatrix} 1-f & f \\ f & 1-f \end{bmatrix}\)$

\(f\) 称为交叉概率或错误率。

含义：二元对称信道（BSC）是最简单的有噪声信道模型——每次传输有概率 \(f\) 被翻转，\(1-f\) 概率保持正确。这就像说悄悄话时偶尔被听错一个字：你说"0"对方有 \(f\) 概率听成"1"，说"1"也有同样的概率听成"0"。

关键在于，你不知道哪一次会被翻转——如果是确定性地翻转（比如第 3, 6, 9 位总是错的），你完全可以预先纠正它，信道容量仍然是 1 bit。正是这种不确定性导致了信息损失，使得 BSC 的容量不是 1 bit 而是 \(1-H_2(f)\)。当 \(f=0.5\) 时，输出与输入完全独立，信道完全不传递任何信息（容量为 0）；当 \(f=0\) 时，信道无噪声，容量为 1 bit。BSC 虽然简单，但它作为理解所有有噪信道的基础模型，在通信理论中有着极其重要的地位。

BSC 的对称性带来了一个方便的性质：均匀输入总是最优的，且容量公式非常简洁。更一般地，BSC 是理解"噪声如何消耗信息传输能力"的起点——每次传输时 \(f\) 的概率被翻转，相当于信道在 \(H_2(f)\) 比特的信息上"做了无用功"，剩下的 \(1-H_2(f)\) 才是真正能用来传信息的容量。

BSC 是最简单也是最重要的有噪声信道模型。无线信道常建模为 BSC。

（3）二元删除信道 (BEC)

$\(\mathcal{X} = \{0,1\}, \quad \mathcal{Y} = \{0,1,e\}\)$

$\(p(y|x) = \begin{cases} 1-\alpha & y=x \\ \alpha & y=e \\ 0 & y \neq x,\; y \neq e \end{cases}\)$

\(\alpha\) 为删除概率，输出 \(e\) 表示"不确定是 0 还是 1"。

课堂补充细节：三种信道的直观理解

无噪信道（课堂）： - 水龙头比喻：如果水管完全没有漏水和污染，打开多少水就流出多少水 - 光纤系统：每次传输可传 log2(4096) = 12 比特，因为几乎没有错误 - 但现实中无噪信道很少——即使光纤也有极低误码率

BSC 信道（课堂）： - 模拟无线通信：发 0 有概率 \(f\) 变成 1，发 1 有概率 \(f\) 变成 0 - 课堂："在紫金港校园里，噪声干扰加起来可能是 1%，在玉泉可能是 2%" - 对称性意味着无论发 0 还是 1，错误概率相同

BEC 信道（课堂）： - 模拟数据包传输：要么正确到达，要么完全丢失（删除） - 删除符号 \(e\) 不传递任何信息——接收端知道"这里丢了一个符号" - BEC 的容量公式 \(C = 1 - \alpha\) 比 BSC 更简单，因为删除符号不造成混淆

易错点
  1. BSC 的 \(f > 0.5\) 情况：若 \(f > 0.5\)，只需将输出 0 和 1 互换，等效于 \(1-f\) 的 BSC。因此容量关于 \(f=0.5\) 对称
  2. BEC 的 \(e\) 与 BSC 的不同：BEC 中接收端知道哪些符号被删除了，这比 BSC 的"不知道哪些错了"更容易处理

2.3 信道容量 🔴必考

定义与性质

定义： $\(\boxed{C = \max_{p(x)} I(X;Y)}\)$

其中 \(I(X;Y) = \sum_{x,y} p(x)p(y|x) \log \frac{p(y|x)}{p(y)}\)，\(p(y) = \sum_x p(x)p(y|x)\)。

直觉：\(C\) 是信道在最优输入分布下，每次使用能可靠传输的最大信息量（单位：bit/channel use）。

性质： 1. \(C \geq 0\)（非负性） 2. \(C \leq \min\{\log|\mathcal{X}|, \log|\mathcal{Y}|\}\)（字母表大小的约束） 3. \(C\) 是 \(p(y|x)\) 的连续函数

含义：信道容量 \(C\) 是信道的固有物理属性，就像水管的最大流量或高速公路的最高车流量。一旦信道确定了（即转移概率 \(p(y|x)\) 确定了），\(C\) 就唯一确定——它告诉你"每次使用这个信道最多能可靠传输多少比特信息"。

不管你用多好的编码，实际传输速率不可能超过 \(C\)；但只要你让速率低于 \(C\)，理论上都可以实现无差错传输。\(C\) 就是这条"能力分界线"。需要注意的是，\(C\) 不是实际使用的速率——就像高速公路的容量是 8 车道，但凌晨 3 点可能只有 1 辆车在跑。实际通信中，工程师的目标就是让实际速率尽可能接近 \(C\)。这也是为什么从 2G 到 5G，每一代移动通信都在不断提升信道容量的物理极限。

从数学上看，\(C = \max_{p(x)} I(X;Y)\) 表示我们在最有利的输入分布下能达到的最大互信息。这个定义很深刻：它不仅依赖于信道本身（\(p(y|x)\)），还依赖于我们如何选择输入。如果输入分布选择不当（比如用均匀输入却对应非对称信道），实际可达的互信息就会低于 \(C\)。因此寻找最优输入分布本身就是通信系统设计的重要课题。

课堂补充细节：容量的物理意义

"C 是一个物理量"（课堂重点强调）： - 信道容量是信道的固有物理属性——就像水管的最大流量、高速公路的最高车流量 - 一旦信道的概率转移矩阵 \(p(y|x)\) 确定了，\(C\) 就唯一确定 - 课堂："你只要给出了一个信道，你一定会有个容量。这是一个客观存在的物理量。"

水龙头类比（课堂）： - 宿舍水龙头：容量就是开到最大时每秒流出的水量 - 你开小一点也能用，但那不是容量——容量是最大值 - 同样地，信道容量是"开到最大"（最优输入分布）时能达到的速率

高速公路类比（课堂）： - 沪杭高速双向 8 车道：容量就是 8 辆车并排行驶 - 虽然很多时候只有 2 辆车在跑，但容量仍然是 8 辆车 - 信道也是一样——你实际使用的速率 \(R\) 可以小于 \(C\)，但 \(C\) 是上限

浙大校园网 WiFi 例子（课堂）： - WiFi 容量是固定的（由物理层技术决定） - 大部分人用不到这个容量——看视频只需要几兆每秒 - 但容量不是"你在用的速率"，而是"最多能传的速率" - 5G 号称每秒 1 Gb，6G 目标是 5G 的 10 倍

香农的贡献： - 首次给出 \(C\) 的数学定义 \(C = \max_{p(x)} I(X;Y)\) - 证明 \(R < C\) 就可以实现无差错传输 - 这为所有通信系统设定了不可逾越的上限

易错点
  1. \(C\) 不是实际传输速率：\(C\) 是上限，实际速率 \(R\) 可以小于 \(C\)
  2. \(C\) 的单位是 bit/channel use，不是 bit/s：乘以每秒的使用次数才得到 bit/s
  3. \(C\) 与输入分布 \(p(x)\) 的关系：\(C\) 是在最优 \(p(x)\) 下定义的；如果使用非最优的 \(p(x)\)，\(I(X;Y) < C\)

2.4 BSC 的信道容量 🔴必考

推导与结果

对于交叉概率为 \(f\) 的 BSC： $$\boxed{C = 1 - H_2(f)} $$

其中 \(H_2(f) = -f\log f - (1-f)\log(1-f)\)。

推导： $\(I(X;Y) = H(Y) - H(Y|X)\)$

$\(H(Y|X) = \sum_x p(x) H(Y|X=x) = H_2(f)\)$

（给定 \(X\) 后，\(Y\) 就是个参数为 \(f\) 的二元随机变量，与 \(x\) 无关。）

为使 \(H(Y)\) 最大，取 \(p(x) = 1/2\)（均匀输入），则 \(p(y) = 1/2\)，\(H(Y) = 1\)。

故 \(C = 1 - H_2(f)\)。

数值示例：

\(f\) \(H_2(f)\) \(C\) (bit/use) 含义
0 0 1 无差错，完美信道
0.1 0.469 0.531 轻度噪声
0.25 0.811 0.189 重度噪声
0.5 1 0 完全随机，信道无用
课堂补充细节：BSC 容量的逐步推导

第一步：写出互信息 $\(I(X;Y) = H(Y) - H(Y|X)\)$

第二步：分析条件熵 \(H(Y|X)\) - 给定 \(X\) 后，\(Y\) 是一个二元随机变量 - \(p(Y \neq X | X) = f\)，\(p(Y = X | X) = 1-f\) - 因此 \(H(Y|X=x) = H_2(f)\) 与 \(x\) 无关 - \(H(Y|X) = \sum_x p(x) H_2(f) = H_2(f)\)

关键点：\(H(Y|X)\) 与输入分布 \(p(x)\) 无关！

第三步：最大化 \(H(Y)\) - 既然 \(H(Y|X)\) 固定，最大化 \(I(X;Y)\) 等价于最大化 \(H(Y)\) - \(H(Y)\) 最大为 1 bit（二元随机变量的最大熵） - 取等条件：\(p(Y=0) = p(Y=1) = 1/2\) - 当输入均匀时：\(p(Y=0) = 0.5(1-f) + 0.5f = 0.5\)，\(p(Y=1) = 0.5\) - 因此均匀输入 \(p(X=0) = p(X=1) = 0.5\) 达到最优

课堂推导关键：\(\max_{p(x)} I(X;Y) = \max_{p(x)} [H(Y) - H(Y|X)] = 1 - H_2(f)\)

第四步：得到容量 $\(C = 1 - H_2(f)\)$

物理意义（课堂）： - 当 \(f=0\) 时，\(C=1\)：每次传输完美传递 1 bit - 当 \(f=0.1\) 时，\(C=0.531\)：噪声消耗了近一半的信息传输能力 - 当 \(f=0.5\) 时，\(C=0\)：输出完全随机，与输入无关，信道完全无用

课堂："这个 \(C\) 告诉你，不管你怎么编解码，每次最多只能传 \(1-H_2(f)\) 比特的信息。这就是物理极限。"

配套练习
  1. BSC 信道 \(f=0.01\)，求 \(C\)。
  2. BSC 信道 \(f=0.8\)，求 \(C\)。提示：考虑对称性。
  3. 证明：BSC 的容量关于 \(f=0.5\) 对称，即 \(C(f) = C(1-f)\)。
  4. 为什么 \(f=0.5\) 时 BSC 的容量为 0？从互信息的角度解释。
答案

  1. \(H_2(0.01) = -0.01\log_2 0.01 - 0.99\log_2 0.99 \approx -0.01(-6.644) - 0.99(-0.0145) = 0.0664 + 0.0144 = 0.0808\) \(C = 1 - 0.0808 = 0.9192\) bit/use

  2. \(f=0.8\) 与 \(f=0.2\) 对称。\(H_2(0.8) = H_2(0.2) = 0.722\)，\(C = 1 - 0.722 = 0.278\) bit/use。 实际操作：将输出 0 和 1 互换即可。

  3. \(H_2(f) = H_2(1-f)\) 因为二元熵函数关于 \(p=0.5\) 对称，所以 \(C(f) = C(1-f)\)。

  4. \(f=0.5\) 时，\(p(Y|X=0) = (0.5, 0.5)\)，\(p(Y|X=1) = (0.5, 0.5)\)。输出分布与输入完全独立， \(I(X;Y) = 0\)。信道不能传递任何信息。

易错点
  1. 忘记 \(\log\) 底数：若无特别说明，\(\log\) 以 2 为底，容量单位为 bit
  2. 混淆 \(f\) 和 \(1-f\)：\(f\) 是交叉概率（错误概率），不是正确概率
  3. 误以为均匀输入总是最优：只有 BSC、BEC、对称信道等特殊信道均匀输入最优；一般信道不一定
  4. \(f=0.5\) 时容量为 0 的误解：不是说"传不过去任何东西"，而是说"每个符号传 0 bit 信息"——即使用无数次信道，信息总量为 0

2.5 BEC 的信道容量 🟡重点

公式

$$\boxed{C = 1 - \alpha} $$

\(\alpha\) 为删除概率。直观理解：均匀输入下，\(1-\alpha\) 比例的符号被正确接收，每个正确接收的符号携带恰好 1 bit 信息。

含义：二元删除信道（BEC）是另一个重要的基本模型——它模拟的是数据包传输的场景：要么正确到达，要么完全丢失（被"删除"），但不会搞错。接收端收到删除符号 \(e\) 时，清楚地知道"这里有一个符号丢了"，而不是把 0 误认为 1 或反之。

这看似只是一个小区别，却导致 BEC 的容量 \(1-\alpha\) 远大于同等错误概率的 BSC 的容量 \(1-H_2(\alpha)\)。例如当 \(\alpha=0.3\) 时，BEC 容量仍有 0.7 bit/use，而 BSC 只有 0.119 bit/use。原因在于 BEC 不会产生"混淆"——接收端知道哪些符号是可靠的、哪些是需要猜测的，这种"知道不知道"本身就是一种宝贵的信息。

BEC 的容量推导也展示了互信息计算的灵活性：\(I(X;Y) = H(X) - H(X|Y)\) 有时比 \(I(X;Y) = H(Y) - H(Y|X)\) 更容易。在 BEC 中，给定 \(Y\) 后 \(X\) 要么完全确定（收到 0 或 1），要么完全不确定（收到 \(e\)），这使得 \(H(X|Y) = \alpha H(X)\) 的计算几乎是一步到位。

课堂补充细节：BEC 容量为什么是 \(1-\alpha\)

推导（课堂）： - 输入 \(X \in \{0,1\}\)，输出 \(Y \in \{0,1,e\}\) - 互信息：\(I(X;Y) = H(X) - H(X|Y)\) - 给定 \(Y\) 后，\(X\) 的不确定性： * 若 \(Y=0\) 或 \(Y=1\)：\(X\) 确定（概率 \(1-\alpha\)），\(H(X|Y)=0\) * 若 \(Y=e\)：\(X\) 完全不确定（概率 \(\alpha\)），\(H(X|Y)=H(X)\) - 因此 \(H(X|Y) = \alpha H(X)\) - \(I(X;Y) = H(X) - \alpha H(X) = (1-\alpha)H(X)\) - 最大化 \(H(X)\) 得 \(C = 1-\alpha\)（bit/use）

与 BSC 的对比： - BEC 的容量公式比 BSC 简单得多 - 原因：BEC 中接收端知道哪些符号被删除了（\(e\)），不会把 0 误认为 1 - BSC 中接收端不知道哪些符号错了，混淆更严重 - 同样的错误概率 \(f=\alpha\)，BEC 的容量 \(1-\alpha\) 大于 BSC 的 \(1-H_2(\alpha)\)

配套练习
  1. BEC 删除概率 \(\alpha = 0.3\)，求 \(C\)。
  2. 对比：BSC(\(f=0.3\)) 和 BEC(\(\alpha=0.3\)) 的容量，哪个更大？为什么？
  3. 证明：对于任意 \(0<\alpha<1\)，\(1-\alpha > 1-H_2(\alpha)\)。
答案

  1. \(C = 1 - 0.3 = 0.7\) bit/use

  2. BSC(0.3)：\(C = 1 - H_2(0.3) = 1 - 0.881 = 0.119\) bit/use BEC(0.3)：\(C = 1 - 0.3 = 0.7\) bit/use BEC 远大于 BSC。因为 BEC 的删除符号 \(e\) 让接收端知道"这里不确定"， 不会造成 0 和 1 之间的混淆。而 BSC 中接收端不知道哪些符号错了。

  3. 当 \(0<\alpha<1\) 时，\(H_2(\alpha) > \alpha\)（二元熵函数在 \(0<p<1\) 时大于直线 \(y=p\)）， 所以 \(1-\alpha > 1-H_2(\alpha)\)。

易错点
  1. BEC 的 \(e\) 与 BSC 的误码不同：\(e\) 不造成 0-1 混淆，BEC 本质上比 BSC"更友好"
  2. 删除概率不是误码率：\(\alpha=0.5\) 时 BEC 仍有 \(C=0.5\)，而 BSC(\(f=0.5\)) 容量为 0

2.6 对称信道的容量 🔴必考

计算公式

若信道转移矩阵的每一行是其他行的排列，且每一列是其他列的排列，则均匀输入分布达到容量： $\(\boxed{C = \log|\mathcal{Y} | - H(\text{转移矩阵任意一行})}\)$

其中 \(H(\text{行})\) 是转移矩阵任一行作为概率分布计算的熵。

含义：对称信道的好处在于——均匀输入就是最优，不需要费心寻找最佳的输入分布。对称信道的每一行（给定输入时的输出分布）都是相同的排列，所以无论发哪个符号，噪声对它的"影响模式"是一样的。这就好比无论你把硬币丢进哪条下水道，水流对硬币的冲撞方式都是相同的。

对于这样的信道，最合理的策略就是平等使用每个输入符号，这导出了一个简洁的容量公式：\(C = \log|\mathcal{Y}| - H(\text{行})\)，即输出端的最大熵减去条件熵。很多实际通信信道（如 BPSK、QPSK、QAM 调制下的 AWGN 信道）都满足对称性，因此这个公式有着非常广泛的应用。

对称信道还有一个更广义的版本——准对称信道，它不要求完整的行排列和列排列，只要求可以将输出集合划分为若干列对称的子集。BEC 就是准对称信道的典型例子（输出集 \(\{0,1,e\}\) 可划分为 \(\{0,1\}\) 和 \(\{e\}\) 两组）。准对称信道的均匀输入仍然是最优的，这大大扩展了对称性理论的应用范围。

教材补充：对称信道的均匀输入最优性可以通过互信息的凸性和对称性严格证明（教材 §4.2.3）。

课堂补充细节：对称信道的分类与判定

行对称（输入对称）（课堂定义）： - 每一行是第一行的某个排列 - 例：\(P = \begin{bmatrix}0.2&0.3&0.1&0.4\\0.3&0.2&0.4&0.1\end{bmatrix}\)，第二行是第一行的置换 - 仅行对称时，均匀输入使 \(H(Y|X)\) 固定，但 \(H(Y)\) 不一定最大

列对称（输出对称）（课堂定义）： - 每一列是第一列的某个排列

全对称信道： - 同时满足行对称和列对称 - 此时均匀输入使输出也均匀，\(H(Y) = \log|\mathcal{Y}|\) - 容量公式：\(C = \log|\mathcal{Y}| - H(\text{行})\)

准对称信道（课堂定义）： - 不是全对称，但可以将输出集合划分为若干子集，每个子集内是列对称的 - 例：\(P = \begin{bmatrix}0.2&0.3&0.2&0.3\\0.3&0.2&0.3&0.2\end{bmatrix}\)：将第 1、3 列分为一组，第 2、4 列分为另一组 - BEC 是准对称信道：把输出分为 \(\{0,1\}\) 和 \(\{e\}\) 两组 - 准对称信道的均匀输入仍达到容量（重要结论）

课堂："不要以为对称信道很少——在实际通信中，很多信道都是对称或准对称的。BPSK、QPSK、64-QAM 的误码模型都是对称信道。"

K 元对称信道（课堂）： - 输入 \(|\mathcal{X}| = K\)，输出 \(|\mathcal{Y}| = K\) - 对角线元素：\(1-P\)，非对角线元素：\(P/(K-1)\) - 容量公式：\(C = \log K - H_2(P) - P\log(K-1)\) - QPSK：\(K=4\)，64-QAM：\(K=64\)

配套练习

  1. 判断以下信道是否为对称信道、准对称信道、或非对称信道： (a) \(P = \begin{bmatrix}0.5&0.3&0.2\\0.2&0.5&0.3\\0.3&0.2&0.5\end{bmatrix}\) (b) \(P = \begin{bmatrix}0.8&0.1&0.1\\0.1&0.8&0.1\\0.1&0.1&0.8\end{bmatrix}\) (c) Z 信道：\(P = \begin{bmatrix}1 & 0\\ P & 1-P\end{bmatrix}\)

  2. 对于 K 元对称信道，证明 \(C = \log K - H_2(P) - P\log(K-1)\)。

答案

  1. (a) 行和列都是排列关系 → 对称信道 (b) 行是排列关系（每行都是 \((0.8,0.1,0.1)\) 的排列），但列不是 → 准对称信道 (c) Z 信道既不是行对称也不是列对称 → 非对称信道

  2. 均匀输入时，\(H(Y) = \log K\)（输出均匀）。 \(H(Y|X) = -[(1-P)\log(1-P) + (K-1)\cdot\frac{P}{K-1}\log\frac{P}{K-1}]\) \(= -[(1-P)\log(1-P) + P\log P - P\log(K-1)]\) \(= H_2(P) + P\log(K-1)\) \(C = \log K - H_2(P) - P\log(K-1)\)

易错点
  1. 行对称 ≠ 对称信道：必须同时行对称和列对称才是全对称信道
  2. 准对称信道的均匀输入最优性：虽然不满足列对称，但均匀输入仍然可以达到容量
  3. 全对称信道的容量公式简化：当 \(|\mathcal{X}| = |\mathcal{Y}|\) 且信道对称时，\(C = \log|\mathcal{Y}| - H(\text{行})\)

2.7 一般 DMC 容量的迭代计算（教材 §4.2.5） 🟡重点

对于非对称的一般 DMC，可用 Blahut-Arimoto 算法迭代求解。算法交替更新输入分布 \(p(x)\) 和条件分布 \(r(x|y)\)：

  1. 初始化 \(p^{(0)}(x)\)（通常取均匀分布）
  2. 更新 \(r^{(k)}(x|y) = \frac{p^{(k)}(x)p(y|x)}{\sum_x p^{(k)}(x)p(y|x)}\)
  3. 更新 \(p^{(k+1)}(x) = \frac{\exp\left(\sum_y p(y|x)\log r^{(k)}(x|y)\right)}{\sum_x \exp\left(\sum_y p(y|x)\log r^{(k)}(x|y)\right)}\)
  4. 重复直到 \(C^{(k)} = \sum_{x,y} p^{(k)}(x)p(y|x)\log\frac{r^{(k)}(x|y)}{p^{(k)}(x)}\) 收敛
课堂补充细节：容量计算定理与 KKT 条件

凸优化视角（课堂第二讲）： - 信道容量计算本质上是一个凸优化问题 - \(I(X;Y)\) 是输入分布 \(p(x)\) 的凹函数（第一章已证明） - 可行域 \(\{p(x): p(x) \geq 0, \sum p(x) = 1\}\) 是凸集 - 因此在凸集上最大化凹函数，有唯一最大值

KKT 条件推导：

最大化 \(I(X;Y)\)，约束 \(\sum_x p(x) = 1\)。构造 Lagrange 函数： $\(J(p) = I(X;Y) - \lambda \sum_x p(x)\)$

对 \(p(x)\) 求偏导并令为 0，得： $\(I(X=x;Y) = \lambda + 1 \triangleq C\)$

即：达到容量时，每个被使用的输入符号 \(x\) 提供的互信息 \(I(X=x;Y)\) 都等于 \(C\)。

容量计算定理（课堂）： 输入分布 \(p^*(x)\) 达到信道容量 \(C\) 的充要条件是： - 若 \(p^*(x) > 0\)，则 \(I(X=x;Y) = C\) - 若 \(p^*(x) = 0\)，则 \(I(X=x;Y) \leq C\)

课堂："这个定理把搜索最优 \(p(x)\) 的问题变成了求解方程组的问题。如果所有符号都被使用，那就是 \(K\) 个方程 \(K\) 个未知数——线性方程组就搞定了。"

Z 信道例子（课堂）： $\(P = \begin{bmatrix}1 & 0 \\ P & 1-P\end{bmatrix}\)$

即发 0 一定收 0，发 1 有概率 \(P\) 收 0、\(1-P\) 收 1。 容量为 \(C = \log(1 + 2^{-H_2(P)/(1-P)})\)，最优输入分布非均匀。

课堂："一个最简单的 \(2\times 2\) 的非对称信道，它的容量已经这么复杂了。所以一般信道没有解析解，只能用迭代算法。"

配套练习
  1. 给定信道 \(P = \begin{bmatrix}0.6 & 0.4 \\ 0.4 & 0.6\end{bmatrix}\)，这是什么信道？容量是多少？
  2. Z 信道：\(P = \begin{bmatrix}1 & 0 \\ 0.3 & 0.7\end{bmatrix}\)，\(P=0.3\)，近似计算容量。
答案
  1. 这是 BSC(\(f=0.4\))，是对称信道。\(C = 1 - H_2(0.4) = 1 - 0.971 = 0.029\) bit/use（接近无用信道）。
  2. Z 信道 \(P=0.3\)：\(H_2(0.3) = 0.881\)，\(1-P = 0.7\)， \(C = \log_2(1 + 2^{-0.881/0.7}) = \log_2(1 + 2^{-1.259}) = \log_2(1 + 0.418) = \log_2(1.418) \approx 0.504\) bit/use

2.8 信道组合 🟢了解

三种组合方式

（1）积信道（平行组合）：\(N\) 个独立信道并联使用，总容量为各信道容量之和： $\(C_{\text{总和}} = \sum_{i=1}^N C_i\)$

（2）和信道：每次从多个信道中选择一个使用，总容量为： $\(C = \log\left(\sum_{i=1}^N 2^{C_i}\right)\)$

（3）级联信道：信道串联，由 DPI 保证： $\(C_{\text{cascade}} \leq \min\{C_1, C_2\}\)$

含义：信道组合研究的是如何将多个信道拼接使用来提升总容量。积信道（平行组合）是最直观的方式——同时使用 \(N\) 个独立信道，总容量是各信道容量之和。这就是 MIMO（多天线）系统为什么能提升容量：每对天线构成一个平行子信道，同时传输互不干扰。

和信道则有更微妙的性质：每次从多个信道中选择一个使用，选择这个动作本身也在传递信息。更惊人的是，两个容量为 0 的无用信道（如 BSC \(f=0.5\)）组合成和信道后，容量竟然变成了 1 bit/use——因为你可以通过"选哪个信道"来传递信息。这就是 FDMA/TDMA 的理论基础：通过分配不同的时频资源，多个用户可以共享信道而不互相干扰。

级联信道是最受限制的组合方式——它串联信道而非并联。由数据处理不等式，信息经过多段处理后只会减少不会增加，因此级联信道容量受限于最窄的那一段。这个结论对通信系统的设计有直接指导意义：在长距离通信中必须在适当位置放置中继器来"打断"级联效应，否则噪声会不断累积。

课堂补充细节：和信道的奇妙性质

两个无用信道组成有用信道（课堂）： - 考虑两个容量为 0 的信道（BSC(\(f=0.5\))） - 单独使用：\(C_1 = C_2 = 0\) - 和信道：\(C = \log(2^{C_1} + 2^{C_2}) = \log(1 + 1) = 1\) bit/use！

课堂："两个容量为 0 的信道，组合起来竟然有 1 bit 的容量！这是因为你可以通过选择用哪个信道来传递信息。"

物理意义： - 和信道的"选择"本身携带信息（\(\log N\) bit） - 这就是频分多址（FDMA）/时分多址（TDMA）的理论基础 - 4G/5G 中每个用户分配不同的时频资源，本质上是和信道

平行组合的现代应用（课堂）： - MIMO（多天线）系统：每个天线对是一个平行信道 - 课堂："为什么增加天线能提高系统容量？因为你在用积信道——每对天线独立传信息。" - OFDM：将宽带信道划分为多个平行窄带子信道，每个子信道独立传输

易错点
  1. 和信道 vs 积信道：和信道是"选一个用"，积信道是"同时用"
  2. 级联信道的 \(\leq\) 不是 \(=\)：通常 \(C_{\text{cascade}} < \min\{C_1,C_2\}\)，除非信道无噪声
  3. 和信道公式的对数以 2 为底：\(C = \log_2(\sum 2^{C_i})\)，其中 \(C_i\) 单位是 bit

2.9 级联信道 🟡重点

定义与结论

两个信道 \(P_1(y|x)\) 和 \(P_2(z|y)\) 串联： $\(X \rightarrow \boxed{P_1} \rightarrow Y \rightarrow \boxed{P_2} \rightarrow Z\)$

由数据处理不等式： $\(I(X;Z) \leq \min\{I(X;Y), I(Y;Z)\}\)$

因此级联信道容量： $\(\boxed{C_{\text{cascade} } \leq \min\{C_1, C_2\}}\)$

"卡脖子的永远是最慢的那一段——\(C \leq \min(C_1, C_2)\)。"

含义：级联信道体现了通信系统中一个朴素的道理——数据经过多段信道传输，最窄的那段决定了整体容量。就像一段由粗细不同的水管串联而成的管道，最细的那段卡住了整个系统的流速，即使其他段再粗也无济于事。

由数据处理不等式，级联信道的容量满足 \(C_{\text{cascade}} \leq \min\{C_1, C_2\}\)。这解释了为什么中继器（repeater）在长距离通信中必不可少——信号每经过一段信道就会引入噪声，如果放任噪声积累（如多级 BSC 级联），等效错误概率会趋近 \(1/2\)，容量趋近 0。中继器的作用就是"打断"级联，在收到信号后先译码再重新发送，从而避免噪声的累积效应。

对于 BSC 的级联，有一个有趣的数学性质：\(k\) 级级联后的等效交叉概率为 \(f_k = \frac12 - \frac12(1-2f)^k\)。当 \(k \to \infty\) 时，只要 \(f \neq 0,1\)，\(f_k\) 一定收敛到 \(1/2\)。这告诉我们一个深刻的道理：即使每一级的噪声都很小，经过足够多级的积累，信道最终一定会变得完全无用。通信系统必须避免"级联过多"——这就是为什么互联网使用分组交换和逐跳确认，而不是让信号经过几百个节点而不做任何处理。

课堂补充细节：瓶颈解释与详细推导

"卡脖子"的物理直觉（课堂）： - 两个水管串联：水流速度由最细的那段决定 - 高速公路：如果杭州到上海 8 车道，上海到南京 4 车道，瓶颈在 4 车道那一段 - 通信系统：中继网络的总吞吐量由容量最小的那段链路决定 - 课堂："卡脖子的永远是最慢的那一段——\(C \leq \min(C_1, C_2)\)。"

BSC 级联的详细推导（课堂第二讲）：

两个 BSC(\(P\)) 和 BSC(\(Q\)) 级联： - 等效交叉概率：\(f_{\text{eq}} = P(1-Q) + (1-P)Q\) - 若 \(P=Q=f\)：\(f_{\text{eq}} = 2f(1-f)\) - 一般 \(k\) 级级联公式：\(f_k = \frac12 - \frac12(1-2f)^k\)

性质： - 当 \(k \to \infty\)：\(f_k \to 1/2\)（只要 \(f \neq 0,1\)） - 即无限级联 BSC 趋近于无用信道（\(C \to 0\)） - 课堂："信号经过的级数越多，噪声积累越大，容量越小。"

一般信道的级联： - 不是任何信道级联都保持同类型 - 但 DPI 始终保证 \(C_{\text{cascade}} \leq \min(C_1, C_2)\) - 这是通信系统设计中继器必须放大/再生信号的原因

2.10 香农第二定理：信道编码定理 🔴必考

问题设置
  • 消息集：\(\{1, \ldots, 2^{nR}\}\)
  • 编码器：\(f_n: \{1, \ldots, 2^{nR}\} \to \mathcal{X}^n\)（称为 \((2^{nR}, n)\) 码）
  • 译码器：\(g_n: \mathcal{Y}^n \to \{1, \ldots, 2^{nR}\}\)

错误概率（最大错误概率）： $\(\lambda^{(n)} = \max_{m} P(g_n(Y^n) \neq m \mid X^n = f_n(m))\)$

码率 \(R\) 可达到：若存在一列 \((2^{nR}, n)\) 码使得 \(\lambda^{(n)} \to 0\)。

定理陈述

$\(\boxed{C = \max_{p(x)} I(X;Y)}\)$

正向（可达到性）：对任意 \(R < C\)，存在一列 \((2^{nR}, n)\) 码使得 \(\lambda^{(n)} \to 0\)。

逆向（逆定理）：若 \(\lambda^{(n)} \to 0\)，则 \(R \leq C\)。

含义：香农第二定理是整个信息论最惊人的发现——它改变了通信工程师的世界观。在香农之前，大家都以为噪声必然导致错误，要提高可靠性就得降低速率，但没有谁知道极限在哪里。香农证明了：只要 \(R < C\)，零差错是可能的！

这个定理把通信问题分成两个世界：\(R < C\) 的世界里，错误概率可以任意小（通过增加码长 \(n\)）；\(R > C\) 的世界里，无论你怎么编解码，错误概率都不可能趋于零。\(C\) 就是这两个世界的分界线。更令人惊叹的是，香农只证明了好码的存在性但没有给出具体编码——他告诉工程师们"好码一定存在"，然后留下了整整 70 年寻找好码的历史（Turbo 码、LDPC 码、Polar 码）。

结合香农第一定理和香农第二定理，我们可以得到一个关于整个通信系统的完整图景：信源压缩到 \(H(X)\) 以下，信道编码到 \(C\) 以下，只要 \(H(X) < R < C\)，就能实现高效且可靠的通信。这套"分离定理"（Separate Source-Channel Coding Theorem）告诉我们，信源编码和信道编码可以独立设计而不损失最优性——这是一个极其强大的工程方法论。

课堂补充细节：随机编码的直观解释

球的比喻（课堂第三讲）： - 发送一个码字 \(x^n\)，经过有噪信道后，接收到的 \(y^n\) 不确定在一个"球"内 - 球的大小由 \(2^{nH(Y|X)}\) 决定（条件熵决定不确定性范围） - 所有可能的 \(y^n\) 总数为 \(2^{nH(Y)}\) - 所以最多可以有 \(\frac{2^{nH(Y)}}{2^{nH(Y|X)}} = 2^{nI(X;Y)}\) 个不相交的球

课堂："如果你发的码字超过 \(2^{nI(X;Y)}\) 个，这些球一定会相交——一码就无法区分了。\(R\) 必须小于 \(I(X;Y)\)。"

为什么随机编码有效（课堂重点）： - 我们按 \(p(x)\) 随机生成了一个巨大的码本 - 计算这个随机码本的平均错误概率 - 如果平均错误概率 \(\to 0\)，则至少存在一个好码 - 课堂："如果所有码都很差，期望不可能为零。所以至少存在一个码满足要求。"

与信源编码定理的对比： - 信源编码（第一定理）：平均码长 \(\geq H\)，存在编码达到 \(H\) - 信道编码（第二定理）：传输速率 \(\leq C\)，存在编码达到 \(C\) - 两者结合：\(H < R < C\) 即可实现有效且可靠的通信 - 课堂："\(H_\infty\) 要小于 \(R\) 小于 \(C\)，这串不等式解决了一个传输的整体问题。"

香农的遗产（课堂）： - 香农证明了存在性，但没有给出具体编码方法 - 后续 70 年：Turbo 码（1993）、LDPC 码（1960/1996）、Polar 码（2009） - 现在 Polar 码已逼近香农极限（差 0.001 dB 以内） - 课堂："这就是为什么 5G 和 6G 的物理层差不多——已经逼近极限了，再提升没有意义。"

含义：随机编码的论证非常巧妙——它不告诉你具体用什么码，只证明好码必然存在。想象你随机生成了大量码字构成一个巨大的码本，然后计算这个随机码本在所有可能的噪声情况下的平均错误概率。如果这个平均值趋近于零，那么必然至少有一个码本是好的。

这就像在一大堆随机生成的钥匙中，只要平均开锁成功率很高，就一定能找到一把能开锁的钥匙。联合典型译码的核心思想则是：接收到的 \(y^n\) 和真正的码字大概率是"联合典型"的（即它们符合信道的统计规律），而和错误的码字几乎不可能是联合典型的。这个论证的精妙之处在于它绕开了"如何构造好码"这一困难问题，从概率角度巧妙地证明了存在性。

联合典型译码的关键性质是：独立产生的两个序列是联合典型的概率随 \(n\) 指数衰减（\(2^{-n(I(X;Y)-3\epsilon)}\)）。这意味着只要 \(R < I(X;Y)\)，错误码字引起的"假阳性"概率就会随着 \(n\) 增长以指数速度趋近于零。随机编码加联合典型译码构成了香农第二定理证明的两大支柱——一个处理"存在性"，一个处理"可区分性"。

课堂补充细节：联合典型译码的严格证明

联合典型集定义： $\(A_\epsilon^{(n)} = \left\{(x^n, y^n): \left|-\frac{1}{n}\log p(x^n) - H(X)\right| < \epsilon, \left|-\frac{1}{n}\log p(y^n) - H(Y)\right| < \epsilon, \left|-\frac{1}{n}\log p(x^n, y^n) - H(X,Y)\right| < \epsilon \right\}\)$

联合典型集的性质： 1. 若 \((X^n, Y^n) \sim p(x^n, y^n)\)（联合分布），则 \(P((X^n, Y^n) \in A_\epsilon^{(n)}) \to 1\) 2. \(|A_\epsilon^{(n)}| \leq 2^{n(H(X,Y) + \epsilon)}\) 3. 若 \(\tilde{X}^n \sim p(x^n)\) 和 \(\tilde{Y}^n \sim p(y^n)\) 独立，则： $\(P((\tilde{X}^n, \tilde{Y}^n) \in A_\epsilon^{(n)}) \leq 2^{-n(I(X;Y) - 3\epsilon)}\)$

第三条是关键：独立产生的两个序列是联合典型的概率随 \(n\) 指数衰减。

译码规则：找到唯一的 \(m\) 使得 \((x^n(m), y^n) \in A_\epsilon^{(n)}\)。

错误分析： - 错误事件 \(E_1\)：发送的码字与接收不联合典型（由性质 1，概率 \(\to 0\)） - 错误事件 \(E_2\)：存在 \(m' \neq m\)，\((x^n(m'), y^n) \in A_\epsilon^{(n)}\) - 由性质 3：\(P(E_2) \leq 2^{nR} \cdot 2^{-n(I(X;Y) - 3\epsilon)} = 2^{-n(I(X;Y) - R - 3\epsilon)}\) - 若 \(R < I(X;Y)\)，则 \(P(E_2) \to 0\)

结论：当 \(n \to \infty\) 时，错误概率 \(\to 0\)。

课堂补充细节：逆定理的 Fano 不等式证明

逆定理思路（课堂第三讲）： - 假设存在码使 \(P_e^{(n)} \to 0\)，证明 \(R \leq C\) - 核心工具：Fano 不等式 - 由 Fano 不等式：\(H(W|\hat{W}) \leq 1 + P_e^{(n)} \log(M-1) \leq 1 + nR P_e^{(n)}\) - 数据链路：\(W \to X^n \to Y^n \to \hat{W}\)，由 DPI：\(I(W;\hat{W}) \leq I(X^n;Y^n) \leq nC\) - 因此 \(nR = H(W) = I(W;\hat{W}) + H(W|\hat{W}) \leq nC + 1 + nR P_e^{(n)}\) - 整理：\(R(1 - P_e^{(n)}) \leq C + \frac{1}{n}\) - 若 \(P_e^{(n)} \to 0\)，取 \(n \to \infty\) 得 \(R \leq C\)

含义：逆定理的证明用到两个核心工具——Fano 不等式和数据处理不等式。Fano 不等式说的是：如果你从接收信号 \(Y\) 估计发送消息 \(W\)，估计的错误概率 \(P_e\) 越大，则 \(W\) 在给定 \(Y\) 后的不确定性 \(H(W|Y)\) 也越大；极端情况下，如果 \(P_e=0\)，则 \(H(W|Y)=0\)，即 \(Y\) 完全决定了 \(W\)。

结合数据处理不等式（处理后的信息不会增加），可以推出一个重要的不等式链：\(nR = H(W) \leq nC + 1 + nR P_e^{(n)}\)。如果 \(P_e^{(n)} \to 0\)，取极限就得 \(R \leq C\)。这个证明的简洁性体现了信息论中"不等式工具"的强大——仅用两个基本不等式就完成了逆定理的严格证明。

Fano 不等式本身也有独立的工程意义：它给出了错误概率的下界。即使你不知道具体的编码方案，只要知道信道容量 \(C\) 和传输速率 \(R\)，Fano 不等式就可以告诉你"错误概率至少有多大"。这在系统设计中非常有用——在开始设计编码之前，就可以评估"有没有可能达到目标误码率"。

课堂："逆定理的证明比正定理简单多了——Fano 不等式加数据处理不等式，几步就推出来了。"

\(R=C\) 的情况： - 严格来说，香农定理只保证了 \(R < C\) 的可达性 - \(R = C\) 时需要无限长编码（\(n \to \infty\)） - 实践中总是取 \(R\) 略小于 \(C\)

配套练习
  1. 某信道的容量 \(C = 1\) bit/use，信源速率 \(R = 0.8\) bit/use。能否实现可靠通信？
  2. 某信道的容量 \(C = 0.3\) bit/use，信源速率 \(R = 0.4\) bit/use。能否实现可靠通信？
  3. 为什么香农定理只保证存在性，不给出具体编码方法？
答案
  1. \(R = 0.8 < 1 = C\)，由香农第二定理正向，存在编码使 \(P_e \to 0\)，可达。
  2. \(R = 0.4 > 0.3 = C\)，由逆定理，\(P_e \not\to 0\)，不可达。
  3. 香农的证明使用随机编码和期望论证：证明平均错误概率 \(\to 0\)，从而存在好码。 但随机码本需要 \(n \to \infty\)，且编码/译码复杂度指数增长，不实用。 后续研究者（Turbo、LDPC、Polar）才给出了实际可行的编解码方案。
易错点
  1. "无差错"不是 100% 无差错：香农定理保证 \(P_e \to 0\) 当 \(n \to \infty\)，不是对有限 \(n\) 的保证
  2. \(R < C\) 是充分必要条件：正向 \(R < C \Rightarrow\) 可达，逆向 \(P_e \to 0 \Rightarrow R \leq C\)
  3. 存在性 ≠ 构造性：定理说存在好码，但没告诉你具体是哪个码
  4. 随机编码不是实际编码方案：随机编码是证明工具，实际中没人用随机码本

2.11 加性高斯白噪声信道容量（教材 §4.5） 🟢了解

含义：加性高斯白噪声（AWGN）信道是最重要的连续信道模型——它描述的是信号在传输过程中叠加了高斯噪声的情况。其容量公式 \(C = \frac{1}{2}\log(1 + \text{SNR})\) 是通信工程中最著名的公式之一，它告诉你信噪比每增加 3 dB，容量大约增加 1 bit/use。这就是为什么工程师们不断追求更高的发射功率和更低的噪声。

灌水法（Water-filling）解决的是平行高斯信道的功率分配问题：你有多个子信道（如多个频率子带），每个子信道的噪声不同，总功率有限。最优策略是向"噪声低的地方多注水"——即噪声小的子信道分配更多功率，噪声大的子信道分配更少甚至不分配。这就像在一个底部不平的容器中倒水——水会自动填满低洼处（噪声小的信道），而高地（噪声大的信道）可能露在水面上。4G/5G 的 OFDM 系统中就使用了类似的原理。

AWGN 信道的容量公式还有一个更深层的意义：它是香农第二定理在连续情况下的体现。在连续信道中，由于输入是连续值（而非离散符号），"码字"的概念被替换为"波形"，但核心结论不变——只要传输速率低于容量，就可以实现任意小的错误概率。现代通信系统（从 4G 到 WiFi 到卫星通信）的设计都是以这个公式为理论基础的。

连续 AWGN 信道（教材 §4.5.1）： $\(Y = X + Z, \quad Z \sim \mathcal{N}(0, N_0/2)\)$

功率约束 \(E[X^2] \leq P\) 下的容量： $\(C = \frac{1}{2} \log_2\left(1 + \frac{P}{\sigma^2}\right) \quad \text{bit/channel use}\)$

推广至平行高斯信道（教材 §4.5.4~4.5.5）：

\(k\) 个平行独立高斯子信道，总功率 \(P\)，各子信道噪声功率 \(\sigma_i^2\)，用灌水（water-filling）法分配功率： $\(P_i = \left(\nu - \sigma_i^2\right)^+\)$ 其中 \(\nu\) 由 \(\sum_i P_i = P\) 确定。总容量为： $\(C = \sum_{i=1}^k \frac{1}{2} \log_2\left(1 + \frac{P_i}{\sigma_i^2}\right)\)$

Hadamard 不等式（教材 §4.5.5，式 4.5.44）：任何正定矩阵 \(K\) 的行列式值小于或等于对角线元之积： $\(|K| \leq \prod_i K_{ii}\)$ 等号仅在 \(K\) 为对角阵时成立。该不等式在推导 MIMO 信道容量时用于对角化协方差矩阵。

2.12 其他重要信道模型（课堂补充） 🟢了解

Z 信道

$\(P = \begin{bmatrix}1 & 0 \\ P & 1-P\end{bmatrix}\)$

  • 发 0 永远不会错（一定收 0）
  • 发 1 有概率 \(P\) 错成 0，概率 \(1-P\) 正确收 1
  • 这是最简单的非对称信道

容量（无闭式解析解，但可表达）： $\(C = \log_2\left(1 + 2^{-\frac{H_2(P)}{1-P}}\right)\)$

当 \(P=0\)：\(C = \log_2(1+1) = 1\) bit/use（无噪声） 当 \(P=1\)：\(C = \log_2(1+0) = 0\) bit/use（无用） 最优输入分布：\(p(X=0) \neq p(X=1)\)（非均匀）

含义：Z 信道展示了最简的非对称性——发 0 永远不会错，发 1 却可能出错。这种"一边倒"的噪声特性使得均匀输入不再是好策略：你应该多发送可靠的 0，少发送不可靠的 1。Z 信道的容量公式比对称信道复杂得多，这告诉我们一个重要的教训："对称性"是数学易处理性的关键——一旦对称性被破坏，即使是 \(2\times 2\) 的简单信道，容量也没有简洁的解析解。

Z 信道的最优输入分布是通过容量计算定理（KKT 条件）求解的：达到容量时，被使用的符号的互信息 \(I(X=x;Y)\) 必须都等于 \(C\)，未使用的符号则不超过 \(C\)。对于 Z 信道，这意味着 \(I(X=0;Y) = I(X=1;Y) = C\)，由此可以得到最优 \(\pi = p(X=0)\)。这种方法（将优化问题转化为方程组）是一般 DMC 容量计算的标准思路。

课堂："\(2\times 2\) 信道里最简单的非对称信道，容量已经这么复杂了。所以一般信道没有解析解。"

打字机信道（Printer Channel）

课堂经典例子——一个坏掉的打字机： - 按 a：等概率输出 a 或 b - 按 b：等概率输出 b 或 c - ... - 按 z：等概率输出 z 或 a（循环）

转移矩阵：每行有两个非零元素，各为 \(1/2\)。

含义：打字机信道是一个绝佳的教学例子——它直观地展示了信道容量的本质：通信不是看"发端能传什么"，而是看"收端能区分什么"。即使打字机坏得只能输出"当前字母或下一个字母"，你仍然可以通过只用一半的字母（奇数位置）来实现无差错通信。

这个例子的精妙之处在于，它的最优编码方案非常直观：只发 a, c, e, ..., y 这 13 个字母，因为每个被发的字母会产生两个不同的输出（如 a → a 或 b），而这两个输出不会与其他被发字母的输出混淆。这正好对应了 \(C = \log_2 13\) 的公式——虽然字母表有 26 个，但真正可区分的"输出等价类"只有 13 个。

打字机信道还揭示了信道编码的一个重要思想：输入星座设计。在打字机信道中，我们不是使用所有可能的输入，而是精心选择了一个子集（奇数位置的字母），使得这些输入在输出端产生的分布互不重叠。同样的思想也存在于现代通信的调制设计中（如 QPSK、16-QAM 的星座图设计）——选择适合信道特性的输入子集，使得接收端能够可靠地区分它们。

容量计算： - \(H(Y|X=x) = H_2(1/2) = 1\)（对所有 \(x\)） - \(H(Y|X) = 1\) - \(I(X;Y) = H(Y) - 1\) - \(H(Y) \leq \log 26\)，等号在均匀输出时成立 - \(C = \log 26 - 1 = \log 13 \approx 3.7\) bit/use

编码方法（课堂）： - 只发 a, c, e, ..., y（隔一个字母发一个），共 13 个符号 - 收到 ab → 译成 a（因为不发 b） - 收到 cd → 译成 c（因为不发 d） - 以此类推 - 每次传输携带 \(\log 13\) bit 信息，无差错！

课堂："打字机坏掉了，不代表传不了任何信息。你还可以传 \(\log 13\) 个比特。通信的本质是从接收端恢复发送端的信息。"

含义：无用信道（\(C = 0\)）看起来像是一个没有价值的特例，但它在信息论中扮演着重要的"边界"角色。它告诉我们一个信道要能传递信息的必要条件——输出必须与输入有关联，哪怕是非常微弱的关联。如果输出分布完全不依赖于输入（即 \(p(y|x) = p(y)\)），则互信息 \(I(X;Y) = 0\)，信道就是无用的。

有趣的是，前文提到的和信道中，两个无用信道组合起来却能变成有用信道（\(C = 1\)）。这看似矛盾，实则揭示了信息的一个本质：信息的载体不限于"信道内的符号"，还可以是"选择了哪个信道"本身。这在哲学层面告诉我们：信息可以附着在任何可区分的事件上，即使每个事件本身不包含信息。

无用信道（Useless Channel）

$\(P = \begin{bmatrix}1/2 & 1/2 \\ 1/2 & 1/2\end{bmatrix}\)$

  • 无论发 0 还是 1，输出都以 \(1/2\) 概率为 0 或 1
  • 输出与输入独立
  • \(I(X;Y) = 0\)，\(C = 0\)
  • 课堂："这个水龙头是关闭的，高速公路是封闭的——任何信息都通不过去。"

对比：BSC(\(f=0.5\)) 等价于无用信道。

K 元对称信道与模 K 加性信道

K 元对称信道： - 输入 \(|\mathcal{X}| = K\)，输出 \(|\mathcal{Y}| = K\) - 正确概率 \(1-P\)，错误时等概率到其他 \(K-1\) 个符号 - 容量：\(C = \log K - H_2(P) - P\log(K-1)\) - 通信中的 QPSK (\(K=4\))、64-QAM (\(K=64\)) 常用此模型

模 K 加性信道（课堂）： $\(Y = X + Z \mod K\)$ - \(Z\) 是噪声，取值 \(\{0,1,\ldots,K-1\}\) - 例：骰子 + 噪声模 6 → 骰子结果被"随机化"了 - 当 \(Z\) 均匀分布时，信道无用（\(C=0\)） - 当 \(Z\) 非均匀时，容量取决于 \(Z\) 的分布

3. 典型例题

例题 1：BSC 信道容量计算

问题：BSC 信道交叉概率 \(f = 0.1\)，求信道容量 \(C\)。

解：

Step 1：计算二元熵 $\(H_2(0.1) = -0.1 \log_2 0.1 - 0.9 \log_2 0.9\)$

查表或计算： $\(\log_2 0.1 \approx -3.322, \quad \log_2 0.9 \approx -0.152\)$

\[H_2(0.1) = -0.1 \times (-3.322) - 0.9 \times (-0.152)$$ $$= 0.3322 + 0.1368 = 0.469\]

Step 2：计算容量 $\(\boxed{C = 1 - H_2(0.1) = 1 - 0.469 = 0.531 \text{ bit/channel use} }\)$

Step 3：物理解释 - 每次发送 1 bit，信道以概率 0.9 正确传输，以概率 0.1 翻转 - 有效传输的信息不是 1 bit，而是 \(1 - 0.469 = 0.531\) bit - 也就是说，要实现可靠通信，必须将原始信息编码为冗余形式，使得有效码率不超过 0.531 bit/use

延伸：若 \(f=0.25\)，则 \(C = 1 - H_2(0.25) = 1 - 0.811 = 0.189\) bit/use。噪声越大，容量越小。

例题 2：对称信道容量计算

问题：给定信道转移矩阵： $\(P = \begin{bmatrix} 0.7 & 0.2 & 0.1 \\ 0.1 & 0.7 & 0.2 \\ 0.2 & 0.1 & 0.7 \end{bmatrix}\)$

\(\mathcal{X} = \{x_1,x_2,x_3\}\)，\(\mathcal{Y} = \{y_1,y_2,y_3\}\)。求信道容量 \(C\)。

解：

Step 1：判断对称性 - 行1: \((0.7, 0.2, 0.1)\) - 行2: \((0.1, 0.7, 0.2)\) ← 是行1的循环移位 - 行3: \((0.2, 0.1, 0.7)\) ← 也是行1的循环移位 - 列同理也是循环排列

因此该信道是对称信道，均匀输入 \(p(x) = (1/3, 1/3, 1/3)\) 达到容量。

Step 2：计算输出熵 均匀输入下，输出分布： $\(p(y) = \sum_x p(x)p(y|x) = \frac{1}{3} \times \begin{bmatrix} 0.7+0.1+0.2 \\ 0.2+0.7+0.1 \\ 0.1+0.2+0.7 \end{bmatrix} = \begin{bmatrix} 1/3 \\ 1/3 \\ 1/3 \end{bmatrix}\)$

\[H(Y) = \log_2 3 = 1.585 \text{ bit}\]

Step 3：计算行熵 $\(H(\text{行}) = -0.7\log_2 0.7 - 0.2\log_2 0.2 - 0.1\log_2 0.1\)$ $\(= -0.7(-0.515) - 0.2(-2.322) - 0.1(-3.322)\)$ $\(= 0.3605 + 0.4644 + 0.3322 = 1.157 \text{ bit}\)$

Step 4：计算容量 $\(\boxed{C = H(Y) - H(\text{行} ) = 1.585 - 1.157 = 0.428 \text{ bit/channel use}}\)$

验证：也可以用直接计算 \(I(X;Y)\) 得到相同结果。

例题 3：级联 BSC 信道

问题：两个 BSC(\(f=0.1\)) 信道级联： $\(X \rightarrow \boxed{\text{BSC} (0.1)} \rightarrow Y \rightarrow \boxed{\text{BSC} (0.1)} \rightarrow Z\)$

(a) 求等效信道转移矩阵 (b) 求等效信道的容量 \(C_{\text{cascade}}\) (c) 与单个 BSC(0.1) 的容量比较

解：

(a) 等效转移矩阵

级联 BSC 仍然是 BSC 信道，等效交叉概率： $\(f_{\text{eq}} = f(1-f) + (1-f)f = 2f(1-f)\)$

代入 \(f=0.1\)： $\(f_{\text{eq}} = 2 \times 0.1 \times 0.9 = 0.18\)$

所以等效信道是 BSC(\(0.18\))： $\(P_{\text{eq}} = \begin{bmatrix} 0.82 & 0.18 \\ 0.18 & 0.82 \end{bmatrix}\)$

解释：级联两次的错误情况有两种—— 1. 第一次错且第二次正确：\(f(1-f)\) 2. 第一次正确且第二次错：\((1-f)f\)

(b) 等效容量 $\(H_2(0.18) = -0.18\log_2 0.18 - 0.82\log_2 0.82\)$ $\(= -0.18(-2.474) - 0.82(-0.287)\)$ $\(= 0.445 + 0.235 = 0.680\)$

\[\boxed{C_{\text{cascade} } = 1 - H_2(0.18) = 1 - 0.680 = 0.320 \text{ bit/channel use}}\]

(c) 对比与讨论

信道 交叉概率 容量 (bit/use)
单个 BSC(0.1) 0.1 0.531
两个 BSC(0.1) 级联 0.18 0.320
三个 BSC(0.1) 级联 \(0.5 - 0.5(0.8)^3 \approx 0.244\) 0.200

级联使等效噪声增大，容量降低。由 DPI 保证 \(C_{\text{cascade}} \leq C_1 = C_2\)。

例题 4：可达性判断

问题：已知某信道容量 \(C = 0.5\) bit/channel use。存在信息速率为 \(R\) 的信源需要传输。判断以下 \(R\) 能否实现可靠通信（\(P_e \to 0\)）：

(a) \(R = 0.3\) bit/use (b) \(R = 0.5\) bit/use (c) \(R = 0.6\) bit/use

解：

由香农第二定理： - 可达：若 \(R < C\)，存在编码使 \(P_e \to 0\) - 不可达：若 \(R > C\)，无论用何种编码，\(P_e \not\to 0\) - 边界：\(R = C\) 时，严格来说需要无限长编码才能达到，实际中认为 \(R\) 必须严格小于 \(C\)

(a) \(R = 0.3 < 0.5 = C\)：

\[\boxed{\text{可达} }\]

我们可以设计一个 \((2^{0.3n}, n)\) 码，当 \(n\) 足够大时，\(P_e\) 可以任意小。例如，\(n=1000\) 时，消息数 \(2^{300} \approx 10^{90}\)，虽然有噪声，但编码后的冗余足以纠正错误。

(b) \(R = 0.5 = C\)：

\[\boxed{\text{边界情况，理论上需要 } n \to \infty}\]

香农定理要求 \(R < C\)（严格小于）。实际中如果 \(n\) 有限，错误概率不会趋于 0。

(c) \(R = 0.6 > 0.5 = C\)：

\[\boxed{\text{不可达} }\]

逆定理保证 \(P_e \not\to 0\)。无论怎样编码，信源速率超过了信道的最大可靠传输能力，必然出现不可忽略的错误概率。

Fano 不等式验证（对(c)）：

假设我们试图传输 \(R = 0.6\) bit/use，使用 \(n\) 次信道。消息数 \(M = 2^{0.6n}\)，则 \(H(W) = 0.6n\) bit。

由 Fano 不等式： $\(P_e \geq \frac{H(W|Y) - 1}{\log(M-1)}\)$

对于可靠译码，\(H(W|Y)\) 必然很大——因为信道容量只有 0.5，最多传递 \(0.5n\) bit，剩余 \(0.1n\) bit 信息必然丢失。

例题 5：打字机信道容量

问题：考虑 26 个字母的打字机信道——按当前字母，等概率输出该字母或下一个字母（z 的下一个是 a）。求信道容量和编码方案。

解：

Step 1：判断信道性质 - 输入 \(|\mathcal{X}| = 26\)，输出 \(|\mathcal{Y}| = 26\) - 每行有两个元素为 \(1/2\)，其余为 0 - 行和列都是排列关系 → 对称信道

Step 2：计算条件熵 $\(H(Y|X=x) = H_2(1/2) = 1 \text{ bit}, \quad \forall x\)$ $\(H(Y|X) = 1 \text{ bit}\)$

Step 3：计算容量 均匀输入时输出也均匀，\(H(Y) = \log_2 26\) $\(C = H(Y) - H(Y|X) = \log_2 26 - 1 = \log_2 13 \approx 3.7 \text{ bit/channel use}\)$

Step 4：编码方案（课堂经典方法） - 只发奇数位置字母：a, c, e, g, ..., y（共 13 个） - 不发 b, d, f, ..., z - 译码规则： * 收到 a 或 b → 译成 a（因为只有 a 能产生 b） * 收到 c 或 d → 译成 c * 以此类推 - 每次传输携带 \(\log_2 13\) bit 信息，完全无差错

课堂："打字机坏掉了，但是你还是能传 \(\log 13\) 个比特。这就是信道容量的意义——在任何信道上，总能找到一个速率 \(R < C\) 的通信方案。"

例题 6：Z 信道容量计算

问题：Z 信道的转移矩阵 \(P = \begin{bmatrix}1 & 0 \\ 0.3 & 0.7\end{bmatrix}\)，求信道容量 \(C\)。

解：

Step 1：判断对称性 行不对称（第一行 \((1,0)\)，第二行 \((0.3,0.7)\)），不是对称信道。需用容量计算定理。

Step 2：设输入分布 设 \(p(X=0) = \pi\)，\(p(X=1) = 1-\pi\)。

输出分布： $\(p(Y=0) = \pi \cdot 1 + (1-\pi) \cdot 0.3 = 0.3 + 0.7\pi\)$ $\(p(Y=1) = \pi \cdot 0 + (1-\pi) \cdot 0.7 = 0.7(1-\pi)\)$

Step 3：计算互信息 $\(I(X;Y) = H(Y) - H(Y|X)\)$ $\(H(Y|X) = \pi \cdot H(Y|X=0) + (1-\pi) \cdot H(Y|X=1)\)$ $\(= \pi \cdot 0 + (1-\pi) \cdot H_2(0.3) = 0.881(1-\pi)\)$

\[H(Y) = -(0.3+0.7\pi)\log(0.3+0.7\pi) - 0.7(1-\pi)\log(0.7(1-\pi))\]

Step 4：数值最大化 对 \(\pi\) 求极值，得 \(\pi^* \approx 0.635\)，代入得： $\(C \approx 0.504 \text{ bit/channel use}\)$

解题技巧

  1. 判断对称性：检查转移矩阵是否每行/每列是排列关系。只要行可排列且列可排列，就是对称信道。

  2. 级联信道计算：

  3. BSC 级联：\(f_{\text{eq}} = \frac12 - \frac12(1-2f)^k\)（\(k\) 级级联）

  4. 一般矩阵级联：\(P_{\text{eq}} = P_1 \times P_2 \times \cdots\)（矩阵乘法）

  5. 可达性证明套路：若 \(R < C\)，需证明存在码使 \(P_e \to 0\)。考试中只需陈述香农第二定理结论，不需要完整证明。

  6. 互信息最大化步骤：

  7. Step 1: 写出 \(I(X;Y) = H(Y) - H(Y|X)\)
  8. Step 2: \(H(Y|X)\) 是否与输入分布无关？（BSC、BEC 是）
  9. Step 3: 若是，只需最大化 \(H(Y)\) → 均匀输出 → 反推 \(p(x)\)

  10. Step 4: 若否，需要用 Lagrange 乘子或 BA 算法

  11. 灌水法：平行高斯信道的功率分配类似往一个容器里注水——噪声小的子信道分配到更多功率。

  12. 打字机信道速算：\(C = \log|\mathcal{Y}| - H(\text{行})\)，当每行有 \(k\) 个等概率输出时，\(H(\text{行}) = \log k\)，所以 \(C = \log|\mathcal{Y}| - \log k\)。

[例 4.2.1 / 教材 §4.2.3] 对称信道容量计算

问题：考虑如下对称离散无记忆信道，求其信道容量。

转移概率矩阵： $\(P = \begin{bmatrix} 1-\epsilon-\delta & \epsilon & \delta \\ \delta & 1-\epsilon-\delta & \epsilon \\ \epsilon & \delta & 1-\epsilon-\delta \end{bmatrix}\)$

其中 \(\mathcal{X} = \mathcal{Y} = \{0, 1, 2\}\)，\(\epsilon, \delta \geq 0\) 且 \(\epsilon + \delta \leq 1\)。

解：

Step 1：验证对称性

各行均为 \((1-\epsilon-\delta, \epsilon, \delta)\) 的排列，各列同理。因此该信道是对称信道，均匀输入分布 \(p(x) = (1/3, 1/3, 1/3)\) 达到容量。

Step 2：计算行熵

\[H(\text{行}) = -(1-\epsilon-\delta)\log(1-\epsilon-\delta) - \epsilon\log\epsilon - \delta\log\delta\]

Step 3：计算容量

均匀输入下输出也是均匀分布，\(H(Y) = \log_2 3\)，因此： $\(C = \log_2 3 - H(\text{行})\)$

当 \(\epsilon = \delta = 0\) 时（无噪），\(C = \log_2 3 \approx 1.585\) bit/use。 当 \(\epsilon + \delta \to 1\) 时，信道噪声增大，容量趋近于 0。

[例 4.2.2 / 教材 §4.5.5] 平行高斯信道的灌水法

问题：考虑 3 个独立的平行高斯信道，噪声方差分别为 \(\sigma_1^2 = 1, \sigma_2^2 = 2, \sigma_3^2 = 4\)，总发射功率 \(P = 10\)。用灌水法求最优功率分配和总信道容量。

解：

Step 1：灌水法公式

最优功率分配： $\(P_i = \left(\nu - \sigma_i^2\right)^+\)$ 其中 \(\nu\) 由 \(\sum_i P_i = P\) 确定，\((x)^+ = \max(x, 0)\)。

Step 2：确定水位 \(\nu\)

尝试 \(\nu\) 值，使 \(\sum_i (\nu - \sigma_i^2)^+ = 10\)：

若 \(\nu = 7\)： $\(P_1 = 7-1 = 6,\; P_2 = 7-2 = 5,\; P_3 = 7-4 = 3\)$ 总和 = 14 > 10。降低 \(\nu\)。

若 \(\nu = 5\)： $\(P_1 = 5-1 = 4,\; P_2 = 5-2 = 3,\; P_3 = 5-4 = 1\)$ 总和 = 8 < 10。增加 \(\nu\)。

若 \(\nu = 5.67\)： $\(P_1 = 4.67,\; P_2 = 3.67,\; P_3 = 1.67\)$ 总和 ≈ 10。✓

Step 3：计算总容量

\[C = \frac{1}{2}\sum_{i=1}^3 \log_2\left(1 + \frac{P_i}{\sigma_i^2}\right)$$ $$= \frac{1}{2}\left[\log_2\left(1 + \frac{4.67}{1}\right) + \log_2\left(1 + \frac{3.67}{2}\right) + \log_2\left(1 + \frac{1.67}{4}\right)\right]$$ $$= \frac{1}{2}\left[\log_2 5.67 + \log_2 2.835 + \log_2 1.4175\right]$$ $$= \frac{1}{2}[2.503 + 1.503 + 0.503] = \frac{4.509}{2} = 2.255 \text{ bit/channel use}\]

对比：均匀分配功率时 \(P_i = 10/3\)： $\(C_{\text{uniform}} = \frac{1}{2}\left[\log_2\left(1+\frac{3.33}{1}\right) + \log_2\left(1+\frac{3.33}{2}\right) + \log_2\left(1+\frac{3.33}{4}\right)\right]\)$ $\(= \frac{1}{2}[2.115 + 1.415 + 0.874] = 2.202 \text{ bit/channel use}\)$

灌水法比均匀分配多约 0.053 bit/use 的容量。

[例 4.5.5 / 教材 §4.5.5] Hadamard 不等式在 MIMO 容量中的应用

问题：已知 \(n\) 维复高斯噪声信道的协方差矩阵为 \(K_z\)，输入协方差矩阵为 \(K_x\)，总功率约束 \(\text{Tr}(K_x) \leq nP\)。试利用 Hadamard 不等式推导最优输入分布。

解：

Hadamard 不等式（教材式 4.5.44）：任何正定矩阵 \(K\) 的行列式值小于或等于对角线元之积： $\(|K| \leq \prod_{i=1}^n K_{ii}\)$ 等号仅当 \(K\) 为对角阵时成立。

应用：信道容量问题化为在 \(\text{Tr}(A) \leq nP\) 约束下最大化 \(|A + \Lambda|\)，其中 \(A = Q^T K_x Q\)，\(\Lambda = \text{diag}(\lambda_1, \ldots, \lambda_n)\) 是 \(K_z\) 的本征值矩阵。

由 Hadamard 不等式： $\(|A + \Lambda| \leq \prod_{i=1}^n (A_{ii} + \lambda_i)\)$

等号仅在 \(A\) 为对角阵时成立，这要求 \(K_x\) 与 \(K_z\) 同时对角化——即输入沿噪声的本征方向分配功率。

最优功率分配（灌水法）： $\(A_{ii} = (\nu - \lambda_i)^+\)$ 其中 \(\nu\) 由 \(\sum_i A_{ii} = nP\) 确定。这对应于每个本征方向独立传输，噪声强的方向分配较少功率。

[教材习题改编] 一般 DMC 的互信息最大化

问题（参考教材习题 4.1、4.2）：给定信道转移矩阵： $\(P = \begin{bmatrix} 0.8 & 0.2 \\ 0.3 & 0.7 \end{bmatrix}\)$ 输入字母表 \(\mathcal{X} = \{0,1\}\)，输出 \(\mathcal{Y} = \{0,1\}\)。求信道容量。

解：

Step 1：判断对称性

行1: (0.8, 0.2)，行2: (0.3, 0.7)。两行不是排列关系，因此该信道不是对称信道，需用 Lagrange 乘子法。

Step 2：写出互信息表达式

设 \(p(X=0) = \pi\)，\(p(X=1) = 1-\pi\)。

输出分布： $\(p(Y=0) = 0.8\pi + 0.3(1-\pi) = 0.3 + 0.5\pi\)$ $\(p(Y=1) = 0.2\pi + 0.7(1-\pi) = 0.7 - 0.5\pi\)$

条件熵 \(H(Y|X)\) 与 \(\pi\) 无关： $\(H(Y|X) = \pi H_2(0.2) + (1-\pi)H_2(0.3) = H_2(0.2) = H_2(0.3) = 0.881 \text{ bit}\)$

实际上，\(H(Y|X=0) = H_2(0.2) = 0.722\)，\(H(Y|X=1) = H_2(0.3) = 0.881\)。

所以 \(H(Y|X) = 0.722\pi + 0.881(1-\pi) = 0.881 - 0.159\pi\)。

互信息： $\(I(X;Y) = H(Y) - H(Y|X)\)$ $\(= -p_0\log p_0 - p_1\log p_1 - (0.881 - 0.159\pi)\)$

其中 \(p_0 = 0.3 + 0.5\pi\)，\(p_1 = 0.7 - 0.5\pi\)。

Step 3：最大化

对 \(\pi\) 求导并令导数为 0（数值求解），得 \(\pi^* \approx 0.385\)，代入得： $\(C \approx 0.258 \text{ bit/channel use}\)$

6. 📝 按题型精选

题型一：BSC 容量计算

题目（教材习题 4.2 改编）：BSC 信道交叉概率 \(f=0.15\)，求 \(C\)。

解答要点：\(H_2(0.15) = -0.15\log_2 0.15 - 0.85\log_2 0.85 \approx 0.610\)，\(C = 1 - H_2(0.15) = 0.390\) bit/use。均匀输入 \(p(0)=p(1)=0.5\) 使 \(H(Y)=1\) 达到最大。

题型二：对称信道容量

题目（教材习题 4.1 改编）：对称信道转移矩阵 \(P = \begin{bmatrix}0.7&0.2&0.1\\0.1&0.7&0.2\\0.2&0.1&0.7\end{bmatrix}\)，求信道容量。

解答要点：①行和列均为循环排列，为对称信道 ②均匀输入 \(p(x)=1/3\) 最优 ③\(H(Y)=\log_2 3 = 1.585\) bit ④\(H(\text{行}) = -0.7\log0.7-0.2\log0.2-0.1\log0.1 = 1.157\) bit ⑤\(C = H(Y)-H(\text{行}) = 0.428\) bit/use。

题型三：级联信道

题目（教材习题 4.9 改编）：两个 BSC(\(f=0.1\)) 级联，求等效信道容量。

解答要点：①等效交叉概率 \(f_{\text{eq}} = 2f(1-f) = 0.18\) ②\(H_2(0.18) \approx 0.680\) ③\(C_{\text{cascade}} = 1-0.680 = 0.320\) bit/use，小于单个 BSC 的 \(0.531\)。级联使噪声增大，由 DPI 保证容量下降。

题型四：可达性判断

题目：\(C=0.5\) bit/use，判断 \(R=0.3\) 和 \(R=0.6\) 能否实现可靠通信。

解答要点：①\(R=0.3<C\)：可达，存在 \((2^{0.3n},n)\) 码使 \(P_e\to0\) ②\(R=0.6>C\)：不可达，逆定理保证 \(P_e\not\to0\)。香农第二定理：\(R<C\) 是可靠通信的充要条件。

题型五：互信息最大化（一般 DMC）

题目（教材习题 4.1）：非对称信道 \(P=\begin{bmatrix}0.8&0.2\\0.3&0.7\end{bmatrix}\)，求 \(C\)。

解答要点：①设 \(p(X=0)=\pi\) ②\(I(X;Y)=H(Y)-[0.722\pi+0.881(1-\pi)]\) ③对 \(\pi\) 数值求导得 \(\pi^*\approx0.385\) ④\(C\approx 0.258\) bit/use。非对称信道不能用 \(C=1-H_2(f)\) 公式。

题型六：BEC 容量

题目：BEC 删除概率 \(\alpha=0.2\)，求 \(C\)。

解答要点：\(C=1-\alpha=0.8\) bit/use。均匀输入时 \(80\%\) 的符号正确到达，每个正确符号携带 1 bit。删除符号 \(e\) 不传递信息。

题型七：平行信道灌水法

题目（教材例 4.2.2）：3 个平行高斯信道 \(\sigma^2=[1,2,4]\)，总功率 \(P=10\)，求最优功率分配和总容量。

解答要点：①灌水法 \(P_i=(\nu-\sigma_i^2)^+\)，水位 \(\nu\approx5.67\) 得 \(P=[4.67,3.67,1.67]\) ②\(C=\frac12\sum\log_2(1+P_i/\sigma_i^2) \approx \frac12(2.503+1.503+0.503)=2.255\) bit/use ③比均匀分配（\(2.202\)）高 \(0.053\)。

题型八：信道组合 — 积信道

题目：两个独立 BSC(\(f=0.1\)) 并联使用，求总容量。

解答要点：①各子信道容量 \(C_i=0.531\) bit/use ②积信道（平行组合）总容量 \(C_{\text{总和}} = C_1 + C_2 = 1.062\) bit/use。和信道则 \(C = \log(2^{C_1}+2^{C_2})\)。

题型九：打字机信道

题目：打字机信道有 26 个字母，按当前字母等概率输出该字母或下一个字母。求信道容量和编码方案。

解答要点：①\(H(Y|X)=1\) ②均匀输入时 \(H(Y)=\log_2 26\) ③\(C=\log_2 26 - 1 = \log_2 13 \approx 3.7\) bit/use ④只发奇数位置字母（a,c,e,...,y），共 13 个符号，无差错传输。

题型十：对称性判断

题目：判断以下信道哪些是对称信道、准对称信道、非对称信道： $\(P_1 = \begin{bmatrix}0.5&0.3&0.2\\0.2&0.5&0.3\\0.3&0.2&0.5\end{bmatrix}, \quad P_2 = \begin{bmatrix}0.8&0.1&0.1\\0.1&0.8&0.1\\0.1&0.1&0.8\end{bmatrix}, \quad P_3 = \begin{bmatrix}1&0\\0.3&0.7\end{bmatrix}\)$

解答要点： - \(P_1\)：行和列都是排列 → 对称信道 - \(P_2\)：行是排列（每行都是 \((0.8,0.1,0.1)\) 排列），列不是 → 准对称信道 - \(P_3\)：行和列都不是排列 → 非对称信道
