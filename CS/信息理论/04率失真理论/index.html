04 率失真理论（Rate-Distortion Theory） 🟢 非考试范围

余官定 | 2026-05-31 + 06-14（2 讲） | 不考，课堂提及但不做考试重点

香农第三定理：有损压缩场景下，给定失真 \(D\)，可达到的最小码率为 \(R(D)\)。

1. 知识框架

率失真理论回答的核心问题：如果允许一定程度的失真，压缩一个信源最少需要多少比特？

无损压缩: R ≥ H(X)             （完美重建，无失真）
    ↓ 引入失真度量
有损压缩: R(D) = min I(X; X̂)        （给定失真 D 下的最小码率）
    ↓ 主要结果
二元信源 + Hamming失真: R(D) = H₂(p) − H₂(D)   （0 ≤ D ≤ min(p, 1−p)）
高斯信源 + 平方误差:  R(D) = ½ log(σ²/D)    （0 ≤ D ≤ σ²）
    ↓ 逆问题
D(R) = σ² · 2^{−2R}             （给定码率 R 的最小可达失真）
    ↓ 一般连续信源
定理 5.7.1: 上界 R(D) ≤ ½log(σ²/D)
定理 5.7.2: Shannon 下限 RL(D) = h(X) − ½log(2πeD)

香农第三定理：\(R(D)\) 曲线下方不可达、上方可达——与信道容量的对偶关系。

2. 核心概念与定理

2.1 失真度量 🟢了解

单字母失真函数：\(d: \mathcal{X} \times \hat{\mathcal{X}} \to \mathbb{R}^+\)

失真类型 定义 典型应用
Hamming 失真 \(d(x,\hat{x}) = \mathbf{1}\{x \neq \hat{x}\}\) 符号误码率（离散信源）
平方误差失真 \(d(x,\hat{x}) = (x - \hat{x})^2\) 连续信源（图像/音频）
绝对值失真 $d(x,\hat{x}) = x - \hat{x}

序列失真（长度为 \(n\)）：

\[d(x^n, \hat{x}^n) = \frac{1}{n} \sum_{i=1}^{n} d(x_i, \hat{x}_i)\]

??? note "课堂补充细节" 老师用通俗的例子解释了失真度量的实际意义：

- **Hamming 失真**就像计算通信中的误码率——"你发送 $n$ 个符号，错了多少个位置？"
- **平方误差失真**在数学上易于处理（可导），而绝对值失真在零点不可导。"为什么用平方不用绝对值？因为求导好求。你可以用 4 次方，但那是给自己徒增烦恼。"
- **失真度量可以任意定义**，只要映射到非负实数且有上界（否则期望失真可能发散）
- 在序列级别，**平均失真与最大失真在 $n\to\infty$ 时等价**（抽屉原理）

**失真的规范性**（regular distortion）：若对每个 $x \in \mathcal{X}$ 都存在 $\hat{x} \in \hat{\mathcal{X}}$ 使 $d(x,\hat{x})=0$，则称失真度量是规范的。Hamming 失真和平方误差失真都是规范的。老师强调：

> "规范失真的好处是 $R(0)=H(X)$——无损编码时码率就是信源熵。如果失真不规范（比如你把所有 $(x,\hat{x})$ 对的失真都定义为 0），那 $R(0)=0$ 都没问题，但这没有意义。"

不规范的失真可以通过减去 $\min_{\hat{x}} d(x,\hat{x})$ 变为规范的，两者只差一个常数。

??? note "配套练习" 练习：设 \(X \in \{0,1,2\}\)，\(P(X=0)=0.5, P(X=1)=0.3, P(X=2)=0.2\)，重建字母表 \(\hat{\mathcal{X}} = \{0,1\}\)。定义失真函数 \(d(0,0)=0,\ d(1,1)=0,\ d(2,0)=1,\ d(2,1)=2\)，其他情况 \(d=1\)。求 \(D_{\max}\) 和零比特编码策略。

??? note "答案"
  $D_{\max} = \min_{\hat{x}} \mathbb{E}[d(X,\hat{x})]$

  若 $\hat{x}=0$：$\mathbb{E}[d] = 0.5\times0 + 0.3\times1 + 0.2\times1 = 0.5$
  若 $\hat{x}=1$：$\mathbb{E}[d] = 0.5\times1 + 0.3\times0 + 0.2\times2 = 0.9$

  $\therefore D_{\max} = \min\{0.5, 0.9\} = \boxed{0.5} $，零比特编码策略为 $\hat{X}=0$。

??? note "易错点" 1. 失真度量的规范性：规范的失真要求对每个 \(x\) 都能找到 \(\hat{x}\) 使 \(d(x,\hat{x})=0\)。反之，若定义"所有 \((x,\hat{x})\) 的失真都是 0"，则 \(R(0)=0\) 而非 \(H(X)\)——因为无需编码就能实现零失真，但这不符合实际 2. \(R(0)=H(X)\) 仅对离散信源和规范失真成立，连续信源 \(R(0)=\infty\) 3. 信源字母表和重建字母表可以不同：老师举例"01 信源变成 01 重建不一定无损，关键看 \(H(\hat{X}) < H(X)\)——商减少了就是有损" 4. 有界性要求：失真函数需有上界，否则 \(D_{\max}\) 可能无穷大，率失真理论失效

2.2 率失真函数 🟢了解

定义：

\[\boxed{R(D) = \min_{p(\hat{x} |x):\; \mathbb{E}[d(X,\hat{X})] \leq D} I(X; \hat{X})}\]

其中期望失真约束：

\[\mathbb{E}[d(X,\hat{X})] = \sum_{x,\hat{x}} p(x) p(\hat{x}|x) d(x,\hat{x}) \leq D\]

性质： 1. 单调不增：\(D_1 < D_2 \Rightarrow R(D_1) \geq R(D_2)\)（失真越小，码率越高） 2. 凸性：\(R(D)\) 是 \(D\) 的凸函数 3. 边界条件： - \(R(0) = H(X)\)（零失真 = 无损编码，仅对离散信源成立） - \(R(D_{\max}) = 0\)，其中 \(D_{\max} = \min_{\hat{x}} \mathbb{E}[d(X,\hat{x})]\)

对连续信源，\(R(0) = \infty\)，因为无损重建需要无限比特。

??? note "课堂补充细节" 老师用 \(R(D)\) 曲线的几何意义阐释了核心概念：

- **零比特编码**：$D_{\max}$ 对应 $R=0$——完全放弃编码，用固定重建值
- **无损编码**：$R(0)=H(X)$（离散）或 $\infty$（连续）
- **可达区域**：$R(D)$ 曲线上方所有 $(R,D)$ 对都是可达的（用更多比特或容忍更大失真）
- **不可达区域**：曲线下方不可达——信息论的根本极限

> 老师总结："$R(D)$ 曲线就是可达区域的下边界（包络），单调下降的凸函数——下方不可达，上方任意取。"

**编码框架的四个要素**：
1. 编码函数 $f_n: X^n \to \{1,\dots,M\}$（映射到 $M=2^{nR}$ 个索引）
2. 解码函数 $g_n: \{1,\dots,M\} \to \hat{X}^n$（重建序列）
3. 失真度量 $d(x^n,\hat{x}^n)$
4. 约束 $\mathbb{E}[d] \leq D$

**凸性证明思路**：设 $D_\theta = \theta D_1 + (1-\theta)D_2$，构造 $p_\theta(\hat{x}|x) = \theta p_1^*(\hat{x}|x) + (1-\theta)p_2^*(\hat{x}|x)$，利用 $I(X;\hat{X})$ 关于 $p(\hat{x}|x)$ 的凸性可得 $R(D_\theta) \leq \theta R(D_1) + (1-\theta)R(D_2)$。

??? note "配套练习" 练习 1：判断以下说法是否正确："若 \(R \geq R(D)\)，则一定存在一个 \((2^{nR}, n)\) 率失真码使得平均失真恰好等于 \(D\)。"

??? note "答案"
  错误。香农第三定理保证存在码使得 $\mathbb{E}[d] \to D$（渐进趋于 $D$），但不保证恰好等于 $D$。实际中 $\mathbb{E}[d]$ 可以小于 $D$——因为 $R \geq R(D)$ 时更宽松的失真约束自动满足，编码器可以用多余的码率进一步降低失真。

**练习 2**：利用凸性证明：若 $D_1 < D_2$，则 $R(D_1) \geq R(D_2)$。

??? note "答案"
  假设存在 $D_1 < D_2$ 但 $R(D_1) < R(D_2)$，取 $\theta=0$ 即得矛盾。更直接的证明：任何满足 $\mathbb{E}[d] \leq D_1$ 的测试信道必然满足 $\mathbb{E}[d] \leq D_2$（因为 $D_1 < D_2$），所以 $\mathcal{Q}_{D_1} \subseteq \mathcal{Q}_{D_2}$，在更小的集上求最小值不会更小，故 $R(D_1) \geq R(D_2)$。

??? note "易错点" 1. \(R(D)\) 不是严格递减的：当 \(D \geq D_{\max}\) 时 \(R(D)=0\) 保持不变，不是严格递减 2. \(D_{\max}\) 是 \(\min\) 不是 \(\max\)：定义是 \(D_{\max} = \min_{\hat{x}} \mathbb{E}[d(X,\hat{x})]\)，即零比特编码能达到的最小失真 3. \(R(0)\) 对连续信源是 \(\infty\)：因为连续信源的真熵是无穷大，无损重建需要无限比特 4. 率失真函数 vs 信息率失真函数：\(R(D)\) 是"有损编码最小码率"，\(R_I(D) = \min I(X;\hat{X})\) 是"互信息最小值"。香农第三定理证明两者相等，但概念上完全不同

2.3 二元信源的率失真函数 🟢了解

\(X \sim \text{Bernoulli}(p)\)，Hamming 失真：

\[\boxed{R(D) = \begin{cases} H_2(p) - H_2(D) & 0 \leq D \leq \min(p, 1-p) \\ 0 & D > \min(p, 1-p) \end{cases}}\]

推导思想：\(I(X;\hat{X}) = H(X) - H(X|\hat{X})\)，利用 Fano 不等式约束 \(H(X|\hat{X}) \geq H_2(D)\)。

??? note "课堂补充细节" 老师详细推导了 Bernoulli 信源的率失真函数，分为两步：

**Step 1：证明下界** $I(X;\hat{X}) \geq H_2(p) - H_2(D)$

$$I(X;\hat{X}) = H(X) - H(X|\hat{X}) = H_2(p) - H(X|\hat{X})$$

利用 Fano 不等式：$H(X|\hat{X}) \leq H_2(P_e) + P_e \log(|\mathcal{X}|-1)$，其中 $P_e = P(X \neq \hat{X}) = \mathbb{E}[d] \leq D$。对二进制信源 $|\mathcal{X}|=2$，有 $H(X|\hat{X}) \leq H_2(P_e) \leq H_2(D)$（$H_2$ 在 $[0,1/2]$ 上单调增）。因此：

$$I(X;\hat{X}) \geq H_2(p) - H_2(D)$$

**Step 2：构造反向测试信道使等号成立**

设 $\hat{X} \sim \text{Bernoulli}(r)$，定义条件分布（反向测试信道）：
$$P(X=0|\hat{X}=0) = 1-D,\quad P(X=1|\hat{X}=0) = D$$
$$P(X=1|\hat{X}=1) = 1-D,\quad P(X=0|\hat{X}=1) = D$$

解 $P(X=0) = r(1-D) + (1-r)D = 1-p$ 得：
$$r = \frac{p-D}{1-2D}, \quad 0 \leq D \leq \min(p,1-p)$$

可以验证 $0 \leq r \leq 1$，因此该反向测试信道存在。代入得 $I(X;\hat{X}) = H_2(p) - H_2(D)$，等号成立。

> 老师总结："这个构造证明了下界 $H_2(p)-H_2(D)$ 就是 $R(D)$——既是最小值，又是可达的。"

??? note "配套练习" 练习 1：\(X \sim \text{Bernoulli}(0.25)\)，Hamming 失真。求 \(R(0.15)\)。

??? note "答案"
  $H_2(0.25) = -0.25\log_2 0.25 - 0.75\log_2 0.75 = 0.5 + 0.311 = 0.811$ bit
  $H_2(0.15) = -0.15\log_2 0.15 - 0.85\log_2 0.85$
  $\log_2 0.15 = \ln 0.15 / \ln 2 = -1.897 / 0.693 = -2.737$
  $\log_2 0.85 = \ln 0.85 / \ln 2 = -0.163 / 0.693 = -0.235$
  $H_2(0.15) = 0.15 \times 2.737 + 0.85 \times 0.235 = 0.411 + 0.200 = 0.611$
  $R(0.15) = 0.811 - 0.611 = \boxed{0.200\ \text{bit} }$

**练习 2**：对 $X \sim \text{Bernoulli}(0.5)$，求 $D$ 的取值范围使 $R(D) > 0$。

??? note "答案"
  $D_{\max} = \min(0.5, 0.5) = 0.5$，故 $0 \leq D < 0.5$ 时 $R(D) > 0$。
  当 $D=0$ 时 $R(0)=H_2(0.5)=1$ bit；当 $D=0.5$ 时 $R(0.5)=0$。

??? note "易错点" 1. \(D\) 的定义域：\(0 \leq D \leq \min(p, 1-p)\)，不是 \(0 \leq D \leq 1\)。当 \(p=0.3\) 时 \(D\) 最大只能到 \(0.3\)，超过后 \(R(D)=0\) 2. \(H_2(D)\) 在 \(D>0.5\) 时递减：但 \(D\) 的定义域为 \([0,\min(p,1-p)] \subseteq [0,0.5]\)，所以 \(H_2(D)\) 单调递增，\(R(D)=H_2(p)-H_2(D)\) 单调递减 3. 对称信源特例：\(p=0.5\) 时 \(D_{\max}=0.5\)，\(R(0.5)=0\)，\(R(0)=1\) bit 4. 反向测试信道中 \(r=\frac{p-D}{1-2D}\) 必须在 \([0,1]\) 内，这恰好要求 \(D \leq \min(p,1-p)\)

2.4 高斯信源的率失真函数 🟢了解

\(X \sim \mathcal{N}(0, \sigma^2)\)，平方误差失真：

\[\boxed{R(D) = \begin{cases} \dfrac{1}{2} \log_2 \dfrac{\sigma^2}{D} & 0 \leq D \leq \sigma^2 \\ 0 & D > \sigma^2 \end{cases}}\]

逆函数（给定码率 \(R\) 的最小失真）：

\[\boxed{D(R) = \sigma^2 \cdot 2^{-2R} }\]

每增加 1 bit 码率，失真降低至原来的 \(1/4\)。

??? note "课堂补充细节" 老师用"1比特量化悖论"生动解释了高斯信源的率失真函数：

**1 比特标量量化**：用 1 个比特表示高斯变量，最优策略是将正半轴映射到 $\hat{X} = \sqrt{2/\pi}\,\sigma$，负半轴映射到 $\hat{X} = -\sqrt{2/\pi}\,\sigma$，均方误差为 $\frac{\pi-2}{\pi}\sigma^2 \approx 0.363\sigma^2$。

**率失真函数预测**：$R=1$ bit 时 $D(1) = \sigma^2 \cdot 2^{-2} = \sigma^2/4 = 0.25\sigma^2$。

**为什么有差距？**因为率失真函数需要 $n\to\infty$ 的矢量量化（联合编码），而 1 比特量化是 $n=1$ 的标量量化。

> 老师解释："你用两比特（$n=2$）做二维联合量化，失真就会比 $\frac{\pi-2}{\pi}\sigma^2$ 小；三比特更小。当 $n\to\infty$ 时趋近于 $\sigma^2/4$——这和 Huffman 编码的证明思路完全一样，码长趋于无穷时逼近熵。"

**每增加 1 bit，失真降至 $1/4$**：$D(R+1) = \sigma^2 \cdot 2^{-2(R+1)} = \frac14 \cdot D(R)$。

??? note "配套练习" 练习 1：\(X \sim \mathcal{N}(0, 16)\)，平方误差失真。求码率 \(R=1.5\) bit 时的最小可达失真。

??? note "答案"
  $D(R) = \sigma^2 \cdot 2^{-2R} = 16 \times 2^{-3} = 16 \times 0.125 = \boxed{2} $
  可以用 1.5 bit/符号编码达到均方误差 2（原始方差 16 的 $1/8$）。

**练习 2**：对 $X \sim \mathcal{N}(0, 16)$，若要求 $D=1$，求所需最小码率。

??? note "答案"
  $R(D) = \frac12 \log_2(\sigma^2/D) = \frac12 \log_2(16/1) = \frac12 \times 4 = \boxed{2\ \text{bit} }$

??? note "易错点" 1. \(D\) 不能取 \(0\)：高斯信源 \(R(0)=\infty\)，无损压缩需要无限比特 2. \(D_{\max} = \sigma^2\)：取 \(\hat{X}=0\)（均值）时均方误差恰好等于方差 3. \(D > \sigma^2\) 时 \(R(D)=0\)：直接用 \(\hat{X}=0\) 重建，失真就是 \(\sigma^2\)；容忍更大的失真没有意义 4. 公式中的对数底数：\(R(D)=\frac12\log_2(\sigma^2/D)\) 单位是 bit；若用 nat 则 \(R(D)=\frac12\ln(\sigma^2/D)\) 5. 标量量化 vs 矢量量化：有限长编码的失真 > \(R(D)\) 理论极限，需要 \(n\to\infty\) 才能达到

2.5 香农第三定理 🟢了解

正向：对任意 \(R > R(D)\)，存在一列 \((2^{nR}, n)\) 率失真码使得 \(\mathbb{E}[d(X^n, \hat{X}^n)] \to D\)。

逆向：若 \(\mathbb{E}[d] \leq D\)，则码率 \(R \geq R(D)\)。

信道容量对偶：信道容量 \(C = \max_{p(x)} I(X;Y)\)，率失真 \(R(D) = \min_{p(\hat{x}|x)} I(X;\hat{X})\)。

??? note "课堂补充细节" 老师用对偶关系总结了香农三大定理的逻辑链条：

| 定理 | 问题 | 关键公式 | 优化方向 |
|------|------|---------|---------|
| 第一定理 | 无损压缩 | $R \geq H(X)$ | 编码效率 |
| 第二定理 | 信道传输 | $R \leq C = \max I(X;Y)$ | 最大化速率 |
| 第三定理 | 有损压缩 | $R \geq R(D) = \min I(X;\hat{X})$ | 最小化速率 |

**信道容量与率失真函数的对偶**：

| 方面 | 信道容量 | 率失真函数 |
|------|---------|-----------|
| 已知 | $p(y\|x)$（信道转移概率） | $p(x)$（信源分布） |
| 优化变量 | $p(x)$（输入分布） | $p(\hat{x}\|x)$（测试信道） |
| 目标 | $\max I(X;Y)$ | $\min I(X;\hat{X})$ |
| 凹凸性 | $I$ 关于 $p(x)$ 凹 | $I$ 关于 $p(\hat{x}\|x)$ 凸 |
| 存在性 | 最大值存在（紧凸集+凹函数） | 最小值存在（紧凸集+凸函数） |

> 老师感叹："香农把 $I(X;Y)$ 的凹凸性用得淋漓尽致——凹函数取最大值、凸函数取最小值，两者都存在且唯一。"

**正向定理的证明思想**：使用率失真典型列（联合典型序列），将 $X^n$ 的典型序列集划分为 $2^{nR}$ 个"再生球"。$n$ 足够大时，每个典型序列与最近球心的失真 $\leq D$。

??? note "配套练习" 练习：\(X \sim \text{Bernoulli}(0.4)\)，Hamming 失真。判断以下 \((R,D)\) 对是否可达： (a) \((R=0.6,\ D=0.2)\) (b) \((R=0.3,\ D=0.1)\) (c) \((R=0.5,\ D=0.4)\)

??? note "答案"
  先计算 $H_2(0.4)=0.971$，$D_{\max}=\min(0.4,0.6)=0.4$

  (a) $R(0.2)=0.971-H_2(0.2)=0.971-0.722=0.249$，$R=0.6 > 0.249$ → **可达** ✓
  (b) $R(0.1)=0.971-0.469=0.502$，$R=0.3 < 0.502$ → **不可达** ✗
  (c) $D=0.4 = D_{\max}$，$R(0.4)=0$，$R=0.5 \geq 0$ → **可达** ✓（用更多比特可以容忍更大的失真）

??? note "易错点" 1. 可达性的方向：\(R \geq R(D)\) 时可达（用更多比特），不是 \(R \leq R(D)\)——这正好与信道容量相反（\(R \leq C\) 才可达） 2. 渐进性：香农第三定理是 \(n\to\infty\) 时的渐近结果，有限长编码的实际失真可能大于 \(D\) 3. 等号情况：当 \(R = R(D)\) 时理论上可达，但需要 \(n\to\infty\) 的无限长编码 4. 与信道容量的对偶不要搞混：信道容量是最大互信息，率失真函数是最小互信息；前者优化输入分布，后者优化测试信道

2.6 率失真函数解的充要条件与参数方程（教材 §5.4、§5.7） 🟢了解

对于连续信源和平方误差失真度量，率失真函数的充要条件由以下参数方程给出（教材式 5.7.6）：

对某个 \(s < 0\)，存在 \(\lambda(x)\) 使得最优条件概率密度满足： $\(q(\hat{x}|x) = \frac{\lambda(x)}{p(\hat{x})} e^{s \cdot d(x,\hat{x})}\)$

其中归一化条件： $\(\int \lambda(x) p(x) e^{s \cdot d(x,\hat{x})} dx = 1, \quad \forall \hat{x}\)$

此时 \(R(D)\) 由参数 \(s\) 确定： $\(D(s) = \iint p(x) q(\hat{x}|x) d(x,\hat{x}) \, dx d\hat{x}\)$ $\(R(s) = sD + \int p(x) \log \lambda(x) dx\)$

??? note "课堂补充细节" 老师解释了参数方程的求解背景：

这是一个**凸函数在凸集上的极小值问题**——$I(X;\hat{X})$ 关于 $p(\hat{x}|x)$ 是凸函数，约束集 $\mathcal{Q}_D = \{p(\hat{x}|x): \mathbb{E}[d] \leq D\}$ 是凸集。

- 可用 Lagrange 乘子法求解，得到参数 $s < 0$（Lagrange 乘子）
- $s$ 的物理意义是 $R(D)$ 曲线的斜率：$s = \frac{dR}{dD}$
- 这与信道容量的 Blahut-Arimoto 算法形成对偶

> 老师说："这块推导很复杂，考试不要求，但要知道率失真函数有完整的数学刻画。"

??? note "易错点" 1. 参数 \(s\) 必须为负数，因为 \(R(D)\) 单调递减（\(dR/dD < 0\)） 2. 参数方程形式复杂，对离散信源积分变为求和 3. 对于高斯信源，最优 \(p(\hat{x})\) 也是高斯的——这验证了"反向测试信道"方法的正确性

2.7 高斯信源的率失真参数方程（教材例 5.7.1） 🟢了解

对于 \(X \sim \mathcal{N}(0, \sigma^2)\)，平方误差失真 \(d(x,\hat{x}) = (x-\hat{x})^2\)：

选择 \(p(\hat{x}) \sim \mathcal{N}(0, \sigma^2 - D)\) 和 \(q(\hat{x}|x) \sim \mathcal{N}(x, D)\)（反向测试信道），代入参数方程得到： $\(D = a, \quad R(D) = \frac{1}{2} \log\frac{\sigma^2}{D}, \quad 0 < D < \sigma^2\)$

其中 \(a\) 满足 \(\sigma^2 = a + (\sigma^2 - D)\)，验证了充要条件。

2.8 连续信源率失真函数的上下界（教材定理 5.7.1、5.7.2） 🟢了解

上界（定理 5.7.1）

令 \(X\) 是零均值、方差为 \(\sigma^2\) 的任意连续随机变量，在平方误差失真度量下： $\(R(D) \leq \frac{1}{2} \log \frac{\sigma^2}{D}, \quad 0 < D \leq \sigma^2\)$

证明思想：构造测试信道 \(q(\hat{x}|x) \sim \mathcal{N}(x, BD)\)（其中 \(B = 1 - D/\sigma^2\)），验证平均失真为 \(D\)，计算 \(I(X;\hat{X})\) 得到上界。

重要推论：在同样功率的随机变量中，高斯变量最不好压缩（需要最高的码率才能达到同样的失真）。

下限（定理 5.7.2，Shannon 下限）

对于差值失真度量 \(d(x,\hat{x}) = \rho(x-\hat{x})\)（包括平方误差）： $\(R(D) \geq R_L(D) = h(X) - \frac{1}{2} \log(2\pi e D)\)$

其中 \(h(X)\) 为信源的微分熵。该下限称为 Shannon 下限。

对于平方误差失真： $\(R_L(D) = h(X) - \frac{1}{2} \log(2\pi e D)\)$

利用熵功率 \(\bar{\sigma}^2 = \frac{1}{2\pi e}2^{2h(X)}\)，可改写为： $\(R_L(D) = \frac{1}{2} \log \frac{\bar{\sigma}^2}{D}\)$

??? note "课堂补充细节" 老师用"高斯变量的最坏情况"解释了上下界的物理意义：

**上界的构造**（定理 5.7.1）：设计测试信道 $q(\hat{x}|x) \sim \mathcal{N}(x, BD)$ 其中 $B=1-D/\sigma^2$，验证平均失真恰好为 $D$，然后计算 $I(X;\hat{X})$ 得到上界。

> "在同样功率的随机变量中，高斯变量最不好压缩——给定同样的失真 $D$，高斯信源需要最高的码率。"

**Shannon 下限**（定理 5.7.2）：利用微分熵的极值性质——在给定方差下，高斯分布的微分熵最大。因此：
$$h(X-\hat{X}|\hat{X}) \leq h(X-\hat{X}) \leq \frac12\log(2\pi e\,\mathbb{E}[(X-\hat{X})^2]) \leq \frac12\log(2\pi e D)$$

反过来得到 $R(D) \geq h(X) - \frac12\log(2\pi e D)$。

**高斯信源达到 Shannon 下限**：当 $X$ 为高斯时，$\bar{\sigma}^2=\sigma^2$，上下界重合：
$$R(D) = \frac12\log\frac{\sigma^2}{D} = h(X) - \frac12\log(2\pi e D)$$

??? note "配套练习" 练习：某连续信源 \(X\) 的微分熵 \(h(X)=2\) nat，方差 \(\sigma^2=10\)，平方误差失真 \(D=2\)。求 \(R(D)\) 的上下界并判断是否可达。

??? note "答案"
  **上界**：$\frac12\log_2(\sigma^2/D) = \frac12\log_2(10/2) = \frac12\log_2 5 \approx \frac12 \times 2.322 = 1.161$ bit

  **Shannon 下限**：$R_L = h(X) - \frac12\ln(2\pi e D) = 2 - \frac12 \times \ln(2\pi e \times 2)$
  $\ln(4\pi e) = \ln(34.14) \approx 3.530$
  $R_L = 2 - 1.765 = 0.235$ nat $= 0.235/\ln 2 \approx 0.339$ bit

  若 $X$ 是高斯的，$\bar{\sigma}^2=\sigma^2=10$，$R_L = \frac12\log(10/2)=1.161$ bit $=R(D)$，上下界重合。
  若 $X$ 不是高斯的，则 $0.339 \leq R(D) \leq 1.161$ bit，可达性取决于具体分布。

??? note "易错点" 1. 熵功率 \(\bar{\sigma}^2\) 总是小于等于真实方差 \(\sigma^2\)，等号仅在高斯分布时成立——这是熵功率不等式的直接结论 2. Shannon 下限只适用于差值失真度量（即 \(d(x,\hat{x})=\rho(x-\hat{x})\) 的形式，包括平方误差），不适用于 Hamming 失真 3. 对数底数必须一致：用 bit 作单位时用 \(\log_2\)，用 nat 作单位时用 \(\ln\)，混用会导致数量级错误 4. 上下界给出了 \(R(D)\) 的范围，但不一定紧：非高斯信源的 \(R(D)\) 在上下界之间某处

3. 典型例题

例题 1：Bernoulli 信源的 R(D) 计算

问题：\(X \sim \text{Bernoulli}(0.3)\)，Hamming 失真度量 \(d(x,\hat{x}) = \mathbf{1}\{x \neq \hat{x}\}\)。求 \(R(D)\) 在 \(D = 0,\;0.1,\;0.2,\;0.3\) 处的值。

解：

Step 1：计算信源熵 \(H(X)\)

\[H_2(0.3) = -0.3\log_2 0.3 - 0.7\log_2 0.7\]
\[ \begin{aligned} \log_2 0.3 &= \frac{\ln 0.3}{\ln 2} = \frac{-1.204}{0.693} = -1.737 \\[2pt] \log_2 0.7 &= \frac{\ln 0.7}{\ln 2} = \frac{-0.357}{0.693} = -0.515 \end{aligned} \]
\[H_2(0.3) = -0.3 \times (-1.737) - 0.7 \times (-0.515) = 0.521 + 0.360 = \boxed{0.881\ \text{bit} }\]

Step 2：确定 \(D_{\max}\)

\[D_{\max} = \min(p, 1-p) = \min(0.3, 0.7) = 0.3\]

当 \(D \geq 0.3\) 时 \(R(D) = 0\)。

Step 3：计算各 \(D\) 对应的 \(R(D)\)

根据公式 \(R(D) = H_2(0.3) - H_2(D)\)（\(0 \leq D \leq 0.3\)）：

\(D\) \(H_2(D)\) 计算 \(H_2(D)\) \(R(D) = 0.881 - H_2(D)\)
0 \(H_2(0) = 0\) 0 $\boxed{0.881} $
0.1 \(-0.1\log_2 0.1 - 0.9\log_2 0.9\) 0.469 $\boxed{0.412} $
0.2 \(-0.2\log_2 0.2 - 0.8\log_2 0.8\) 0.722 $\boxed{0.159} $
0.3 \(D = D_{\max}\)，\(R(D)=0\) — $\boxed{0} $

以 \(D=0.1\) 为例展示详细计算：

\[ \begin{aligned} H_2(0.1) &= -0.1\log_2 0.1 - 0.9\log_2 0.9 \\ &= -0.1 \times (-3.322) - 0.9 \times (-0.152) \\ &= 0.332 + 0.137 = 0.469 \\[4pt] R(0.1) &= 0.881 - 0.469 = 0.412\ \text{bit} \end{aligned} \]

结论：如果容忍 \(10\%\) 的符号错误率，只需 \(0.412\) bit/符号（无损时需要 \(0.881\) bit/符号）。

??? note "易错点" 1. \(D_{\max}=0.3\) 时 \(R(D)=0\)，不是 \(R(0.3)=H_2(0.3)\)——允许失真超过 \(D_{\max}\) 后无需任何编码 2. \(H_2(D)\) 在 \(D\in[0,0.5]\) 上单调递增，本例 \(D_{\max}=0.3\) 在该区间内，因此 \(R(D)=H_2(p)-H_2(D)\) 单调递减 3. 实际编码中 \(R(D)\) 是最小码率，实际码率可以比 \(R(D)\) 大，此时失真可以小于 \(D\) 4. \(D=0\) 时 \(R(0)=H_2(p)\) 对离散信源成立，因为 \(H_2(0)=0\)

\[D_{\max} = \sigma^2 = 4\]

当 \(D \geq 4\) 时 \(R(D) = 0\)（直接用 \(\hat{X}=0\) 估所有值，均方误差恰好为方差）。

Step 2：计算各 \(D\) 对应的 \(R(D)\)

\(D\) 计算过程 \(R(D)\) (bit)
1 \(\frac{1}{2}\log_2\frac{4}{1} = \frac{1}{2} \times 2\) $\boxed{1.000} $
2 \(\frac{1}{2}\log_2\frac{4}{2} = \frac{1}{2} \times 1\) $\boxed{0.500} $
3 \(\frac{1}{2}\log_2\frac{4}{3} = \frac{1}{2} \times 0.415\) $\boxed{0.208} $
4 \(D = D_{\max}\) $\boxed{0} $

以 \(D=3\) 为例展示详细计算：

\[ \begin{aligned} R(3) &= \frac{1}{2} \log_2 \frac{4}{3} = \frac{1}{2} \log_2 1.333 \\ \log_2 1.333 &= \frac{\ln 1.333}{\ln 2} = \frac{0.2877}{0.6931} = 0.415 \\ R(3) &= 0.5 \times 0.415 = 0.208\ \text{bit} \end{aligned} \]

物理意义：允许均方误差 \(D=3\) 时，每个符号只需 \(0.208\) bit；若要求 \(D=1\)，则需要 \(1\) bit/符号。

??? note "易错点" 1. 高斯信源 \(D_{\max}=\sigma^2\) 比 Bernoulli 信源的 \(D_{\max}\) 更容易记忆——直接用 \(\hat{X}=0\)（均值）重建 2. \(R(D)\) 公式中 \(D\) 不能取 \(0\)：\(R(0)=\frac12\log(\sigma^2/0)=\infty\)，连续信源无损编码需要无限比特 3. \(\log_2\) 计算技巧：\(\log_2 x = \frac{\ln x}{\ln 2} \approx \frac{\ln x}{0.6931}\)，熟记 \(\log_2 2=1\)、\(\log_2 3\approx1.585\)、\(\log_2 4=2\)、\(\log_2 5\approx2.322\) 可快速估算 4. \(D(R)\) 的缩放特性：\(D(R+1)=\sigma^2\cdot2^{-2(R+1)}=\frac14\cdot\sigma^2\cdot2^{-2R}=D(R)/4\)，每增加 1 bit 失真降至 \(1/4\)

例题 3：D_max 的计算

问题：\(X \sim \text{Bernoulli}(0.3)\)，Hamming 失真。求 \(D_{\max}\)，并给出达到 \(D_{\max}\) 的编码策略。

解：

Step 1：\(D_{\max}\) 的定义

\[D_{\max} = \min_{\hat{x}} \mathbb{E}[d(X, \hat{x})]\]

即：用一个固定的重建值 \(\hat{x}\) 来代表所有 \(X\) 时，能达到的最小平均失真。

Step 2：对 Bernoulli(0.3) 计算

由于 \(X \in \{0, 1\}\)，我们有两个候选重建值：

  • 若 \(\hat{x} = 0\)：失真 = \(P(X=1) = 0.7\)（所有 \(X=1\) 都错）
  • 若 \(\hat{x} = 1\)：失真 = \(P(X=0) = 0.3\)（所有 \(X=0\) 都错）
\[D_{\max} = \min\{0.7, 0.3\} = \boxed{0.3} \]

Step 3：编码策略

最优的零比特编码策略：始终输出 \(\hat{X} = 1\)（因为 \(X=1\) 的概率更大，为 \(0.7\)）。

此时平均失真 = \(P(X=0) = 0.3\)，恰好等于 \(D_{\max}\)。

推广：对任意 \(\text{Bernoulli}(p)\)，\(D_{\max} = \min(p, 1-p)\)。

??? note "配套练习" 练习：\(X \sim \text{Bernoulli}(0.2)\)，Hamming 失真。求 \(D_{\max}\) 及零比特编码策略。

??? note "答案"
  $D_{\max} = \min(0.2, 0.8) = 0.2$
  零比特编码策略：始终输出 $\hat{X}=1$（概率更大的符号 $P(X=1)=0.8$），平均失真为 $0.2$。

  若错误地选择 $\hat{X}=0$，平均失真为 $P(X=1)=0.8$，比 $D_{\max}=0.2$ 大 4 倍。

---

老师补充："注意 $D_{\max}$ 对应的零比特编码策略一定选概率最大的那个符号。"

例题 4：率失真逆问题

问题：\(X \sim \text{Bernoulli}(0.3)\)，Hamming 失真。给定码率 \(R = 0.5\) bit/符号，求可达的最小失真 \(D^*\)。

解：

Step 1：建立方程

由率失真函数 \(R(D) = H_2(0.3) - H_2(D)\)，令 \(R(D) = 0.5\)：

\[H_2(0.3) - H_2(D^*) = 0.5 \quad\Rightarrow\quad H_2(D^*) = 0.881 - 0.5 = 0.381\]

Step 2：解 \(H_2(D^*) = 0.381\)

由于 \(H_2(D)\) 在 \([0, 0.5]\) 上单调递增，我们需要找到 \(D^*\) 使得 \(H_2(D^*) \approx 0.381\)。

试探 \(D = 0.07\)：

\[ \begin{aligned} H_2(0.07) &= -0.07\log_2 0.07 - 0.93\log_2 0.93 \\ \log_2 0.07 &= -3.837,\quad \log_2 0.93 = -0.105 \\ H_2(0.07) &= -0.07 \times (-3.837) - 0.93 \times (-0.105) \\ &= 0.269 + 0.098 = 0.367 \end{aligned} \]

试探 \(D = 0.08\)：

\[ \begin{aligned} H_2(0.08) &= -0.08\log_2 0.08 - 0.92\log_2 0.92 \\ \log_2 0.08 &= -3.644,\quad \log_2 0.92 = -0.120 \\ H_2(0.08) &= -0.08 \times (-3.644) - 0.92 \times (-0.120) \\ &= 0.292 + 0.111 = 0.402 \end{aligned} \]

Step 3：线性插值

\[D^* \approx 0.07 + \frac{0.381 - 0.367}{0.402 - 0.367} \times (0.08 - 0.07) = 0.07 + \frac{0.014}{0.035} \times 0.01 = \boxed{0.074} \]

验证：

\[H_2(0.074) = -0.074\log_2 0.074 - 0.926\log_2 0.926 \approx 0.381 \quad\checkmark\]

结论：使用 \(0.5\) bit/符号编码时，可达到的最小 Hamming 失真约为 \(0.074\)（即约 \(7.4\%\) 的符号会出错）。

??? note "易错点" 1. 逆问题本质上是在解方程 \(H_2(D^*) = H_2(p)-R\)，需要数值求解，封闭解一般不存在 2. 线性插值是近似方法，精确解需要解超越方程；如果要求高精度，可以用 Newton 法迭代 3. 验证解的正确性：检查 \(D^* \leq D_{\max}\) 且 \(H_2(D^*) \approx H_2(p)-R\)，例如本例 \(D^*=0.074 < 0.3\) ✓ 4. \(D(R)\) 与 \(R(D)\) 互为反函数，但 \(D(R)\) 只在 \(R \leq H(X)\) 时有定义（离散信源）

[例 5.7.1] 平方误差失真下高斯随机变量的率失真函数

问题：考虑概率密度为 \(p(x) = \frac{1}{\sqrt{2\pi\sigma^2}} e^{-x^2/(2\sigma^2)}\) 的高斯随机变量，失真度量 \(d(x,\hat{x}) = (x-\hat{x})^2\)。求其率失真函数 \(R(D)\)。

解：

Step 1：确定 \(D_{\min}\) 和 \(D_{\max}\)

\(D_{\min} = 0\)（需要无限比特），\(D_{\max} = \sigma^2\)（取 \(\hat{x}=0\) 时）。

Step 2：构造测试信道

对 \(0 < D < \sigma^2\)，选择以下分布满足充要条件（教材式 5.7.5）：

输出再生概率密度： $\(p(\hat{x}) = \frac{1}{\sqrt{2\pi(\sigma^2 - D)}} e^{-\hat{x}^2/[2(\sigma^2 - D)]}\)$

条件概率密度（反向测试信道）： $\(q(\hat{x}|x) = \frac{1}{\sqrt{2\pi D}} e^{-(x-\hat{x})^2/(2D)}\)$

Step 3：验证充要条件

Lagrange 乘子： $\(\lambda(x) = \int p(\hat{x}) e^{s(x-\hat{x})^2} d\hat{x}\)$

取 \(s = -\frac{1}{2D}\)，代入参数方程（教材式 5.7.6）：

\[D = \iint p(x) q(\hat{x}|x) (x-\hat{x})^2 dx d\hat{x} = D \quad \checkmark\]
\[R(D) = sD + \int p(x) \log \lambda(x) dx = \frac{1}{2} \log \frac{\sigma^2}{D}\]

Step 4：最终结果

\[R(D) = \begin{cases} \dfrac{1}{2} \log_2 \dfrac{\sigma^2}{D}, & 0 < D \leq \sigma^2 \\ 0, & D > \sigma^2 \end{cases}\]

结论：高斯信源的率失真函数是 \(\frac{1}{2} \log(\sigma^2/D)\)，信源方差越大、或允许失真越小，所需码率越高。

[定理 5.7.1] 连续信源率失真函数的上界

问题：令 \(X\) 是零均值、方差为 \(\sigma^2\) 的任意连续随机变量，在平方误差失真度量下，证明： $\(R(D) \leq \frac{1}{2} \log \frac{\sigma^2}{D}, \quad 0 < D \leq \sigma^2\)$

证明：

Step 1：构造测试信道

设 \(X\) 分布为 \(p(x)\)，定义条件概率密度： $\(q(\hat{x}|x) = \frac{1}{\sqrt{2\pi BD}} \exp\left(-\frac{(\hat{x} - x)^2}{2BD}\right)\)$ 其中 \(B = 1 - D/\sigma^2\)。

Step 2：验证平均失真

\[\mathbb{E}[d] = \iint p(x) q(\hat{x}|x) (x-\hat{x})^2 dx d\hat{x}$$ $$= \int p(x) \left[BD + (B-1)^2 x^2\right] dx$$ $$= BD + (B-1)^2 \sigma^2 = D \quad \checkmark\]

因此 \(q(\hat{x}|x) \in \mathcal{Q}_D\)。

Step 3：计算互信息上界

由率失真函数定义： $\(R(D) \leq I(X;\hat{X}) = h(\hat{X}) - h(\hat{X}|X)\)$

因为 \(h(\hat{X}|X) = \frac{1}{2} \log(2\pi e BD)\)，且 \(h(\hat{X}) \leq \frac{1}{2} \log[2\pi e (\sigma^2 + BD - \sigma^2 B^2)]\)，代入化简得： $\(R(D) \leq \frac{1}{2} \log \frac{\sigma^2}{D}\)$

等号当 \(X\) 为高斯变量时成立（此时 \(\hat{X}\) 也为高斯变量）。

推论：在同样功率的随机变量中，高斯变量最不好压缩——给定同样失真 \(D\)，高斯信源需要最高的码率。

[定理 5.7.2] 率失真函数的 Shannon 下限

问题：在差值失真度量 \(d(x,\hat{x}) = \rho(x - \hat{x})\)（包括平方误差）下，推导率失真函数的 Shannon 下限。

解：

Step 1：Shannon 下限公式

对任何 \(s < 0\)，定义： $\(R_L(D) = \sup_{s<0} \left[ sD + \int p(x) \log \lambda_s(x) dx \right]\)$ 其中 \(\lambda_s(x) = \frac{p(x)}{\int e^{s\rho(z)} dz}\)。

Step 2：对平方误差失真简化

当 \(\rho(z) = z^2\) 时，\(\int_{-\infty}^\infty e^{s z^2} dz = \sqrt{-\pi/s}\)，因此： $\(\lambda_s(x) = p(x) \sqrt{-\frac{s}{\pi}} e^{-sx^2}\)$

代入并优化 \(s\)，得到： $\(R_L(D) = h(X) - \frac{1}{2} \log(2\pi e D)\)$

Step 3：用熵功率表示

由熵功率定义 \(\bar{\sigma}^2 = \frac{1}{2\pi e}2^{2h(X)}\)： $\(R_L(D) = \frac{1}{2} \log \frac{\bar{\sigma}^2}{D}\)$

Step 4：与高斯情形对比

当 \(X\) 为高斯变量时，\(h(X) = \frac{1}{2}\log(2\pi e\sigma^2)\)，\(\bar{\sigma}^2 = \sigma^2\)，此时： $\(R_L(D) = \frac{1}{2}\log\frac{\sigma^2}{D} = R(D)\)$

即高斯信源达到 Shannon 下限——对非高斯信源，真实 \(R(D)\) 介于 Shannon 下限和 \(\frac12\log(\sigma^2/D)\) 之间： $\(\frac{1}{2}\log\frac{\bar{\sigma}^2}{D} \leq R(D) \leq \frac{1}{2}\log\frac{\sigma^2}{D}\)$

[教材 §5.2.2] 高斯信源率失真函数的反向测试信道推导

问题：用反向测试信道（backward test channel）方法推导高斯信源的率失真函数。

解：

方法：建立反向测试信道 \(\hat{X} \to X\)，即 \(X = \hat{X} + Z\)，其中 \(Z \perp \hat{X}\)，\(Z \sim \mathcal{N}(0, D)\)。

约束条件：\(\mathbb{E}[X^2] = \sigma^2\)，\(\mathbb{E}[(X-\hat{X})^2] = \mathbb{E}[Z^2] = D\)。

由正交性和独立性： $\(\sigma^2 = \mathbb{E}[X^2] = \mathbb{E}[\hat{X}^2] + D \Rightarrow \mathbb{E}[\hat{X}^2] = \sigma^2 - D\)$

因此 \(\hat{X} \sim \mathcal{N}(0, \sigma^2 - D)\)（在最优解下）。

互信息计算： $\(I(X;\hat{X}) = h(X) - h(X|\hat{X}) = \frac{1}{2}\log(2\pi e\sigma^2) - \frac{1}{2}\log(2\pi e D) = \frac{1}{2}\log\frac{\sigma^2}{D}\)$

这正是率失真函数。

反向测试信道方法的优势：将约束优化问题转化为简单的加性噪声信道问题，物理意义清晰——压缩过程等价于在重建值上加一个独立高斯噪声。

题型一：\(R(D)\) 计算

题目 1（教材习题 5.1）：\(X\sim\text{Bernoulli}(0.4)\)，Hamming 失真。求 \(R(0.1)\) 和 \(R(0.2)\)。

解答要点：①\(H_2(0.4) = -0.4\log_2 0.4 - 0.6\log_2 0.6 = 0.971\) bit ②\(R(D)=H_2(p)-H_2(D)\)，\(0\leq D\leq\min(p,1-p)=0.4\) ③\(R(0.1)=0.971-0.469=0.502\)，\(R(0.2)=0.971-0.722=0.249\) bit。

题目 2（教材习题 5.2）：\(X\sim\mathcal{N}(0,9)\)，平方误差失真。求 \(R(3)\)。

解答要点：\(R(D)=\frac12\log_2(\sigma^2/D)\)，\(0<D\leq\sigma^2\)。\(R(3)=\frac12\log_2(9/3)=\frac12\log_2 3\approx 0.793\) bit/符号。

题型二：\(D_{\max}\) 计算

题目（教材习题 5.1 改编）：\(X\sim\text{Bernoulli}(0.4)\)，Hamming 失真。求 \(D_{\max}\) 及对应编码策略。

解答要点：①\(D_{\max}=\min_{\hat{x}}\mathbb{E}[d(X,\hat{x})]=\min\{P(X=1),P(X=0)\}=\min(0.4,0.6)=0.4\) ②最优零比特编码：始终输出 \(\hat{X}=1\)（概率更大的符号），平均失真 \(0.4\)。

题型三：可达到性判断

题目：\(X\sim\mathcal{N}(0,4)\)，平方误差失真。判断 \((R=0.5,D=2)\) 是否可达。

解答要点：\(R(2)=\frac12\log_2(4/2)=0.5\) bit。\(R=0.5=R(2)\)，理论上 \(n\to\infty\) 时可达。若 \(R< R(D)\)（如 \(R=0.3\)），则不可达——任何编码的失真必然大于 \(D\)。

题型四：逆问题 — 给定 \(R\) 求 \(D(R)\)

题目（教材习题 5.2 改编）：\(X\sim\mathcal{N}(0,9)\)，平方误差失真。求 \(D(0.25)\)。

解答要点：\(D(R)=\sigma^2\cdot2^{-2R}=9\times2^{-0.5}=9\times0.7071\approx 6.364\)。含义：用 \(0.25\) bit/符号编码时，最小可达均方误差约为 \(6.36\)（原始方差 \(9\) 的 \(70.7\%\)）。

题型五：连续信源的上下界

题目（教材习题 5.6）：零均值、方差 \(\sigma^2\) 的连续信源，比较 Shannon 下限与高斯上界的关系。

解答要点：①定理 5.7.1（上界）：\(R(D)\leq\frac12\log(\sigma^2/D)\)，高斯信源达到该界 ②定理 5.7.2（Shannon 下限）：\(R(D)\geq h(X)-\frac12\log(2\pi e D)=\frac12\log(\bar{\sigma}^2/D)\) ③\(\bar{\sigma}^2\leq\sigma^2\)，故 \(R_L(D)\leq\frac12\log(\sigma^2/D)\)；当且仅当 \(X\) 为高斯时 \(\bar{\sigma}^2=\sigma^2\)，上下界重合。

??? note "配套练习 — 综合练习" 综合题：某图像信源可建模为 \(X \sim \mathcal{N}(0, 100)\)，平方误差失真。压缩系统要求码率不超过 3 bit/像素。 (a) 求最小可达均方误差 (b) 如果使用标量量化（每像素独立量化），是否能达到该极限？为什么？ (c) 如果改用 1 bit/像素，失真会增大到多少？

??? note "答案"
  (a) $D(3) = \sigma^2 \cdot 2^{-2R} = 100 \times 2^{-6} = 100/64 = \boxed{1.5625} $

  (b) 不能。标量量化对应 $n=1$，率失真函数需要 $n\to\infty$ 的矢量量化才能达到极限。
  正如老师举例：1 bit 标量量化失真为 $\frac{\pi-2}{\pi}\sigma^2 \approx 0.363\sigma^2$，
  而率失真极限为 $0.25\sigma^2$，差了约 45%。

  (c) $D(1) = 100 \times 2^{-2} = \boxed{25} $

??? note "易错点 — 全章总结" 1. 率失真函数不是编码算法，而是理论极限——就像信道容量不是调制方式 2. \(R(D)\) 曲线下方不可达是信息论的根本结论，任何编码方案都不能突破 3. 证明依赖 \(n\to\infty\)：香农第三定理的证明依赖于联合典型序列和无限长编码，这一点与第一、第二定理一致 4. 反向测试信道是构造性证明的关键工具——先假设重建分布，再推导条件分布 5. 凹凸性：\(I(X;\hat{X})\) 关于 \(p(x)\) 是凹函数，关于 \(p(\hat{x}|x)\) 是凸函数，决定了信道容量和率失真函数分别有唯一的最大值和最小值
