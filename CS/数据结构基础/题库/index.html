01 算法分析（5题）

Q1: 算法分析为何关注增长率而非常数因子？

当 \(N\) 足够大时，主导项（如 \(N^2\)）决定运行时间趋势，常数项与低阶项可忽略。

Q2: \(O\)、\(\\Omega\)、\(\\Theta\) 三种记号分别描述什么？\(\\Theta\) 为何最强？

\(O\) 是上界，\(\\Omega\) 是下界，\(\\Theta\) 是紧确界（上下界同阶）。\(\\Theta\) 要求 \(O\) 与 \(\\Omega\) 同时成立，故最强。

Q3: 把 \(\\log N\)、\(N\\log N\)、\(N^2\)、\(2^N\) 按增长率从小到大排列。

\(\\log N < N\\log N < N^2 < 2^N\)。多项式远慢于对数，但指数 \(2^N\) 又远快于任何多项式。

Q4: 嵌套两层循环（外层 \(N\) 次、内层 \(N\) 次，循环体 \(O(1)\)）的总复杂度是多少？依据什么法则？

\(O(N^2)\)。依据"嵌套循环复杂度相乘"法则：\(N \\times N \\times O(1) = O(N^2)\)。

Q5: 主定理中 \(T(N)=aT(N/b)+f(N)\)，如何判断结果属于哪种情形？

比较 \(f(N)\) 与 \(N^{\\log_b a}\) 的大小：\(f\) 更小→情形1（叶子主导 \(N^{\\log_b a}\)）；相等→情形2（\(N^{\\log_b a}\\log N\)）；\(f\) 更大→情形3（根主导 \(f(N)\)）。

02 线性表/栈/队列（9题）

Q1: 数组实现线性表，访问和插入/删除的复杂度分别是多少？为什么？

访问 \(O(1)\)（下标直接寻址，连续内存）；插入/删除 \(O(N)\)（需移动后续元素）。

Q2: 循环队列如何区分空与满？

只用 front/rear 时空满都 rear==front。解决：留一个空位 \((rear+1)\\%cap==front\) 判满，或加 size 字段。

Q3: 栈的 LIFO 特性适合解决什么问题？列举两个应用。

括号匹配（最近未闭合的左括号最先处理）、后缀表达式求值（操作数入栈、运算符弹栈计算）。

Q4: 后缀表达式 3 4 + 5 × 的求值结果是多少？

\((3+4)\\times 5 = 35\)。操作数入栈，遇运算符弹两个计算。

Q5: 反转单链表的时间复杂度是多少？需要多少额外空间？

迭代法 \(O(N)\) 时间、\(O(1)\) 空间（三指针法）；递归法 \(O(N)\) 时间、\(O(N)\) 栈空间。

Q6: ADT 的核心思想是什么？

将数据与操作封装为一体，对外暴露接口、隐藏实现。同一 ADT（如 List）可由数组或链表实现，调用者不感知差异。

Q7: 动态数组扩容到 2 倍时，插入的均摊复杂度是多少？为什么？

均摊 \(O(1)\)。\(N\) 次插入总代价 \(N+N/2+N/4+\\cdots<2N\)，每次摊还 \(O(1)\)。

Q8: 循环队列用 front+size 表示时，最大容量是多少？

最大容量 = m（不是 m−1）。因为 size 字段可区分空（size==0）和满（size==m），不需要留空位。

Q9: 链表删除已知节点 p，单链表和双向链表分别需要什么条件？

单链表需要知道 p 的前驱（或用偷值法把后继值复制到 p 再删后继）；双向链表通过 p->prior 直接 \(O(1)\) 删除。

03 树（10题）

Q1: 树的递归定义包含哪两个要素？空树算不算树？

根节点 + 若干互不相交的子树（每棵本身也是树）。空树也是树。

Q2: 深度为 \(d\) 的二叉树最多有多少节点？\(N\) 个节点的二叉树最小高度是多少？

最多 \(2^{d+1}-1\) 个节点；最小高度 \(\\lceil\\log_2(N+1)\\rceil-1\)（完全平衡时）。

Q3: 完全二叉树数组存储（下标从1开始），节点 \(i\) 的父、左子、右子下标分别是多少？

父：\(\\lfloor i/2\\rfloor\)；左子：\(2i\)；右子：\(2i+1\)。

Q4: 树的四种遍历方式是什么？中序遍历 BST 有什么特殊性质？

前序（根左右）、中序（左根右）、后序（左右根）、层序（逐层）。中序遍历 BST 得到有序序列。

Q5: 由前序+中序如何重建二叉树？

前序第一个是根，在中序中定位根，左侧即左子树中序、右侧即右子树中序；递归处理。

Q6: BST 的核心性质是什么？为什么中序遍历能得到有序序列？

左子树所有值 < 根值 < 右子树所有值。中序遍历（左→根→右）天然按升序访问，故输出有序。

Q7: BST 各操作的最坏复杂度是多少？它取决于哪个量？

最坏 \(O(N)\)（退化为链表时）。复杂度正比于树高 \(h\)：平衡 \(O(\\log N)\)，退化 \(O(N)\)。

Q8: BST 在什么情况下退化为 \(O(N)\)？如何解决？

按序插入（如 \(1,2,3,\\ldots\)）退化为单链表。需用自平衡结构（如 AVL 树）。

Q9: AVL 树有哪四种失衡情形？分别用单旋还是双旋？

LL/RR（外侧失衡）用单旋，LR/RL（内侧失衡）用双旋。口诀：外侧单旋，内侧双旋。

Q10: \(N\) 个节点的 AVL 树高度上界是多少？

\(h < 1.44\\log_2(N+2) - 0.328\)，仍是对数级，保证所有操作 \(O(\\log N)\)。

04 优先队列/堆（7题）

Q1: 二叉堆的两个核心性质是什么？

结构性（完全二叉树）+ 堆序性（父 \(\\le\) 子或父 \(\\ge\) 子）。结构性保证可用数组紧凑存储无空洞。

Q2: 数组存储堆时（下标从1开始），节点 \(i\) 的父、左子、右子下标分别是多少？

父：\(\\lfloor i/2\\rfloor\)；左子：\(2i\)；右子：\(2i+1\)。

Q3: 插入新元素时先放哪里？上滤的复杂度是多少？

先放数组末尾（保持结构性），再向上与父比较交换。最坏 \(O(\\log N)\)（沿树高）。

Q4: DeleteMin 时把哪个元素搬到根？下滤时为何要选较小的子节点比较？

把最后一个元素搬到根。选较小子节点上移才能保持父 \(\\le\) 子；选较大的会破坏堆序。

Q5: BuildHeap 为何是 \(O(N)\) 而非 \(O(N\\log N)\)？

堆中大多数节点在底层，底层节点 PercolateDown 几乎不动。\(\\sum h\\cdot N/2^{h+1} = O(N)\)，指数衰减使总和收敛。

Q6: d-堆的树高是多少？为什么适合插入多、删除少的场景？

树高 \(\\log_d N\)（比二叉堆浅），插入 \(O(\\log_d N)\) 更快；但 DeleteMin 需比较 \(d\) 个子代价 \(O(d)\)，删除多则不利。

Q7: 堆排序的两个阶段是什么？为何不稳定？

先 BuildHeap \(O(N)\)，再反复取最大放末尾 + PercolateDown。不稳定因为 PercolateDown 的交换会打乱相等元素相对顺序。

05 排序（8题）

Q1: 插入排序的最佳时间复杂度是多少？在什么情况下出现？

最佳 \(O(N)\)，数据已有序时出现。每趟只比较一次、不移动。

Q2: 为什么希尔排序的增量序列要求相邻互素？

增量不互素时不同趟排序比较的位置集合重叠，效率低下。Hibbard 增量 \(2^k-1\) 相邻互素，最坏 \(\\Theta(N^{3/2})\)。

Q3: 堆排序的两个阶段是什么？时间复杂度如何？

先 BuildHeap \(O(N)\) 建堆，再反复取最大放末尾 + PercolateDown。整体 \(O(N\\log N)\)（最坏也是），原地，不稳定。

Q4: 归并排序的时间递推式是什么？为何稳定？

\(T(N) = 2T(N/2) + O(N) \\implies T(N) = O(N\\log N)\)。合并时相等元素先取左侧（<=），相对顺序不变，故稳定。

Q5: 快排的最坏时间复杂度是多少？什么情况下出现？如何避免？

最坏 \(O(N^2)\)，分区极度不平衡（如有序输入固定选首/尾）时出现。用三数中值分割法使枢轴接近中位数。

Q6: 桶排序的期望时间复杂度是多少？什么情况下退化为最坏？

期望 \(O(N)\)（数据均匀时）；最坏 \(O(N^2)\)（数据全落在一个桶）。

Q7: 基数排序的时间复杂度公式是什么？为何要求低位优先且每趟稳定？

\(O(d \\cdot N)\)，\(d\) 为位数。从最低位开始每趟用稳定排序，使高位排序时高位相同的元素保持低位排序的相对顺序。

Q8: 给第1趟结果如何反推排序方法？

前段+后段都局部有序但两端都不全到位 → merge sort；只有最小元到位 → 选择/冒泡；无元素到最终位 → quicksort。

06 散列（7题）

Q1: 取模哈希中，模数 \(M\) 为何通常选素数？

若 \(M\) 含小因子（如 \(2^k\)），而键的分布也含该因子结构，哈希值会聚集到少数槽位；素数 \(M\) 使 \(x\\bmod M\) 对各种键分布都接近均匀。

Q2: 线性探测为何产生一次聚集？平方探测为何产生二次聚集？

线性：冲突键都走 \(+1,+2,\\ldots\)，形成连续块。平方：哈希值相同的键走相同序列互相碰撞（未消除"哈希值相同"导致的聚集）。

Q3: 再散列单次 \(O(N)\)，为何平均仍 \(O(1)\)？

摊还分析：表从 \(M\) 扩到 \(2M\) 期间可插入约 \(\\lambda_0 M\) 个元素（每个 \(O(1)\)），再散列 \(O(M)\) 摊到 \(\\lambda_0 M\) 次上得 \(O(1)\)。

Q4: Robin Hood 哈希的核心思想是什么？

"劫富济贫"——让探测距离远的"穷"键抢探测距离近的"富"键的位置，使所有键的探测距离尽量接近，降低最坏情况。

Q5: Robin Hood 哈希如何实现查找的提前终止？

沿探针序列前进时各位置 Disp 单调不减。查找时一旦 Disp > CurrentDisp 即可提前终止——\(x\) 不在表中。把最坏查找从 \(O(N)\) 降到 \(O(\\log N)\)。

Q6: \(\\lambda\)（负载因子）如何影响哈希表性能？

\(\\lambda = N/M\)。\(\\lambda\) 越小查找越快（冲突少）；\(\\lambda\) 接近 1 时性能急剧下降。开放定址要求 \(\\lambda < 1\)；平方探测要求 \(\\lambda \\le 0.5\) 保证成功。

Q7: 双散列如何消除聚集？

用 hash2(x) 给每个键不同的步长，使哈希值相同的键也走不同路径，接近无聚集。

07 并查集（4题）

Q1: 等价关系需要满足哪三个性质？

自反性（\(a\\sim a\)）、对称性（\(a\\sim b\\Rightarrow b\\sim a\)）、传递性（\(a\\sim b,\\ b\\sim c\\Rightarrow a\\sim c\)）。

Q2: Union by Size 如何合并两棵树？保证的树高上界是多少？

将较小树的根指向较大树，保证树高 \(\\le\\log_2 N\)，即 Find \(=O(\\log N)\)。

Q3: 路径压缩如何把 Find 降到近 \(O(1)\)？

Find(x) 时把从 x 到根路径上所有节点的父指针直接指向根——路径被"拍扁"为高度 1。后续该路径上所有节点的 Find 都 \(O(1)\)。

Q4: Union by Size + Path Compression 的均摊复杂度是多少？

\(O(\\alpha(N))\)，其中 \(\\alpha\) 是反阿克曼函数，\(N\\le 10^{540}\) 时 \(\\alpha(N)\\le 4\)，实际是常数。

08 图算法（9题）

Q1: 稠密图应选邻接矩阵还是邻接表？为什么？

邻接矩阵。稠密图 \(E \\approx V^2\)，矩阵 \(O(V^2)\) 空间与边数相当，且判邻 \(O(1)\)；邻接表判邻需 \(O(\\deg(v))\)。

Q2: 为什么 BFS 能求无权图最短路径，而 DFS 不能？

BFS 逐层扩展，先访问到的顶点距离最短，满足"层 = 距离"。DFS 深度优先，先到的不一定最短。

Q3: Dijkstra 为什么要求边权非负？

贪心选最小距离顶点入 \(S\) 后假定其距离不再更新；负边会破坏该不变量（后续顶点经负边可得更小值），故失效。

Q4: Bellman-Ford 为什么要松弛 \(V-1\) 轮？如何检测负权环？

最短路径最多 \(V-1\) 条边，第 \(k\) 轮得到最多 \(k\) 条边路径。第 \(V\) 轮仍能松弛则存在负环。

Q5: Kruskal 如何判断加边会形成环？用什么数据结构？

用并查集：若边的两端点在同一集合则会成环，跳过；否则合并两集合并加入该边。

Q6: Prim 每次选什么样的边？与 Kruskal 视角有何不同？

Prim 每次选连接已选集合 \(S\) 与 \(V\\setminus S\) 的最小横切边（顶点视角）。Kruskal 全局按边权排序加入（边视角）。

Q7: 最大流与最小割容量有何关系？

最大流值 = 最小割容量。当残量图中无 \(s\\to t\) 增广路径时，当前流即最大流。

Q8: 非根节点 \(u\) 成为关节点的充要条件是什么？

存在子 \(v\) 使 \(\\text{low}[v] \\ge \\text{num}[u]\)，即 \(v\) 子树无法绕过 \(u\) 回到 \(u\) 的祖先，删 \(u\) 后不连通。

Q9: 求有向图 SCC 的常见算法及其复杂度？

Tarjan 或 Kosaraju 算法，基于 DFS，复杂度均为 \(O(V + E)\)。
