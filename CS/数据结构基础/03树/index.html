03 树与搜索树（Trees & Search Trees）

树是一种"一对多"的分层结构，是计算机科学中应用最广泛的数据结构之一。本章从树的基本概念出发，深入二叉搜索树及其平衡变体（AVL），并介绍 B 树与线段树等扩展。

1. 树的基本概念

1.1 递归定义与术语

自测

Q: 树的递归定义包含哪两个要素？空树算不算树？

答案

根节点 + 若干互不相交的子树（每棵本身也是树）。空树也是树。

树的递归定义：一棵树是由根节点及若干棵互不相交的子树（每棵本身也是树）构成的集合。空树也是树。

关键术语：

术语 定义
度（degree） 节点拥有的子树个数
叶子（leaf） 度为 0 的节点
深度（depth） 从根到该节点的边数（根深度为 0）
高度（height） 从该节点到最深叶子的边数（叶子高度为 0）
层（level） 深度相同的节点属同一层

1.2 二叉树（Binary Tree）

自测

Q: 深度为 \(d\) 的二叉树最多有多少节点？\(N\) 个节点的二叉树最小高度是多少？

答案

最多 \(2^{d+1}-1\) 个节点；最小高度 \(\lceil\log_2(N+1)\rceil-1\)（完全平衡时）。

每个节点最多有两个子节点：左子树和右子树，左右不可交换（区别于一般的树）。

重要性质：

  • 深度为 \(d\) 的二叉树最多有 \(2^{d+1}-1\) 个节点。
  • \(N\) 个节点的二叉树，高度至少为 \(\lceil\log_2(N+1)\rceil-1\)（完全平衡时）。
  • 满二叉树（full）：每个节点要么是叶子，要么有 2 个子节点。
  • 完全二叉树（complete）：除最后一层外全满，且最后一层从左到右连续。
  • 完美二叉树（perfect）：所有内部节点都有 2 子，所有叶子同层（共 \(2^{h+1}-1\) 个节点）。
完全二叉树的数组存储

完全二叉树可用数组紧凑存储（下标从 1 开始）：节点 \(i\) 的父节点为 \(\lfloor i/2\rfloor\)，左子为 \(2i\)，右子为 \(2i+1\)。这是堆（第 04 章）的基础。

2. 树的遍历（Tree Traversals）

遍历方式 顺序 典型应用
前序（Preorder） 根 \(\to\) 左 \(\to\) 右 复制树、前缀表达式
中序（Inorder） 左 \(\to\) 根 \(\to\) 右 BST 排序输出（有序）
后序（Postorder） 左 \(\to\) 右 \(\to\) 根 求树高度、释放内存
层序（Level-order） 逐层从左到右 BFS、最短路径
遍历的实现与复杂度

前序/中序/后序既可递归（\(O(N)\) 时间、\(O(h)\) 栈空间）也可用显式栈迭代实现；层序用队列实现。对一棵 \(N\) 节点的树，四种遍历都是 \(O(N)\)。

由前序 + 中序重建二叉树：前序第一个是根，在中序中定位根，左侧即左子树中序、右侧即右子树中序；递归处理。这是常考的构造题。

课堂代码：二叉树四种遍历 
/* 前序：根 → 左 → 右（用于复制树、前缀表达式） */
void preorder( tree_ptr tree ) {
    if ( tree ) {
        visit( tree );
        preorder( tree->Left );
        preorder( tree->Right );
    }
}

/* 中序：左 → 根 → 右（BST 中序得有序序列） */
void inorder( tree_ptr tree ) {
    if ( tree ) {
        inorder( tree->Left );
        visit( tree->Element );
        inorder( tree->Right );
    }
}

/* 后序：左 → 右 → 根（用于释放内存、求高度） */
void postorder( tree_ptr tree ) {
    if ( tree ) {
        postorder( tree->Left );
        postorder( tree->Right );
        visit( tree->Element );
    }
}

/* 层序：逐层从左到右（用队列，BFS） */
void levelorder( tree_ptr tree ) {
    enqueue( tree );
    while ( queue is not empty ) {
        T = dequeue();
        visit( T );
        if ( T->Left )  enqueue( T->Left );
        if ( T->Right ) enqueue( T->Right );
    }
}

要点：前/中/后序仅 visit 的位置不同（根在前/中/后），代码几乎对称；层序改用队列实现 BFS，逐层扩展。中序遍历 BST 得升序序列——这是 BST 的标志性应用。

课堂代码：中序遍历的迭代实现（用栈） 
void iter_inorder( tree_ptr tree ) {
    Stack S = CreateStack( MAX_SIZE );
    for ( ; ; ) {
        for ( ; tree; tree = tree->Left )   /* 一路向左压栈 */
            Push( tree, S );
        if ( IsEmpty( S ) )  break;
        tree = Top( S ); Pop( S );          /* 弹出栈顶访问 */
        visit( tree->Element );
        tree = tree->Right;                 /* 转向右子树 */
    }
}

要点：模拟递归的栈行为——先把左链一路压栈，弹出时访问并转向右子。用显式栈替代递归调用栈，避免深树栈溢出。

课堂例题：表达式树

表达式 \((a+b)\times c\) 的表达式树：

      ×
     / \
    +   c
   / \
  a   b
  • 前序遍历得前缀表达式：× + a b c
  • 中序遍历得中缀表达式（加括号）：((a+b)×c)
  • 后序遍历得后缀表达式：a b + c ×

后缀表达式无需括号即能被栈机求值——这是树遍历的经典应用。

3. 二叉搜索树（BST）

3.1 性质

自测

Q: BST 的核心性质是什么？为什么中序遍历能得到有序序列？

答案

左子树所有值 < 根值 < 右子树所有值。中序遍历（左→根→右）天然按升序访问，故输出有序。

对任意节点，左子树所有值 < 根值 < 右子树所有值。这一性质使中序遍历得到有序序列——这是 BST 最有用的特征。

3.2 基本操作

自测

Q: BST 各操作的最坏复杂度是多少？它取决于哪个量？

答案

最坏 \(O(N)\)（退化为链表时）。复杂度正比于树高 \(h\)：平衡 \(O(\log N)\)，退化 \(O(N)\)。

操作 平均复杂度 最坏复杂度
Find(x) \(O(\log N)\) \(O(N)\)
FindMin() / FindMax() \(O(\log N)\) \(O(N)\)
Insert(x) \(O(\log N)\) \(O(N)\)
Delete(x) \(O(\log N)\) \(O(N)\)

所有操作的复杂度正比于树高 \(h\)：平衡时 \(h=O(\log N)\)，退化为链表时 \(h=O(N)\)。

课堂代码：BST 的 Find / FindMin / FindMax 
/* 递归查找 */
SearchTree Find( ElementType X, SearchTree T ) {
    if ( T == NULL )
        return NULL;                  /* not found in an empty tree */
    if ( X < T->Element )
        return Find( X, T->Left );
    else if ( X > T->Element )
        return Find( X, T->Right );
    else
        return T;                     /* found */
}

/* 迭代查找（等价，避免递归开销） */
Position Iter_Find( ElementType X, SearchTree T ) {
    while ( T ) {
        if ( X == T->Element ) return T;       /* found */
        if ( X <  T->Element ) T = T->Left;
        else                    T = T->Right;
    }
    return NULL;                     /* not found */
}

/* 递归找最小值：一路向左走到底 */
Position FindMin( SearchTree T ) {
    if ( T == NULL )
        return NULL;                 /* not found in an empty tree */
    else if ( T->Left == NULL )
        return T;                     /* 最左叶子即最小 */
    else
        return FindMin( T->Left );
}

/* 迭代找最大值：一路向右走到底 */
Position FindMax( SearchTree T ) {
    if ( T != NULL )
        while ( T->Right != NULL )
            T = T->Right;            /* keep moving to find rightmost */
    return T;
}

要点：BST 查找每次根据"左小右大"二选一方向，\(O(h)\)。FindMin 一路向左、FindMax 一路向右——均到叶子。递归版清晰但占栈空间，迭代版 FindMax 是范式。

课堂代码：BST 的 Insert 
SearchTree Insert( ElementType X, SearchTree T ) {
    if ( T == NULL ) {               /* Create and return a one-node tree */
        T = malloc( sizeof( struct TreeNode ) );
        if ( T == NULL )
            FatalError( "Out of space!!!" );
        else {
            T->Element = X;
            T->Left = T->Right = NULL;
        }
    }
    else if ( X < T->Element )
        T->Left  = Insert( X, T->Left );
    else if ( X > T->Element )
        T->Right = Insert( X, T->Right );
    /* else X is in the tree already; do nothing */
    return T;
}

要点：递归到空位即插入新节点，返回时沿调用栈把新节点挂回父节点。注意 T = Insert(...) 的返回值赋回——这是"函数式更新"风格，保证父指针正确链接。

BST 删除的三种情况（重点）
  1. 叶子节点：直接删除。
  2. 一个子节点：用子节点替代被删节点。
  3. 两个子节点：用右子树最小值（或左子树最大值）替换被删节点的值，再递归删除那个最小值节点（它最多有一个右子，回到情形 1 或 2）。

情形 3 的关键：选右子树最小值替换，保证替换后左 < 根 < 右的性质仍成立（右子树最小值 > 被删节点，且 < 右子树其余值）。

// BST 删除（情形3：两个子节点）
void Delete( ElementType X, SearchTree T ) {
    Position TmpCell;
    if ( T == NULL )  Error( "Element not found" );
    else if ( X < T->Element )  T->Left  = Delete( X, T->Left );
    else if ( X > T->Element )  T->Right = Delete( X, T->Right );
    else {  /* found the element to delete */
        if ( T->Left && T->Right ) {              /* 情形3：两个子节点 */
            TmpCell = FindMin( T->Right );         /* 右子树最小值 */
            T->Element = TmpCell->Element;
            T->Right = Delete( T->Element, T->Right );  /* 递归删那个最小值 */
        } else {                                   /* 情形1,2：0 或 1 个子 */
            TmpCell = T;
            if ( T->Left == NULL )        T = T->Right;
            else if ( T->Right == NULL )  T = T->Left;
            free( TmpCell );
        }
    }
    return T;
}
课堂代码：线索二叉树（Threaded Tree）节点定义 
typedef struct ThreadedTreeNode *PtrToThreadedNode;
typedef struct PtrToThreadedNode ThreadedTree;
struct ThreadedTreeNode {
    ElementType          Element;
    PtrToThreadedNode    Left;
    PtrToThreadedNode    Right;
    bool                 LeftThread;    /* Left  是线索(指前驱)还是真左子 */
    bool                 RightThread;   /* Right 是线索(指后继)还是真右子 */
};

要点：利用空指针域存前驱/后继线索，使中序遍历无需栈、可双向遍历。LeftThread=true 时 Left 指向中序前驱，RightThread=true 时 Right 指向中序后继——把空指针"废物利用"的经典技巧。

3.3 缺陷

自测

Q: BST 在什么情况下退化为 \(O(N)\)？如何解决？

答案

按序插入（如 \(1,2,3,\ldots\)）退化为单链表。需用自平衡结构（如 AVL 树）。

最坏情况退化为单链表（如按序插入 \(1,2,3,\ldots\)），所有操作退化为 \(O(N)\)——这正是 AVL 树要解决的问题。

4. AVL 树

AVL 树（Adelson-Velsky 和 Landis, 1962）是自平衡二叉搜索树，任一节点的左右子树高度差 \(\le 1\)（平衡因子 \(\in\{-1,0,1\}\)）。这保证树高 \(h=O(\log N)\)。

4.1 四种失衡与旋转

自测

Q: AVL 树有哪四种失衡情形？分别用单旋还是双旋？

答案

LL/RR（外侧失衡）用单旋，LR/RL（内侧失衡）用双旋。口诀：外侧单旋，内侧双旋。

插入节点后若某节点失衡，根据插入位置分四种情形，用对应旋转恢复平衡：

失衡情形 插入位置 旋转方式
LL（左左） 在左子树的左子树插入 右单旋（单旋）
RR（右右） 在右子树的右子树插入 左单旋（单旋）
LR（左右） 在左子树的右子树插入 先左旋后右旋（双旋）
RL（右左） 在右子树的左子树插入 先右旋后左旋（双旋）

AVL 树保证：所有操作（查找/插入/删除）均为 \(O(\log N)\)。

单旋与双旋的区别
  • 单旋（LL/RR）：一次旋转即可恢复平衡，因为失衡发生在"外侧"。
  • 双旋（LR/RL）：需要两次旋转——先旋转子树把它变成 LL/RR 情形，再做单旋。因为失衡发生在"内侧"，一次旋转不够。

记忆：外侧失衡单旋，内侧失衡双旋。

课堂例题：AVL 插入序列

依次插入 3, 2, 1, 4, 5, 6, 7，画出每次插入后的 AVL 树：

  1. 插 3,2,1 → 插 1 后根 3 失衡（LL），右单旋 → 根变 2。
  2. 插 4,5 → 插 5 后 3 失衡（RR），左单旋 → 4 为根的右子。
  3. 插 6 → 根 2 失衡（RR），左单旋 → 根变 4，左子 2、右子 6。
  4. 插 7 → 6 失衡（RR），左单旋。

最终得到平衡的 AVL 树，高度 \(\approx\log_2 7\approx3\)。

4.2 AVL 高度界

自测

Q: \(N\) 个节点的 AVL 树高度上界是多少？这保证了什么？

答案

\(h < 1.44\log_2(N+2) - 0.328\)，仍是对数级，保证所有操作 \(O(\log N)\)。

\(N\) 个节点的 AVL 树高度 \(h\) 满足：

\[ \log_2(N+1) \le h < 1.44\log_2(N+2) - 0.328 \]

即最坏情况下 AVL 树高度不超过 \(1.44\log N\)——比理想平衡略差，但仍是对数级。

5. B 树基础

B 树是一种多路平衡搜索树（\(m\) 阶 B 树），每个节点可包含多个键和多个子节点，广泛用于数据库和文件系统（减少磁盘 I/O）。

  • 所有叶子在同一深度。
  • 每个非根节点的键数范围：\(\lceil m/2\rceil-1\) 到 \(m-1\)；子节点数 \(\lceil m/2\rceil\) 到 \(m\)。
  • 根节点若非叶子，至少有 2 个子节点。
  • 插入和删除通过分裂（节点溢出）与合并（节点过空）保持平衡。
为什么 B 树适合磁盘

磁盘 I/O 以"块"为单位，读一个块代价远大于块内计算。B 树让每个节点装满一个磁盘块（多个键），使树变"矮胖"——\(N\) 个键的 B 树高度约 \(\log_m N\)，I/O 次数大幅减少。这是数据库索引（B+ 树）的理论基础。

6. 线段树（Segment Tree，课堂补充专题）

线段树是课堂补充的高效数据结构，用于频繁区间查询与单点更新。

6.1 动机

自测

Q: 线段树解决什么问题？把朴素区间求和的什么复杂度降到了什么？

答案

频繁区间查询与单点更新；把朴素 \(O(N)\) 区间求和降到 \(O(\log N)\)。

给定数组 \(A[1000000]\)，频繁求任意区间 \([L,R]\) 内元素之和：

ElementType Query( ElementType A[], int L, int R ) {
    ElementType sum = 0;
    for ( int i = L; i <= R; ++i )  sum += A[i];
    return sum;     // T(N) = O(N) —— 作为频繁操作太慢
}

朴素法每次查询 \(O(N)\)。线段树把它降到 \(O(\log N)\)。

6.2 结构

自测

Q: 线段树是什么形态的树？每个节点存储什么？

答案

完全二叉树，每个节点对应数组一个区间并存储该区间的聚合值（如和、最值）。

线段树是一棵完全二叉树，每个节点对应数组的一个区间，存储该区间的聚合值（如和、最值）：

  • 根节点对应整个区间 \([0, n-1]\)。
  • 每个节点把区间对半分给左右子。
  • 叶子节点对应单个元素。

例如数组 A[5] 的线段树（节点存区间和）：

        [0,4]=25
        /      \
    [0,2]=14    [3,4]=11
    /    \      /    \
 [0,1]=9 [2]=5 [3]=8 [4]=3
  /   \
[0]=7 [1]=2

完全二叉树可用数组紧凑存储：int tree[2*N]，节点 \(i\) 的左右子为 \(2i, 2i+1\)。

课堂代码：线段树建树 Build 
int A[5];            /* 原始数据 */
int tree[2 * N];     /* 线段树数组 */

void Build( int node, int start, int end ) {
    if ( start == end ) {                 /* 叶子节点 */
        tree[node] = A[start];
        return;
    }
    int mid = ( start + end ) / 2;
    Build( 2 * node,     start, mid );    /* 左子 */
    Build( 2 * node + 1, mid + 1, end );  /* 右子 */
    tree[node] = tree[2 * node] + tree[2 * node + 1];  /* 合并：求和 */
}

要点：后序递归——先递归建左右子，再把子和汇总到父节点。叶子存单元素，内部节点存区间和。整体 \(O(N)\)（每个节点访问一次）。

课堂代码：线段树区间查询 Query 
int Query( int node, int start, int end, int L, int R ) {
    if ( R < start || end < L )           /* Case 1: 不相交，返回单位元 */
        return 0;
    if ( L <= start && end <= R )         /* Case 2: 完全包含，直接返回 */
        return tree[node];
    /* Case 3: 部分相交，递归左右子合并 */
    int mid = ( start + end ) / 2;
    int left_sum  = Query( 2 * node,     start, mid, L, R );
    int right_sum = Query( 2 * node + 1, mid + 1, end, L, R );
    return left_sum + right_sum;
}

要点：三情况剪枝——不相交返回 0、完全包含直接取节点值、否则递归合并。完全包含的节点最多 \(O(\log N)\) 个，故查询 \(O(\log N)\)。这是线段树的核心思想。

课堂代码：线段树单点更新 Update 
void Update( int node, int start, int end, int idx, int val ) {
    if ( start == end ) {                 /* 叶子节点，更新值 */
        tree[node] = val;
        return;
    }
    int mid = ( start + end ) / 2;
    if ( start <= idx && idx <= mid )
        Update( 2 * node,     start, mid, idx, val );     /* 在左子 */
    else
        Update( 2 * node + 1, mid + 1, end, idx, val );  /* 在右子 */
    tree[node] = tree[2 * node] + tree[2 * node + 1];     /* 回溯更新祖先 */
}

要点：沿路径下到叶子改值，回溯时更新路径上所有祖先。单条路径长度 \(O(\log N)\)，故单点更新 \(O(\log N)\)。注意最后一步的"回溯汇总"是关键——否则祖先节点的区间和会过期。

6.3 操作与复杂度

自测

Q: 线段树建树、区间查询、单点更新的复杂度各是多少？

答案

建树 \(O(N)\)，区间查询 \(O(\log N)\)，单点更新 \(O(\log N)\)。

操作 复杂度 说明
建树 build \(O(N)\) 后序递归，子节点和汇总到父节点
区间查询 query(L,R) \(O(\log N)\) 递归到完全被覆盖的节点直接取值
单点更新 update(i, val) \(O(\log N)\) 改叶子后沿路径更新祖先
区间查询的剪枝思想

查询 \([L,R]\) 时递归到某节点对应区间 \([l,r]\)：

  • 若 \([l,r]\subseteq[L,R]\)（完全包含）：直接返回该节点存的值，不往下走。
  • 若 \([l,r]\cap[L,R]=\varnothing\)（不相交）：返回 0/单位元，不往下走。
  • 否则：递归左右子，合并结果。

完全包含的节点最多 \(O(\log N)\) 个，故查询 \(O(\log N)\)。

线段树 vs 树状数组
  • 线段树：支持任意区间查询 + 单点更新，\(O(\log N)\)；可扩展到区间更新（lazy 标记）。
  • 树状数组（BIT）：更轻量，仅支持前缀查询 + 单点更新，\(O(\log N)\)；常数更小。

需要区间最值、区间非可减聚合（如 max/min）时只能用线段树；前缀和类问题树状数组更优。

本章小结

  • 二叉树是最基本的分层结构，遍历方式决定处理顺序；中序遍历 BST 得有序序列。
  • BST 利用中序有序性实现 \(O(\log N)\) 平均查找，但按序插入会退化为 \(O(N)\)。
  • AVL 树通过四种旋转严格维持平衡，保证最坏 \(O(\log N)\)。
  • B 树扩大分支因子，减少磁盘 I/O，是数据库索引的基础。
  • 线段树支持高效的区间查询与单点更新（\(O(\log N)\)），适合频繁区间操作。
