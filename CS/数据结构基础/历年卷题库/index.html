2015-2016-M1-Q1-3. The Fibonacci number sequence {F_N} is defined as: F_0=0, F_1=1, F_N=F_{N-1}+F_{N-2}, N=2, 3, .... The time complexity of the function which calculates F_N iteratively is Θ(F_N). (1分) - T / F

F（迭代求 F_N 为 O(N)，而 F_N 指数增长，Θ(F_N) 远大于 O(N)）

2015-2016-M1-Q1-9. There exists a binary tree with 2016 nodes in total, and with 16 nodes having only one child. (1分) - T / F

bool IsTopSeq( LGraph Graph, Vertex Seq[] ){
    int Indegree[MaxVertexNum];
    int i;
    PtrToAdjVNode T;
    for(i=0;i<MaxVertexNum;i++) Indegree[i]=0;
    for(i=0;i<Graph->Nv;i++){
        T=Graph->G[i].FirstEdge;
        while(T){ Indegree[T->AdjV]++; T=T->Next; }

    for(i=0;i<Graph->Nv;i++){
        int V=Seq[i]-1;          /* 顶点编号从 1 起，下标从 0 起 */

    }
    return true;
}

typedef struct GNode *PtrToGNode;
struct GNode {
    int NV;  /* number of vertices */
    int Ne;  /* number of edges */
    int G[MaxVertexNum][MaxVertexNum];  /* adjacency matrix */
};
typedef PtrToGNode MGraph;

where MaxVertexNum is a constant defined by the judge. The indices of the vertices in the resulting independent set is stored in the array int S[]. Note that the vertices are indexed from 1 to the number of vertices NV. However, the indices of the adjacency matrix G starts from 0. The function Independent_Set is supposed to follow the above algorithm to produce an independent set, save the results in S, and return the number of vertices in S.

Sample Input: 

8
1 5
5 4
2 3
3 6
6 2

Sample Output: 

1 2 7 8

Note: This method can help us find an independent set, but not necessarily a maximum independent set. For example, the maximum solution of the sample graph is {1, 3, 4, 7, 8}.

参考答案 
int Independent_Set(MGraph G, int S[]) {
    int top = 0, i;
    int *flag = (int*)malloc((1 + G->NV) * sizeof(int));

    for (i = 1; i <= G->NV; i++) {
        flag[i] = 0;
    }

    while (1) {
        int index = 1;
        while (index <= G->NV && flag[index] != 0) {
            index++;
        }
        if (index > G->NV) break;

        flag[index] = 1;
        S[top++] = index;

        for (i = 0; i < G->NV; i++) {
            if (G->G[index - 1][i] != 0) {
                flag[i + 1] = 1;
            }
        }
    }
    return top;
}

        if ( L < R ) Swap( &A[L], &A[R] );
        else break;
    }
    Swap( &A[Left], &A[R] );
    if ( K < (L-Left) )
        return Qselect(A, K, Left, R-1);
    else if ( K > (L-Left) )
        return Qselect(A,   ②  , R+1, Right);   /* (3分) */
    else
        return Pivot;
}

答案

① A[--R] > Pivot ② K - (L - Left)

第三部分：常用结论速记

从历年卷反复出现的"结论型"考点，每条一行，简洁直接。

复杂度结论

  • 仅基于比较的排序，最坏时间复杂度下界 \(O(N\log N)\)。
  • 归并排序趟数 \(O(\log N)\)，每趟 \(O(N)\)，总 \(O(N\log N)\)。
  • 堆排序平均/最坏均 \(O(N\log N)\)，额外空间 \(O(1)\)，不稳定。
  • 希尔排序不稳定；插入排序稳定；归并排序稳定；快排不稳定。
  • 建堆线性算法复杂度 \(O(N)\)（非 \(O(N\log N)\)，因底层节点下滤少）。
  • 快排最坏 \(O(N^2)\)（有序输入 + 固定选首/尾枢轴）；三数中值可缓解。
  • 快排所有元素相等时：指针停止 → \(O(N\log N)\)；指针不停止 → \(O(N^2)\)。
  • BST 退化为链表时查找 \(O(N)\)；平衡时 \(O(\log N)\)。
  • 二叉查找（折半）恒 \(O(\log N)\)，与 BST 不同。
  • 斐波那契递归 \(T(N)=O(F_N)\) 指数级；迭代 \(O(N)\)；递归空间 \(O(N)\)。
  • \((\log N)^k = O(N)\)（对数多项式慢于任何正幂）。
  • 桶排序期望 \(O(N)\)，最坏 \(O(N^2)\)（全落一桶）。
  • 基数排序 \(O(d\cdot N)\)，\(d\) 为位数，要求每趟稳定。

树的结论

  • 完全二叉树数组存储（根下标 1）：父 \(\lfloor i/2\rfloor\)，左子 \(2i\)，右子 \(2i+1\)。
  • 节点 \(i\) 与 \(i+1\) 同层 ↔ \(i\) 在该层最后一个之前。
  • \(N\) 个节点二叉树最小高度 \(\lceil\log_2(N+1)\rceil-1\)，最大 \(N-1\)。
  • 树转二叉树：先根遍历 = 二叉树先序；后根遍历 = 二叉树中序。
  • 先序+后序相反 ↔ 每个非叶节点只有一个孩子（树退化为链，高度=节点数-1）。
  • 先序+中序 / 中序+后序 可唯一确定二叉树；先序+后序不能。
  • 叶子节点在先/中/后序中的相对顺序不变。
  • 中序遍历 BST 得升序序列。
  • BST 插入 1025 节点最坏比较 [11, 1024]（高度+1 到节点数）。
  • BST 含 4,5,6 且 4、6 同层 → 5 必为公共祖先（未必是父）。
  • AVL：LL/RR 单旋，LR/RL 双旋；\(N\) 节点高度 \(<1.44\log_2(N+2)-0.328\)。
  • 线索二叉树：无左子→左线索指前驱；无右子→右线索指后继。

堆的结论

  • 二叉堆 = 完全二叉树（结构性）+ 父≤子或父≥子（堆序性）。
  • 最大堆根到任一节点路径非递增。
  • 最大堆中最小元必在叶子（下标 \(\lfloor n/2\rfloor+1\) 到 \(n\)）。
  • d 叉堆树高 \(\log_d N\)；插入 \(O(\log_d N)\)，DeleteMin \(O(d\log_d N)\)。
  • DeleteMin：末元素搬根 + 下滤（选较小子）。
  • 堆排序不稳定（下滤交换打乱相等元素顺序）。

散列结论

  • 装填因子 \(\lambda=N/M\)；开放定址要求 \(\lambda<1\)；平方探测要求 \(\lambda\le 0.5\) 保证插入成功。
  • 平方探测：表长素数且 \(\lambda\le 0.5\) 可探查半数位置。
  • 线性探测产生一次聚集；平方探测产生二次聚集（哈希值相同的键走相同序列）。
  • 双散列用 hash2(k) 给不同步长，消除聚集。
  • n 个同哈希值键 + 线性探测：总探测次数 \(n(n-1)/2\)。
  • 线性探测 = 步长 1 的双散列（hash2(k)=1）。
  • 分离链接法在 \(\lambda\approx 1\) 时仍可工作（不像开放定址严重退化）。
  • 再散列表长取质数（约为原表 2 倍）。
  • 哈希表平均查找长度主要取决于装填因子，非表长。
  • 哈希表插入失败 → 必须再散列。
  • 顺序栈/链表等"顺序"指存储方式，非元素有序。

并查集结论

  • 等价关系：自反 + 对称 + 传递。
  • union-by-size：小树根指向大树，树高 \(\le\log_2 N+1\)，Find \(O(\log N)\)。
  • union-by-height：浅树根指向深树，高度不超过 \(\log_2 N\)。
  • 路径压缩：Find 时把路径上所有节点父指针指向根，后续 \(O(1)\)。
  • union-by-size + 路径压缩均摊 \(O(\alpha(N))\)，实际常数。

图论结论

  • 邻接矩阵空间 \(O(V^2)\)，与边数无关；判邻 \(O(1)\)；易求入度。
  • 邻接表空间 \(O(V+E)\)；判邻 \(O(\deg)\)。
  • 无向图：度之和 = 2E；有向图：入度和 = 出度和 = E。
  • 强连通图最少 N 条边（围成圈）。
  • N 顶点无向图至多 N 个连通分量（无边时）。
  • 10 顶点图保证任何情况连通需 \(\tfrac{(N-1)(N-2)}{2}+1=37\) 边。
  • BFS 类似层序遍历（队列），可求无权图最短路。
  • DFS 类似先序遍历（栈/递归）。
  • BFS 两次才遍历完 ↔ 图有 2 个连通分量（非因回路）。
  • Dijkstra 按距离递增顺序确定最短路；要求边权非负。
  • Dijkstra + 优先队列松弛总时间 \(O(E\log V)\)。
  • 负权边使 Dijkstra 失效；用 Bellman-Ford（V-1 轮松弛）。
  • BFS 适用于等权图最短路。
  • 单源最短路计数：count[S]=1，其余 count[V]=0；松弛时更短则 count[W]=count[V]，等长则 count[W]+=count[V]。
  • MST 唯一 ↔ 无相同权值边（无环时）；有权值相同边则不一定唯一。
  • Prim 适合稠密图 \(O(V^2)\)；Kruskal 适合稀疏图 \(O(E\log E)\)。
  • Prim 每次加连接 S 与 V\S 的最小横切边（顶点视角）。
  • Kruskal 维护森林，每次加全局最小边不形成环（边视角，并查集判环）。
  • 关节点非根：存在子 \(v\) 使 low[v] ≥ num[u]。
  • 根是关节点 ↔ 根有 ≥2 个 DFS 子。
  • |V|>2 时无向图至多 |V|-2 个关节点。
  • 欧拉回路：所有顶点度数为偶数（连通图）。
  • 欧拉路径：恰好 0 或 2 个奇度顶点。
  • 连通图无拓扑排序 ↔ 有环。
  • DAG 任两顶点间有路 ↔ 拓扑序列唯一。
  • 邻接矩阵三角化不保证拓扑序列唯一；拓扑序列存在不要求矩阵三角。
  • 最大流 = 最小割容量。
  • 增广路径不存在时当前流即最大流。
  • 哈密顿回路每顶点恰好一次，无简单多项式算法。

栈/队列结论

  • 栈 LIFO，队列 FIFO。
  • 餐厅"先来先服务"用队列。
  • 括号匹配、后缀表达式用栈。
  • 后缀表达式 3 4 + 5 × = 35。
  • 出栈序列 {p1,...,pn}，若 p2=n 则有 n-1 种可能。
  • 循环队列：front+size 表示时最大容量 = m（不需留空位）。
  • 循环队列：front/rear 表示时空满都是 rear==front，需留空位或加 size。
  • 双端入队单端出队：输入有序，输出必从 a 起向两侧扩展。

排序趟识别

  • 第 1 趟后：最小元到位 → 选择/冒泡。
  • 第 1 趟后：前段+后段都局部有序但两端都不全到位 → merge sort。
  • 第 1 趟后：无元素到最终位 → quicksort。
  • 插入排序最佳 \(O(N)\)（已有序）；逆序对少时插入优于快排和堆排。
  • 简单选择排序比较次数恒 \(\tfrac{n(n-1)}{2}\)，与初始状态无关。
  • 冒泡排序交换次数取决于逆序对数量。
  • 基数排序 LSD 第 1 趟按个位排序。
  • 希尔增量须相邻互素（Hibbard \(2^k-1\)，最坏 \(\Theta(N^{3/2})\)）。

散列表查找长度

  • 线性探测成功查找平均长度 \(\frac{1}{2}(1+\frac{1}{1-\lambda})\)。
  • 线性探测失败查找平均长度 \(\frac{1}{2}(1+\frac{1}{(1-\lambda)^2})\)。
  • 平方探测成功/失败约为 \(-\frac{1}{\lambda}\ln(1-\lambda)\) / \(\frac{1}{1-\lambda}\)。
  • 查找失败平均长度按"散列函数可映射到的位置"计算（注意 %7 时只算 0~6）。
