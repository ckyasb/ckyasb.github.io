反应堆

基础概念

反应堆关键组成部分

  1. 核燃料：裂变反应的物质基础。通常由浓缩铀（铀-235）或钚-239制成。
  2. 慢化剂:用于减慢中子速度，降低中子能量，增加中子引发破裂变的几率。常见材料包括重水、石墨或轻水。
  3. 控制棒：由吸收中子能力强的材料（如心血管或硼）制成，控制中子的数量，通过插入或提出堆芯来调节反应速率和控制功率。
  4. 冷却剂：占用热量储存。将从芯堆中剔除产生巨大的热量，常见的有水或动物园钠。
  5. 屏蔽层：安全屏障通常由厚重的混凝土和铅层构成，用于吸收辐射，保护人员和环境安全。

中子能量分类

  • 特快中子：能量范围在10 MeV ~ 50 MeV之间。
  • 快中子：能量范围在0.5 MeV ~ 10 MeV之间。裂变产生的中子几乎属于这个能量段（平均能量约2 MeV）。
  • 中能中子：能量范围在1 keV ~ 0.5 MeV之间。
  • 慢中子：能量范围在0 ~ 1 keV之间。慢中子内部又进一步解析为：
    • 超热中子：能量约为0.2 ~ 10 eV 。
    • 热中子：能量约为0.025 eV 。此时这是中子与周围介质原子核处于热平衡状态时的能量水平。

反应堆分类

  • 快中子反应堆：不需要慢化剂，直接利用裂变产生的快中子维持链式反应，可用于增殖核燃料。
  • 热中子反应堆：利用慢化剂将中子分解成为热中子来引发裂变，是目前使用最广泛的类型。按冷却剂和缓化剂种类划分为：
    • 重水堆：使用重水作为冷却剂和慢化剂，可使用天然铀燃料燃料。
    • 轻水堆：使用轻水同时作为冷却剂和慢化剂。主要解释为：
      • 压水堆：水在高温高压下保持兔子不加热。
      • 沸腾水堆：水在堆芯内部直接蒸发产生蒸汽。
    • 气冷堆：使用气体（如二氧化碳或氦气）导出热量，通常用石墨作为慢化剂

压水堆（就是一般印象中的反应堆）

气冷堆

  1. 优点：
    • 选址灵活
    • 核燃料以及热效率高，
    • 安全性高，堆芯热容量大，具有负温度系数。即使失去冷却，堆芯也不会熔化。
    • 不停堆换料，球床式高温气冷堆可以在运行中进行燃料循环
  2. 挑战：
    • 材料与设备制造，需要研发耐高温、高压的氦气回路设备以及高温材料。
    • 制备燃料元件技术要求极高。
    • 燃料废弃物处理

快堆：

  1. 优点
    • 燃料增殖，燃料利用率更高。快堆能利用热堆无法利用的贫铀（铀-238），将铀资源的利用率扩大数十倍，甚至数百倍。
    • 清洁持续
    • 热效率高：低压堆芯设计可实现较高的热效率
  2. 缺点（由于冷却剂——液态钠）
    • 运维困难，钠在室温下是固态
    • Na化学性质活泼
    • 辐射与腐蚀，钠在快中子照射下会生成放射性同位素，且含氧的钠会对系统结构造成严重腐蚀。
    • 安全性问题，堆内液态钠若沸腾产生气泡，会导致功率异常升高

燃料

核燃料放入合金管组成燃料元件(燃料棒)，燃料元件+定位格架正方形排列形成燃料组件（17*17最常见）

中子

中子与核作用

  • 散射: 作用后，产物依然是中子和原子核，但中子的能量和运动方向可能改变。
    • 弹性散射
    • 非弹性散射
  • 吸收
    • 辐射俘获，原子核吸收中子后变成激发态，随即放出 γ 射线回到基态。
    • 裂变反应，重核（如U-235）吸收中子后分裂成两个较轻的碎片，同时释放出巨大的能量（约200MeV）和新的中子（2-3个）。这是反应堆能量来源的核心。
    • 带电粒子引出反应，吸收中子后放出质子或 α 粒子

中子截面

以上每种反应都有自己对应的截面

  1. 微观截面 (\(\sigma\)) 反映单个原子核与单个入射中子发生相互作用的概率大小。

    • 单位: 靶恩 (Barn, \(b\))。
    • 换算: \(1 b = 10^{-24} \text{ cm}^2\)。

  2. 宏观截面 (\(\Sigma\)) 描述中子束在介质中穿行单位距离发生相互作用的概率。

    • 公式: \(\Sigma = N \sigma\)
    • 单位: \(\text{cm}^{-1}\)

宏观截面与微观截面的关系推导

这部分内容在原子物理中其实已经接触过很多了
设靶物质的原子核数密度为 \(N\) (个/\(\text{cm}^3\))。 中子束强度为 \(I\)，穿过厚度为 \(\Delta x\) 的薄靶。

发生的反应数 \(\Delta I\) 正比于入射强度、靶核密度和厚度：

\[\Delta I = \sigma \cdot I \cdot N \cdot \Delta x\]

整理得衰减微分方程：

\[\frac{-dI}{dx} = (N\sigma) I = \Sigma I\]

其中 \(\Sigma\) 即为宏观截面，表示单位长度上的反应概率。 由这两个公式反算\(\Sigma,\sigma\)即可

平均自由程

中子在介质中与原子核发生作用前所穿行的平均距离。

\[\lambda = \frac{1}{\Sigma}\]

核反应率

单位体积、单位时间内发生的核反应次数。

\[R = n v \Sigma = \phi \Sigma = n v \frac{1}{\lambda}\]

对于多种粒子的体系

\[R = \sum_{i} R_{i} = nv \sum_{i} \Sigma_{i} = nv \Sigma\]

其中： \(n\): 中子密度 \(v\): 中子速度 \(\phi\): 中子通量密度 (\(nv\))

链式裂变反应与临界

有效增殖因数

定义

\[k_{eff} = \frac{\text{产生率}}{\text{消失率}} = \frac{\text{产生率}}{\text{吸收率+泄露率}}\]
  • \(k_{eff} = 1\): 临界 (稳态)
  • \(k_{eff} > 1\): 超临界 (功率上升)
  • \(k_{eff} < 1\): 次临界 (功率下降)

四因子公式

此时针对无限介质的情况无限介质增殖因数 \(k_{\infty}\)，在无限大介质中，不考虑泄漏：

\[k_{\infty} = \epsilon p f \eta\]

\(\epsilon\) (快裂变因数): 快中子引起裂变的贡献。 \(p\) (逃脱共振俘获概率): 中子在慢化过程中逃脱共振吸收的概率。 \(f\) (热中子利用系数): 热中子被燃料吸收的份额。 \(\eta\) (再生系数): 燃料每吸收一个热中子所产生的平均裂变中子数。

考虑泄漏的修正

\[k_{eff} = k_{\infty} P_L\]

其中 \(P_L\) 为中子不泄漏概率。

结合扩散理论（单群）， \(P_L\) 与几何曲率 \(B_g^2\) 和扩散长度 \(L\) 有关，这些因素会引起反射和泄露等因素

\[k_{eff} = \frac{k_{\infty}}{1 + L^2 B_g^2}\]

3.3 反应性 (\(\rho\))

描述偏离临界的程度：

\[\rho = \frac{k_{eff} - 1}{k_{eff}} \approx \frac{\Delta k}{k}\]

单位: \(pcm\) (\(10^{-5}\)), \(mk\) (\(10^{-3}\)), \(\$\) ( \(1\$ = \beta\))。

慢化剂

  1. 几个定义

    • 平均对数能降（\(\xi\)），代表每次碰撞后降低的能量
    • 宏观吸收截面：和散射截面类似

  2. 常见选择

    • 慢化能力 (\(\xi\Sigma_s\)) \(\rightarrow\) 数值越大，中子慢化所需的距离越短，慢化能力越强，堆芯体积可以做得越小（降低基建和容器成本）。
    • 热中子吸收截面 (\(\Sigma_a\)) \(\rightarrow\) 数值越小越好。如果 \(\Sigma_a\) 大（如轻水）：必须使用浓缩铀（增加U-235浓度来补偿损失）。如果 \(\Sigma_a\) 极小（如重水、石墨）：可以使-用便宜的天然铀。
    • 慢化比 (\(\xi\Sigma_s / \Sigma_a\)) \(\rightarrow\) 数值越大，说明该材料在有效慢化中子的同时，几乎不浪费中子。 重水堆：天然铀；轻水堆：浓缩铀；石墨堆：天然铀，体积大

中子扩散理论

4.1 菲克定律 (Fick's Law)

描述中子流密度与通量密度梯度的关系（类比分子扩散）：

\[J = -D \nabla \phi\]

其中 \(D\) 为扩散系数，\(D \approx \frac{1}{3\Sigma_{tr}} = \frac{\lambda_{tr}}{3}\)。

4.2 扩散方程

单速稳态无源扩散方程：

\[D \nabla^2 \phi - \Sigma_a \phi + S = 0\]

对于临界反应堆：

\[\nabla^2 \phi + B^2 \phi = 0\]

4.3 几何曲率与材料曲率

临界条件

  • 几何曲率 (\(B_g^2\)): 取决于反应堆的几何形状和尺寸（表征泄漏）。
  • 材料曲率 (\(B_m^2\)): 取决于材料成分（表征增殖能力）。
\[B_m^2 = \frac{k_{\infty} - 1}{L^2}\]

临界时: \(B_g^2 = B_m^2\)

4.4 关键长度

扩散长度 (\(L\)): 热中子从产生到被吸收穿行的平均直线距离（的 \(1/\sqrt{6}\)）。

慢化长度 (\(L_s\) 或 \(\sqrt{\tau}\)): 快中子慢化为热中子的平均位移。

徙动长度 (\(M\)): 综合了慢化和扩散过程。

\[M^2 = L^2 + \tau\]
  1. 反应性控制与运行物理

5.1 温度效应

反应性随温度变化而变化的特性。

\[\alpha_T = \frac{d\rho}{dT}\]

为保证安全，总温度系数必须为负值 (\(\alpha_T < 0\))。

燃料温度系数 (\(\alpha_{TF}\)): 多普勒效应导致共振峰展宽，吸收增加，反应性下降（瞬发，负值）。

慢化剂温度系数 (\(\alpha_{TM}\)): 密度降低导致慢化能力下降，通常设计为负值。

为什么多普勒效应会引入负反应性？

燃料温度升高加剧了原子核的热运动。对于入射中子而言，相对速度分布变宽，导致共振吸收峰“展宽”且“变矮”。 虽然峰值截面下降，但总的共振吸收面积（共振积分）增加。这意味着更多的中子在慢化过程中被共振俘获（\(p\) 减小），从而导致 \(k_{eff}\) 下降，引入负反应性。

5.2 毒物效应 (Xenon Poisoning)

碘坑 (Iodine Pit): 停堆后，\(^{135}I\) 继续衰变生成强吸收体 \(^{135}Xe\)，而 \(^{135}Xe\) 因中子通量消失不再消耗，导致氙浓度先上升后下降的现象。

后果: 停堆后一段时间内（碘坑期）可能无法重新启动反应堆。

5.3 控制方式

控制棒: 银-铟-镉等强吸收材料，调节快速反应性变化。

积分价值: 棒从堆外插至某位置的总反应性。

微分价值: 插入单位距离引起的反应性变化（中间大，两端小）。

可燃毒物: 硼、钆。补偿寿期初过剩反应性，随燃耗消耗。

化学补偿 (可溶硼): 调节慢化剂中硼酸浓度，控制慢变化（如燃耗）。

  1. 中子动力学

6.1 缓发中子的作用

重要性

如果没有缓发中子，反应堆周期极短（微秒级），人类无法控制。

  • 瞬发中子寿命 (\(l\)): \(\approx 10^{-4} s\)。
  • 缓发中子: 裂变产物衰变产生，平均寿命长。

6.2 反应堆周期 (\(T\))

中子通量密度（或功率）改变 \(e\) 倍所需的时间。

\[n(t) = n(0) e^{t/T}\]

6.3 倒时方程 (点堆模型近似)

描述反应性 \(\rho\) 与反应堆周期 \(T\) 的关系：

\[\rho = \frac{l}{T} + \sum_{i} \frac{\beta_i}{1 + \lambda_i T}\]

\(\beta\): 缓发中子总份额。

当 \(\rho < \beta\) 时，周期主要由缓发中子决定，反应堆可控。

点堆模型假设
  1. 时空分离: 假设中子通量密度的空间分布形状不随时间变化，仅幅度随时间变化。
  2. 适用范围: 反应堆偏离临界不远，局部扰动不大的情况。
  3. 忽略反馈: 在简单的点堆动力学方程推导中，通常暂不考虑温度和毒物的反馈。
