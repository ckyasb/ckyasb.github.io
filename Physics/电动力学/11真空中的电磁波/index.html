11 真空中的电磁波

电磁波 (electromagnetic wave) 是电磁场在真空中的自由传播形态。本章从麦克斯韦方程组出发，系统推导真空中的波动方程，并详细研究平面波与球面波这两类基本解的性质，包括色散关系、偏振结构、能量动量传输以及洛伦兹变换下的行为。

1. 波动方程的导出

1.1 真空中的麦克斯韦方程组

自测

Q: 无源真空中安培-麦克斯韦定律相比静磁安培定律多出哪一项？为什么这一项必不可少？

答案

多出位移电流项 \(\mu_0\epsilon_0\partial_t\mathbf{E}\)。没有它，\(\nabla\times\mathbf{B}\) 的散度恒为零会与 \(\partial_t\rho\neq 0\) 时的电流连续性方程矛盾，且无法导出波动方程。

在无源区域 (\(\rho = 0, \mathbf{J} = 0\))，真空中的麦克斯韦方程组为：

\[ \nabla \cdot \mathbf{E} = 0 \tag{11.1} \]
\[ \nabla \times \mathbf{E} + \frac{\partial \mathbf{B}}{\partial t} = 0 \tag{11.2} \]
\[ \nabla \times \mathbf{B} - \epsilon_0 \mu_0 \frac{\partial \mathbf{E}}{\partial t} = 0 \tag{11.3} \]
\[ \nabla \cdot \mathbf{B} = 0 \tag{11.4} \]

1.2 电磁势与洛伦兹规范

自测

Q: 引入电磁势 \(\mathbf{B}=\nabla\times\mathbf{A}\)、\(\mathbf{E}=-\nabla\phi-\partial_t\mathbf{A}\) 的依据是什么？为什么还需施加洛伦兹规范？

答案

依据是无源麦克斯韦方程：\(\nabla\cdot\mathbf{B}=0\) 保证 \(\mathbf{B}\) 有矢势，\(\nabla\times(\mathbf{E}+\partial_t\mathbf{A})=0\) 保证存在标势 \(\phi\)。施加洛伦兹规范 \(\nabla\cdot\mathbf{A}+c^{-2}\partial_t\phi=0\) 是为了消去 \(\phi\) 与 \(\mathbf{A}\) 方程的耦合项，使二者满足相同的达朗贝尔波动方程 \(\Box\phi=0,\ \Box\mathbf{A}=0\)。

引入电磁势，令 \(\mathbf{B} = \nabla \times \mathbf{A}\)，\(\mathbf{E} = -\nabla \phi - \partial \mathbf{A}/\partial t\)。代入无源麦克斯韦方程，采用洛伦兹规范 (Lorenz gauge)：

\[ \nabla \cdot \mathbf{A} + \frac{1}{c^2} \frac{\partial \phi}{\partial t} = 0 \tag{11.5} \]

可得到对称的波动方程：

\[ \Box \phi \equiv \left( \nabla^2 - \frac{1}{c^2} \frac{\partial^2}{\partial t^2} \right) \phi = 0 \]
\[ \Box \mathbf{A} = 0 \tag{11.6} \]

1.3 四维形式

自测

Q: 用四维协变形式写出无源真空的波动方程，并指出洛伦兹规范条件在四维下的形式。

答案

\(\Box A^\mu=0\)，其中 \(\Box=\partial_\mu\partial^\mu\)。洛伦兹规范即 \(\partial_\mu A^\mu=0\)。

📅 05-07 & 教材 p.245

引入四维势 \(A_\mu = (\phi/c, \mathbf{A})\)，四维电流密度 \(I_\mu = (\rho c, \mathbf{J})\)，达朗贝尔算符的协变形式为 \(\Box = \partial_\mu \partial^\mu\)。在洛伦兹规范下，有极简洁的四维波动方程：

\[ \Box A_\mu = -\mu_0 I_\mu = 0 \quad (\text{无源情形}) \tag{11.7} \]

在无源真空中，\(I_\mu = 0\)，故：

\[ \Box A^\mu = 0 \tag{11.8} \]
从麦克斯韦方程组到四维波动方程

第一步：由 \(\nabla \cdot \mathbf{B} = 0\) 引入矢势 \(\mathbf{A}\)，\(\mathbf{B} = \nabla \times \mathbf{A}\)。

第二步：代入法拉第定律，得 \(\nabla \times (\mathbf{E} + \partial_t \mathbf{A}) = 0\)，引入标势 \(\phi\)，\(\mathbf{E} = -\nabla \phi - \partial_t \mathbf{A}\)。

第三步：将上述表达式代入安培-麦克斯韦定律和高斯电定律，得到联立方程：

\[ \nabla^2 \phi + \frac{\partial}{\partial t} (\nabla \cdot \mathbf{A}) = -\frac{\rho}{\epsilon_0} \]
\[ \Box \mathbf{A} + \nabla \left( \nabla \cdot \mathbf{A} + \frac{1}{c^2} \frac{\partial \phi}{\partial t} \right) = \mu_0 \mathbf{J} \]

第四步：施加洛伦兹规范条件 (11.5)，交叉项消去，得到对称波动方程 (11.6)。

第五步：将 \(\phi\) 和 \(\mathbf{A}\) 合写为四维势 \(A^\mu\)，注意到洛伦兹条件正是 \(\partial_\mu A^\mu = 0\)，达朗贝尔算子 \(\Box = \partial_\mu \partial^\mu\)，即得 (11.7)。

1.4 洛伦兹规范与库仑规范的比较

自测

Q: 库仑规范与洛伦兹规范哪一个具有相对论协变性？为什么辐射问题通常选洛伦兹规范？

答案

洛伦兹规范具有显式相对论协变性。辐射问题选洛伦兹规范是因为 \(\phi\) 与 \(\mathbf{A}\) 满足形式完全相同的波动方程 \(\Box\phi=-\rho/\epsilon_0\)、\(\Box\mathbf{A}=-\mu_0\mathbf{J}\)，无耦合项，便于求推迟势解；而库仑规范下 \(\phi\) 满足瞬时泊松方程，破坏因果性，处理辐射不便。

特性 库仑规范 (\(\nabla \cdot \mathbf{A} = 0\)) 洛伦兹规范 (\(\nabla \cdot \mathbf{A} + c^{-2}\partial_t \phi = 0\))
标势方程 \(\nabla^2 \phi = -\rho/\epsilon_0\)（瞬时泊松方程） \(\Box \phi = -\rho/\epsilon_0\)（波动方程）
矢势方程 \(\Box \mathbf{A} = -\mu_0 \mathbf{J} + \nabla(\partial_t \phi)/c^2\)（含耦合项） \(\Box \mathbf{A} = -\mu_0 \mathbf{J}\)（无耦合项）
纵向/横向分离 自然分离，\(\mathbf{A}_\perp\) 横波，\(\mathbf{A}_\parallel\) 纵场 不显式分离
相对论协变性 否 是
适用场景 静磁场、量子力学中的规范场 辐射问题、数值相对论、协变量子场论

洛伦兹规范的主要优势在于其显式的相对论协变性，以及标势和矢势满足形式完全相同的波动方程。在量子场论中，这对应着光子传播子的简单形式。

2. 单色波

2.1 傅里叶分解

自测

Q: 时间傅里叶分解后，波动方程 \(\Box A^\mu=0\) 退化为哪种方程？其中波数 \(k\) 与频率 \(\omega\) 的关系是什么？

答案

退化为亥姆霍兹方程 \((\nabla^2+k^2)\tilde A^\mu=0\)，其中 \(k=\omega/c\)。

由于波动方程 \(\Box A^\mu = 0\) 是线性齐次方程，其一般解可通过傅里叶叠加得到。对时间变量做傅里叶变换：

\[ A^\mu(t, \mathbf{x}) = \int_{-\infty}^{\infty} \frac{d\omega}{2\pi} \, \tilde{A}^\mu(\omega, \mathbf{x}) \, e^{-i\omega t} \tag{11.9} \]

代入波动方程，每个傅里叶分量满足亥姆霍兹方程 (Helmholtz equation)：

\[ (\nabla^2 + k^2) \tilde{A}^\mu(\omega, \mathbf{x}) = 0, \quad k = \frac{\omega}{c} \tag{11.10} \]

2.2 复化表示

自测

Q: 对单色波采用复化表示 \(A^\mu=\mathcal{A}^\mu e^{-i\omega t}+\text{c.c.}\)，时间导数 \(\partial_t\) 如何简化？

答案

复化后时间导数变为代数乘法：\(\partial_t\to -i\omega\)。约定取实部即得物理场量。

📅 05-07 教材 p.246

对于单色 (monochromatic) 电磁波，角频率 \(\omega\) 固定，采用复振幅表示：

\[ A^\mu(t, \mathbf{x}) = \mathcal{A}^\mu(\mathbf{x}) e^{-i\omega t} + \text{c.c.} \tag{11.11} \]

约定取实部即得物理场量。这种复化表示的优势在于： 1. 将时间导数简化为代数乘法：\(\partial_t \rightarrow -i\omega\) 2. 波动方程退化为亥姆霍兹方程 3. 线性运算（求导、叠加）与复化操作可交换

3. 平面波

3.1 平面波解的形式

自测

Q: 平面波解 \(A_\mu=\xi_\mu e^{ik_\nu x^\nu}\) 代入波动方程得到什么约束？由此得到的真空色散关系是什么？

答案

得到波矢的零模条件 \(k^\mu k_\mu=0\)，即 \(\omega^2/c^2-|\mathbf{k}|^2=0\)。色散关系为 \(\omega=c|\mathbf{k}|\)。

📅 05-07, 05-12 & 教材 p.246-247

亥姆霍兹方程最简单的解是平面波 (plane wave)。四维势的平面波解为：

\[ A_\mu(x) = \xi_\mu e^{i k_\nu x^\nu} \tag{11.12} \]

其中 \(x^\nu = (ct, \mathbf{x})\) 为四维坐标，\(k_\nu = (\omega/c, -\mathbf{k})\) 为四维波矢 (wave 4-vector)，\(\xi_\mu\) 为偏振矢量 (polarization 4-vector)。

代入波动方程 \(\Box A_\mu = 0\)，得到：

\[ \Box A_\mu = (-i k^\nu)(i k_\nu) A_\mu = k^\nu k_\nu A_\mu = 0 \]

因此波矢满足零模条件 (null condition)：

\[ k^\mu k_\mu = 0 \quad \Longrightarrow \quad \frac{\omega^2}{c^2} - |\mathbf{k}|^2 = 0 \tag{11.13} \]

这就是真空中的色散关系 (dispersion relation)：

\[ \boxed{\omega = c |\mathbf{k}|} \tag{11.14} \]

3.2 偏振与横波性

自测

Q: 洛伦兹规范条件加在平面波解上给出什么关系？扣除剩余规范自由度后，物理偏振态有几个？

答案

给出 \(k_\mu\xi^\mu=0\)（偏振矢量与波矢正交）。扣除剩余规范自由度 \(\xi_\mu\to\xi_\mu+\alpha k_\mu\) 后，物理偏振态数为 2，对应横波的两个独立偏振方向。

洛伦兹规范条件 \(\partial_\mu A^\mu = 0\) 施加在平面波解上：

\[ \partial_\mu A^\mu = i k_\mu \xi^\mu e^{i k_\nu x^\nu} = 0 \quad \Longrightarrow \quad k_\mu \xi^\mu = 0 \tag{11.15} \]

即四维偏振矢量与四维波矢正交。这给出自由电磁波的横波性 (transversality)。

平面波还具有剩余规范自由度 (residual gauge freedom)：形如 \(\xi_\mu \rightarrow \xi_\mu + \alpha k_\mu\) 的变换保持物理场不变。利用此自由度，可选取便于计算的规范，例如：

  • 辐射规范 (radiation gauge)：\(\xi_0 = 0\) 且 \(\mathbf{\xi} \cdot \mathbf{k} = 0\)
  • 此时偏振矢量纯空间且横向
平面波的偏振自由度

四维偏振矢量 \(\xi_\mu\) 受两个约束：

  1. 色散关系 \(k^\mu k_\mu = 0\)（来自波动方程）
  2. 洛伦兹条件 \(k^\mu \xi_\mu = 0\)（来自规范条件）

扣除剩余规范自由度后，物理的偏振态数为 2（对应于横波的两个独立偏振方向）。

在辐射规范 (\(\xi_0 = 0\)) 下：

\[ \mathbf{\xi} \cdot \mathbf{k} = 0 \tag{11.16} \]

即偏振矢量 \(\mathbf{\xi}\) 垂直于传播方向 \(\mathbf{k}\)。这就是电磁波的横波性：电场和磁场的振动方向均垂直于波的传播方向。

3.3 电场与磁场的表达式

自测

Q: 平面波中 \(\mathbf{E}\)、\(\mathbf{B}\)、\(\hat{\mathbf{k}}\) 三者方向关系如何？\(|\mathbf{B}|\) 与 \(|\mathbf{E}|\) 的幅度关系是什么？

答案

三者两两垂直，构成右手正交系，且 \(\mathbf{B}=\hat{\mathbf{k}}\times\mathbf{E}/c\)。幅度关系 \(|\mathbf{B}|=|\mathbf{E}|/c\)，电场与磁场同相位。

由电磁势与场量的关系：

\[ \mathbf{E} = -\frac{\partial \mathbf{A}}{\partial t} - \nabla \phi, \quad \mathbf{B} = \nabla \times \mathbf{A} \tag{11.17} \]

代入平面波解 (11.12)（辐射规范下 \(\phi = 0\)），得到电场和磁场的复振幅：

\[ \mathbf{E}(\mathbf{x}, t) = i \omega \mathbf{\xi} \, e^{i(\mathbf{k} \cdot \mathbf{x} - \omega t)} = \mathbf{e}_E \, e^{i(\mathbf{k} \cdot \mathbf{x} - \omega t)} \tag{11.18} \]
\[ \mathbf{B}(\mathbf{x}, t) = i (\mathbf{k} \times \mathbf{\xi}) \, e^{i(\mathbf{k} \cdot \mathbf{x} - \omega t)} = \frac{1}{c} \hat{\mathbf{k}} \times \mathbf{E} \tag{11.19} \]

其中 \(\hat{\mathbf{k}} = \mathbf{k}/|\mathbf{k}|\) 为传播方向的单位矢量。电场与磁场满足：

  1. 相互垂直：\(\mathbf{B} \perp \mathbf{E}\)
  2. 均垂直于传播方向：\(\mathbf{E} \perp \hat{\mathbf{k}}\)，\(\mathbf{B} \perp \hat{\mathbf{k}}\)
  3. 幅度关系：\(|\mathbf{B}| = |\mathbf{E}|/c\)
  4. 相位相同：电场的相位与磁场相位完全相同

4. 偏振态

📅 05-12 & 教材 p.247-248

偏振态 (polarization state) 描述了电场矢量在垂直于传播方向平面内的振动轨迹。取传播方向为 \(z\) 轴，电场矢量可写为：

\[ \mathbf{E}(z, t) = (e_x \hat{\mathbf{x}} + e_y \hat{\mathbf{y}}) \, e^{i(kz - \omega t)} \tag{11.20} \]

其中 \(e_x, e_y\) 为复振幅。

4.1 线偏振

自测

Q: 线偏振成立的相位条件是什么？此时电场矢量的振动特征是什么？

答案

\(e_x\) 与 \(e_y\) 相位差 \(\delta=0\) 或 \(\pi\)。电场矢量沿固定方向振动，端点轨迹为一直线。

当 \(e_x\) 与 \(e_y\) 的相位差 \(\delta = 0\) 或 \(\pi\) 时，电场矢量沿固定方向振动，称为线偏振 (linear polarization)：

  • \(\delta = 0\)：\(e_x / e_y \in \mathbb{R}^+\)，振动方向为 \(\hat{\mathbf{x}}\) 与 \(\hat{\mathbf{y}}\) 的线性组合方向
  • \(\delta = \pi\)：\(e_x / e_y \in \mathbb{R}^-\)，振动方向相反

常用基矢：

\[ \hat{\mathbf{\epsilon}}_1 = \hat{\mathbf{x}}, \quad \hat{\mathbf{\epsilon}}_2 = \hat{\mathbf{y}} \tag{11.21} \]

4.2 圆偏振

自测

Q: 圆偏振的振幅与相位条件是什么？右旋与左旋圆偏振的相位差符号有何区别？

答案

满足 \(|e_x|=|e_y|\) 且 \(\delta=\pm\pi/2\)。右旋 (RCP) \(\delta=\pi/2\)（\(e_y=i|e|\)），左旋 (LCP) \(\delta=-\pi/2\)（\(e_y=-i|e|\)）。

当 \(|e_x| = |e_y| \equiv |e|\) 且相位差 \(\delta = \pm \pi/2\) 时，电场矢量末端在空间画出一个圆，称为圆偏振 (circular polarization)：

  • 右旋圆偏振 (RCP)：\(\delta = \pi/2\)，\(e_x = |e|\)，\(e_y = i|e|\)

$$ \mathbf{E}(z, t) = |e|(\hat{\mathbf{x}} - i\hat{\mathbf{y}}) e^{i(kz - \omega t)} \tag{11.22} $$

  • 左旋圆偏振 (LCP)：\(\delta = -\pi/2\)，\(e_x = |e|\)，\(e_y = -i|e|\)

$$ \mathbf{E}(z, t) = |e|(\hat{\mathbf{x}} + i\hat{\mathbf{y}}) e^{i(kz - \omega t)} \tag{11.23} $$

圆偏振基矢（琼斯矢量）：

\[ \hat{\mathbf{\epsilon}}_+ = \frac{1}{\sqrt{2}} (\hat{\mathbf{x}} + i\hat{\mathbf{y}}), \quad \hat{\mathbf{\epsilon}}_- = \frac{1}{\sqrt{2}} (\hat{\mathbf{x}} - i\hat{\mathbf{y}}) \tag{11.24} \]

4.3 椭圆偏振

自测

Q: 椭圆偏振情况下，电场矢量端点的轨迹由什么完全确定？任意偏振态可在哪两组基下展开？

答案

由复振幅比 \(e_y/e_x\) 完全确定长短轴方向、旋向和离心率。可在线偏振基 \((\hat\epsilon_1,\hat\epsilon_2)\) 或圆偏振基 \((\hat\epsilon_+,\hat\epsilon_-)\) 下展开。

一般情况下，\(e_x\) 与 \(e_y\) 的复比值任意，电场矢量末端在空间画出一个椭圆，称为椭圆偏振 (elliptical polarization)。椭圆的长短轴方向、旋向和离心率由复振幅比 \(e_y/e_x\) 完全确定。

任意偏振态可在线偏振基或圆偏振基下展开：

\[ \mathbf{E} = (e_1 \hat{\mathbf{\epsilon}}_1 + e_2 \hat{\mathbf{\epsilon}}_2) e^{i(kz-\omega t)} = (e_+ \hat{\mathbf{\epsilon}}_+ + e_- \hat{\mathbf{\epsilon}}_-) e^{i(kz-\omega t)} \tag{11.25} \]

答案

5. 能量与动量

📅 05-12 & 教材 p.248-249

5.1 能量密度与时间平均

自测

Q: 单色平面波中电场与磁场对能量密度的贡献有何关系？一个周期时间平均后的能量密度 \(\langle u\rangle\) 是多少？

答案

电场与磁场贡献相等（均分定理）。\(\langle u\rangle=\epsilon_0|\mathbf{e}_E|^2/2\)。

电磁场的瞬时能量密度：

\[ u(t) = \frac{1}{2} \left( \epsilon_0 |\mathbf{E}(t)|^2 + \frac{1}{\mu_0} |\mathbf{B}(t)|^2 \right) \tag{11.26} \]

对于单色平面波，电场与磁场的能量贡献相等（均分定理）。取一个周期内的时间平均：

\[ \langle u \rangle = \frac{1}{T} \int_0^T u(t) \, dt = \frac{\epsilon_0}{2} |\mathbf{e}_E|^2 \tag{11.27} \]

其中 \(\mathbf{e}_E = i\omega \mathbf{\xi}\) 为电场复振幅。

5.2 玻印廷矢量

自测

Q: 时间平均玻印廷矢量 \(\langle\mathbf{S}\rangle\) 沿什么方向？用 \(\mathbf{e}_E\) 写出其大小。

答案

沿波的传播方向 \(\hat{\mathbf{k}}\)。大小为 \(|\mathbf{e}_E|^2/(2c\mu_0)\)，即 \(\langle\mathbf{S}\rangle=(|\mathbf{e}_E|^2/2c\mu_0)\hat{\mathbf{k}}\)。

瞬时玻印廷矢量 (Poynting vector)：

\[ \mathbf{S}(t) = \frac{1}{\mu_0} \mathbf{E}(t) \times \mathbf{B}(t) \tag{11.28} \]

时间平均后的能流密度：

\[ \langle \mathbf{S} \rangle = \frac{1}{2\mu_0} \operatorname{Re} (\mathbf{E}^* \times \mathbf{B}) = \frac{|\mathbf{e}_E|^2}{2c\mu_0} \hat{\mathbf{k}} \tag{11.29} \]

可见平均能流方向沿波的传播方向 \(\hat{\mathbf{k}}\)。

5.3 动量密度

自测

Q: 电磁波动量密度 \(\langle\mathbf{g}\rangle\) 与平均能量密度 \(\langle u\rangle\) 之间是什么关系？这对应光子的什么性质？

答案

\(\langle\mathbf{g}\rangle=\langle u\rangle\hat{\mathbf{k}}/c\)，即 \(\langle\mathbf{g}\rangle=\langle u\rangle/c\cdot\hat{\mathbf{k}}\)。这对应光子作为零质量粒子的能量-动量关系 \(E=pc\)。

电磁波的动量密度为：

\[ \mathbf{g} = \epsilon_0 \mu_0 \mathbf{S} = \epsilon_0 \mathbf{E} \times \mathbf{B} \tag{11.30} \]

时间平均后的动量密度：

\[ \langle \mathbf{g} \rangle = \frac{|\mathbf{e}_E|^2}{2c^2\mu_0} \hat{\mathbf{k}} = \frac{\langle u \rangle}{c} \hat{\mathbf{k}} \tag{11.31} \]

能量与动量的关系呈线性：\(\langle \mathbf{g} \rangle = \langle u \rangle / c \cdot \hat{\mathbf{k}}\)，这体现了电磁波作为零质量粒子（光子）的量子性质——光子的能量与动量关系为 \(E = pc\)。

6. 平面波的洛伦兹变换

📅 05-12 & 教材 p.250-251

6.1 波矢的变换

自测

Q: 平面波的四维波矢 \(k^\mu=(\omega/c,\mathbf{k})\) 在洛伦兹变换下按什么规则变换？这一事实的物理含义是什么？

答案

按四维矢量规则变换：\(k'^\mu=\Lambda^\mu{}_\nu k^\nu\)。这保证色散关系 \(k^\mu k_\mu=0\) 在所有惯性系中形式不变，体现了电磁波动方程的相对论协变性。

平面波的四维波矢 \(k^\mu = (\omega/c, \mathbf{k})\) 是一个四维矢量，在洛伦兹变换下按矢量规则变换。考虑 \(S'\) 系相对于 \(S\) 系沿 \(x\) 方向以速度 \(v\) 运动：

\[ k'^0 = \gamma \left( k^0 - \frac{v}{c} k^1 \right), \quad k'^1 = \gamma \left( k^1 - \frac{v}{c} k^0 \right), \quad k'^2 = k^2, \quad k'^3 = k^3 \tag{11.32} \]

其中 \(\gamma = 1/\sqrt{1-v^2/c^2}\)。

6.2 多普勒效应

自测

Q: 横向多普勒效应（\(\theta=\pi/2\)）的频率公式是什么？为什么说它是纯相对论效应？

答案

\(\omega'=\omega_0\gamma=\omega_0/\sqrt{1-\beta^2}\)。经典多普勒理论中横向无频移，此处频移纯粹来自时间膨胀（\(\gamma\) 因子），故为纯相对论效应。

设光源在 \(S\) 系中静止，波矢为 \(k^\mu = (\omega_0/c, \mathbf{k}_0)\)，观察者在 \(S'\) 系中运动。若 \(\mathbf{k}_0\) 与相对运动方向夹角为 \(\theta\)，则观察者测得的频率为：

\[ \omega' = \gamma (\omega_0 - v k_0 \cos\theta) = \omega_0 \gamma (1 - \beta \cos\theta) \tag{11.33} \]

其中 \(\beta = v/c\)。几种特殊情况：

  • 纵向多普勒效应（光源沿视线方向运动，\(\theta = 0\)）：

$$ \omega' = \omega_0 \sqrt{\frac{1-\beta}{1+\beta}} \tag{11.34} $$

光源远离观察者时红移 (\(\omega' < \omega_0\))，靠近时蓝移 (\(\omega' > \omega_0\))。

  • 横向多普勒效应（\(\theta = \pi/2\)）：

$$ \omega' = \omega_0 \gamma = \frac{\omega_0}{\sqrt{1-\beta^2}} \tag{11.35} $$

这是纯相对论效应，经典多普勒理论中不存在横向多普勒效应。

6.3 物理含义

自测

Q: 光源远离观察者时产生红移还是蓝移？频率如何变化？

答案

产生红移，频率降低（\(\omega'<\omega_0\)），谱线向红端移动。光源靠近时则蓝移，频率升高。

  1. 红移 (redshift)：光源远离时波长变长，频率降低，谱线向红端移动
  2. 蓝移 (blueshift)：光源靠近时波长变短，频率升高，谱线向蓝端移动
  3. 宇宙学红移：宇宙膨胀导致遥远星系光谱的系统性红移，是宇宙膨胀的重要证据
  4. 引力红移：广义相对论效应，光在引力场中传播时频率发生变化

注：多普勒效应在雷达测速、天文观测、GPS 导航等应用中均有重要作用。

6.4 偏振矢量的变换

自测

Q: 偏振矢量 \(\xi^\mu\) 在洛伦兹变换下按什么规则变换？不同惯性系中观测到的偏振态是否可能不同？

答案

按四维矢量规则变换 \(\xi'^\mu=\Lambda^\mu{}_\nu\xi^\nu\)。不同惯性系中观测到的偏振态可能变化，但物理可观测量（线偏振方向、圆偏振旋向）具有确定的变换规律。

偏振矢量 \(\xi^\mu\) 作为四维矢量，在洛伦兹变换下同样遵守矢量变换规则。不同惯性系中观测到的偏振态可能会发生变化，但物理上可观测的量（如线偏振方向、圆偏振的旋向等）在变换下具有确定的变换规律。

7. 球面波

7.1 球面波解

自测

Q: 球对称亥姆霍兹方程的出射波解形式是什么？振幅与强度分别如何随 \(r\) 衰减？

答案

出射波 \(\psi_{\text{out}}=\frac{1}{r}e^{-i\omega t+ikr}\)。振幅 \(\propto 1/r\)，强度 \(\propto 1/r^2\)，保证通过任意球面总能量通量相同（能量守恒）。

📅 05-14 & 教材 p.252-253

除去平面波外，亥姆霍兹方程的另一类基本解是球面波 (spherical wave)。在球坐标系下，标量亥姆霍兹方程：

\[ (\nabla^2 + k^2) \psi = 0 \tag{11.36} \]

考虑球对称解 \(\psi = \psi(r)\)，方程化为：

\[ \frac{1}{r^2} \frac{d}{dr} \left( r^2 \frac{d\psi}{dr} \right) + k^2 \psi = 0 \tag{11.37} \]

其解为：

\[ \psi(r) = \frac{e^{\pm ikr}}{r} \tag{11.38} \]

代入时间因子 \(e^{-i\omega t}\)，给出出射波 (outgoing wave) 和入射波 (incoming wave)：

\[ \psi_{\text{out}}(t, r) = \frac{1}{r} e^{-i\omega t + ikr}, \quad \psi_{\text{in}}(t, r) = \frac{1}{r} e^{-i\omega t - ikr} \tag{11.39} \]

物理上最关心的出射球面波具有以下形式：

\[ \boxed{H(\mathbf{x}, t) = \frac{H_0}{r} e^{-i\omega t + ikr}} \tag{11.40} \]

其中 \(H_0\) 为振幅系数。球面波的振幅随 \(1/r\) 衰减，强度（正比于振幅平方）随 \(1/r^2\) 衰减，这符合能量守恒的要求——通过任意球面的总能量通量相同。

7.2 标量球面波的性质

自测

Q: 球面波与平面波的等相面分别是什么？二者强度随空间如何变化？

答案

球面波等相面为球面 \(r=\text{const}\)，强度 \(\propto 1/r^2\)；平面波等相面为平面 \(\mathbf{k}\cdot\mathbf{x}=\text{const}\)，强度为常数。

性质 球面波 平面波
振幅 \(\propto 1/r\) 常数
等相面 球面 \(r = \text{const}\) 平面 \(\mathbf{k} \cdot \mathbf{x} = \text{const}\)
波矢方向 径向 \(\hat{\mathbf{r}}\) 固定方向 \(\hat{\mathbf{k}}\)
强度 \(\propto 1/r^2\) 常数

7.3 多极展开

自测

Q: 亥姆霍兹方程的通解用球汉克尔函数和球谐函数如何展开？远场出射波的径向依赖关系是什么？

答案

\(\psi=\sum_{l,m}[A_{lm}h_l^{(1)}(kr)+B_{lm}h_l^{(2)}(kr)]Y_{lm}(\theta,\varphi)\)。远场出射波径向依赖统一为 \(e^{ikr}/r\)，角度分布由 \(Y_{lm}\) 描述。

📅 05-14 & 教材 p.253-255

实际辐射源通常不是完美的点源。更一般的球面波解可通过多极展开 (multipole expansion) 得到。在球坐标系下，亥姆霍兹方程的通解为：

\[ \psi(\mathbf{x}) = \sum_{l=0}^{\infty} \sum_{m=-l}^{l} \left[ A_{lm} h_l^{(1)}(kr) + B_{lm} h_l^{(2)}(kr) \right] Y_{lm}(\theta, \varphi) \tag{11.41} \]

其中：

  • \(h_l^{(1)}(kr)\) 和 \(h_l^{(2)}(kr)\) 为第一类和第二类球汉克尔函数 (spherical Hankel functions)，分别对应出射波和入射波
  • \(Y_{lm}(\theta, \varphi)\) 为球谐函数 (spherical harmonics)
  • \(A_{lm}, B_{lm}\) 为展开系数

远场区域 (\(kr \gg l\)) 的渐进行为：

\[ h_l^{(1)}(kr) \sim \frac{(-i)^{l+1}}{kr} e^{ikr}, \quad h_l^{(2)}(kr) \sim \frac{i^{l+1}}{kr} e^{-ikr} \tag{11.42} \]

远场出射波的径向依赖关系统一为 \(e^{ikr}/r\)，角度分布由 \(Y_{lm}(\theta, \varphi)\) 描述。

8.2 TM 模 (横磁模)

自测

Q: TM 模（横磁模）的特征是什么？其电磁场由哪个德拜势生成？

答案

特征是磁场无径向分量 \(B_r=0\)，电场有径向分量。由德拜势 \(\Pi_e\) 生成：\(\mathbf{E}_{\text{TM}}=\nabla\times\nabla\times(\mathbf{r}\Pi_e)\)，\(\mathbf{B}_{\text{TM}}=-i\omega\nabla\times(\mathbf{r}\Pi_e)\)。

横磁模 (Transverse Magnetic mode, TM mode) 的特征是磁场没有径向分量 (\(B_r = 0\))，电场有径向分量。引进德拜势 (Debye potential) \(\Pi_e\)，满足标量亥姆霍兹方程：

\[ (\nabla^2 + k^2) \Pi_e = 0 \tag{11.43} \]

TM 模的电磁场由 \(\Pi_e\) 生成：

\[ \mathbf{E}_{\text{TM}} = \nabla \times \nabla \times (\mathbf{r} \Pi_e) \]
\[ \mathbf{B}_{\text{TM}} = -i\omega \nabla \times (\mathbf{r} \Pi_e) \tag{11.44} \]

8.3 TE 模 (横电模)

自测

Q: TE 模（横电模）的特征是什么？与 TM 模相比，电场与磁场的径向分量有何互换关系？

答案

特征是电场无径向分量 \(E_r=0\)，磁场有径向分量。由德拜势 \(\Pi_m\) 生成：\(\mathbf{E}_{\text{TE}}=i\omega\nabla\times(\mathbf{r}\Pi_m)\)，\(\mathbf{B}_{\text{TE}}=\nabla\times\nabla\times(\mathbf{r}\Pi_m)\)。TM 与 TE 在 \(E_r\)、\(B_r\) 的有无上互换。

横电模 (Transverse Electric mode, TE mode) 的特征是电场没有径向分量 (\(E_r = 0\))，磁场有径向分量。引进德拜势 \(\Pi_m\)，同样满足标量亥姆霍兹方程：

\[ (\nabla^2 + k^2) \Pi_m = 0 \tag{11.45} \]

TE 模的电磁场由 \(\Pi_m\) 生成：

\[ \mathbf{E}_{\text{TE}} = i\omega \nabla \times (\mathbf{r} \Pi_m) \]
\[ \mathbf{B}_{\text{TE}} = \nabla \times \nabla \times (\mathbf{r} \Pi_m) \tag{11.46} \]

8.4 TM/TE 模的性质比较

自测

Q: TM 模与 TE 模在远场分别对应哪种多极辐射？物理来源有何不同？

答案

TM 模远场主导电多极辐射，源于电荷电流分布；TE 模远场主导磁多极辐射，源于等效磁荷磁流分布。

性质 TM 模 (横磁) TE 模 (横电)
径向电场 \(E_r\) \(\neq 0\) \(= 0\)
径向磁场 \(B_r\) \(= 0\) \(\neq 0\)
德拜势 \(\Pi_e\)（电型） \(\Pi_m\)（磁型）
远场主导 电多极辐射 磁多极辐射
物理来源 电荷电流分布 等效磁荷磁流分布

8.5 多极辐射的一般展开

自测

Q: 自由空间任意电磁场如何用 TM/TE 模展开？\(l=1\) 对应什么辐射？

答案

\(\mathbf{E}=\sum_{l,m}[a_E(l,m)\mathbf{E}_{lm}^{(\text{TM})}+a_M(l,m)\mathbf{E}_{lm}^{(\text{TE})}]\)，磁场类似。\(l=1\) 对应偶极辐射，\(l=2\) 对应四极辐射。

📅 05-14 教材 p.255

任何自由空间的电磁场可在球坐标系中分解为 TM 模和 TE 模的叠加：

\[ \mathbf{E} = \sum_{l=1}^{\infty} \sum_{m=-l}^{l} \left[ a_E(l, m) \mathbf{E}_{lm}^{\text{(TM)}} + a_M(l, m) \mathbf{E}_{lm}^{\text{(TE)}} \right] \]
\[ \mathbf{B} = \sum_{l=1}^{\infty} \sum_{m=-l}^{l} \left[ a_E(l, m) \mathbf{B}_{lm}^{\text{(TM)}} + a_M(l, m) \mathbf{B}_{lm}^{\text{(TE)}} \right] \tag{11.47} \]

其中 \(a_E(l, m)\) 和 \(a_M(l, m)\) 分别为电多极矩系数 (electric multipole coefficient) 和磁多极矩系数 (magnetic multipole coefficient)。\(l = 1\) 对应偶极辐射，\(l = 2\) 对应四极辐射，依次类推。

球面波的这种分类在以下问题中至关重要： 1. 天线辐射 — 不同类型的天线产生不同的 TM/TE 模组合 2. 散射理论 — Mie 散射的严格解正是基于 TM/TE 模的展开 3. 波导与谐振腔 — 波导中的模式也正是 TM 和 TE 模 4. 宇宙微波背景辐射 — 温度起伏的多极展开是宇宙学分析的基础

9. 典型例题（来自课堂与作业）

9.1 例题（HW12-1，必考）：洛伦兹变换下平面波的规范变换

题目：参考系 \(A\) 中平面电磁波沿 \(x_2\) 正向传播，偏振沿 \(x_3\)，矢势 \(A^\mu(x)=\text{Re}\,(0,0,0,C)\,e^{-i\omega t+ikx_2}\)。参考系 \(B\) 相对 \(A\) 沿 \(x_3\) 正向以速度 \(v\) 运动，\(t=0\) 时两系原点重合。要求 \(B\) 中取特定规范使势矢量空间部分仍垂直于波矢，求 \(B\) 中势矢量。

思路与答案

关键：\(B\) 沿 \(x_3\)（即偏振方向）运动，而波沿 \(x_2\) 传播——运动方向与波矢垂直，是横向 boost。直接做 Lorentz 变换会使 \(A^\mu\) 的空间分量不再严格垂直于新波矢（因 boost 引入 \(A^3\to\gamma(A^3-v\phi/c^2)\) 等耦合），需用规范变换恢复横波条件。

  • 步骤 1：对 \(A^\mu\) 做 Lorentz 变换（沿 \(x_3\)）：\(A'^3=\gamma A^3\)，\(A'^0=-\gamma\beta A^3\)（\(\beta=v/c\)），故变换后 \(A'^\mu=(A'^0,0,0,A'^3)\)，出现了非零时间分量 \(A'^0\)，势矢量不再纯空间。
  • 步骤 2：波矢与频率也变换，新波矢仍沿 \(x_2'\)（横向 boost 不改变传播方向的横向分量性质），但 \(A'^\mu\) 不满足横波规范 \(k'_\mu A'^\mu=0\)。
  • 步骤 3：做规范变换 \(A'^\mu\to A'^\mu+\partial^\mu\Lambda\)，选 \(\Lambda\) 使新 \(A^0=0\) 且空间部分垂直于 \(\mathbf{k}'\)。由 \(\partial^0\Lambda=-A'^0\) 定出 \(\Lambda\)（含 \(e^{-i\omega t+ikx_2}\) 因子），最终
\[ A_B^\mu=\text{Re}\,(0,0,0,C_B)\,e^{-i\omega_B t'+ik_B x_2'} \]

其中 \(\omega_B=\gamma\omega\)（多普勒效应，横向 boost 仍有横向多普勒）、\(C_B=\gamma C\)（振幅变换），且空间部分恢复为纯 \(x_3\) 方向。

考点：横向 boost 下的多普勒频移 + 规范变换恢复横波性——这是相对论电动力学中"势的协变性"与"规范自由度"协同使用的典型题。

9.2 例题（HW12-2）：\(l=1\) 球面电磁波规范变换（洛伦茨→库仑）

题目：洛伦茨规范下 \(l=1\) 球面电磁波矢势 \(A_i(\mathbf{x})=\text{Re}\,\tilde p_{ji}\frac{x_j}{r^3}(-1+ikr)e^{-i\omega t+ikr}\)（\(\tilde p_{ji}\) 对称无迹）。(a) 求洛伦茨规范下对应的标势；(b) 做规范变换使解同时满足库仑规范，求此时矢势。

答案要点

(a) 标势：洛伦茨规范 \(\partial_\mu A^\mu=0\) 即 \(\frac{1}{c^2}\partial_t\phi+\nabla\cdot\mathbf{A}=0\)。由 \(\nabla\cdot\mathbf{A}\)（含 \(\frac{x_j}{r^3}\) 的散度，注意 \(r\to0\) 奇异与 \(1/r\) 衰减）积分得

\[ \phi=-\frac{1}{c^2}\partial_t^{-1}(\nabla\cdot\mathbf{A})\propto\text{Re}\,\tilde p_{ji}\frac{x_j}{r^3}\cdot(\cdots)e^{-i\omega t+ikr} \]

形式上仍含 \(\tilde p_{ji}x_j/r^3\) 结构（因 \(\tilde p_{ji}\) 对称无迹保证了 Lorentz 规范自洽）。

(b) 库仑规范：库仑规范 \(\nabla\cdot\mathbf{A}=0\)。需找规范函数 \(\Lambda\) 使 \(\mathbf{A}\to\mathbf{A}+\nabla\Lambda\) 的散度为零。由 \(\nabla^2\Lambda=-\nabla\cdot\mathbf{A}\)（Poisson 方程）解 \(\Lambda\)，最终矢势的横波部分

\[ \mathbf{A}_{\text{Coulomb}}\propto\text{Re}\,\tilde p_{ji}\left[\frac{x_j}{r^3}(-1+ikr)-\partial_i(\cdots)\right]e^{-i\omega t+ikr} \]

多出的是由 \(\Lambda\) 梯度提供的修正项，保证 \(\nabla\cdot\mathbf{A}=0\)。

考点：球面电磁波在不同规范（洛伦茨/库仑）间的转换——与平面波不同，球面波的规范变换含 \(1/r\) 幂次修正，体现了辐射场的近场/远场结构差异。
