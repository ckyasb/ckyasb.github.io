02玻尔-索末菲模型

1. 黑体辐射与普朗克假说

物理背景与经典困境

黑体 (Blackbody) 是一个理想模型，对应光学部中的“完全吸收体”。 在热力学中，黑体处于热平衡状态。

  • 瑞利-金斯公式 (Rayleigh-Jeans, R-J)：

    该公式的推导基于经典电磁学和统计力学：

    1. 模式密度：将空腔内的电磁场看作驻波。在三维空腔中，频率 \(\nu\) 到 \(\nu+d\nu\) 之间的电磁振动模式数（自由度）为：
    \[N(\nu)d\nu = \frac{8\pi \nu^2}{c^3}d\nu\]
    1. 能量均分定理：根据经典热学，每个谐振子的平均动能和势能各为 \(k_B T/2\)，总平均能量为 \(\bar{\epsilon} = k_B T\)。

    将两者相乘得到能量密度：

    \[u(\nu, T)d\nu = \frac{8\pi k_B T}{c^3}\nu^2 d\nu\]
    • 紫外灾难：当 \(\nu \to \infty\) 时，能量密度趋于无穷大。这在物理上显然是荒谬的，说明经典统计物理的“能量均分定理”在高频区失效。

普朗克假说与修正

普朗克引入了量子化的概念来修正平均能量的计算。

  • 能量量子化假设：

    谐振子的能量不能连续取值，只能是最小能量单元的整数倍：

    \[\epsilon_n = n h \nu, \quad n=1, 2, 3...\]

    其中 \(h\) 是普朗克常数。

  • 普朗克公式：

    利用玻尔兹曼分布 \(P(\epsilon) \propto e^{-\epsilon/k_BT}\) 重新计算平均能量：，这里的计算是两个很经典的级数求和

    \[\bar{\epsilon} = \frac{\sum \epsilon_n e^{-\epsilon_n/k_BT}}{\sum e^{-\epsilon_n/k_BT}} = \frac{h\nu}{e^{h\nu / (k_B T)} - 1}\]

    结合模式密度，得到最终的普朗克黑体辐射公式：

    \[u(\nu, T)d\nu = \frac{8\pi h \nu^3}{c^3} \frac{1}{e^{h\nu / (k_B T)} - 1} d\nu\]
斯忒藩—玻尔兹曼定律

总辐射本领 \(R\) 是对所有频率的能量密度积分：

\[R = \int_0^{\infty} f_{\nu} d\nu = \frac{8\pi h}{c^3} \int_0^{\infty} \frac{\nu^3 d\nu}{e^{h\nu / (k_B T)} - 1}\]

令 \(x = \frac{h\nu}{k_B T}\)，则 \(\nu = \frac{k_B T}{h}x\)，\(d\nu = \frac{k_B T}{h}dx\)。

\[R = \frac{8\pi h}{c^3} \left( \frac{k_B T}{h} \right)^4 \int_0^{\infty} \frac{x^3 dx}{e^x - 1}\]

利用标准积分 \(\int_0^{\infty} \frac{x^3}{e^x - 1}dx = \frac{\pi^4}{15}\)：

\[R = \frac{4}{c} \sigma T^4\]

其中 \(\sigma = \frac{2\pi^5 k_B^4}{15 c^2 h^3} \approx 5.67 \times 10^{-8} \text{ W}/(\text{m}^2\cdot\text{K}^4)\)。

维恩位移定律

求辐射能量密度最大值对应的频率 \(\nu_m\)，令 \(\frac{df_{\nu}}{d\nu} = 0\)：

\[3\nu^2(e^x - 1) - \nu^3 \frac{h}{k_B T} e^x = 0, \quad \text{其中 } x = \frac{h\nu}{k_B T}\]

化简得超越方程：\(x = 3(1 - e^{-x})\)。

解得 \(x \approx 2.8214\)，因此：

\[\frac{h\nu_m}{k_B T} \approx 2.82 \Rightarrow \nu_m \propto T\]

这意为 \(\lambda_m T = \text{常数}\)。

2. 光电效应

经典波动光学的困境

在经典波动光学中，光的能量取决于振幅（光强），与频率无关。 如果光是波，那么：

  • 只要光强足够大，电子就应该能逸出。

  • 电子吸收能量需要时间积累。

实验结果与这些预言完全相反。

爱因斯坦光子模型

爱因斯坦借鉴了普朗克的观点，不仅认为发射是量子化的，认为光在传播过程中本身就是粒子流。

  • 光电效应方程：

    这是能量守恒的直接体现：

    \[E_K = h\nu - W\]

    其中 \(W\) 是逸出功,即为电子从金属表面势阱中逃逸所需的最小能量。

  • 动质量与红限：

    \[m = \frac{h\nu}{c^2}\]

    光子没有静质量，但有动量 \(p=h/\lambda\)。 红限频率 \(\nu_0 = W/h\) 由能量守恒直接决定。

3. 玻尔模型

玻尔模型是经典力学与量子假设的半经典半量子结合。

三大假设

  1. 定态假设：电子在特定轨道上做圆周运动不辐射电磁波。

  2. 频率条件：跃迁释放光子，\(\Delta E = h\nu\)。

  3. 角动量量子化：

    这是从经典力学通往量子力学的桥梁：

    \[L = m_e v r = n\hbar\]

    （这仅仅是一个假设，没有任何推导过程，后来被德布罗意物质波解释为驻波条件 \(2\pi r = n \lambda\)。）

氢原子轨道推导

牛二：

\[\frac{1}{4\pi\epsilon_0}\frac{Ze^2}{r^2} = m_e \frac{v^2}{r}\]

联立角动量量子化条件 \(v = \frac{n\hbar}{m_e r}\)，消去 \(v\)，即可解出：

  • 轨道半径：

    \[r_n = \frac{4\pi\epsilon_0 \hbar^2}{m_e Z e^2} n^2 = \frac{n^2}{Z} a_0\]

    \(a_0 \approx 0.53 \mathring{A}\) 为玻尔半径。

  • 能级：

    总能量 = 动能 + 电势能。由维里定理可知 \(E = -K = \frac{1}{2}U\)：

    \[E_n = -\frac{1}{(4\pi\epsilon_0)^2} \frac{m_e Z^2 e^4}{2 n^2 \hbar^2} = -13.6 \frac{Z^2}{n^2} \text{ eV}\]

有限核质量修正

在力学中，当中心天体质量不是无穷大时，我们需要用折合质量 (Reduced Mass) \(\mu\) 来处理二体问题。

  • 折合质量：

    \[\mu = \frac{m_e M}{M + m_e}\]

  • 里德堡常数修正：

    将公式中的 \(m_e\) 替换为 \(\mu\)，解释了氢 (\(H\)) 与氘 (\(D\)) 的同位素位移。

    \[R_A = R_{\infty} \frac{1}{1 + m_e/M}\]

4. 夫兰克-赫兹实验

这是一个验证能级存在的碰撞实验。

  • 物理过程：

    电子与原子的碰撞分为弹性碰撞和非弹性碰撞。

    • 弹性碰撞：电子能量不足以激发原子，仅改变方向，动能几乎不变（因为电子质量远小于原子）。

    • 非弹性碰撞：电子能量 \(E_e \ge \Delta E\)（激发能），原子吸收能量跃迁，电子损失大量动能。

    \[\frac{1}{2}m_e v^2 \ge \Delta E\]

  • 实验现象：

    电压每增加 \(4.9 \text{ V}\)（也就是汞的第一激发能），电流就跌落一次，直接证明了原子内部能量是分立的。

5. 索末菲模型与相空间

为了解释氢原子光谱的精细结构，索末菲引入了椭圆轨道和相对论修正。这部分用到了分析力学中的相空间概念。

量子化通则

对于周期性运动系统，其作用量变量 是量子化的，来源于玻尔的量子化假设，广义动量与广义坐标之间的积分一定是量子化的。

  • 相积分条件：

    \[\oint p_q dq = n_q h\]

    这里的 \(\oint p dq\) 实际上是相空间 \((q, p)\) 闭合曲线包围的面积。

椭圆轨道与简并

在库仑场（中心力场）中，运动有两个自由度：径向 \(r\) 和角向 \(\phi\)。

  • 角向子化：

    \[\oint p_{\phi} d\phi = \int_0^{2\pi} L d\phi = 2\pi L = n_{\phi} h \implies L = n_{\phi}\hbar\]

    这推导出了玻尔的角动量假设。

  • 形状量子化：

    \[\frac{b}{a} = \frac{n_{\phi}}{n}\]

    \(n\) 主量子数决定能量（半长轴 \(a\)），\(n_{\phi}\) 决定椭圆的扁率。 在非相对论情况下，能量只与 \(n\) 有关，这称为能量简并,这代表只有偏心率是某些固定取值的轨道才能存在。

空间量子化

在外磁场中，轨道的取向不是任意的。

  • 磁量子数：

    \[L_z = m_l \hbar\]

    这意味着角动量矢量 \(\vec{L}\) 在 \(z\) 轴上的投影是分立的。这与经典力学中磁矩可以在磁场中任意取向完全不同。

另外一点，这个关系实际上是旧量子论中的近似关系，实际上在量子力学中应该遵循\(L = \sqrt{l(l+1)}\hbar\)，\(L=n_{\phi}-1 = 0,1,...,n-1\)
但是由于广义坐标和广义动量的关系，角动量在Z轴上的投影依旧是整数，次数取值变为\(-l,...,l\)，后续使用的都是由量子力学导出的结论进行计算

6. 碱金属原子光谱

碱金属可以看作：1个价电子 + 原子实（即核+内层填满轨道的电子）。

屏蔽效应与轨道贯穿

我们可以利用高斯定理来定性理解：

  • 远核区：

    当价电子在原子实外部时，内层电子完全屏蔽了部分核电荷。 有效电荷 \(Z^* \approx Z - (Z-1) = 1\)。此时势场像氢原子。

  • 近核区（轨道贯穿）：

    当电子穿过内层电子云进入内部时，根据高斯定理，屏蔽效应减弱，感受到的 \(Z^*\) 增大。

  • 原子实极化：

    价电子对内层电子和原子核造成的力，引起正负电荷中心偏移

  • 物理结果：

    受到更强的库仑引力 \(\to\) 势能更低 \(\to\) 结合得更紧。 所以，对于相同的主量子数 \(n\)，角量子数 \(l\) 越小，能量越低（这破坏了氢原子的 \(l\) 简并）。

  • 里德堡-里兹公式：

    \[T_{n,l} = \frac{R_A}{(n - \Delta l)^2}\]

    \(\Delta l\) 称为量子亏损，反映了轨道贯穿带来的能量修正。

典型例题与考点

例题1：玻尔模型计算氢原子能级与光谱

题目：用玻尔模型求氢原子基态能量、第一玻尔半径、莱曼系最短波长。

答案要点

玻尔角动量量子化 \(m_e v r=n\hbar\) + 圆周运动向心力 = 库仑力 \(\frac{mv^2}{r}=\frac{e^2}{4\pi\epsilon_0 r^2}\)，解得

  • 玻尔半径：\(a_0=\frac{4\pi\epsilon_0\hbar^2}{m_e e^2}\approx0.529\) Å
  • 能级：\(E_n=-\frac{13.6\text{ eV}}{n^2}\)
  • 基态能量：\(E_1=-13.6\) eV

莱曼系（\(n\to1\) 跃迁），最短波长对应 \(n=\infty\to1\)：

\[ \frac{1}{\lambda_{\min}}=R_\infty=1.097\times10^7\text{ m}^{-1}\Rightarrow\lambda_{\min}\approx912\text{ Å} \]

考点：玻尔模型三假设（轨道量子化、定态、跃迁频率 \(\nu=\Delta E/h\)）；里德伯常数 \(R_\infty\)。

例题2：类氢离子能级

题目：求 \(\text{He}^+\)（\(Z=2\)）的基态能量与第一玻尔半径。

答案要点

类氢离子核电荷 \(Ze\)，能级 \(E_n=-\frac{13.6\text{ eV}\cdot Z^2}{n^2}\)，半径 \(r_n=\frac{a_0}{Z}\cdot n^2\)。

  • \(\text{He}^+\) 基态：\(E_1=-13.6\times4=-54.4\) eV
  • 玻尔半径：\(a_0/2\approx0.265\) Å

考点：类氢离子的 \(Z^2\) 缩放——核电荷越大束缚越紧、轨道越小。

例题3：量子亏损与碱金属能级

题目：为何碱金属能级对相同 \(n\)、不同 \(l\) 不简并（而氢原子简并）？

答案要点

氢原子核外只有一个电子，势场是纯 \(1/r\) 库仑势，能级只依赖 \(n\)（\(l\) 简并）。

碱金属（如 Na）价电子受原子实屏蔽，但当 \(l\) 小（轨道贯穿原子实）时，价电子感受到更大有效核电荷 \(Z^*\)，势能更低、结合更紧。故同 \(n\) 下 \(l\) 越小能量越低（\(l\) 简并破缺）。

里德堡-里茨公式 \(T_{n,l}=\frac{R_A}{(n-\Delta_l)^2}\)，量子亏损 \(\Delta_l\) 反映轨道贯穿修正（\(l\) 小 \(\Delta_l\) 大）。
