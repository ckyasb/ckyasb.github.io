必考计算类型

第2题（微分几何计算）核心题型

这是占半学期、必考的计算题。给一个度规，要求算出全套量：

度规 g_μν → Christoffel Γ^λ_μν → Riemann R^ρ_σμν → Ricci R_μν → 标量 R → Einstein G_μν

必练的典型度规：

度规 课堂/作业出处 关键结果
二维球面 \(ds^2=d\theta^2+\sin^2\theta\,d\varphi^2\) 课堂 + HW1-3 \(R=2\)
庞加莱半平面 \(ds^2=(dx^2+dy^2)/y^2\) HW2-4（必考） \(R=-2\)，测地线为 \(x\) 轴圆弧
Schwarzschild \(ds^2=-(1-2GM/r)dt^2+\cdots\) 第5章 经典检验
BTZ 黑洞 \(ds^2=-f\,dt^2+f^{-1}dr^2+r^2d\varphi^2\) HW5-1 \(\Lambda=-1/\ell^2\)
庞加莱半平面——最可能考的计算题

老师明确说 HW2-4 庞加莱半平面"必考"。完整流程：

  1. Christoffel：\(\Gamma^y_{yy}=\Gamma^x_{xy}=\Gamma^x_{yx}=-1/y\)，\(\Gamma^y_{xx}=1/y\)。
  2. Riemann：\(R_{xyxy}=-1/y^2\)。
  3. Ricci：\(R_{xx}=R_{yy}=1/y^2\)。
  4. 标量：\(R=-2\)（常负曲率，双曲几何）。
  5. 测地线：\(\ddot x-\frac{2}{y}\dot x\dot y=0\) → \((x-x_0)^2+y^2=1/C^2\)（圆心在 \(x\) 轴的圆弧）。
  6. 正交标架法：\(\theta^1=dx/y\)，\(\theta^2=dy/y\)，\(\omega^1{}_2=-dx/y\)，\(R_{12}=-dx\wedge dy/y^2\)。

两种方法（坐标基 + 正交标架）都要会。

应用题（第3、4题）核心题型

老师原话："原则上如果你什么都不知道，你光靠试卷上给的公式，你也足够把它算出来。"——应用题考的不是背公式，而是知道用什么公式、怎么用。以下每题给出完整解题链。

应用1：有效势与测地线（最核心，所有应用题的基础）

题目原型：给定一个静态球对称度规（如 Schwarzschild、BTZ），写出径向测地线方程并分析轨道类型。

解题链（每一步卷面公式都会给，但你必须知道为什么要做这一步）：

步骤1：从度规的 Killing 矢量提取守恒量。度规不显含 \(t\) 和 \(\varphi\)，故有

\[ E = -g_{\mu\nu}\xi^\mu_{(t)}u^\nu = B(r)\frac{dt}{d\tau}\quad(\text{能量}),\qquad L = g_{\mu\nu}\xi^\mu_{(\varphi)}u^\nu = r^2\frac{d\varphi}{d\tau}\quad(\text{角动量}) \]

（对 Schwarzschild，\(B(r)=1-2GM/r\)；对 BTZ，\(B(r)=f(r)=r^2/\ell^2-M\)。）

为什么走这一步

静态球对称时空中，Killing 矢量给出的守恒量是唯一的简化手段。找到 \(E\) 和 \(L\) 后，二阶测地线 ODE 直接降为一阶有效势问题——不需要解完整的耦合 ODE。

步骤2：代入归一化条件。测地线切矢量满足 \(g_{\mu\nu}u^\mu u^\nu=\epsilon\)（\(\epsilon=-1\) 类时，\(\epsilon=0\) 类光）：

\[ -B\dot t^2 + B^{-1}\dot r^2 + r^2\dot\varphi^2 = \epsilon \]

用步骤1的 \(E,L\) 消去 \(\dot t,\dot\varphi\)：

\[ \boxed{\frac12\dot r^2 + V_{\text{eff}}(r) = \frac12 E^2},\qquad V_{\text{eff}}(r) = \frac12\!\left(\epsilon + \frac{L^2}{r^2}\right)\!B(r) \]

步骤3：分析有效势。画出 \(V_{\text{eff}}(r)\) 的形状，找到极值点（圆轨道条件 \(V'_{\text{eff}}=0\)），判断束缚/逃逸/坠入。

Schwarzschild 有效势详解
\[ V_{\text{eff}}(r) = \frac12\!\left(\epsilon+\frac{L^2}{r^2}\right)\!\left(1-\frac{2GM}{r}\right) \]
  • 展开：\(V_{\text{eff}}=-\frac{\epsilon GM}{r}+\frac{L^2}{2r^2}-\frac{GML^2}{r^3}\)（牛顿项 + 离心项 + GR \(1/r^3\) 修正）
  • \(1/r^3\) 项是 GR 独有的——它使有效势在 \(r\) 很小时被拉向 \(-\infty\)（坠入奇点不可避免），也使得圆轨道有最内层稳定圆轨道 ISCO \(r_{\text{ISCO}}=6GM\)（牛顿力学中无 \(1/r^3\) 项，无 ISCO）

步骤4：判轨道。由 \(\frac12\dot r^2=E^2/2-V_{\text{eff}}(r)\)，初始 \(E\) 与 \(V_{\text{eff}}\) 比较： - \(E^2/2 > V_{\text{eff}}\) 极大值 → 粒子从无限远来，达到最接近点反弹（散射） - \(E^2/2 = V_{\text{eff}}\) 极小值 → 稳定圆轨道 - \(E^2/2 < 0\) → 束缚椭圆轨道（进动！见应用2）

应用2：水星近日点进动

解题链：

步骤1：用 Binet 变量 \(u=1/r\)（或无量纲 \(\xi=L^2/(GMr)\)），把轨道方程从 \((r,\tau)\) 转换为 \((\xi,\varphi)\)。由测地线方程消去 \(\tau\)，对 \(\varphi\) 求导得

\[ \frac{d^2\xi}{d\varphi^2} + \xi - \alpha = \frac{G^2M^2}{L^2}\!\left[3\gamma\xi^2 + (4\alpha-2\beta-2\gamma)\xi\right] \]

（PPN 参数化下 \(A(r)=1+2\gamma GM/r+\cdots\)，\(B(r)=1-2\alpha GM/r+2(\beta-\gamma)(GM/r)^2+\cdots\)。）

步骤2：零阶解（右边为零）\(\xi_0=\alpha+e\cos\varphi\)——这是牛顿椭圆（要求 \(\alpha=1\) 即质量正确定标）。牛顿椭圆是闭合的，每圈回到同一点。

步骤3：一阶微扰。把 \(\xi_0\) 代入右边，右边含 \(3\gamma\xi_0^2\)（来自 GR 的 \(1/r^3\) 修正）和线性项。展开 \(\xi_0^2=1+2e\cos\varphi+(e^2/2)(1+\cos2\varphi)\)： - 共振项 \(2e\cos\varphi\)：频率与齐次解相同 \(\varphi\) → 产生长期进动（每圈积累） - \(\cos2\varphi\) 项：频率不同，产生周期振荡（不积累）

\[ \boxed{\Delta\varphi = \frac{2+2\gamma-\beta}{3}\cdot\frac{6\pi GM}{a(1-e^2)}} \]

步骤4：代数值。GR 下 \(\beta=\gamma=1\)，得 \(\Delta\varphi=6\pi GM/[a(1-e^2)]\)。水星 \(a=5.79\times10^7\) km，\(e=0.2056\)，\(M_\odot=1.99\times10^{30}\) kg → \(\Delta\varphi\approx43''\)/世纪。

为什么是43角秒/世纪

每圈进动 \(6\pi GM/[a(1-e^2)]\approx5\times10^{-7}\) rad，水星每世纪约 415 圈，累积 \(\approx2\times10^{-4}\) rad \(\approx43\) 角秒。这个数很小但水星轨道偏心、离太阳近，效应恰好可测——是 GR 第一个实验胜利。

应用3：光线偏折

解题链：

步骤1：光子 \(\epsilon=0\)，类光测地线。与有质量粒子唯一区别：归一化条件的 \(\epsilon\) 从 \(-1\) 变成 \(0\)。

步骤2：引入碰撞参数 \(b=L/E\)（\(E=1\) 方便标度）。无量纲化得

\[ \frac{d^2\xi}{d\varphi^2} + \xi + \gamma - 1 = 3\gamma\frac{G^2M^2}{L^2}\xi^2 \]

（PPN 下 \(L\approx b\)。）

步骤3：零阶解（忽略 \(\xi^2\)）——Newton 直线：

\[ \xi_0 = 1-\gamma + \left(\frac{L}{GM}+\gamma-1\right)\sin\varphi \]

（GR 下 \(\gamma=1\) → \(\xi_0=(L/GM)\sin\varphi\)，即 \(r=b/\sin\varphi\)——沿 \(x=b\) 的直线。）

步骤4：一阶修正由 \(\xi_0^2\) 代入，解得

\[ \xi_1 \approx 3\gamma\!\left(\frac12 + \frac16\cos2\varphi\right) \]

常数项 \(1/2\) 是关键——它使无穷远处 \(\xi=0\) 不再发生在 \(\varphi=0\) 而是 \(\varphi=-(1+\gamma)GM/b\)。

步骤5：偏折角 = 两倍渐近角

\[ \boxed{\Delta = 2|\varphi_{r=\infty}| = \frac{1+\gamma}{2}\cdot\frac{4GM}{b}} \]

太阳边缘 \(b=R_\odot\)，GR \(\gamma=1\) → \(\Delta=4GM_\odot/R_\odot\approx1.75''\)。1919 Eddington 日食观测 \(\approx1.61\pm0.30''\)，与 GR 一致。

为什么光子是无质量粒子，却有'偏折'

Newton 力学里光子无质量不受引力——这是粒子力学的问题。GR 里光子沿测地线，是时空本身弯曲使光的路径弯曲，与光子有质量否无关。Newton 给 \(\Delta_{\text{Newton}}=2GM/b=0.875''\)，GR 给 \(4GM/b=1.75''\)——恰是两倍。这是经典检验区分 Newton 与 GR 最清晰的信号。

应用4：引力红移

题目原型：光线从 \(r_1\) 发射、在 \(r_2\) 接收到，频率比是多少？

解题链：

步骤1：静态时空中，沿类光测地线 \(k^\mu\)，由 Killing 矢量 \(\partial_t\) 得守恒量 \(E=-g_{\mu\nu}\xi^\mu_{(t)}k^\nu=g_{00}k^0\)。注意 \(g_{00}=-B(r)\)。

步骤2：静态观测者的四速 \(u^\mu=(1/\sqrt{B},0,0,0)\)（归一化 \(u^\mu u_\mu=-1\)）。观测频率为 \(\omega=-u_\mu k^\mu\)。

步骤3：消去 \(k^\mu\)：

\[ \frac{\omega_2}{\omega_1} = \sqrt{\frac{g_{00}(r_1)}{g_{00}(r_2)}} = \sqrt{\frac{B(r_1)}{B(r_2)}} = \sqrt{\frac{1-2GM/r_1}{1-2GM/r_2}} \]

\(r_2\gg r_1\) 时（远处收到）：

\[ z = \frac{\omega_2-\omega_1}{\omega_1} \approx -\frac{GM}{r_1} \]

物理解读：光子爬出引力势时损失能量、波长变长（红移）。引力红移是 \(g_{00}\) 随位置变化的直接效应——"时钟在不同引力势处走速不同"。

应用5：Friedmann 方程应用

题目原型：给定物态方程 \(w=p/\rho\)，求 \(a(t)\)；或由观测 \(\rho\) 推断宇宙几何 \(k\)。

解题链：

步骤1：Friedmann 方程（卷面给）：

\[ H^2 = \left(\frac{\dot a}{a}\right)^2 = \frac{8\pi G}{3}\rho - \frac{k}{a^2} + \frac{\Lambda}{3} \]

步骤2：联合能量守恒 \(\dot\rho+3H(\rho+p)=0\)。代入 \(p=w\rho\)，积分得 \(\rho\propto a^{-3(1+w)}\)。

步骤3：代回 Friedmann 方程（平直 \(k=0\)，暂时忽略 \(\Lambda\)）：

\[ \left(\frac{\dot a}{a}\right)^2 \propto a^{-3(1+w)} \;\Longrightarrow\; \dot a \propto a^{-(1+3w)/2} \;\Longrightarrow\; a(t) \propto t^{\frac{2}{3(1+w)}} \]
成分 \(w\) \(a(t)\)
物质 \(0\) \(a\propto t^{2/3}\)
辐射 \(1/3\) \(a\propto t^{1/2}\)
暗能量 \(-1\) \(a\propto e^{Ht}\)（指数膨胀）

步骤4（如有数值）：定义临界密度 \(\rho_c=3H^2/(8\pi G)\)，密度参数 \(\Omega_i=\rho_i/\rho_c\)。\(\Omega=1\) → \(k=0\) 平直；\(\Omega>1\) → \(k=+1\) 闭；\(\Omega<1\) → \(k=-1\) 开。代观测数据推断宇宙几何。

应用6：Olbers 佯谬（定量估算题）

解题链：

步骤1：经典静态宇宙。球壳 \(r\to r+dr\) 内恒星数 \(dN=n\cdot4\pi r^2 dr\)，每颗星流量 \(L/(4\pi r^2)\)，球壳贡献 \(dF=nL\,dr\)——与 \(r\) 无关（球壳体积 \(\propto r^2\) 与逆平方 \(\propto 1/r^2\) 精确抵消）。

\[ F = \int_0^\infty nL\,dr \to \infty \]

步骤2：有限年龄修正。宇宙年龄 \(t_0\)，光最多传播 \(ct_0\)，截断积分

\[ F = nL\,ct_0 \]

数值（\(n\approx0.04\)/光年³，\(L\approx3.8\times10^{26}\) W，\(t_0\approx138\) 亿年）→ \(F\approx10^3\) W/m²。比太阳常数 1367 W/m² 还小一个量级但同量级——仅靠年龄有限不解决问题。

步骤3：膨胀红移。Tolman 关系 \(I_{\text{obs}}=I_{\text{emit}}/(1+z)^4\)（光子能量+到达率+立体角+时间膨胀四重效应）。用 \(H(z)\) 与 \(dF/dz\) 积分，\((1+z)^4\) 使高红移贡献指数衰减 → 积分收敛。

结论：宇宙膨胀红移（\((1+z)^4\)）是解决 Olbers 佯谬的主导机制，比年龄有限更重要。

复习策略

  1. 公式不背：卷面全给，重在知道哪个公式解决哪类问题。
  2. 计算熟练度：庞加莱半平面、Schwarzschild 测地线这类标准计算要练到 1 小时内完成全套。
  3. 概念清晰：第1题纯概念（如"曲率 vs 联络"、"为何挠率为0"、"Weyl 对应引力波"），理解即得分。
  4. 先易后难：老师反复强调优先做自己能做的，不要在一题耗太久（计算题给分反而不高）。

三分里奇分解不做（04-07 课堂）

Ricci 的迹/无迹拆分'意义不大，不做'

"就是如果你要把它做拆分的话，它是分成这样两部分，但是事实上我后面会发现这样的拆分意义不是特别大……所以我们并不做这样的拆分。"

老师明确说 Riemann 的三分分解（标量曲率部分 + 无迹 Ricci 部分 + Weyl 部分）课堂不做，只做二分（Ricci 受方程约束 vs Weyl 自由→引力波）。

不考：标准三分式 \(R_{\rho\sigma\mu\nu}=C_{\rho\sigma\mu\nu}+(\text{无迹Ricci项})+(\text{标量项})\) 的完整展开。 考：\(N=4\) 时 \(20=10(\text{Ricci})+10(\text{Weyl})\) 的二分、Weyl 不受 Einstein 方程约束→引力波。

费米子耦合与挠率（04-07 课堂）

耦合费米子的挠率理论不考

"我们这个课估计不会讲到了，但是比如说你需要把我们这个理论耦合耦合到费米子……通常人们就不会采用这个（Levi-Civita 联络），会采用其他的方式。"

不考：挠率非零的理论（如 Einstein-Cartan）、耦合费米子时需引入自旋联络的进阶讨论。 考：GR 取挠率为 0 是物理假设（Levi-Civita 联络），原因理解即可。

不可约表示的语言不用（04-07 课堂）

不用群论/不可约表示的语言

"不考虑这个就是用群论的语言去讨论，我们是采用直接构造的方式把这些分量全部构造出来。"

不考：用群论不可约表示（irreducible representation）分解曲率张量。 考：直接构造 Weyl 张量 + 缩并得 Ricci。

高频必考点（老师反复强调）

1. 镜像法（电动力学第6章，最高频）

  • 接地球外点电荷 → 镜像电荷 \(q'=-\frac{R}{r}Q\) 在 \(R^2/r\) 处。
  • 线性叠加：非接地 → 接地（镜像）+ 均匀带电球。
  • 电偶极子的镜像：纵向诱导镜像电荷+偶极子，横向只诱导偶极子。
  • 锐角区域 Green 函数：夹角 \(\pi/n\) 可用多重镜像。

2. 张量方法（\(\epsilon\epsilon\) 恒等式）

\[ \epsilon_{ijk}\epsilon_{ilm}=\delta_{jl}\delta_{km}-\delta_{jm}\delta_{kl} \]

所有矢量恒等式、边界↔体积分转换都靠它。小测 A 第1题就是这类。

3. 相对论电磁场（小测 B 第2题原型）

  • 横向 boost：\(\mathbf{E}_\perp'=\gamma(\mathbf{E}_\perp+\mathbf{v}\times\mathbf{B})\)，\(\mathbf{B}_\perp'=\gamma(\mathbf{B}_\perp-\mathbf{v}\times\mathbf{E}/c^2)\)。
  • 线偏振在另一系可能变椭圆偏振（两分量不同相）。
  • 多普勒：\(\omega'=\gamma\omega(1-v\cos\theta/c)\)。

4. 辐射（考试截止线前最后一章）

  • 电偶极辐射功率 \(P\propto\ddot{\mathbf{p}}^2\)（Larmor 类比）。
  • 圆周运动电荷：偶极矩以 \(\omega\) 旋转（\(\omega\) 辐射），四极矩以 \(2\omega\) 振荡（\(2\omega\) 辐射），磁偶极矩常量（不辐射）。
  • 球面波能量守恒：通量 \(\propto1/r^2\)，球面能流与 \(R\) 无关。

公式策略

电动力学：基本公式要熟

电动力学不像 GR 那样全部给公式——老师明确："一些基本的公式还是需要大家基本的很常用的公式，还是需要大家这个要要能够心里有数的。"

需熟记：Maxwell 方程、Lorentz 力、Coulomb/Biot-Savart、镜像法核心式、Lorentz 变换、Larmor/偶极辐射功率。复杂公式（如多极展开系数、推迟势详细形式）卷面会给或不必精确记忆，重在定性结构（如 \(1/r\) vs \(1/r^2\) 衰减、\(\omega^4\) 依赖）。

"哪怕你整个公式记不清楚，就是没关系……对于这种足够主要的方式就是我我就比如说真的考试要遇到的话，我是可以给大家的……但是一些基本的很常用的公式，还是需要大家心里有数。"
