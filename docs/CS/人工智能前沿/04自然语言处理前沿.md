# 04 自然语言处理前沿

**2024–2025 春夏学期 | 第三讲 (05-17)** | 大语言模型重新定义了 NLP 的研究范式，从独立的任务系统迈向通用语言智能体。

---

## 1. 大语言模型能力解析

### 1.1 核心能力维度

- **生成能力** — 流畅连贯的长文本生成，支持多风格、多领域
- **推理能力** — 数学推理、常识推理、逻辑推理
- **知识整合** — 从海量训练语料中提取并整合知识
- **指令遵循** — 理解并执行复杂自然语言指令
- **多轮对话** — 维持上下文，进行连贯对话

### 1.2 上下文学习 (In-Context Learning)

无需梯度更新，仅通过 Prompt 中的示例即可完成任务。ICL 的涌现依赖于模型规模和训练数据多样性：

$$
\text{Prompt} = [\text{示例}_1, \text{示例}_2, \dots, \text{示例}_k, \text{查询}] \xrightarrow{\text{LLM}} \text{回答}
$$

??? note "ICL 的可能机制"
    ICL 可理解为隐式的梯度下降：Transformer 前向传播中，示例的注意力模式隐式编码了任务结构，等价于在元学习空间中进行参数更新。

## 2. 思维链与推理增强

### 2.1 CoT (Chain-of-Thought)

通过逐步推理提升复杂问题的准确率。主要变体：

| 方法 | 描述 |
|:---|:---|
| Zero-shot CoT | "Let's think step by step" |
| Few-shot CoT | 提供推理示例 |
| Self-Consistency | 多次采样取多数投票 |
| Tree-of-Thoughts | 树状搜索推理路径 |
| Graph-of-Thoughts | 图结构推理规划 |

### 2.2 推理的 Scaling

**Test-Time Compute Scaling** — 在推理阶段分配更多计算资源（如多次采样、搜索），可显著提升推理质量。

## 3. 人类对齐 (Alignment)

### 3.1 RLHF (Reinforcement Learning from Human Feedback)

📅 05-17
</p>

三阶段流程：

1. **SFT** — 在高质量指令数据上微调
2. **奖励建模** — 训练奖励模型 $r_\theta(x, y)$ 拟合人类偏好
3. **RL 优化** — 使用 PPO 算法最大化奖励，同时约束 KL 散度

$$
\text{目标} = \mathbb{E}_{y \sim \pi_\phi}[r_\theta(x, y)] - \beta \cdot \text{KL}(\pi_\phi \| \pi_{\text{SFT}})
$$

### 3.2 DPO 与替代方案

**DPO (Direct Preference Optimization)** 无需显式奖励模型，直接利用偏好对优化策略：

$$
\mathcal{L}_{\text{DPO}} = -\mathbb{E}_{(x, y_w, y_l)} \left[ \log \sigma \left( \beta \log \frac{\pi_\theta(y_w|x)}{\pi_{\text{ref}}(y_w|x)} - \beta \log \frac{\pi_\theta(y_l|x)}{\pi_{\text{ref}}(y_l|x)} \right) \right]
$$

## 4. RAG 与 Agent

### 4.1 检索增强生成 (RAG)

将外部知识库的检索与 LLM 生成结合，缓解幻觉与知识过时问题：

$$
\text{查询} \xrightarrow{\text{检索}} \text{相关文档} \xrightarrow{\text{上下文注入}} \text{LLM} \xrightarrow{\text{生成}} \text{基于事实的回答}
$$

### 4.2 LLM Agent

将 LLM 作为核心调度器，结合工具调用、记忆管理和规划能力：

- **工具使用** — 调用搜索、计算、代码执行等外部 API
- **记忆机制** — 短期记忆（上下文窗口）与长期记忆（向量存储）
- **任务规划** — 将复杂任务分解为子任务，动态调整

## 本章小结

LLM 的能力涌现、上下文学习、思维链推理和人类对齐是当前 NLP 最核心的前沿议题。RAG 和 Agent 框架将 LLM 从对话系统扩展为通用智能体。评估基准的持续发展推动着对模型能力边界的深入理解。
