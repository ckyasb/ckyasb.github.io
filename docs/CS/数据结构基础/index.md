# 数据结构基础

**2025-2026 春夏学期 | 浙江大学 | 教材：Mark Allen Weiss, Data Structures and Algorithm Analysis in C**

本讲义覆盖数据结构的核心内容，从算法分析基础出发，系统介绍线性结构、树形结构、图结构以及各种经典算法。
