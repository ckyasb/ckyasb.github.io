# 08 图算法（Graph Algorithms）

图是表示"多对多"关系的数据结构。本章涵盖图的表示、遍历、最短路径、网络流与最小生成树等核心算法。

---

## 1. 图的基本概念

**图** $G = (V, E)$，$V$ 为顶点集，$E$ 为边集。

| 类型 | 说明 |
|:---|:---|
| 无向图 | 边无方向，$(u, v) = (v, u)$ |
| 有向图 | 边有方向，$\langle u, v \rangle \neq \langle v, u \rangle$ |
| 加权图 | 边/弧附有权值 |

### 1.1 表示方法

| 方法 | 空间 | 判邻 | 遍历某点邻边 |
|:---|:---|:---|:---|
| **邻接矩阵** | $O(V^2)$ | $O(1)$ | $O(V)$ |
| **邻接表** | $O(V + E)$ | $O(\deg(v))$ | $O(\deg(v))$ |

---

## 2. 拓扑排序（Topological Sort）

对有向无环图（DAG）的顶点进行线性排序，使每条边 $\langle u, v \rangle$ 中 $u$ 出现在 $v$ 之前。

**算法**：维护入度表，反复删除入度为 0 的顶点。复杂度 $O(V + E)$。

---

## 3. 最短路径（Shortest Path）

### 3.1 无权图 — BFS

广度优先搜索：从起点逐层扩展。

$$
\boxed{\text{BFS 最短路径} = O(V + E)}
$$

### 3.2 正权图 — Dijkstra 算法

贪心策略：每次选取未确定顶点中距离最小的进行松弛。

$$
\boxed{\text{Dijkstra} = O(E + V\log V)\;(\text{堆优化})}
$$

| 实现方式 | 复杂度 |
|:---|:---|
| 数组扫描 | $O(V^2)$ |
| 二叉堆 | $O(E\log V)$ |
| 斐波那契堆 | $O(E + V\log V)$ |

### 3.3 负权图 — Bellman-Ford 算法

进行 $V-1$ 轮松弛，第 $k$ 轮得到最多 $k$ 条边的最短路径。

$$
\boxed{\text{Bellman-Ford} = O(VE)}
$$

可检测**负权环**：第 $V$ 轮仍有松弛则存在负环。

---

## 4. 网络流（Network Flow）

**最大流问题**：在容量限制下最大化从源点 $s$ 到汇点 $t$ 的流量。

### 最大流最小割定理

$$
\boxed{\text{最大流值} = \text{最小割容量}}
$$

**Ford-Fulkerson 方法**：沿增广路径增加流量。Edmonds-Karp 用 BFS 找最短增广路，复杂度 $O(VE^2)$。

---

## 5. 最小生成树（MST）

### 5.1 Kruskal 算法

按边权从小到大加入，若形成环则跳过，使用**并查集**判环。

$$
\boxed{\text{Kruskal} = O(E\log E)}
$$

### 5.2 Prim 算法

从起点开始，每次选择与当前树相连的最小边扩展。

$$
\boxed{\text{Prim} = O(E\log V)\;(\text{堆优化})}
$$

---

## 6. 深度优先搜索（DFS）应用

### 6.1 关节点（Articulation Point）

DFS 树中，若节点 $u$ 的某个子节点 $v$ 满足 $\text{low}[v] \ge \text{num}[u]$，则 $u$ 是关节点（去除后图不连通）。

### 6.2 强连通分量（SCC）

**Tarjan 算法** / **Kosaraju 算法**用于求有向图的强连通分量，复杂度 $O(V + E)$。

---

## 本章小结

- 邻接表适合稀疏图，邻接矩阵适合稠密图
- Dijkstra 解决正权最短路径，Bellman-Ford 处理负权并检测负环
- 网络流基于增广路径，最大流 = 最小割
- Kruskal 和 Prim 分别以边和顶点为视角构造 MST
- DFS 扩展应用包括关节点和强连通分量

**参考**：DS08_Ch09_Graph, DS09_Ch09_Shortest-Path, DS10_Ch09_Network Flow_MST, DS11_Ch09_DFS PPT

## 7. 典型例题与课堂重点

### 7.1 例题：Dijkstra 执行过程

**题目**：给定图（见 DS09 PPT），从源点 $v_1$ 跑 Dijkstra，写出每轮选中的顶点与距离更新。

??? note "思路与答案要点"
    Dijkstra 维护"已确定最短距离"集合 $S$ 和"当前估计距离" $d[v]$：

    1. 初始化 $d[v_1]=0$，其余 $d[v]=+\infty$。
    2. 每轮从 $V\setminus S$ 中选 $d$ 最小的顶点 $u$ 加入 $S$，并对 $u$ 的每条出边 $(u,v,w)$ 做**松弛**：若 $d[u]+w < d[v]$ 则更新 $d[v]$。
    3. 重复直到所有顶点入 $S$。

    关键不变量：每轮选中的顶点 $u$ 的 $d[u]$ 已是最终最短距离（因边权非负，后续不会再被更小值更新）。

    **复杂度**：数组实现选最小 $O(V)$、松弛 $O(1)$，共 $V$ 轮 → $O(V^2)$；堆优化选最小 $O(\log V)$、共 $E$ 次松弛 → $O(E\log V)$；斐波那契堆 $O(E+V\log V)$。

    **正权限制**：Dijkstra 要求**边权非负**——若有负权，"后续顶点入 $S$ 后不再更新"的不变量被破坏，需用 Bellman-Ford。

### 7.2 例题：拓扑排序（DAG）

**题目**：对给定 DAG 求一种拓扑序。

??? note "答案要点"
    **Kahn 算法**（入度法）：

    1. 计算所有顶点入度，把入度 0 的顶点入队。
    2. 反复出队一个顶点输出，并把它的所有出边邻点入度减 1；若某邻点入度变 0 则入队。
    3. 直到队空。若输出顶点数 $<V$，说明图有环（非 DAG）。

    复杂度 $O(V+E)$。

    **DFS 法**：对图 DFS，顶点**完成时**（后序）入栈，最后栈顶到栈底即一种拓扑序。同样 $O(V+E)$。

    **应用**：编译依赖顺序、课程先修关系、任务调度。

### 7.3 例题：最小生成树（Prim vs Kruskal）

**题目**：对给定加权无向图，分别用 Prim 和 Kruskal 求 MST，对比过程。

??? note "答案要点"
    **Prim**（顶点视角，"长树"）：

    - 从任一顶点出发，维护已选集合 $S$。
    - 每次选**连接 $S$ 与 $V\setminus S$ 的最小权边**（横切边），把对端顶点加入 $S$。
    - 用最小堆维护横切边，$O(E\log V)$。

    **Kruskal**（边视角，"并森林"）：

    - 所有边按权排序。
    - 依次考虑每条边，若两端点不在同一连通分量（用**并查集**判）则加入 MST，否则跳过。
    - 排序 $O(E\log E)$、并查集近 $O(1)$，整体 $O(E\log E)$。

    **对比**：Prim 适合**稠密图**（堆优化下 $O(E\log V)$，与边数有关但 V 小）；Kruskal 适合**稀疏图**且实现简单（排序为主）。两者都保证得到总权最小的生成树（由**割性质**：横切最小边必在某 MST 中）。

### 7.4 例题：关节点与桥（DFS 应用）

**题目**：求无向连通图的关节点（割点）。

??? note "答案要点"
    对图做 DFS，维护：

    - `num[u]`：$u$ 的 DFS 发现时间戳。
    - `low[u]`：$u$ 经由其后代最多一条回边能到达的最早祖先的 `num`。

    `low[u] = min( num[u], min{low[v] : v 是 u 的子}, min{num[w] : (u,w) 是回边} )`

    **关节点判定**：

    - **根**是关节点 ⟺ 根有 $\ge 2$ 个 DFS 子（删根后子树彼此断开）。
    - **非根 $u$** 是关节点 ⟺ 存在子 $v$ 使 `low[v] >= num[u]`（$v$ 的子树无法绕过 $u$ 回到 $u$ 的祖先，删 $u$ 后 $v$ 子树与外界断开）。

    **桥**（割边）判定：边 $(u,v)$（$v$ 是 $u$ 的子）是桥 ⟺ `low[v] > num[u]`（严格大于，$v$ 子树完全无法回达 $u$）。

    复杂度 $O(V+E)$。

### 7.5 例题：网络流（Ford-Fulkerson / Edmonds-Karp）

**题目**：求源 $s$ 到汇 $t$ 的最大流。

??? note "答案要点"
    **Ford-Fulkerson 方法**：

    1. 初始流为 0。
    2. 在**残量图**中找一条 $s\to t$ 的**增广路径**（残量 $>0$ 的边组成的路径）。
    3. 沿增广路径推送流量（取路径上最小残量），更新残量图（正向减、反向加）。
    4. 重复直到无增广路径。此时流即最大流。

    **最大流最小割定理**：最大流值 = 最小 $s$-$t$ 割的容量。

    **Edmonds-Karp**：用 BFS 找**最短**增广路（按边数），保证 $O(VE^2)$，避免 Ford-Fulkerson 在容量为无理数时不收敛或退化为 $O(E\cdot\text{最大流值})$。

    **应用**：二分图最大匹配（建超级源汇，最大流即最大匹配）、项目选择、图像分割等。

## 8. 课堂重点速记

| 概念 | 关键点 |
|:---|:---|
| 图表示 | 稀疏图用邻接表 $O(V+E)$，稠密图用邻接矩阵 $O(V^2)$ |
| BFS | 无权最短路 $O(V+E)$；逐层扩展，用队列 |
| DFS | 用栈/递归；`num`/`low` 数组支撑关节点、桥、SCC |
| Dijkstra | 正权最短路；贪心 + 松弛；堆优化 $O(E\log V)$ |
| Bellman-Ford | 负权最短路 + 负环检测；$O(VE)$；$V-1$ 轮松弛 |
| 拓扑排序 | DAG；Kahn 入度法或 DFS 后序；$O(V+E)$ |
| Kruskal | MST，边视角 + 并查集，$O(E\log E)$ |
| Prim | MST，顶点视角 + 堆，$O(E\log V)$ |
| 最大流 | 增广路径；Edmonds-Karp $O(VE^2)$；最大流=最小割 |
| 关节点/桥 | `low[v] >= num[u]` / `low[v] > num[u]` |
| SCC | Tarjan / Kosaraju，$O(V+E)$ |
