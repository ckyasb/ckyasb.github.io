# 02 线性表、栈与队列（Lists, Stacks, Queues）

线性结构是数据结构中最基础的一类：元素按顺序排列，每个元素有唯一的"前驱"与"后继"。栈和队列是两种受限的线性表，因受限而获得高效。

---

## 1. 抽象数据类型（ADT）

ADT 将**数据**与**操作**封装为一体，对外暴露接口、隐藏实现。用户只需知道"能做什么"而非"怎么做"。

**意义**：分离接口与实现，使算法可独立于数据结构的具体实现而设计。同一 ADT（如 List）可由数组或链表实现，调用者不感知差异。

---

## 2. 线性表（List ADT）

### 2.1 数组实现

??? note "自测"
    **Q**: 数组实现线性表，访问和插入/删除的复杂度分别是多少？为什么？

    ??? note "答案"
        访问 $O(1)$（下标直接寻址，连续内存）；插入/删除 $O(N)$（需移动后续元素）。

- 元素在**连续内存**中存储。
- **访问**：$O(1)$ 随机访问（下标直接寻址）。
- **插入/删除**：$O(N)$ 平均（需移动后续元素）。

??? note "动态数组：摊还 $O(1)$ 插入"
    静态数组容量固定。**动态数组**（如 C++ `vector`、Java `ArrayList`）在满时扩容到 2 倍：

    - 单次扩容 $O(N)$（复制全部元素）。
    - 摊还分析：$N$ 次插入总代价 $N+N/2+N/4+\cdots<2N$，故每次插入摊还 $O(1)$。

    这是摊还分析的经典例子——最坏情况被大量便宜操作分摊。

### 2.2 链表实现

??? note "自测"
    **Q**: 单链表删除已知节点（无前驱指针时）如何做到 $O(1)$？

    ??? note "答案"
        偷值法：把后继节点的值复制到当前节点，再删除后继。$O(1)$，但尾节点不适用。

| 操作 | 单链表 | 双链表 |
|:---|:---|:---|
| 头插 | $O(1)$ | $O(1)$ |
| 尾插（有尾指针） | $O(1)$ | $O(1)$ |
| 按值查找 | $O(N)$ | $O(N)$ |
| 按索引查找 | $O(N)$ | $O(N)$ |
| 删除已知节点 | $O(1)$（需双链或偷值法） | $O(1)$ |

**单链表删除已知节点**的偷值法（无前驱指针时）：把后继节点的值复制到当前节点，再删除后继——$O(1)$ 删除，但尾节点不适用。

### 2.3 双向链表

??? note "自测"
    **Q**: 双向链表相比单链表的主要优势是什么？代价呢？

    ??? note "答案"
        优势：$O(1)$ 删除已知节点（有 `prev` 指针，无需遍历找前驱）。代价：每节点多一个指针，空间开销更大。

每个节点含 `prev` 和 `next` 指针，用于 $O(1)$ 删除指定节点（已知前驱），但空间开销更大（每节点多一个指针）。

??? note "数组 vs 链表的选择"
    | 特性 | 数组 | 链表 |
    |:---|:---|:---|
    | 随机访问 | $O(1)$ | $O(N)$ |
    | 头/尾插入 | $O(N)$/$O(1)$（尾） | $O(1)$（有尾指针） |
    | 中间插删 | $O(N)$ | $O(1)$（已知位置） |
    | 内存 | 连续，缓存友好 | 分散，缓存不友好 |
    | 空间开销 | 仅数据 | 每节点 +指针 |

    **经验**：需频繁随机访问用数组；需频繁头尾插删用链表。现代 CPU 缓存使数组常更优（连续访问预取），除非插删极频繁。

## 3. 栈（Stack ADT）

**后进先出**（LIFO, Last-In First-Out）。

### 3.1 基本操作

??? note "自测"
    **Q**: 栈是 LIFO 还是 FIFO？`Push`/`Pop` 的复杂度是多少？

    ??? note "答案"
        LIFO（后进先出）。`Push`/`Pop` 均 $O(1)$。

| 操作 | 含义 | 复杂度 |
|:---|:---|:---|
| `Push(x)` | 入栈 | $O(1)$ |
| `Pop()` | 出栈 | $O(1)$ |
| `Top()` / `Peek()` | 查看栈顶 | $O(1)$ |
| `IsEmpty()` | 判空 | $O(1)$ |

### 3.2 实现

??? note "自测"
    **Q**: 数组栈和链栈各自的主要特点是什么？

    ??? note "答案"
        数组栈：栈底固定，`top` 指针移动，需处理扩容。链栈：以链表头部作栈顶，不担心溢出。

- **数组栈**：栈底固定，`top` 指针移动；需处理扩容。
- **链栈**：以链表头部作为栈顶，不担心溢出。

### 3.3 应用

??? note "自测"
    **Q**: 为什么括号匹配天然适合用栈？后缀表达式求值相比中缀有什么优势？

    ??? note "答案"
        栈 LIFO 恰好匹配"最近未闭合括号最先处理"。后缀表达式无需括号、无需优先级，从左到右扫描即可求值。

??? note "括号匹配（Balancing Symbols）"
    扫描表达式：

    1. 遇左括号 `(` `[` `{` 入栈。
    2. 遇右括号，弹出栈顶检查是否匹配。
    3. 结束时栈非空则错误（有未闭合左括号）。

    **复杂度** $O(N)$。栈"后进先出"恰好匹配"最近未闭合括号最先处理"的需求。

??? note "后缀表达式求值（Postfix Evaluation）"
    "逆波兰"表达式（如 `3 4 + 5 ×`，对应 $(3+4)\times5=35$）：

    1. 遇操作数入栈。
    2. 遇运算符，弹出两操作数计算，结果入栈。
    3. 最终栈顶即结果。

    后缀表达式**无需括号、无需优先级**，从左到右扫描即可求值——这是栈机（如 JVM 字节码）的基础。

??? note "函数调用栈"
    程序的函数调用天然是栈结构：调用函数时压入栈帧（局部变量、返回地址），返回时弹出。**递归**深度受栈大小限制（栈溢出）。尾递归优化可避免压栈。

## 4. 队列（Queue ADT）

**先进先出**（FIFO, First-In First-Out）。

### 4.1 基本操作

??? note "自测"
    **Q**: 队列是 LIFO 还是 FIFO？`Enqueue`/`Dequeue` 的复杂度是多少？

    ??? note "答案"
        FIFO（先进先出）。`Enqueue`/`Dequeue` 均 $O(1)$。

| 操作 | 含义 | 复杂度 |
|:---|:---|:---|
| `Enqueue(x)` | 入队 | $O(1)$ |
| `Dequeue()` | 出队 | $O(1)$ |
| `Front()` | 查看队首 | $O(1)$ |

### 4.2 实现方式

??? note "自测"
    **Q**: 循环队列中 `front` 和 `rear` 如何更新？为什么用模运算？

    ??? note "答案"
        `front = (front+1) % capacity`，`rear = (rear+1) % capacity`。模运算让指针在数组末尾回绕到开头，复用已出队空间，避免假溢出。

**数组实现（循环队列）**：利用模运算避免假溢出（队首前移腾出空间）：

$$
\text{front} = (\text{front} + 1) \bmod \text{capacity},\quad
\text{rear} = (\text{rear} + 1) \bmod \text{capacity}
$$

**链表实现**：头指针 `front`、尾指针 `rear`；入队在尾节点后插入。

??? note "循环队列空满判断"
    若只用 `front`、`rear` 两个指针：空和满都对应 `rear == front`，无法区分！两种解决：

    - **方法一**：留一个空位，`(rear + 1) % cap == front` 判定满（损失一个槽）。
    - **方法二**：增加 `size` 字段记录元素个数，空 `size==0`、满 `size==cap`。

### 4.3 应用

??? note "自测"
    **Q**: 双端队列（Deque）与普通队列的区别是什么？优先队列按什么顺序出队？

    ??? note "答案"
        Deque 两端都可入出，$O(1)$，是栈和队列的超集。优先队列按优先级出队（非 FIFO）。

- **BFS**（广度优先搜索）：逐层扩展节点。
- **任务调度**：操作系统进程就绪队列。
- **缓冲区**：生产者-消费者模型、打印机队列。

??? note "双端队列（Deque）与优先队列"
    - **Deque**：两端都可入出，$O(1)$，是栈和队列的超集。
    - **优先队列**：出队按优先级（非 FIFO），见第 04 章堆。

## 5. 本章小结

- 线性表分数组实现（$O(1)$ 访问、$O(N)$ 插删）和链表实现（$O(1)$ 头尾插删、$O(N)$ 访问）。
- 栈（LIFO）用于括号匹配、后缀求值、函数调用栈。
- 队列（FIFO）用于 BFS、调度、缓冲区。
- 循环队列用模运算高效复用数组空间，空满区分用留空位或加 `size`。
- 动态数组扩容是摊还分析的经典例子。

**参考**：DS02_Ch03_List PPT, DS03_Ch03_Stack and Queue PPT；《数据结构与算法分析》Ch03

## 6. 典型例题与课堂重点

### 6.1 例题：栈的应用——括号匹配

**题目**：用栈检查 `[(a+b)*{c-d}]-[e/f]` 是否匹配。

??? note "答案要点"
    扫描字符串：遇左括号压栈；遇右括号与栈顶比对，配对则弹栈，不配对则非法；扫完栈空则合法。复杂度 $O(n)$。栈"后进先出"恰好匹配"最近未闭合括号最先处理"。

### 6.2 例题：后缀表达式求值

**题目**：求 `a b + c ×`（$a=2,b=3,c=4$）。

??? note "答案要点"
    `a=2` 压栈；`b=3` 压栈；`+` 弹 3、2 得 5 压栈；`c=4` 压栈；`×` 弹 4、5 得 20。结果 20。后缀表达式无需括号与优先级，是栈机求值的基础。

### 6.3 例题：反转单链表

**题目**：反转 `1→2→3→4→5`。

??? note "答案要点"
    三指针迭代：`prev=NULL, curr=head`，循环 `next=curr->next; curr->next=prev; prev=curr; curr=next`。$O(N)$ 时间 $O(1)$ 空间。

### 6.4 例题：循环队列空满区分

**题目**：循环队列如何区分空与满？

??? note "答案要点"
    只用 `front`/`rear` 时空满都 `rear==front`。解决：留一个空位 `(rear+1)%cap==front` 判满，或加 `size` 字段。这是循环队列最常考点。

### 6.5 课堂重点速记

| 概念 | 关键点 |
|:---|:---|
| 数组 vs 链表 | 数组 $O(1)$ 访问、$O(N)$ 插删；链表反之；缓存友好性倾向数组 |
| 动态数组 | 扩容 2 倍，摊还 $O(1)$ 插入 |
| 栈 LIFO | 压弹 $O(1)$；括号匹配、后缀求值、函数调用栈 |
| 队列 FIFO | 入出 $O(1)$；BFS、调度 |
| 循环队列 | 模运算复用空间；空满区分（留空位或加 size） |

## 5. 典型例题与课堂重点

### 5.1 例题：栈的应用——括号匹配

**题目**：用栈检查括号串 `[(a+b)*{c-d}]-[e/f]` 是否匹配。

??? note "答案要点"
    扫描字符串：

    - 遇左括号 `(` `[` `{` → 压栈。
    - 遇右括号 → 与栈顶左括号比对：若配对则弹栈，不配对则非法。
    - 扫完栈空 → 合法；栈非空 → 有未闭合左括号，非法。

    复杂度 $O(n)$。这是栈"后进先出"特性的典型应用——最近未匹配的左括号最先进栈最后处理。

### 5.2 例题：栈的应用——后缀表达式求值

**题目**：求后缀表达式 `a b + c ×`（对应 `(a+b)×c`，$a=2,b=3,c=4$）。

??? note "答案要点"
    扫描后缀表达式：

    - 遇操作数 → 压栈。
    - 遇运算符 → 弹出栈顶两个操作数计算，结果压栈。

    `a=2` 压栈；`b=3` 压栈；`+` 弹 3、2 得 5 压栈；`c=4` 压栈；`×` 弹 4、5 得 20。结果 20。

    后缀表达式的优势：**无需括号、无需运算符优先级**，从左到右扫描即可求值。这是栈机（如 JVM）求值的基础。

### 5.3 例题：链表操作——反转单链表

**题目**：反转单链表 `1→2→3→4→5`。

??? note "答案要点"
    三指针迭代法：

    ```c
    Node* Reverse( Node* head ) {
        Node *prev = NULL, *curr = head, *next;
        while ( curr ) {
            next = curr->next;   // 暂存下一个
            curr->next = prev;   // 反转指针
            prev = curr;          // prev 前移
            curr = next;          // curr 前移
        }
        return prev;             // prev 是新头
    }
    ```

    复杂度 $O(N)$ 时间、$O(1)$ 空间。也可递归实现（$O(N)$ 栈空间）。

### 5.4 例题：循环队列判空判满

**题目**：循环队列（数组大小 `cap`）如何区分空与满？

??? note "答案要点"
    若只用 `front`、`rear` 两个指针：

    - 空和满都对应 `rear == front`，无法区分！

    两种解决：

    - **留一个空位**：永远保留一个槽不用，满的判定改为 `(rear+1) % cap == front`，空仍是 `rear == front`。损失一个槽的空间。
    - **加 `size` 字段**：记录元素个数，空 `size==0`，满 `size==cap`。无空间损失，但每次操作维护 `size`。

    这是循环队列最常见的考点。

### 5.5 课堂重点速记

| 概念 | 关键点 |
|:---|:---|
| 数组 vs 链表 | 数组 $O(1)$ 随机访问、$O(N)$ 插删；链表反之 |
| 栈 LIFO | 压栈/弹栈 $O(1)$；括号匹配、后缀求值、函数调用栈 |
| 队列 FIFO | 入队/出队 $O(1)$；BFS、调度 |
| 循环队列 | 模运算复用空间；空满区分（留空位或加 size） |
