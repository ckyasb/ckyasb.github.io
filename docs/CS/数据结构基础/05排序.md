# 05 排序（Sorting）

排序是计算机科学中最基础的算法问题之一。本章覆盖从简单排序到高效分治排序，再到非比较型排序，并讨论各算法的稳定性、空间与最坏复杂度。

---

## 1. 简单排序

### 1.1 插入排序（Insertion Sort）

??? note "自测"
    **Q**: 插入排序的最佳时间复杂度是多少？在什么情况下出现？
    
    ??? note "答案"
        最佳 $O(N)$，数据已有序时出现。每趟只比较一次、不移动，外层循环遍历一次即可。

将牌逐个插入已排序部分——像整理手中扑克牌。

```c
void InsertionSort( ElementType A[], int N ) {
    for ( int i = 1; i < N; i++ ) {
        ElementType Tmp = A[i];
        int j = i;
        for ( ; j > 0 && A[j-1] > Tmp; j-- )  A[j] = A[j-1];  // 后移
        A[j] = Tmp;  // 插入
    }
}
```

| 性质 | 最坏 | 平均 | 最佳 | 空间 | 稳定 |
|:---|:---|:---|:---|:---|:---|
| 插入排序 | $O(N^2)$ | $O(N^2)$ | $O(N)$ | $O(1)$ | 是 |

**适用**：小数据（$N\le16$）、近似有序数据——常数小、最佳线性。许多高效排序（快排、归并）在小区段转用插入排序。

### 1.2 希尔排序（Shell Sort）

??? note "自测"
    **Q**: 为什么希尔排序的增量序列要求相邻互素？
    
    ??? note "答案"
        增量不互素时不同趟排序比较的位置集合重叠，效率低下。Hibbard 增量 $2^k-1$ 相邻互素，避免重复比较，最坏 $\Theta(N^{3/2})$。

按**增量序列**分组进行插入排序，最后增量为 1 完成整体排序。利用"大跨度插入"快速减少逆序对。

$$
\boxed{\text{希尔增量：} h_k = N/2,\; h_{k-1} = h_k/2,\; \ldots}
$$

| 增量序列 | 最坏复杂度 | 说明 |
|:---|:---|:---|
| Shell（原始 $N/2^k$） | $\Theta(N^2)$ | 增量不互素，有重复比较 |
| Hibbard ($2^k-1$) | $\Theta(N^{3/2})$ | 相邻互素 |
| Sedgewick | $O(N^{4/3})$ | 优化序列 |

??? note "为何增量必须相邻互素"
    若增量间不互素（如 $N/2, N/4, N/8$，都含因子 2），则不同趟排序比较的位置集合高度重叠，效率低下。Hibbard 增量 $2^k-1$ 相邻互素（$\gcd(2^k-1,2^{k+1}-1)=1$），避免重复——这是希尔排序性能的关键。

| 性质 | 平均 | 最坏 | 空间 | 稳定 |
|:---|:---|:---|:---|:---|
| 希尔排序 | $O(N^{6/5})$ | $O(N^{3/2})$ | $O(1)$ | 否 |

??? note "课堂代码：Shellsort 实现"
    ```c
    void Shellsort( ElementType A[], int N ) {
        int i, j, Increment;
        ElementType Tmp;
        for ( Increment = N / 2; Increment > 0; Increment /= 2 )
            for ( i = Increment; i < N; i++ ) {
                Tmp = A[i];
                for ( j = i; j >= Increment && A[j - Increment] > Tmp; j -= Increment )
                    A[j] = A[j - Increment];        /* 组内后移 */
                A[j] = Tmp;                          /* 插入 */
            }
    }
    ```
    
    **要点**：外层 `Increment` 从 $N/2$ 折半到 1，每趟对相距 `Increment` 的元素做插入排序。大增量先快速减少逆序对，最后增量 1 时数据已近似有序，插入排序近 $O(N)$。增量序列决定最坏复杂度（Shell 增量 $O(N^2)$，Hibbard $O(N^{3/2})$）。

**优势**：原地、实现简单、中等数据下比 $O(N\log N)$ 排序常数更小。

## 2. 高效排序

### 2.1 堆排序（HeapSort）

??? note "自测"
    **Q**: 堆排序的两个阶段是什么？时间复杂度如何？
    
    ??? note "答案"
        先 `BuildHeap` $O(N)$ 建堆，再反复取最大放末尾 + `PercolateDown`。整体 $O(N\log N)$（最坏也是），原地，不稳定。

见第 04 章。时间 $O(N\log N)$（最坏也是），原地，不稳定。先 `BuildHeap` $O(N)$，再反复取最大放末尾 + `PercolateDown`。

### 2.2 归并排序（Merge Sort）

??? note "自测"
    **Q**: 归并排序的时间递推式是什么？为何稳定？
    
    ??? note "答案"
        $T(N) = 2T(N/2) + O(N) \implies T(N) = O(N\log N)$。合并时相等元素先取左侧，相对顺序不变，故稳定。

**分治**策略：将序列对半分，分别排序后合并。

```c
void MergeSort( ElementType A[], int N ) {
    ElementType *Tmp = malloc(N * sizeof(ElementType));
    MSort(A, Tmp, 0, N-1);
    free(Tmp);
}
```

$$
\boxed{T(N) = 2T(N/2) + O(N) \implies T(N) = O(N\log N)}
$$

??? note "课堂代码：归并的合并函数 Merge"
    ```c
    /* Lpos = start of left half, Rpos = start of right half, RightEnd = end of right half */
    void Merge( ElementType A[], ElementType TmpArray[],
                int Lpos, int Rpos, int RightEnd ) {
        int i, LeftEnd, NumElements, TmpPos;
        LeftEnd   = Rpos - 1;
        TmpPos    = Lpos;
        NumElements = RightEnd - Lpos + 1;
        /* main loop */
        while ( Lpos <= LeftEnd && Rpos <= RightEnd ) {
            if ( A[Lpos] <= A[Rpos] )              /* <= 保证稳定 */
                TmpArray[TmpPos++] = A[Lpos++];
            else
                TmpArray[TmpPos++] = A[Rpos++];
        }
        while ( Lpos <= LeftEnd )                  /* copy rest of left half */
            TmpArray[TmpPos++] = A[Lpos++];
        while ( Rpos <= RightEnd )                 /* copy rest of right half */
            TmpArray[TmpPos++] = A[Rpos++];
        /* copy TmpArray back */
        for ( i = 0; i < NumElements; i++, RightEnd-- )
            A[RightEnd] = TmpArray[RightEnd];
    }
    ```
    
    **要点**：双指针比较左右半，**相等时取左**（`<=`）保证稳定性。合并代价 $O(N)$（每个元素移动一次），是归并排序 $T(N)=2T(N/2)+O(N)$ 的合并项。

??? note "课堂代码：归并排序主递归 MSort"
    ```c
    void MSort( ElementType A[], ElementType TmpArray[],
                int Left, int Right ) {
        int Center;
        if ( Left < Right ) {
            Center = ( Left + Right ) / 2;
            MSort( A, TmpArray, Left,  Center );     /* 递归排左半 */
            MSort( A, TmpArray, Center + 1, Right );  /* 递归排右半 */
            Merge( A, TmpArray, Left, Center + 1, Right );  /* 合并 */
        }
    }
    ```
    
    **要点**：对半分治，递归排两半后调用 `Merge` 合并。递归深度 $\log N$，每层合并共 $O(N)$，故 $O(N\log N)$。辅助数组 `TmpArray` 一次性分配（在外层 `MergeSort` 中），避免每层重复 `malloc`。

| 性质 | 值 |
|:---|:---|
| 最坏 | $O(N\log N)$ |
| 空间 | $O(N)$（辅助数组） |
| 稳定性 | **稳定** |

??? note "归并为何稳定"
    合并时双指针比较，相等时**先取左侧**——保证相等元素相对顺序不变。这是归并相对快排/堆排的主要优势。

    **适用**：需稳定排序、外部排序（数据放不下内存，分块排序后归并）、链表排序（归并是链表最优排序）。

### 2.3 快速排序（Quick Sort）

??? note "自测"
    **Q**: 快排的最坏时间复杂度是多少？什么情况下出现？如何避免？
    
    ??? note "答案"
        最坏 $O(N^2)$，在分区极度不平衡（如有序输入固定选首/尾）时出现。用三数中值分割法使枢轴接近中位数，或 intro sort 深度超限转堆排。

选取**枢轴**（pivot），将数组分为小于和大于枢轴的两部分，递归排序两部分。

```c
void QuickSort( ElementType A[], int Low, int High ) {
    if ( Low < High ) {
        int p = Partition(A, Low, High);  // 枢轴归位
        QuickSort(A, Low, p-1);
        QuickSort(A, p+1, High);
    }
}
```

??? note "枢轴选择策略"
    - **三数中值分割法**（Median-of-Three）：取 left、center、right 的中值——保证枢轴接近中位数，使分区平衡。
    - **随机选**：避免最坏情况概率极低。
    - **固定选首/尾**：有序数据退化为 $O(N^2)$（最坏情况）。

    三数中值是工程实践的标准选择——避免对有序输入的退化，同时代价低。

| 性质 | 平均 | 最坏 | 空间 | 稳定 |
|:---|:---|:---|:---|:---|
| 快速排序 | $O(N\log N)$ | $O(N^2)$ | $O(\log N)$ | 否 |

**快排是最常用的通用排序**——平均最快、缓存友好。最坏 $O(N^2)$ 可用 intro sort（深度超限转堆排）避免。

## 3. 表排序（Table Sort）

当排序对象为**大对象**（每元素体积大，移动代价高）时，使用**间接排序**：只移动指针（下标）而非数据本身。最终通过物理重排整理数据。

```c
// 用 index 数组排序，不移动大对象
for ( i = 0; i < N; i++ )  Table[i] = i;  // 初始指向自身
// 按 A[Table[i]] 比较排序 Table[]
```

**应用**：数据库记录排序、大结构体排序。避免 $O(N)$ 次大数据拷贝。

## 4. 线性时间排序

### 4.1 桶排序（Bucket Sort）

??? note "自测"
    **Q**: 桶排序的期望时间复杂度是多少？什么情况下退化为最坏？
    
    ??? note "答案"
        期望 $O(N)$（数据均匀时）；最坏 $O(N^2)$（数据全落在一个桶）。适用键均匀分布在已知范围。

将数据均匀分布到 $M$ 个桶中，桶内再排序。

**期望时间** $O(N)$（数据均匀时）；最坏 $O(N^2)$（数据全在一个桶）。

**适用**：键均匀分布在已知范围（如 $[0,1)$ 浮点数）。

### 4.2 基数排序（Radix Sort）

??? note "自测"
    **Q**: 基数排序的时间复杂度公式是什么？为何要求低位优先且每趟稳定？
    
    ??? note "答案"
        $O(d \cdot N)$，$d$ 为位数。从最低位开始每趟用稳定排序，使高位排序时高位相同的元素保持低位排序的相对顺序。

按位（digit by digit）排序：先按**最低位**排序，逐步向高位，每趟用**稳定**的桶排序（计数排序）。

$$
\boxed{\text{基数排序时间} = O(d \cdot N),\quad d\text{ 为位数}}
$$

??? note "为何低位优先"
    从最低位开始，每位用**稳定**排序——高位排序时，高位相同的元素保持低位排序的相对顺序。若从高位开始则需递归分组，复杂且易错。

    当 $d$ 较小（如 32 位整数 $d\le10$）时优于比较排序的 $O(N\log N)$。**适用**：整数键、定长字符串。

## 5. 比较总结

| 排序算法 | 平均 | 最坏 | 空间 | 稳定 | 适用 |
|:---|:---|:---|:---|:---|:---|
| 插入排序 | $N^2$ | $N^2$ | 1 | 是 | 小数据/近似有序 |
| 希尔排序 | $N^{6/5}$ | $N^{3/2}$ | 1 | 否 | 中等数据 |
| 堆排序 | $N\log N$ | $N\log N$ | 1 | 否 | 内存受限 |
| 归并排序 | $N\log N$ | $N\log N$ | $N$ | 是 | 稳定/外部/链表 |
| 快速排序 | $N\log N$ | $N^2$ | $\log N$ | 否 | 通用最快 |
| 基数排序 | $dN$ | $dN$ | $N$ | 是 | 整数/定长键 |

??? note "选择排序的决策"
    - 数据小（$N\le16$）：插入排序（常数小）。
    - 通用大规模：快排（平均最快）。
    - 需最坏保证：堆排或归并（intro sort = 快排 + 深度超限转堆排）。
    - 需稳定：归并。
    - 整数键且范围小：基数/桶排序。

---

## 6. 本章小结

- 插入排序适合小规模或近似有序数据；希尔排序用增量分组提升效率。
- 归并排序稳定但需额外空间；快速排序平均最快但最坏退化。
- 堆排序在空间受限时是不错的选择（最坏 $O(N\log N)$ + 原地）。
- 基数/桶排序利用数据特性可在 $O(N)$ 内完成，但需键可分解。

## 7. 典型例题与课堂重点

### 7.1 例题：快排分区过程

**题目**：对 `8,1,4,9,6,3,5,2,7,0` 跑一趟快排（三数中值法选枢轴）。

??? note "答案要点"
    三数中值取 `left=8, center=6, right=0` 的中值 **6** 作枢轴，先把三数排好（小放左、大放右、中放 `right-1`），再从两端向中间扫描交换。分区后枢轴 6 归位，左侧全 $<6$、右侧全 $>6$，再递归两半。

    **为何三数中值**：避免固定选首/尾时对**有序输入**退化 $O(N^2)$——三数中值保证枢轴接近中位数，分区平衡，期望 $O(N\log N)$。

### 7.2 例题：希尔增量序列

**题目**：Shell 增量（$N/2,N/4,\ldots,1$）与 Hibbard 增量（$2^k-1$）的最坏复杂度差异。

??? note "答案要点"
    - Shell 增量 $\Theta(N^2)$：增量不互素，重复比较。
    - Hibbard 增量 $\Theta(N^{3/2})$：相邻互素，避免重复。
    - Sedgewick 增量 $O(N^{4/3})$。

    增量序列必须**相邻互素**才能避免最坏退化。

### 7.3 例题：归并排序的合并与稳定性

**题目**：归并排序为何稳定？空间代价如何？

??? note "答案要点"
    合并阶段双指针比较，相等时**先取左侧**——保证相等元素相对顺序不变，故稳定。空间 $O(N)$ 辅助数组（非原地）。适用：需稳定、外部排序、链表排序。

### 7.4 例题：基数排序的位序

**题目**：基数排序为何"低位优先"？

??? note "答案要点"
    从最低位开始，每位用**稳定**桶排序——高位排序时高位相同的元素保持低位排序的相对顺序。若从高位开始则需递归分组，复杂易错。$O(dN)$，$d$ 为最大位数，$d$ 小时优于 $O(N\log N)$。

### 7.5 课堂重点速记

| 概念 | 关键点 |
|:---|:---|
| 插入排序 | 小数据/近似有序，$O(N^2)$，稳定 |
| 希尔排序 | 增量分组，需相邻互素；Hibbard $\Theta(N^{3/2})$ |
| 堆排 | 原地、最坏 $O(N\log N)$、不稳定 |
| 归并 | 稳定、$O(N)$ 空间；外部/链表首选 |
| 快排 | 平均最快、三数中值、最坏 $O(N^2)$、不稳定 |
| 基数 | 低位优先 + 稳定桶排序；$O(dN)$ |
