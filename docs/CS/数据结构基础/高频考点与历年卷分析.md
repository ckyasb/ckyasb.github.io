# FDS 高频考点与历年卷分析

> 基于 **2015-2021 共 13 份历年卷**（含学长学姐整理）统计。频次标记：★★★ 几乎每年必考；★★ 多年出现；★ 偶发。

## 4. 易错点汇总

1. **"merge runs 是 O(NlogN)" → 错**。归并趟数是 O(logN)，**总比较次数**才是 O(NlogN)。
2. **"快排最坏 O(NlogN)" → 错**，是 O(N²)。但"比较排序最好下界 O(NlogN)"是对的。
3. **完全二叉树数组编号**：根在 1 时，位置 23 和 24 **不是兄弟**（父分别为 11、12）。务必看清下标起点。
4. **max-heap 最小值位置**：只能在叶子 $[\lfloor n/2 \rfloor+1, n]$。常被误选 $\lfloor n/2 \rfloor$。
5. **循环队列容量**：用 front+rear 时容量 m−1；用 front+size 时容量 = **m**。
6. **BFS 两次 ⇒ 有环？错**。应是 2 个连通分量。DFS 才判环。
7. **邻接表空间与边数有关**（O(V+E)）；**邻接矩阵空间与边数无关**（O(V²)）。
8. **Shell sort 不稳定**；**Merge sort 稳定**；**Quick sort 不稳定**。
9. **单链表即使有序也不能二分查找**（无法 O(1) 随机访问）。
10. **Fibonacci 迭代 O(N)，递归 O(F_N)≈O(φⁿ)**；递归空间 O(N)。
11. **quadratic probing 插入不一定成功**（表满时失败），即使表长为素数也不保证。
12. **quadratic probing ≠ double hashing**（Hash₂=k 或 Hash₂=1 都不对）。
13. **最短路径所有边权加 1 后不再保证最短**。
14. **前序+后序不能唯一确定二叉树**（除非无节点有双子树）。
15. **树→二叉树**：原树后序 = 二叉树**中序**（不是后序）。
16. **堆排序第一趟**（建堆后）只保证堆性质，**不是**有序；选择/冒泡第一趟让一个极值到位；归并第一趟长度为 2 的有序段；快排第一趟 pivot 到位但两端未必有序。
17. **双向选择排序**中：先交换 min 到 i 后，若 `maxi == i`，最大值已被换到 mini 位置，需改交换 `r[mini]` 与 `r[n-i+1]`。
18. **QSelect 第二空**递归右区间时 K 要减去左区间长度：`K-(L-Left)`。
19. **快排所有元素相等**：左右指针**都停** → O(N²)；**都不停** → O(NlogN)。结论反直觉，必考。
20. **并查集** find 带路径压缩后，路径上所有点直连最终根。

## 5. 复杂度结论速记表

### 排序算法

| 算法 | 最好 | 平均 | 最坏 | 空间 | 稳定 | 备注 |
|---|---|---|---|---|---|---|
| Insertion Sort | O(N) | O(N²) | O(N²) | O(1) | ✓ | 逆序对少时最优 |
| Bubble Sort | O(N) | O(N²) | O(N²) | O(1) | ✓ | 第一趟最大值到位 |
| Selection Sort | O(N²) | O(N²) | O(N²) | O(1) | ✗ | 比较次数恒定 N(N−1)/2 |
| Shell Sort | O(N) | O(N^1.25) | O(N²) | O(1) | ✗ | 取决于增量序列 |
| Heap Sort | O(NlogN) | O(NlogN) | O(NlogN) | O(1) | ✗ | 建堆 O(N)；第一趟只建堆不有序 |
| Merge Sort | O(NlogN) | O(NlogN) | O(NlogN) | O(N) | ✓ | 趟数 O(logN)；适合外排序 |
| Quick Sort | O(NlogN) | O(NlogN) | O(N²) | O(logN) | ✗ | 有序时退化；非递归栈存 Left/Right |
| Radix Sort | O(d·N) | O(d·N) | O(d·N) | O(N+radix) | ✓ | LSD 按位稳定排序 |
| Bucket Sort | O(N) | O(N) | O(N) | O(N) | ✓ | 1 位数/均匀分布时 O(N) |
| 比较排序下界 | — | — | Ω(NlogN) | — | — | 决策树高度 ≥ ⌈log₂(N!)⌉ |

| 操作 | 平均 | 最坏 | 备注 |

## 6. 备考优先级

按出现频次排序的备考优先级：

1. **图论**：最大流/MST/拓扑/哈希探测/关节点
2. **排序**：第一趟反推方法/LSD/快排相等元素
3. **树**：BST 插入序列/遍历重建/并查集/堆调整
4. **栈队列**：循环队列容量/出栈序列

**代码题**务必练熟：CheckBST、IsTopologicalOrder、QSelect、IsBalanced、Union/Find 数组填空五类。
