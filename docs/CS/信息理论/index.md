# 信息理论

**2025–2026 春夏学期 | 余官定 | 智云课堂 13 讲 | 期末随堂考 06-21**

香农信息论基础，涵盖三大定理：信息度量（熵/互信息/KL 散度）、无损压缩（AEP/信源编码）、信道传输（信道容量/信道编码定理），以及率失真理论与信息瓶颈入门。

> 这门课本质上是一门应用数学课——基于概率论与随机过程。香农 1948 年的《通信的数学理论》是整门课的基石。
