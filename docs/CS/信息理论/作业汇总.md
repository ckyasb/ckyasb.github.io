## 第一章：信息度量 🔴 考试核心

### 题型一：计算题

**题目 1**：设离散信源分布为 $p = \{0.5, 0.3, 0.2\}$，求 $H(X)$。

??? note "答案"
    $H(X) = -0.5\log_2 0.5 - 0.3\log_2 0.3 - 0.2\log_2 0.2 = 0.5 + 0.521 + 0.464 = 1.485$ bit

**题目 2**：$X$ 与 $Y$ 联合分布为 $p(0,0)=0.4,\;p(0,1)=0.1,\;p(1,0)=0.2,\;p(1,1)=0.3$。求 $H(X)$, $H(Y)$, $H(X,Y)$, $H(X|Y)$, $I(X;Y)$。

??? note "答案"
    ①边缘分布 $p_X=(0.5,0.5)$，$p_Y=(0.6,0.4)$  
    ②$H(X)=1$，$H(Y)=0.971$，$H(X,Y)=1.846$ bit  
    ③$H(X|Y)=0.875$，$I(X;Y)=0.125$ bit

**题目 3**：设 $P=(0.4,0.3,0.2,0.1)$，$Q=(0.25,0.25,0.25,0.25)$，求 $D(P\|Q)$。

??? note "答案"
    $D(P\|Q) = 0.4\log_2\frac{0.4}{0.25} + 0.3\log_2\frac{0.3}{0.25} + 0.2\log_2\frac{0.2}{0.25} + 0.1\log_2\frac{0.1}{0.25} = 0.154$ bit

### 题型二：性质证明题

**题目**：证明互信息三等式 $I(X;Y) = H(X) - H(X|Y) = H(Y) - H(Y|X) = H(X) + H(Y) - H(X,Y)$。

??? note "答案"
    $I(X;Y) = \sum p(x,y)\log\frac{p(x|y)}{p(x)} = -\sum p(x,y)\log p(x) + \sum p(x,y)\log p(x|y) = H(X) - H(X|Y)$

**题目**：证明 $H(X|Y) \leq H(X)$，并指出等号条件。

??? note "答案"
    $H(X|Y) - H(X) = -D(p(x,y) \Vert p(x)p(y)) \leq 0$。等号当且仅当 $X \perp Y$。

---

### 题型三：Fano 不等式

**题目**：设 $|\mathcal{X}| = 4$，$H(X|Y) = 1.2$ bit，求 $P_e$ 的下界。

??? note "答案"
    $P_e \geq \frac{H(X|Y)-1}{\log(|\mathcal{X}|-1)} = \frac{1.2-1}{\log_2 3} \approx 0.126$。错误率至少 12.6%。

---

### 题型四：马尔可夫信源（教材习题 2.23）🔴

**题目**：二阶二元马尔科夫信源，$p(0|00)=p(1|11)=0.8$，$p(0|01)=p(0|10)=p(1|01)=p(1|10)=0.5$。求熵率 $H_\infty(X)$。

??? note "答案"
    ①化为一阶 4 状态 Markov：00, 01, 10, 11  
    ②稳态方程：$\pi(00)=\pi(11)=5/14$，$\pi(01)=\pi(10)=1/7$  
    ③$H_\infty = \sum_s \pi(s)H(X|S=s) = \frac{5}{14}H_2(0.8)+\frac{1}{7}\times1+\frac{1}{7}\times1+\frac{5}{14}H_2(0.8) \approx 0.802$ bit

---

### 题型五：微分熵

**题目**：连续随机变量 $X$，方差 $\sigma^2=4$，求最大微分熵。

??? note "答案"
    正态分布达到最大：$h(X) = \frac12\log_2(2\pi e\sigma^2) \approx 2.047$ bit。熵功率 $\bar{\sigma}^2 = \sigma^2 = 4$。

## 第二章：无损压缩与信源编码 🔴 考试核心

### 题型一：典型列判断

**题目**：$X \sim \text{Bernoulli}(0.3)$，$n=10$，$\epsilon=0.1$。判断 10个1 和 3个1+7个0 是否为典型序列。

??? note "答案"
    $H(X) \approx 0.881$。10个1：$|1.737-0.881|=0.856 > 0.1$ → 非典型。  
    3个1,7个0：$|0.8816-0.881|=0.0006 \leq 0.1$ → 是典型。

---

### 题型二：Huffman 编码 🔴

**题目**：信源分布 $P = \{0.5, 0.25, 0.125, 0.125\}$（符号 $a,b,c,d$），构造 Huffman 编码，求 $L$ 和效率。

??? note "答案"
    $H(X) = 1.75$ bit。码字：$a=1$, $b=01$, $c=000$, $d=001$。  
    $L = 1.75$ bit，效率 100%（概率全是 $2^{-k}$）。

---

### 题型三：Shannon 编码

**题目**：同上分布，构造 Shannon 编码。

??? note "答案"
    $\ell_a = \lceil -\log_2 0.5 \rceil = 1$，$\ell_b = 2$，$\ell_c = \ell_d = 3$。$L = 1.75$ bit。

---

### 题型四：分组编码与 Kraft 不等式

**题目**：验证上述 Huffman 编码满足 Kraft 不等式。

??? note "答案"
    $\sum 2^{-\ell_i} = 2^{-1} + 2^{-2} + 2^{-3} + 2^{-3} = 1$ → 完备前缀码。

## 第三章：信道容量与信道编码 🔴 考试核心

### 题型一：BSC 容量（教材习题 4.2）🔴

**题目**：BSC($f=0.15$)，求 $C$。$R=0.4$ 是否可达？

??? note "答案"
    $C = 1 - H_2(0.15) \approx 1 - 0.610 = 0.390$ bit/use。$R=0.4 > C$，不可达。

---

### 题型二：对称信道（教材习题 4.1）🔴

**题目**：$3\times 3$ 对称信道矩阵行 $(0.7,0.2,0.1)$ 循环排列。求 $C$。

??? note "答案"
    $H(Y) = \log_2 3 = 1.585$，$H(\text{行}) \approx 1.157$。$C = 0.428$ bit/use。

---

### 题型三：级联信道（教材习题 4.9）🔴

**题目**：两 BSC($f=0.1$) 级联，求等效信道容量，与单级比较。

??? note "答案"
    $f_{\text{eq}} = 2f(1-f) = 0.18$。$C_{\text{cascade}} = 1 - H_2(0.18) \approx 0.320$。  
    单级 $C = 0.531$。级联下降约 40%。$C_{\text{cascade}} < \min(C_1,C_2)$。

---

### 题型四：可达到性判断

**题目**：$C=0.5$，判断 $R=0.3$、$R=0.6$ 是否可达。

??? note "答案"
    $R=0.3 < C$ → 可达。$R=0.6 > C$ → 不可达（香农第二定理）。

## 第四章：率失真理论 🟢

**题目 1**：$X\sim\text{Bernoulli}(0.3)$，Hamming 失真，求 $R(0.1)$。

??? note "答案"
    $R(0.1) = H_2(0.3) - H_2(0.1) = 0.881 - 0.469 = 0.412$ bit

**题目 2**：$X\sim\mathcal{N}(0,4)$，平方误差失真，求 $R(1)$。

??? note "答案"
    $R(1) = \frac12\log_2(4/1) = 1$ bit

**题目 3**：Bernoulli(0.3) + Hamming，求 $D_{\max}$。

??? note "答案"
    $D_{\max} = \min(0.7, 0.3) = 0.3$。最优策略：始终输出 $\hat{X}=1$。

## 第五章：信息瓶颈理论 🟢

**题目 1**：给定 $I(X;T)=0.192$，$I(T;Y)=0.085$。$\beta=1$，求 $\mathcal{L}$。

??? note "答案"
    $\mathcal{L} = I(X;T) - \beta I(T;Y) = 0.192 - 0.085 = 0.107$ bit

**题目 2**：$\beta \to 0$ 和 $\beta \to \infty$ 时，最优 $T$ 是什么？

??? note "答案"
    $\beta \to 0$：$T$ 与 $X$ 独立 → 常数。$\beta \to \infty$：$T=X$，$I(T;Y)=I(X;Y)$。
