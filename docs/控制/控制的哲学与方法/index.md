# 控制的哲学与方法

**2025-2026 春夏学期 | 浙江大学控制科学与工程学院 | 主讲：邵之江、李翔等**

本课程从哲学、方法论与工程实践的多维视角审视控制科学，涵盖系统思维、因果推理、反馈原理、控制论思想史、社会治理应用、工业控制前沿以及不确定性调控等主题。
