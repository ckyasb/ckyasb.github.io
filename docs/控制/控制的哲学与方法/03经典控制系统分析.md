# 03 经典控制系统分析

## 1. 控制系统的基本结构

### 1.1 方框图

控制系统方块图是描述系统组成和信号传递的图形化工具。每个方块代表一个系统组件，箭头表示信号的传递方向。

**基本组成**：

| 组件 | 功能 |
|------|------|
| 被控对象 (Plant/Process) | 被控制的设备或过程 |
| 控制器 (Controller) | 产生控制信号的决策单元 |
| 执行机构 (Actuator) | 将控制信号转换为物理动作 |
| 传感器/检测仪表 (Sensor) | 测量被控变量 |
| 比较器 (Comparator) | 计算偏差（期望值 - 反馈值） |

**三个通道**：

1. **前向通道**：从参考输入到被控对象输出的路径
2. **反馈通道**：从输出到比较器的检测反馈路径
3. **扰动通道**：扰动输入影响被控对象的路径

### 1.2 SISO 与 MIMO

| 类型 | 说明 | 示例 |
|------|------|------|
| SISO | 单输入单输出 | 简单温度控制 |
| MIMO | 多输入多输出 | 锅炉-汽机协调控制 |

MIMO系统的控制难度远高于SISO系统，因为各变量之间存在**耦合**。

### 1.3 控制系统分类

- **按反馈方式**：反馈控制、前馈控制、前馈-反馈复合控制
- **按信号形式**：连续（模拟）控制系统、离散（采样）控制系统
- **按设定值**：定值控制系统（设定值恒定）、随动控制系统（设定值变化）

## 2. 前馈控制与反馈控制

### 2.1 前馈与反馈的对比

| 维度 | 反馈控制 | 前馈控制 |
|------|----------|----------|
| **时机** | "事后"控制 | "事前"控制 |
| **原理** | 偏差产生后消除偏差 | 检测扰动后提前补偿 |
| **特点** | 对任何扰动都有效 | 只对可测的特定扰动有效 |
| **结构** | 闭环 | 开环 |
| **局限** | 存在时延 | 对模型精度要求高 |

前馈控制和反馈控制可以结合使用：前馈负责快速补偿已知扰动，反馈负责消除残余偏差和未知扰动。

## 3. 系统的性能要求

### 3.1 稳定性

> 稳定性是保证系统正常工作的**先决条件**。

当系统受到扰动后，若能回到平衡状态，则系统稳定；若发散，则不稳定。

### 3.2 瞬态（动态）性能

当给定输入变化时，希望系统能快速、平稳地跟随变化；当扰动出现时，希望系统能迅速克服扰动回到平衡状态。

**动态性能指标**：

- 上升时间 (Rise Time)
- 峰值时间 (Peak Time)
- 最大超调量 (Overshoot)
- 恢复时间 (Settling Time)

> 动态性能的核心矛盾：**振荡性与快速性**——既要有足够快的响应速度，又要避免过度振荡。

### 3.3 稳态性能

动态过程结束后，系统进入新的平稳状态。稳态性能要求**稳态误差尽可能小**。

## 4. 经典控制实例

### 4.1 家用取暖炉控制

恒温器中的双金属片利用不同金属的热膨胀系数差异，产生形变以驱动触点：

- 温度低于设定值 → 触点闭合 → 炉子开启
- 温度高于设定值 → 触点断开 → 炉子关闭

从开环到闭环的进化路径：

```
启停 → 加热档位/定时 → 温控(模拟→数字) → 遥控 → 网络控制 → 均匀 → 协同/节能 → 舒适
                                                                          ↑
                                                                      从自动到智能
```

### 4.2 谷物加湿控制系统

谷物磨粉加工前需要加水调节湿度：

- **对象**：传送装置输送谷物、自动喷淋加水
- **被控变量**：输出谷物湿度
- **操作变量**：加湿喷淋阀门开度
- **干扰变量**：输入谷物湿度、水源水压、温度

### 4.3 锅炉汽包液位控制

锅炉汽包液位是典型的复杂控制对象，存在**虚假水位**（Shrink and Swell Effect）现象。

**三冲量控制**：综合液位、给水流量、蒸汽流量三个信号，采用**串级+前馈**结构：

1. 主控制器（液位控制器）→ 副控制器（给水流量控制器）→ 调节阀
2. 蒸汽流量作为前馈信号提前补偿

### 4.4 汽车操控系统

```
期望行驶方向 → [驾驶员] → [方向盘/刹车/油门] → [汽车] → 实际行驶方向
                      ↑                                                    |
                      └────────── 视觉/仪表/体感反馈 ←──────────────────────┘
```

- 操作变量：方向盘、油门、刹车
- 被控变量：方向、速度、安全性、舒适性
- 干扰变量：路面、坡度、侧风、障碍物

## 5. 控制的文化密码

### 5.1 矫枉过正

> 矫枉必须过正，不过正不能矫枉。—— 毛泽东《湖南农民运动考察报告》

控制论解读：系统在阶跃响应中必然出现超调量，过正的目的在于加快系统响应速度。超调量、上升时间、恢复时间之间存在**权衡取舍**。

### 5.2 治大国若烹小鲜

> 治大国，若烹小鲜。—— 老子《道德经》

控制论解读：
- 大国治理的高度复杂性：不平衡、不充分、内外不确定性
- 如履薄冰，如临深渊——不能频繁翻动（避免过度调控）
- 充分了解国情、深切体察民意——建立好模型
- 不懈怠、不冒进、不折腾——把握调控的"度"

### 5.3 卖油翁

> 无他，但手熟尔。—— 欧阳修《卖油翁》

控制论解读：通过反复练习（反馈学习），建立准确的内模（Internal Model），实现开环与闭环控制的完美融合——这就是**手熟**的本质。

### 5.4 其他控制成语

| 成语 | 控制思想 |
|------|----------|
| 趁热打铁 | 实时控制、把握时机 |
| 未雨绸缪 | 前馈控制、预防为主 |
| 亡羊补牢 | 反馈控制、事后修正 |
| 防微杜渐 | 早期干预、防止发散 |
| 一叶知秋 | 观测与预测、信号提取 |
| 不战而屈人之兵 | 最优控制、以最小代价达成目标 |

## 本章小结

- 控制系统由被控对象、控制器、执行机构、传感器等组成，通过前向通道、反馈通道、扰动通道相互作用
- SISO与MIMO系统在复杂度和控制难度上有本质差异
- 系统性能的三项基本要求是稳定性、动态性能和稳态性能
- 经典控制实例展示了反馈控制的普遍性和多样性
- 中国文化中的许多成语和典故蕴含着深刻的控制论思想

## 附：课堂原话与哲学要点（03-22）

!!! important "控制的两个前提：不确定性与可能性"
    > "就是因为有不确定性，所以我们希望能够把它按照我们的意图给它消灭掉，所以这构成了控制的一个主要的目的。"

    > "正是有可能性，有选择有余地，有弹性，有可行性，那么你这里面才会有一个策略，去寻找一个最合适的、误差最小的。"（引金观涛《控制论与科学方法论》的"可能性空间"）

??? note "流动性是控制的根本"
    > "不管是物质的、能量的、时空的变化，它都是在流动转化运动……一旦流动起来，背后一定是有一个规律在支配，这个规律被我们认识和运用，我们就可以进行控制。"

    控制 = 在目的性驱动下形成有序的、有组织的、有价值的、恰如其分的流动。

??? note "方块图的灵魂：信号流而非物质流"
    > "每个输入和输出……不是物质也不是能量，是信息的影响关系。所有东西都是信息，要么是信息，要么是信息的变化，要么是信息的差异。水流在这里面没有用的。"

    方块图上画的箭头是**信号（信息流）**，不是物质/能量流。这是理解方块图的关键。

??? note "误差是驱动力"
    > "误差是一个真正的驱动力，没有误差我们这个事情就不用动，正是由于误差驱动了所有的事情。"

    闭环控制的本质是误差驱动——设定值与检测值之差驱动控制器动作。

??? note "自动化是懒人哲学"
    > "控制就是创造工具创造条件，使人能够偷懒……自动化控制就是一个懒人哲学，怎么懒怎么好，机器换人。"

??? note "开环 vs 闭环：各有适用"
    > "当你对规律的认识非常精准的时候，开环当然是可以的，这就是上帝视角。"

    > "闭环如果设计不当，动作过猛，可能就震了……闭环不一定好，开环也不一定不好。"

??? note "矫枉过正的哲学"
    毛泽东"矫枉必须过正，不过正不能矫枉"——材料解释 = 弹性形变 vs 塑性形变（要超过屈服强度才能根本改变）；控制解释 = 超调与震荡。

    > "搞控制实际上是在正当性（稳定性）和快速性之间做出一个折中。"

??? note "考核要点：控制品质指标"
    老师明确要求掌握刻画控制品质的指标（可能考核）：

    - **超调量**（overshoot）
    - **上升时间**（rise time）
    - **峰值时间**（peak time）
    - **回复时间**（settling time）
    - **稳态误差**（steady-state error）

    > "用这几个指标去刻画控制品质，然后去设计控制。"

    稳定性是控制系统**首要要求**（不能发散），其次是瞬态性能（跟踪/抗干扰）与稳态误差。
