# 你好，我是 ckyasb

欢迎来到我的数字花园。这里记录我在浙江大学本科课程中的学习与思考，也收藏一路遇到的有趣问题。

我把课堂语音转写、PPT、板书与作业整理成笔记，希望让零散的知识慢慢连起来：既能在复习时快速找到一个结论，也能在有空的时候重新走一遍推导。

## 这里种着什么

- **物理**：从光学、原子物理、电动力学，到广义相对论与相关数学工具。
- **计算机**：数据结构、信息理论与人工智能。
- **人文与其他**：文学、控制的哲学、思政课程与口译。

这些笔记会持续修订。课堂结论、我自己的理解和补充推导难免有疏漏，欢迎通过 [GitHub Issues](https://github.com/ckyasb/ckyasb.github.io/issues) 指出问题，或一起讨论。

## 逛一逛这座花园

从[首页的学科入口](index.md#explore)挑一个主题，或者用顶部搜索寻找知识点。课程目录汇总了章节与补充专题，正文中的自测题可以展开查看答案。

如果正在准备考试，可以先看看[广义相对论考试重点](Physics/广义相对论/考试重点.md)、[电动力学公式汇总](Physics/电动力学/重要公式汇总.md)和[数据结构自测题库](CS/数据结构基础/题库.md)。

## 花园里的小伙伴 { #companions }

右下角住着《崩坏3》的希儿，使用死生之律者的 Q 版半身动画。点点她，会收到不同的回应；读到文章的不同位置，也可能遇到一句小提醒。

页面上的小蝴蝶会轻轻游走，靠近鼠标时逐个跟随、排成小队。点击页面会有短暂的蝴蝶光点，可以用角色旁的「蝴蝶」按钮关闭，也可以收起角色安静阅读。手机上保留角色互动；开启系统「减少动态效果」时，动画与鼠标跟随特效会自动停用。

互动台词为本站原创，并非游戏原台词。角色与原始美术属于《崩坏3》及其权利方；希儿动画取自 [xinna2001/Seele 的 bss.gif](https://github.com/xinna2001/Seele/blob/d34179e52d0d80e8acf8781615292ae11a5ed825/image/bss.gif)，仓库附 MIT 许可证。这是一段半身循环动画，并非包含行走动作的完整 Shimeji 模型。
