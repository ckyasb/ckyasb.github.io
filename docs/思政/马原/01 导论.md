# 导论

## 1. 核心概念与定义

### 什么是马克思主义？
马克思主义是由**马克思和恩格斯**创立的，并由其后继者（列宁、中国共产党等）不断发展的科学理论体系。

* **从创造者角度**：是马克思、恩格斯创立的，由其后继者发展的理论体系。
* **从内容角度**：是关于自然、社会和人类思维发展一般规律的学说。
* **从阶级立场角度**：是关于社会主义必然代替资本主义、最终实现共产主义的学说。
* **从社会功能角度**：是指引人民创造美好生活的行动指南。

### 马克思主义的组成部分
马克思主义是一个有机整体，包含三个主要组成部分：

1.  **马克思主义哲学**（世界观与方法论基础）
2.  **马克思主义政治经济学**（对资本主义运作规律的剖析）
3.  **科学社会主义**（最终的政治结论和社会理想）

---

## 马克思主义的创立与发展

马克思主义的产生具备深刻的**经济社会根源**、**阶级基础**和**思想渊源**。

### 客观条件
* **经济社会背景**：工业革命推动了资本主义生产方式的成熟，资本主义固有矛盾（生产社会化与生产资料私有制之间的矛盾）日益暴露。
* **阶级基础**：无产阶级作为独立的政治力量登上历史舞台（如法国里昂工人起义、英国宪章运动、德国西里西亚纺织工人起义）。
* **科学背景**：19世纪自然科学的三大发现（细胞学说、能量守恒与转化定律、生物进化论）为马克思主义哲学提供了实证科学基础。

### 理论渊源
马克思主义是在批判继承人类文明优秀成果的基础上产生的：

| 理论来源 | 代表人物/流派 | 对应马克思主义组成部分 |
| :--- | :--- | :--- |
| **德国古典哲学** | 黑格尔（辩证法）、费尔巴哈（唯物主义） | 马克思主义哲学 |
| **英国古典政治经济学** | 亚当·斯密、大卫·李嘉图 | 马克思主义政治经济学 |
| **英法空想社会主义** | 圣西门、傅立叶、欧文 | 科学社会主义 |

---

* **起源**：
    * **黑格尔的辩证法 + 费尔巴哈的唯物主义** $\rightarrow$ **辩证唯物主义与历史唯物主义**。
        * 马克思不是简单的拼凑，而是剔除了黑格尔的唯心主义糟粕，保留了辩证法内核；克服了费尔巴哈的形而上学局限，将其唯物主义贯彻到历史领域。
    * **古典政治经济学** $\rightarrow$ **剩余价值理论**。
        * 从劳动价值论出发，发现了资本剥削的秘密（剩余价值），揭示了资本主义运行的经济规律。
    * **空想社会主义** $\rightarrow$ **科学社会主义**。
        * 将对未来社会的憧憬从“空想”变为基于现实规律的“科学”预测，指明了通往共产主义的现实道路（阶级斗争、无产阶级专政）。


### **核心特征**：
    1.  **科学性**：它揭示了自然、社会和人类思维发展的客观规律，是经过实践检验的真理。
    2.  **人民性**：这是马克思主义最鲜明的政治立场。它不为少数人谋利益，而是为无产阶级和绝大多数人谋幸福。
    3.  **实践性**：马克思主义不仅仅是用来解释世界的，更重要的是用来**改造世界**的。它是行动的指南。
    4.  **发展性（开放性）**：它不是封闭僵化的教条，而是随着时代、实践和科学的发展而不断发展的“源头活水”。
