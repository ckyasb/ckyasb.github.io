# 专题四：社会主义改造理论

## 1. 为什么要向社会主义社会过渡

### 1.1 新民主主义社会的性质

中华人民共和国的成立，标志着中国进入了**新民主主义社会**。新民主主义社会不是一个独立的社会形态，而是由新民主主义向社会主义转变的过渡性社会形态。

新民主主义社会的特点：

**在经济上**：实行国营经济主导下的五种经济成分并存的经济制度：
- 国营经济（社会主义性质）
- 合作社经济（半社会主义性质）
- 个体经济
- 私人资本主义经济
- 国家资本主义经济

**在政治上**：实行工人阶级领导的、以工农联盟为基础的、各革命阶级联合专政的人民民主专政。

**在文化上**：实行马克思主义指导下的新民主主义文化。

### 1.2 向社会主义过渡的条件

新中国成立初期，我国基本建立了人民民主专政的国家政权，马克思主义在思想文化领域处于指导地位，中国共产党执政并得到人民群众的广泛拥护。

**经济条件**：
- 1950年6月，全国开展土地改革运动，3亿多无地少地的农民获得了土地
- 社会主义经济不断发展，国营工业在全国工业中的比重从1949年的34.2%上升到了1952年的52.8%
- 1949—1952年，国民经济迅速恢复

**政治条件**：
- 人民民主专政的巩固
- 中国共产党执政地位的加强

### 1.3 向社会主义过渡的理论依据

马克思、恩格斯认为，从资本主义社会到社会主义社会，需要经历一个过渡时期。列宁指出，在先进国家无产阶级的帮助下，落后国家可以不经过资本主义发展阶段而过渡到苏维埃制度。

毛泽东指出：只有完成了由生产资料的私人所有制到社会主义所有制的过渡，才利于社会生产力的迅速向前发展，才利于在技术上起一个革命。

## 2. 新民主主义社会如何向社会主义社会过渡

### 2.1 党在过渡时期的总路线

1953年，毛泽东和党中央提出了党在过渡时期的总路线和总任务：

> 从中华人民共和国成立，到社会主义改造基本完成，这是一个过渡时期。党在这个过渡时期的总路线和总任务，是要在一个相当长的时期内，逐步实现国家的社会主义工业化，并逐步实现国家对农业、对手工业和对资本主义工商业的社会主义改造。

过渡时期总路线的核心内容是**"一化三改"**：

| 内容 | 说明 |
|------|------|
| **"一化"** | 实现国家社会主义工业化（主体） |
| **"三改"** | 完成对个体农业、手工业和资本主义工商业的社会主义改造（两翼） |

"一化三改"被形象地比喻为**"一体两翼"**：好比一只鸟，主体是发展社会主义工业，翅膀是对农业、手工业的改造和对私营工商业的改造。

### 2.2 对农业的社会主义改造

**原则**：自愿互利、典型示范和国家帮助

**阶级政策**：依靠贫下中农，发展互助合作，由逐步限制到最后消灭富农剥削

**三个阶段**：

| 阶段 | 形式 | 性质 |
|------|------|------|
| 第一阶段 | 互助组 | 社会主义萌芽性质 |
| 第二阶段 | 初级农业生产合作社 | 半社会主义性质 |
| 第三阶段 | 高级农业生产合作社 | 完全社会主义性质 |

到1956年底，农业的社会主义改造基本完成。

### 2.3 对手工业的社会主义改造

采取了**积极领导、稳步前进**的方针。在方法步骤上，通过：
1. 办手工业供销小组
2. 办手工业供销合作社
3. 建立手工业生产合作社

从供销合作入手逐步发展到走生产合作的道路。

### 2.4 对资本主义工商业的社会主义改造

中国共产党根据中国资本主义工商业的实际情况，采取了**赎买**的方式进行和平改造。

**实行和平赎买的原因**：
1. 民族资产阶级既有剥削工人取得利润的一面，又有拥护宪法、愿意接受社会主义改造的一面
2. 中国共产党与民族资产阶级长期保持着统一战线的关系
3. 我国建立了人民民主专政的国家政权，建立了强大的社会主义国营经济

**采取从低级到高级的国家资本主义的过渡形式**：

| 形式 | 说明 |
|------|------|
| **低级形式** | 委托加工、计划订货、统购包销、经销代销 |
| **高级形式（个别行业公私合营）** | 国家投资入股，共同占有生产资料，实行"四马分肥" |
| **高级形式（全行业公私合营）** | 定股定息，企业变成社会主义性质 |

!!! info ""四马分肥""
    在公私合营企业中，利润按四个方面分配：国家所得税、企业公积金、工人福利费、资方红利。资方红利只占四分之一。

在对资本主义工商业的改造中，中国共产党依据"量才使用，适当照顾"的原则，把原来的民族资本家改造成了自食其力的社会主义劳动者。

### 2.5 社会主义改造的历史经验

**成功经验**：
1. **坚持社会主义工业化建设与社会主义改造同时并举**
2. **采取积极引导、逐步过渡的方式**
3. **用和平方法进行改造**

**存在的问题**：
- 要求过急
- 工作过粗
- 改变过快
- 形式也过于简单划一
- 对于一部分原工商业者的使用和处理不当

??? note "两个世所罕见的事实"
    我国社会主义改造实现了两个世所罕见的成就：
    1. 在一个几亿人口的大国比较顺利地实现了复杂而深刻的社会变革，不仅没有造成生产力的破坏，反而促进了工农业和整个国民经济的发展
    2. 生产关系的深刻变革没有引起巨大的社会动荡，反而极大地加强了人民的团结，并且是在人民普遍拥护下完成的

## 3. 社会主义改造的意义

### 3.1 确立了社会主义基本制度

社会主义改造的基本完成，标志着社会主义基本制度在中国确立。这是中华民族有史以来最为广泛而深刻的社会变革，为当代中国一切发展进步奠定了根本政治前提和制度基础。

### 3.2 创造性地回答了重大历史课题

社会主义改造创造性地回答了：
- 经济文化落后国家能不能建立社会主义的问题
- 如何用和平的方法消灭资产阶级的问题
- 如何引导农民走社会主义道路的历史课题

### 3.3 为社会主义建设奠定了基础

社会主义改造促进了工农业和整个国民经济的发展，为中国后来的社会主义建设奠定了制度基础和经济基础。
