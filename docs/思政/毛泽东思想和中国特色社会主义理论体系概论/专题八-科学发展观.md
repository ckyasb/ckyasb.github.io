# 专题八：科学发展观

## 1. 科学发展观的形成

### 1.1 形成条件

科学发展观是我们党坚持以马克思列宁主义、毛泽东思想、邓小平理论和"三个代表"重要思想为指导，根据新的发展要求，在准确把握世界发展趋势、认真总结我国发展经验、深入分析我国发展阶段性特征的基础上提出来的。

**1. 现实依据：深刻把握我国基本国情和新的阶段性特征**

科学发展观的最初提出，源于2003年初那场突如其来的**非典疫病灾害**。非典使我们党痛定思痛，深刻认识到：我国的经济发展和社会发展、城市发展和农村发展还不够协调；公共卫生事业发展滞后，公共卫生体系存在缺陷；经济发展这条腿比较长，社会事业发展这条腿比较短。

我国发展呈现新的阶段性特征：

| 成就 | 同时存在的问题 |
|------|---------------|
| 经济实力显著增强 | 结构性矛盾和粗放型增长方式尚未根本改变 |
| 社会主义市场经济体制初步建立 | 影响发展的体制机制障碍依然存在 |
| 人民生活总体上达到小康水平 | 收入分配差距拉大趋势还未根本扭转 |
| 协调发展取得显著成绩 | 农业基础薄弱、农村发展滞后的局面尚未改变 |
| 社会主义民主政治不断发展 | 民主法制建设与扩大人民民主和经济社会发展的要求还不完全适应 |
| 社会主义文化更加繁荣 | 人们思想活动的独立性、选择性、多变性、差异性明显增强 |
| 社会活力显著增强 | 社会结构、社会组织形式、社会利益格局发生深刻变化 |
| 对外开放日益扩大 | 面临的国际竞争日趋激烈，可以预见和难以预见的风险增多 |

我国正处于**发展关键期、改革攻坚期、矛盾凸显期**，解决好这些突出矛盾和问题，必须深刻回答**"实现什么样的发展、怎样发展"**这一重大问题。

**2. 实践基础：深入总结改革开放以来的实践经验**

党带领人民战胜各种风险挑战、坚持和发展中国特色社会主义的成功探索，是科学发展观形成的实践基础。包括：抗击非典疫情、应对国际金融危机、举办奥运会和世博会、抗击汶川地震等。

十年来（2002—2012），中国经济年均增长率达到10.7%，经济总量从世界第六位跃升到第二位。

**3. 时代背景：深刻分析国际形势、顺应世界发展趋势**

进入21世纪，世界处在大发展大变革大调整之中：
- 和平与发展仍然是时代主题
- 世界多极化不可逆转
- 经济全球化深入发展
- 科技革命加速推进
- 各国相互依存逐步加深
- 大国关系深刻变动

国际社会中，一些国家由于单纯追求经济增长，或照搬别国发展模式，出现了能源资源紧张、经济结构失衡、社会发展滞后、政治动荡、生态环境恶化等问题，为我们提供了深刻教训。

### 1.2 形成过程

| 时间 | 事件 | 意义 |
|------|------|------|
| 2003年初 | 非典疫情 | 集中暴露出我国经济社会发展中的薄弱环节和突出问题 |
| 2003年7月 | 胡锦涛总结抗击非典斗争经验 | 明确提出"我们要更好坚持全面发展、协调发展、可持续发展的发展观" |
| 2003年10月 | 党的十六届三中全会 | 第一次提出科学发展观概念："坚持以人为本，树立全面、协调、可持续的发展观，促进经济社会和人的全面发展" |
| 2004年3月 | 中央人口资源环境座谈会 | 胡锦涛深刻阐明科学发展观背景、意义，明确界定了深刻内涵和基本要求，标志着科学发展观的形成 |
| 2004年9月 | 党的十六届四中全会 | 把树立和落实科学发展观作为提高党的执政能力的重要内容 |
| 2005年10月 | 十六届五中全会 | 强调要坚定不移地以科学发展观统领经济社会发展全局 |
| 2007年 | 党的十七大 | 全面阐述科学发展观的理论定位、理论依据、理论内涵，标志着科学发展观进一步走向成熟 |
| 2012年 | 党的十八大 | 把科学发展观同马克思列宁主义、毛泽东思想、邓小平理论、"三个代表"重要思想一道，确立为党必须长期坚持的指导思想 |

## 2. 科学发展观的科学内涵和主要内容

### 2.1 科学内涵

科学发展观，**第一要义是发展，核心立场是以人为本，基本要求是全面协调可持续，根本方法是统筹兼顾**。

| 要素 | 内涵 | 回答的问题 |
|------|------|-----------|
| **第一要义：发展** | 必须加快转变经济发展方式，善于抓住和用好重要战略机遇期 | "为什么发展" |
| **核心立场：以人为本** | 始终把最广大人民的根本利益作为党和国家工作的根本出发点和落脚点 | "发展为了谁和依靠谁" |
| **基本要求：全面协调可持续** | 全面推进经济建设、政治建设、文化建设、社会建设，促进现代化建设各环节相协调 | "实现什么样的发展" |
| **根本方法：统筹兼顾** | 统筹城乡发展、区域发展、经济社会发展、人与自然和谐发展、国内发展和对外开放 | "怎样发展" |

!!! info "以人为本"
    以人为本体现了马克思主义的基本原理，体现了我们党全心全意为人民服务的根本宗旨和推动经济社会发展的根本目的。要始终把实现好、维护好、发展好最广大人民的根本利益作为党和国家一切工作的出发点和落脚点。

### 2.2 推动经济社会发展是第一要义

**必须加快转变经济发展方式**：
- 主攻方向：经济结构战略性调整
- 重要支撑：科技进步和创新
- 根本出发点和落脚点：保障和改善民生
- 重要着力点：建设资源节约型、环境友好型社会
- 强大动力：改革开放

从"又快又好"到**"又好又快"**——2006年，胡锦涛在党外人士座谈会上强调要促进经济"又好又快发展"，一改长期以来"快"字在前的习惯，把"好"字放在"快"字之前，体现了发展理念的重大变化。

**必须善于抓住和用好重要战略机遇期**：21世纪头二十年，对我国来说，是一个必须紧紧抓住并且可以大有作为的重要战略机遇期。

### 2.3 以人为本是核心立场

- 尊重人民主体地位，发挥人民首创精神，保障人民各项权益
- 走共同富裕道路，促进人的全面发展
- 做到发展为了人民、发展依靠人民、发展成果由人民共享

### 2.4 全面协调可持续是基本要求

全面推进**经济建设、政治建设、文化建设、社会建设**（四位一体，后发展为"五位一体"）。

坚持走生产发展、生活富裕、生态良好的文明发展道路，建设**资源节约型、环境友好型社会**。

### 2.5 统筹兼顾是根本方法

统筹兼顾是正确处理经济社会发展中重大关系的方针，要统筹：
- 城乡发展
- 区域发展
- 经济社会发展
- 人与自然和谐发展
- 国内发展和对外开放
- 中央和地方关系
- 个人利益和集体利益、局部利益和整体利益、当前利益和长远利益
- 国内国际两个大局

## 3. 科学发展观的历史地位

### 3.1 中国特色社会主义理论体系的接续发展

科学发展观是中国特色社会主义理论体系的重要组成部分，是对党的三代中央领导集体关于发展的重要思想的继承和发展，是马克思主义关于发展的世界观和方法论的集中体现。

### 3.2 发展中国特色社会主义必须坚持和贯彻的重大战略思想

科学发展观是我国经济社会发展的重要指导方针，是发展中国特色社会主义必须坚持和贯彻的重大战略思想。它深刻认识和回答了"实现什么样的发展、怎样发展"等重大问题。

### 3.3 对马克思主义发展理论的重大贡献

科学发展观借鉴了国外发展经验，批判地吸收了西方发展理论的合理成分，同时又立足于中国实际，以丰富的实践内容和理论创新深刻把握了经济社会发展的客观规律，丰富和发展了马克思主义发展理论。

??? note "科学发展观的理论定位"
    科学发展观是同马克思列宁主义、毛泽东思想、邓小平理论和"三个代表"重要思想既一脉相承又与时俱进的科学理论，是马克思主义关于发展的世界观和方法论的集中体现，是我国经济社会发展的重要指导方针，是发展中国特色社会主义必须坚持和贯彻的重大战略思想。
    
    ——党的十七大报告
