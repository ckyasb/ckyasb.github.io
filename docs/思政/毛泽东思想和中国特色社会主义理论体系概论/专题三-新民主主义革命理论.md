# 专题三：新民主主义革命理论

## 1. 新民主主义革命理论形成的依据

### 1.1 近代中国国情

毛泽东指出："认清中国社会的性质，就是说，认清中国的国情，乃是认清一切革命问题的基本的根据。"

近代中国是一个**半殖民地半封建性质的社会**，这是最基本的国情。

| 特征 | 含义 |
|------|------|
| **半殖民地** | 帝国主义列强通过政治的、经济的和文化的侵略，操纵中国的财政和经济命脉，操纵中国的政治和军事力量。中国没有完整的主权，没有国家的统一 |
| **半封建** | 帝国主义的侵略一方面促使自给自足的封建经济基础解体，另一方面，中国封建制度的根基——地主阶级对农民的剥削依旧存在，同买办资本和高利贷资本的剥削结合在一起 |

近代中国社会的主要矛盾：
- **帝国主义和中华民族的矛盾**（各种矛盾中最主要的矛盾）
- **封建主义和人民大众的矛盾**

近代中国的基本国情和主要矛盾，决定了近代中国革命的**根本任务**是：推翻帝国主义、封建主义和官僚资本主义的统治，争取民族独立和人民解放。

中国政治经济发展不平衡——微弱的资本主义经济和严重的半封建经济同时存在，近代式的若干工商业都市和停滞着的广大农村同时存在，几百万产业工人和几万万旧制度统治下的农民和手工业工人同时存在——这一特点决定了中国革命道路的特殊性。

### 1.2 近代中国革命的时代特征

十月革命开辟了世界无产阶级社会主义革命的新时代，使中国反帝反封建的民主革命从旧的世界资产阶级民主革命的一部分转变为新的世界无产阶级社会主义革命的一部分。

先进的中国人选择了马克思主义，用马克思主义分析、认识中国问题，通过把马克思列宁主义与中国工人运动相结合，创建了中国共产党。

中国革命要分两步走：
1. **第一步**：完成反帝反封建的新民主主义革命任务
2. **第二步**：完成社会主义革命任务

### 1.3 新民主主义革命实践探索

为了拯救民族危亡，中国人民奋起反抗，太平天国运动、戊戌变法、义和团运动、辛亥革命接连而起，各种救国方案轮番出台，但都以失败而告终。

在中国共产党的幼年时期，由于缺乏领导革命的实践经验，加上理论上不成熟，在革命的领导权、武装斗争、革命道路等问题上没有形成科学正确的认识，犯过一些错误，走过一些弯路。

革命实践要求中国共产党不仅要坚持马克思主义，而且要善于把马克思主义基本原理与中国革命实际相结合。以毛泽东同志为主要代表的中国共产党人独立自主地分析和研究中国革命的实际问题，逐步深化对中国革命的认识，形成了新民主主义革命理论。

新民主主义革命理论源于实践：
- 建立和巩固农村根据地的实践 → 中国革命道路理论
- 革命战争的实践 → 人民军队和革命战争的理论
- 两次国共合作的实践 → 统一战线理论
- 党在革命中从小到大、由弱到强的实践 → 党的建设理论

??? note "没有实践就没有新民主主义革命理论"
    没有中国革命的实践，没有党对革命实践经验的概括和总结，新民主主义革命理论就无法形成和发展。

## 2. 新民主主义革命的总路线和基本纲领

### 2.1 新民主主义革命的总路线

毛泽东在《中国革命和中国共产党》（1939年）中第一次提出了**"新民主主义革命"**的科学概念，在《在晋绥干部会议上的讲话》（1948年）中完整地表述了新民主主义革命总路线的内容：

> **无产阶级领导的，人民大众的，反对帝国主义、封建主义和官僚资本主义的革命**

总路线主要回答了革命的任务、对象、动力、领导力量、性质和前途等基本问题。

### 2.2 革命的对象

近代中国社会的性质和主要矛盾，决定了中国革命的主要敌人就是**帝国主义、封建主义、官僚资本主义**——压在中国人民身上的"三座大山"。

| 对象 | 原因 |
|------|------|
| **帝国主义** | 中国革命的首要对象，是近代中国贫困落后和一切灾难祸害的总根源 |
| **封建主义** | 帝国主义统治中国和封建军阀实行专制统治的社会基础，是中国经济现代化和政治民主化的主要障碍 |
| **官僚资本主义** | 对广大劳动人民的残酷剥削和对民族工商业的巧取豪夺，严重束缚了中国社会生产力的发展 |

在不同的历史阶段，随着社会主要矛盾的变化，革命的主要对象有所不同：
- 大革命时期：北洋军阀
- 土地革命时期：国民党新军阀
- 抗日战争时期：日本帝国主义
- 解放战争时期：国民党反动派

中国革命的两个基本任务：
- **民族革命**：对外推翻帝国主义的压迫
- **民主革命**：对内推翻封建地主阶级和官僚资产阶级的压迫

### 2.3 革命的动力

| 阶级 | 地位 |
|------|------|
| **无产阶级** | 中国革命最基本的动力，领导力量 |
| **农民** | 中国革命的主力军（占全国人口百分之九十的工人农民是根本的力量） |
| **城市小资产阶级** | 无产阶级的可靠同盟者 |
| **民族资产阶级** | 既有革命的一面，又有动摇、妥协的一面（两面性） |

### 2.4 新民主主义的基本纲领

| 纲领 | 主要内容 |
|------|---------|
| **政治纲领** | 推翻帝国主义和封建主义的统治，建立一个无产阶级领导的、以工农联盟为基础的、各革命阶级联合专政的新民主主义的共和国 |
| **经济纲领** | 没收封建地主阶级的土地归农民所有，没收官僚资产阶级的垄断资本归新民主主义的国家所有，保护民族工商业 |
| **文化纲领** | 无产阶级领导的、人民大众的、反帝反封建的文化，即民族的科学的大众的文化 |

### 2.5 新民主主义革命的道路

**农村包围城市、武装夺取政权的道路**——这是中国革命胜利的唯一正确道路。

必要性：
- 在半殖民地半封建的中国，内部没有民主制度，外部没有民族独立，只能以武装的革命反对武装的反革命
- 农民占全国人口绝大多数，是革命的主力军
- 敌人长期占据中心城市，农村是其统治的薄弱环节

可能性（红色政权存在发展的条件）：
- 中国政治经济发展不平衡
- 良好的群众基础
- 全国革命形势继续向前发展
- 相当力量的正式红军的存在
- 共产党的正确领导

### 2.6 新民主主义革命的基本经验（三大法宝）

毛泽东在《〈共产党人〉发刊词》中总结了中国革命的经验，提出**统一战线、武装斗争、党的建设**是中国共产党在中国革命中战胜敌人的三个法宝。

| 法宝 | 内容 |
|------|------|
| **统一战线** | 团结一切可以团结的力量，建立最广泛的统一战线 |
| **武装斗争** | 中国革命的主要形式，是农村包围城市道路的必然要求 |
| **党的建设** | 着重从思想上建设党，保持党的先进性纯洁性 |

??? note "三大法宝的关系"
    统一战线和武装斗争是战胜敌人的两个基本武器。统一战线是实行武装斗争的统一战线，武装斗争是统一战线的中心支柱。而党的组织则是掌握这两个武器以实行对敌冲锋陷阵的英勇战士。

## 3. 新民主主义革命理论的意义

### 3.1 理论意义

新民主主义革命理论是马克思主义中国化的重要理论成果，开辟了马克思主义中国化的发展道路。它科学地回答了在半殖民地半封建的中国如何进行革命的一系列重大问题，丰富和发展了马克思主义的革命理论。

### 3.2 实践意义

在新民主主义革命理论的指引下，中国共产党领导中国人民取得了新民主主义革命的伟大胜利，建立了中华人民共和国，实现了民族独立、人民解放，为实现中华民族伟大复兴创造了根本社会条件。

### 3.3 世界意义

中国新民主主义革命的胜利，是20世纪人类历史上具有重大意义的事件。它改变了世界政治力量对比，鼓舞了世界被压迫民族和被压迫人民争取民族独立和解放的斗争。
