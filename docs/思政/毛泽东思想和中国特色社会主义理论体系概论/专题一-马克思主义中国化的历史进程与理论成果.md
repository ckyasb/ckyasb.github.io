# 专题一：马克思主义中国化的历史进程与理论成果

## 1. 马克思主义在中国的传播

### 1.1 历史背景：近代中国的危机与救亡

1840年鸦片战争以后，由于西方列强的入侵和封建统治的腐败，中国逐步成为半殖民地半封建社会，国家蒙辱、人民蒙难、文明蒙尘，中华民族遭受了前所未有的劫难。

近代中国签订的主要不平等条约：

| 年份 | 条约 | 影响 |
|------|------|------|
| 1842 | 《南京条约》 | 中国开始沦为半殖民地半封建社会 |
| 1858 | 《天津条约》 | 进一步丧失主权 |
| 1860 | 《北京条约》 | 加深半殖民地化 |
| 1895 | 《马关条约》 | 民族危机空前严重 |
| 1901 | 《辛丑条约》 | 中国完全沦为半殖民地半封建社会 |

为了拯救民族危亡，中国人民奋起反抗，仁人志士奔走呐喊：

- **太平天国运动**（农民阶级）：提出"无处不均匀，无人不饱暖"的天朝田亩制度，但因阶级局限性、没有科学斗争路线而失败。
- **洋务运动**（地主阶级洋务派）：以李鸿章、曾国藩、左宗棠为代表，主张"自强求富"，引进西方技术，但未触动封建体制核心，甲午战败宣告破产。
- **戊戌变法**（资产阶级维新派）：以康有为、梁启超为代表，进行政治体制改革，历时103天即告失败，力量过于弱小。
- **义和团运动**：农民自发的反帝爱国运动。
- **辛亥革命**（资产阶级革命派）：以孙中山为代表，推翻了封建帝制，但因缺乏强有力的领导核心、不熟悉中国国情、没有彻底的反帝反封建纲领而失败。

此外，各种社会思潮也纷纷传入中国——自由主义、改良主义、无政府主义、实用主义、工团主义、民粹主义、社会达尔文主义等——但无论哪一种主义，都未能解决中国的实际问题。

!!! info "半殖民地半封建社会"
    近代中国的基本国情。帝国主义侵略破坏了中国的领土和主权完整，封建统治阻碍了生产力的发展。这一特殊国情决定了中国革命不能照搬马列主义的"本本"，必须走自己的路。

### 1.2 十月革命与马克思主义的传入

"十月革命一声炮响，给我们送来了马克思列宁主义。"

1917年俄国十月革命的胜利，开辟了世界无产阶级社会主义革命的新时代。中国先进分子从马克思列宁主义中看到了解决中国问题的出路。

第一次世界大战（1914—1918）充分暴露了资本主义制度的弊端——资本主义现代化之路充满掠夺与鲜血，不仅是殖民地人民的灾难，也给本国人民带来巨大痛苦。这促使中国先进分子重新思考：中国的现代化之路是否只有资本主义一条道路可走？

??? note "十月革命对中国的影响"
    十月革命对中国产生了深远影响：
    1. 提供了一个成功的革命范例——经济文化落后的国家也可以走社会主义道路；
    2. 为中国送来了马克思列宁主义的科学理论；
    3. 开辟了人类历史的新纪元，改变了世界历史的方向；
    4. 使中国反帝反封建的民主革命从旧的世界资产阶级民主主义革命的一部分，转变为新的世界无产阶级社会主义革命的一部分。

### 1.3 早期马克思主义者的活动

陈独秀、李大钊等人成为最早在中国传播马克思列宁主义的知识分子。"南陈北李，相约建党"，标志着马克思主义在中国从理论传播走向建党实践。

在马克思列宁主义同中国工人运动的紧密结合中，中国共产党于1921年应运而生。中国共产党的成立，深刻改变了近代以后中华民族发展的方向和进程，深刻改变了中国人民和中华民族的前途和命运，深刻改变了世界发展的趋势和格局。中国人民从精神上由被动转为主动。

!!! info "中国选择马克思主义"
    中国选择马克思主义，是历史的选择，是人民的选择。马克思主义是科学的理论、人民的理论、实践的理论、不断发展的开放的理论。

### 1.4 毛泽东向马克思主义者的转变

毛泽东也是在不断学习和革命实践的过程中，认识到只有马克思主义、只有社会主义才能救中国的深刻道理，从而实现了向马克思主义者的转变。

毛泽东确立马克思主义信仰的过程：

1. **早年经历**：出生于湖南韶山的一个农民家庭（后达到富农阶层），从小具有强烈的反抗意识和反抗精神。喜欢读《水浒传》《三国演义》《盛世危言》等"闲书"和进步书籍。

2. **长沙求学**（1911年后）：进入湖南第一师范学校学习，创办**新民学会**（1918年，源自"大学之道，在明明德，在新民，在止于至善"），宗旨是"改造中国与世界"。学会会员后来多加入中国共产党。

3. **第一次北上北京**（1918年）：在北京大学担任图书管理员，加入马克思主义研究会，结识李大钊、陈独秀等进步知识分子，开始系统阅读马克思主义理论。

4. **创办《湘江评论》**（1919年）：主编并创办《湘江评论》，以白话文宣传新思想，发表《民众的大联合》一文，提出建立人民革命统一战线的思想。刊物被查封后又投身其他刊物。

5. **组织工人运动**：通过参加和组织工人运动，他越来越相信只有经过群众的行动、取得群众的政治权利，才能保证有效的革命的实现。在这一过程中，他开始受到马克思主义理论和俄国革命历史的影响和指导。

6. **确立信仰**（1936年回忆）："我第二次到北京期间，读了许多关于俄国情况的书。我热心地搜寻那时候能找到的为数不多的用中文写的共产主义书籍。有三本书特别深地铭刻在我的心中，建立起我对马克思主义的信仰。我一旦接受了马克思主义对历史的正确解释以后，我对马克思主义的信仰就没有动摇过。"

??? note "毛泽东为什么没有去法国勤工俭学"
    毛泽东原本计划赴法国勤工俭学，但最终没有成行。他自己总结了四个原因：一是钱的问题，手头紧张；二是法语没有学好，语言障碍大；三是留在国内可以为新民学会招收新会员；**第四（最关键）**：他认为自己是一个行动派，追求的是参与政治组织和政治行动，而非单纯追求学问。

## 2. 马克思主义中国化的提出

### 2.1 马克思主义必须中国化

马克思主义既然是科学的理论，是当时中国人选择的救国救民的真理，那么按照它的理论照着做就行了，为什么还要马克思主义中国化？

**两个方面的需要：**

1. **解决中国实际问题的客观需要**：近代中国的国情既不同于马克思所分析的西方资本主义国家，也不同于十月革命前的俄国。照搬外国经验无法解决中国问题。毛泽东曾批评："把马克思列宁主义书本上的某些个别字句看作现成的灵丹圣药，似乎只要得了它，就可以不费气力地包医百病。这是一种幼稚者的蒙昧。"

2. **马克思主义理论发展的内在要求**：马克思恩格斯的整个世界观不是教义，而是方法。它提供的不是现成的教条，而是进一步研究的出发点和供这种研究使用的方法。列宁也指出：马克思主义的全部精神要求人们对每一个原理都要历史地、同其他原理联系起来、同具体的历史经验联系起来加以考察。

!!! info "马克思主义中国化的必要性"
    马克思主义只有实现中国化，才能真正解决中国的实际问题，才能体现其科学性，彰显其强大力量。正如习近平总书记所言："中国共产党为什么能，中国特色社会主义为什么好，归根到底是因为马克思主义行。"

### 2.2 从《反对本本主义》到六届六中全会

**早期探索**：李大钊在《再论问题与主义》中已指出："大凡一个主义，都有理想与实用两面。把这个理想适用到实际的政治上去，那就因时、因所、因事的性质情形，有些不同。"

**《反对本本主义》**（1930年5月）：毛泽东提出了"没有调查，就没有发言权"的著名论断，指出"马克思主义的'本本'是要学习的，但是必须同我国的实际情况相结合。我们需要'本本'，但是一定要纠正脱离实际情况的本本主义。中国革命斗争的胜利要靠中国同志了解中国情况。"

**六届六中全会**（1938年9月29日—11月6日，延安）：这是马克思主义中国化进程中的里程碑。为总结抗战以来的斗争经验，纠正王明在抗日战争前期的右倾投降主义错误，明确党在民族战争中的地位而召开。

毛泽东在六届六中全会上作了《论新阶段》的报告，正式提出"马克思主义中国化"的命题：

> "没有抽象的马克思主义，只有具体的马克思主义。马克思主义的中国化，使之在其每一表现中带着中国的特性，即是说，按照中国的特点去应用它，成为全党亟待了解并亟须解决的问题。"

??? note "六届六中全会的意义"
    1. 正式提出了"马克思主义中国化"这一科学命题；
    2. 总结了抗战以来的斗争经验；
    3. 纠正了王明的右倾错误；
    4. 明确了党在民族战争中的领导地位；
    5. 为全党确立了马克思主义与中国实际相结合的方向。

**党的七大**（1945年）：刘少奇在《关于修改党的章程的报告》中，对"马克思主义中国化"从理论上作了进一步阐述，并指出毛泽东思想就是"中国化的马克思主义"。七大正式将毛泽东思想写入党章，确立为党的指导思想。

### 2.3 马克思主义中国化的科学内涵

马克思主义中国化，就是把马克思主义基本原理同中国具体实际相结合、同中华优秀传统文化相结合。具体包括三个层面：

1. **运用马克思主义的立场、观点、方法研究和解决中国革命、建设、改革中的实际问题**——推动了中华民族从站起来、富起来到强起来的伟大飞跃。

2. **总结和提炼中国革命、建设、改革的实践经验，认识和掌握客观规律，为马克思主义理论宝库增添新的内容**——形成了毛泽东思想、邓小平理论、"三个代表"重要思想、科学发展观、习近平新时代中国特色社会主义思想。

3. **运用中国人民喜闻乐见的民族语言来阐述马克思主义理论**——把马克思主义理论的精髓用通俗易懂的中国语言表达出来，让马克思主义植根于中华优秀传统文化的土壤之中，使之成为具有中国特色、中国风格、中国气派的马克思主义。

!!! info ""两个结合""
    马克思主义中国化的科学内涵，核心是"两个结合"：**把马克思主义基本原理同中国具体实际相结合、同中华优秀传统文化相结合**。这是习近平总书记在庆祝中国共产党成立一百周年大会上提出的重要论断，深化了对马克思主义中国化的认识。

## 3. 马克思主义中国化的历史进程

我们党的历史，就是一部不断推进马克思主义中国化的历史，就是一部不断推进理论创新、进行理论创造的历史。

马克思主义中国化经历了四个历史阶段：

### 3.1 新民主主义革命时期（1921—1949）

**历史背景**：中国共产党团结带领中国人民，浴血奋战，百折不挠，创造了新民主主义革命的伟大成就，建立了人民当家作主的中华人民共和国，实现了民族独立、人民解放。

**理论成果**：在这个时期，以毛泽东同志为主要代表的中国共产党人，把马克思列宁主义基本原理同中国具体实际相结合，**创立了毛泽东思想**。开辟了农村包围城市、武装夺取政权的正确革命道路，为夺取新民主主义革命胜利指明了正确方向。

**主要阶段**：
- 大革命时期（1924—1927）
- 土地革命战争时期（1927—1937）
- 抗日战争时期（1937—1945）
- 解放战争时期（1945—1949）

中国人民站起来了！中华民族任人宰割、饱受欺凌的时代一去不复返了！

### 3.2 社会主义革命和建设时期（1949—1978）

**历史背景**：中国共产党团结带领中国人民，自力更生、发愤图强，创造了社会主义革命和建设的伟大成就，实现了中华民族有史以来最为广泛而深刻的社会变革。

**理论成果**：毛泽东同志提出把马克思列宁主义基本原理同中国具体实际进行**"第二次结合"**，以毛泽东同志为主要代表的中国共产党人，结合新的实际**丰富和发展了毛泽东思想**。

**重要成就**：
- 1954年宪法颁布，确立社会主义基本制度
- 1956年完成社会主义改造（"一化三改"）
- 长春第一汽车制造厂（1956年）
- 第一架"初教5"飞机
- 第一台"东方红"拖拉机（1958年）
- 第一代主战坦克"五九"式
- 南京长江大桥、"两弹一星"等

1981年《关于建国以来党的若干历史问题的决议》对毛泽东思想作出科学评价，概括了毛泽东思想的科学内涵。

### 3.3 改革开放和社会主义现代化建设新时期（1978—2012）

**历史背景**：从党的十一届三中全会到十八大，中国共产党高举中国特色社会主义伟大旗帜，团结带领中国人民，解放思想、锐意进取，创造了改革开放和社会主义现代化建设的伟大成就。

**理论成果**：
- 以邓小平同志为主要代表的中国共产党人，**创立了邓小平理论**——围绕"什么是社会主义、怎样建设社会主义"这一根本问题，深刻揭示社会主义本质，确立社会主义初级阶段基本路线；
- 以江泽民同志为主要代表的中国共产党人，**形成了"三个代表"重要思想**——加深了对"建设什么样的党、怎样建设党"的认识，确立了社会主义市场经济体制；
- 以胡锦涛同志为主要代表的中国共产党人，**形成了科学发展观**——深刻认识和回答了"实现什么样的发展、怎样发展"等重大问题。

我国实现了从生产力相对落后的状况到经济总量跃居世界第二的历史性突破，实现了人民生活从温饱不足到总体小康、奔向全面小康的历史性跨越。中国大踏步赶上了时代！

### 3.4 中国特色社会主义新时代（2012年至今）

**历史背景**：中国共产党团结带领中国人民，自信自强、守正创新，统揽伟大斗争、伟大工程、伟大事业、伟大梦想，创造了新时代中国特色社会主义的伟大成就。

**理论成果**：以习近平同志为主要代表的中国共产党人，坚持把马克思主义基本原理同中国具体实际相结合、同中华优秀传统文化相结合，深刻总结并充分运用党成立以来的历史经验，从新的实际出发，**创立了习近平新时代中国特色社会主义思想**。

习近平新时代中国特色社会主义思想是**当代中国马克思主义、二十一世纪马克思主义**，是**中华文化和中国精神的时代精华**，实现了马克思主义中国化**新的飞跃**。

党的十九届六中全会从13个方面分领域总结了新时代党和国家事业取得的历史性成就、发生的历史性变革。中华民族迎来了从站起来、富起来到强起来的伟大飞跃！

## 4. 马克思主义中国化的理论成果

在中国革命、建设、改革的历史进程中，马克思主义中国化实现了**三次历史性飞跃**：

| 理论成果 | 主要创立者 | 历史地位 | 解决的核心问题 |
|---------|-----------|---------|--------------|
| 毛泽东思想 | 毛泽东 | 第一次历史性飞跃 | 中国革命与建设的道路问题 |
| 中国特色社会主义理论体系 | 邓小平、江泽民、胡锦涛 | 新的飞跃 | 什么是社会主义、怎样建设社会主义等 |
| 习近平新时代中国特色社会主义思想 | 习近平 | 新的飞跃 | 新时代坚持和发展什么样的中国特色社会主义等 |

### 4.1 毛泽东思想

毛泽东思想是马克思列宁主义在中国的创造性运用和发展，是被实践证明了的关于中国革命和建设的正确的理论原则和经验总结，是马克思主义中国化的**第一次历史性飞跃**。

**毛泽东思想的主要内容包括**：
1. 新民主主义革命理论
2. 社会主义革命和社会主义建设理论
3. 革命军队建设和军事战略的理论
4. 政策和策略的理论
5. 思想政治工作和文化工作的理论
6. 党的建设的理论

此外还包括国际战略和外交工作理论等内容。

**毛泽东思想的活的灵魂**：实事求是、群众路线、独立自主。这三个方面贯穿于毛泽东思想各个组成部分的立场、观点和方法。

**毛泽东思想科学内涵的三段论**（1981年《历史决议》+十二大党章）：
1. 毛泽东思想是马克思列宁主义在中国的运用和发展；
2. 毛泽东思想是被实践证明了的关于中国革命和建设的正确的理论原则和经验总结；
3. 毛泽东思想是中国共产党集体智慧的结晶。

!!! info "毛泽东的思想 vs 毛泽东思想"
    这是考试常见辨析点。毛泽东思想是一个科学的思想体系，是集体智慧的结晶，只包括被实践证明为正确的理论原则和经验总结。毛泽东个人的思想则包括其晚年错误。那些被实践证明为错误的理论原则和经验总结，**不属于毛泽东思想**。

### 4.2 中国特色社会主义理论体系

中国特色社会主义理论体系，包括**邓小平理论、"三个代表"重要思想、科学发展观**。

- **邓小平理论**：深刻揭示社会主义本质，确立社会主义初级阶段基本路线，作出改革开放的历史性决策，成功开创了中国特色社会主义。
- **"三个代表"重要思想**：在国内外形势十分复杂、世界社会主义出现严重曲折的严峻考验面前捍卫了中国特色社会主义，确立了社会主义市场经济体制的改革目标。
- **科学发展观**：在全面建设小康社会进程中推进实践创新、理论创新、制度创新，强调以人为本、全面协调可持续发展。

### 4.3 习近平新时代中国特色社会主义思想

习近平同志对关系新时代党和国家事业发展的一系列重大理论和实践问题进行了深邃思考和科学判断，就新时代重大时代课题提出一系列原创性的治国理政新理念新思想新战略。

**三大时代课题**：
1. 新时代坚持和发展什么样的中国特色社会主义、怎样坚持和发展中国特色社会主义；
2. 建设什么样的社会主义现代化强国、怎样建设社会主义现代化强国；
3. 建设什么样的长期执政的马克思主义政党、怎样建设长期执政的马克思主义政党。

### 4.4 三大理论成果既一脉相承又与时俱进

三大理论成果的共同点：
- 都是马克思主义中国化的理论成果；
- 都是中国化的马克思主义；
- 都是马克思主义基本原理与中国具体实际相结合的产物；
- 共同确立为国家的指导思想（2018年宪法修正案）。

**一脉相承**：都坚持马克思主义的基本原理，坚持社会主义的方向，坚持党的领导，坚持以人民为中心。

**与时俱进**：每个理论成果都是针对不同历史阶段的时代课题作出的回答，都推进了马克思主义中国化的发展。

??? note "指导思想的宪法确认"
    2018年十三届全国人大一次会议通过的宪法修正案，将习近平新时代中国特色社会主义思想载入宪法，与马克思列宁主义、毛泽东思想、邓小平理论、"三个代表"重要思想、科学发展观共同确立为国家指导思想。

## 5. 继续推进马克思主义中国化

### 5.1 当代意义

当代中国正在经历人类历史上最为宏大而独特的实践创新，改革发展稳定任务之重、矛盾风险挑战之多、治国理政考验之大都前所未有，世界百年未有之大变局深刻变化前所未有，提出了大量亟待回答的理论和实践课题。

推进马克思主义中国化时代化的任务不是轻了，而是更重了。

### 5.2 发展方向

我们应当：
1. **准确把握时代大势**，勇于站在人类发展前沿，聆听人民心声，回应现实需要；
2. **坚持解放思想、实事求是、守正创新**，更好把坚持马克思主义和发展马克思主义统一起来；
3. **坚持用马克思主义之"矢"去射新时代中国之"的"**，继续推进马克思主义基本原理同中国具体实际相结合、同中华优秀传统文化相结合；
4. **使马克思主义呈现出更多中国特色、中国风格、中国气派**，续写马克思主义中国化时代化新篇章。

### 5.3 "归根到底是因为马克思主义行"

习近平总书记指出：中国共产党为什么能，中国特色社会主义为什么好，归根到底是因为马克思主义行。马克思主义是我们立党立国、兴党强国的根本指导思想。马克思主义理论不是教条而是行动指南，必须随着实践发展而发展，必须中国化才能落地生根、本土化才能深入人心。
