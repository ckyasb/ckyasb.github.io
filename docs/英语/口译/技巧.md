# 口译技巧

1. 准备工作: A4草稿纸竖向对折，较小的宽度更有利于集中注意力和快速记录，同时整体记录也更整齐
2. 听记过程中：
    - 使用目标语言记录，方便翻译
    - One component one line 每行内容较少，梯度呈现，最重要信息出现在左上侧。
    - Parallel structures in vertical对于并列结构，垂直方向记录，表明语法与逻辑都为并列关系。
    - Meaning clusters draw a line 分割线，表明语句和段落的间隔区分，逻辑，如因果、转折或举例,需要重点关注，（方便后面编）。
    - Language & Logic are equally important将表明逻辑顺序的关联词提取出后，记录在左上侧。
    - 多使用简写或者符号进行记录，至少对我而言几乎来不及，另外符号体系因人而异，符合自身习惯即可，
