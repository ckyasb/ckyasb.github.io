## 一、冰山理论与现代小说技法

### 海明威《白象似的群山》

| 要素 | 内容 |
|:---|:---|
| **作者** | 欧内斯特·海明威（Ernest Hemingway, 1899–1961），美国"迷惘的一代"代表作家，诺贝尔文学奖得主 |
| **故事** | 一对男女在西班牙火车站等车，喝苦艾酒，讨论"一个手术" |
| **未明说的事** | "手术"是堕胎——全文没有出现"堕胎"二字 |
| **冰山理论** | 海明威的写作原则：作家只写八分之一，剩下的八分之七藏在水下 |

### 课堂分析

> "海明威这篇小说，男女在喝酒，在闲聊，但整个对话底下都是刀光剑影。女的说'那就做吧'，男的说'你要是不想做就不做'——每一句都是试探，每一句都是伤害。这就是冰山——你看得见的只是水面上的冰尖，水面下的才是全部的重量。"

**冰山理论的四个层次：**

| 层次 | 说明 |
|:---|:---|
| **文字之简** | 不用形容词，不说心理，只记对话和动作 |
| **情感之藏** | 人物的真实感受从不直接说出 |
| **主题之隐** | 堕胎、死亡的恐惧、关系的破裂——只字不提却有千钧之力 |
| **留白之美** | 读者需要自己填补冰山下的空间 |

### "人生"启示

> "生活中最多的不是戏剧性的表白，而是欲说还休的沉默。海明威教会我们：真正的痛苦是不说出来的。说出来的痛苦，已经消化了一半。"

## 二、福楼拜《包法利夫人》与中国镜像

### 作品简介

**居斯塔夫·福楼拜**（Gustave Flaubert, 1821–1880），法国现实主义大师。《包法利夫人》（1857）讲述外省医生夫人爱玛因沉溺于浪漫幻想最终走向毁灭的故事。

### 翟教授的"包法利夫人谱系"

翟教授提出一个极有洞见的观点：**《包法利夫人》是一个"母本"，中国当代文学和电影中有一整条"包法利夫人变体"的谱系。**

| 作品 | 类型 | 与包法利夫人的关联 |
|:---|:---|:---|
| 顾长卫《立春》 | 电影 | 小城女性郁郁寡欢，怀揣不切实际的艺术梦想 |
| 顾长卫《孔雀》 | 电影 | 姐姐张静初演的——在小城压抑的环境中窒息 |
| 路遥《人生》中的刘巧珍 | 小说 | 农村女性的爱情幻想与残酷现实的碰撞 |

> "小地方、怀抱幻想、不甘平庸、最终被现实碾碎的女性——这个原型从福楼拜开始，一直延续到现在。每一代都有包法利夫人，只是她们换了个名字、换了身衣服。"

## 三、司汤达《红与黑》与中国式进城叙事

### 作品简介

**司汤达**（Stendhal, 1783–1842），法国批判现实主义作家。《红与黑》（1830）的主人公于连·索雷尔是一个木匠的儿子，凭借聪明和野心在贵族社会中向上攀爬。

### "于连困境"在中国

> "当代中国小说里三分之一的故事都是这个套路——农村青年通过读书、考大学来到城市，在城市里迷失、挣扎、堕落或成功。于连就是他们的祖师爷。《红与黑》就是'进城叙事'的圣经。"

**于连模式的特点：**

| 要素 | 于连 | 中国变体 |
|:---|:---|:---|
| **出身** | 木匠之子 | 农家子弟 |
| **武器** | 拉丁文、记忆力 | 文凭、知识 |
| **途径** | 教会、贵族沙龙 | 考公、考编、进大厂 |
| **女性关系** | 德·雷纳夫人、玛蒂尔德 | 城市女友、富家千金 |
| **结局** | 上断头台 | 成功/堕落/返乡三重可能 |

## 四、林奕含《房思琪的初恋乐园》：文学能否拯救？

### 作品简介

**林奕含**（1991–2017），台湾作家。《房思琪的初恋乐园》出版于2017年，讲述少女房思琪被补习班老师李国华性侵的故事。小说出版后不久，作者自杀身亡。

### 课堂讨论

学生展示围绕"文学能否真实反映现实"这一命题展开，引用了从柏拉图到博尔赫斯的文学理论谱系：

| 阶段 | 代表 | 观点 |
|:---|:---|:---|
| 古典模仿论 | 柏拉图 | 现实是理念的摹本，文艺是摹本的摹本 |
| 浪漫主义 | 华兹华斯等 | 文学是情感的自然流露 |
| 现实主义 | 司汤达、福楼拜 | 文学是社会的镜子 |
| 现代主义 | 普鲁斯特、伍尔夫 | 文学是意识流的记录 |
| 后现代/元小说 | 纪德《伪币制造者》、博尔赫斯 | 文学本身就是现实——虚构也是一种真实 |

### 最沉重的问题

学生提出了一个尖锐的问题：**房思琪在小说中试图用文学来理解和消化自己的遭遇，但文学最终没有拯救她。那么，文学到底是解毒的药——还是包裹毒药的糖衣？**

> "房思琪的故事让我们不得不面对一个残酷的问题：当一个女孩子在遭受侵害的时候，她读过的那些关于美和爱的文学作品，是让她更坚强——还是让她更容易被欺骗？林奕含用生命给出了自己的答案。"

## 五、真实事件改编：三种模式

### 课堂框架

学生展示系统梳理了真实事件改编电影的三种模式：

| 模式 | 特点 | 代表作品 |
|:---|:---|:---|
| **纪实性改编** | 最大限度还原真实事件原貌 | 《聚焦》（Spotlight）——波士顿环球报调查教会性侵丑闻 |
| **戏剧化改编** | 在真实框架内增加戏剧冲突 | 《中国机长》——川航3U8633备降事件 |
| **情感化改编** | 突出人物的情感弧线，可改动细节 | 《当幸福来敲门》——克里斯·加德纳真实经历改编 |
| **控诉性改编** | 以真实事件为素材进行社会批判 | 《黑水》（Dark Waters）——杜邦化工污染诉讼 |

### 改编哲学

> "真实事件改编电影永远面临一个悖论：改了，有人说你违背历史；不改，有人说你缺乏艺术。所以改编本身就是一种'现实'和'虚构'之间的博弈——这个博弈的过程，就是文学和现实的张力在电影中的体现。"

## 六、《简·爱》：阶级与尊严

### 作品简介

**夏洛蒂·勃朗特**（Charlotte Brontë, 1816–1855），英国女作家。《简·爱》（1847）是维多利亚时代女性文学的经典。

### 空间即阶级

学生展示从"空间"角度切入分析：

| 空间 | 对应的阶级/权力关系 |
|:---|:---|
| **红房子** | 简·爱被关禁闭的地方——象征儿童的无力与被惩罚 |
| **洛伍德慈善学校** | 布洛克赫斯特的教化——对穷人子弟的系统性羞辱 |
| **桑菲尔德府三楼** | 简·爱以家庭教师身份居住——既不属于主人也不属于仆人 |
| **阁楼上的伯莎·梅森** | 被隐藏的、被压抑的女性——殖民地的他者 |

### 真/人/的/尊严

> "《简·爱》最核心的一句话是：'我和你一样是人。'跨越阶级的爱情在小说中之所以成立，不是因为罗切斯特的慷慨，而是因为简·爱的不屈——她用尊严换来了尊重。"
