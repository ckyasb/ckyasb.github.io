# 03 中国现代文学（一）：文学与羞耻·文学与现实

## 课程概览

四月课程围绕两个核心主题展开：**羞耻的文学书写**与**文学与现实的关系**。翟教授引导学生在经典与现代文本之间穿梭，从孟子到鲁迅、从路遥到铁凝、从余华到林奕含，审视中国现代文学如何处理"羞耻"与"现实"这两个沉重命题。

---

## 一、羞耻谱系：从儒家到现代文学

### 理论框架

翟教授在4月7日的课上系统梳理了羞耻哲学谱系：

| 思想来源 | 主要观点 |
|:---|:---|
| **孟子** | "羞恶之心，义之端也"——羞耻是一切道德的起点 |
| **柏拉图《普罗泰戈拉斯篇》** | 普罗米修斯盗火使人获得技艺，但人缺乏政治智慧，于是宙斯赐予"羞耻"与"正义"以维系城邦 |
| **贝尔纳·斯蒂格勒《技术与时间》** | 技术（爱比米修斯的过失）使人先天不足，人类必须通过后天教化来弥补 |
| **舍勒** | 羞耻是"自我价值的失落感"——人在理想自我与现实自我之间的落差中感到羞耻 |

> "要理解中国现代文学中的羞耻叙事，首先要明白：羞耻不是一种低级的情感，它是文明的基石。孟子说得最透彻——'无羞恶之心，非人也'。在这句话面前，整个中国现代文学的羞耻叙事有了根源。"

### 铁凝《哦，香雪》：物质匮乏的羞耻

| 要素 | 内容 |
|:---|:---|
| **作者** | 铁凝（1957–），中国当代作家，现任中国作家协会主席 |
| **故事** | 台儿沟的女孩们每天等火车停靠一分钟，用鸡蛋换城里人的东西 |
| **香雪的秘密** | 她最想要的是城里同学的**磁铁铅笔盒**——一个自动合上的、带有磁铁的铅笔盒 |
| **高潮** | 香雪用40个鸡蛋换了一个铅笔盒，在夜色中走30里山路回家 |

**羞耻的载体：** 香雪的木制铅笔盒与城里同学的磁铁铅笔盒之间的对比，正是**物质匮乏带来的深层羞耻**。翟教授指出：这部作品之所以动人，不是因为山村的贫穷，而是因为香雪对"体面"的渴望。

### 路遥《人生》：身份的撕裂

| 要素 | 内容 |
|:---|:---|
| **作者** | 路遥（1949–1992），陕西作家，代表作《人生》《平凡的世界》 |
| **主角** | 高加林——农村出身、城市求学，在城乡夹缝中挣扎 |
| **羞耻来源** | 农民的出身、穿不上的西装、回不去的农村、融不进的城市 |
| **爱情纠葛** | 在纯朴的巧珍和城市姑娘黄亚萍之间摇摆 |

> "高加林最大的痛苦不是穷，而是**羞耻**——他为自己的农村身份感到羞耻，但又为自己的背叛感到羞耻。羞耻套着羞耻，这就是现代中国人的精神困境。"

### 铁凝《谁能让我害羞》：尊严的战争

一个送水少年的故事——他送水到豪宅，女主人的冷漠让他感到屈辱。他试图通过换一件干净衣服来挽回尊严，但最终引发了暴力冲突。翟教授指出：**羞耻的极端反应是暴力——当一个人感到自己的尊严被剥夺到无法承受时，他会用撕破脸的方式找回存在感。**

### 课堂讨论

??? note "学生展示：路遥《人生》分析"
    学生小组深入分析了高加林与刘巧珍、黄亚萍的情感纠葛，指出高加林的悲剧不仅是爱情的悲剧，更是一个时代的悲剧——**城乡二元结构下，人的身份是撕裂的，爱情也无法缝合这种撕裂。**

## 二、文学与羞耻的现代形态

### 物质羞耻

以**《平凡的世界》**中孙少平的"黑面馍"为核心案例：

> "孙少平每次去食堂打饭，都要等到所有人都打完了才去——因为他的菜是丙菜，他的馍是黑面馍。他害怕别人看见他的贫穷。"

**讨论框架：**

| 羞耻类型 | 文本例证 | 深层分析 |
|:---|:---|:---|
| 物质羞耻 | 孙少平的黑面馍 | 贫穷不是罪，但在贫穷中被看见才是真正的羞辱 |
| 身体羞耻 | 《我经过风暴》 | 女人的身体从来不只是身体——它是社会规训的战场 |
| 职业羞耻 | 电竞少年案例 | "正经工作"的观念枷锁——读书才是正路？ |
| 性羞耻 | 月经羞耻、处女膜神话 | 女性的身体被神化也被污名化 |

### 历史视角：女巫与身体的规训

学生展示中引用了**西尔维娅·费代里奇《凯列班与女巫》**——16至18世纪欧洲猎巫运动本质上是资本主义对女性身体的规训。约10万女性被当作女巫处决，不是因为她们真的有魔法，而是因为她们的**身体和知识**威胁到了新兴的资本主义秩序。

## 三、文学与现实：余华《第七天》

### 作品简介

**余华**（1960–），浙江海盐人，中国当代最重要的小说家之一。代表作《活着》《许三观卖血记》《兄弟》《第七天》。

**《第七天》**出版于2013年，以一个死者的视角写死后七天的见闻。

| 角度 | 内容 |
|:---|:---|
| **叙事者** | 杨飞——死于火灾，灵魂游走于殡仪馆和墓地之间 |
| **现实指涉** | 强拆、卖肾买iPhone、火灾瞒报、卖淫女被打 |
| **关键意象** | "死无葬身之地"——在小说中变成对所有亡灵一视同仁的乌托邦 |
| **风格** | 新闻串烧式写作——将真实新闻直接嵌入小说 |

### 翟教授的分析

> "余华说：'与现实的荒诞相比，小说的荒诞真是小巫见大巫。'2013年，余华写《第七天》，贾樟柯拍《天注定》，两个人不约而同地选择了同一个手法——把社会新闻串起来。这说明什么？说明中国的现实已经荒诞到只能用荒诞才能描述了。"

**齐泽克论贾樟柯：** 斯拉沃热·齐泽克称贾樟柯为"世界前三的导演"，因为他捕捉到了资本主义全球化边缘地带的荒诞感。

### "人生"启示

> "文学不是逃避现实的工具。恰恰相反，最荒诞的文学，往往是离现实最近的文学。《第七天》写的是死后的世界，但句句说的都是活着的痛苦。"

## 四、巴金《家》：亲情的牢笼

### 作品简介

**巴金**（1904–2005），原名李尧棠，中国现代文学巨匠。"激流三部曲"（《家》《春》《秋》）是其代表作。

### 人物分析

| 人物 | 性格 | 命运 |
|:---|:---|:---|
| **高觉新** | 长房长孙——隐忍、软弱、背负家族期望 | 被封建礼教吞噬，牺牲爱情与婚姻 |
| **高觉民** | 二弟——有所反抗但不够决绝 | 介于新旧之间，痛苦摇摆 |
| **高觉慧** | 三弟——觉醒者、出走的娜拉 | 最终离开家庭，走向广阔天地 |
| **瑞珏** | 觉新的妻子——善良温顺 | 被"血光之灾"的迷信害死——封建礼教的祭品 |

### 课堂讨论

> "巴金的《家》告诉我们：亲情不一定是港湾，它可能是牢笼。而最可怕的不是这个牢笼有锁，而是这个牢笼里的人已经习惯了——他们甚至认为这才是正常的。"

### "人生"启示

亲情既是支持，也是牵绊。中国传统文化中的"孝道"在提供安全感的同时，也制造了巨大的压抑。现代人面临的挑战是：**如何在爱中保持独立，如何在亲情中不失自我。**
