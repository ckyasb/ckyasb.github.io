# 文学与人生

**2025–2026 春夏学期 | 翟业军 教授 | 浙江大学通识核心课 | 智云课堂 79 讲**

文学作品研读与人生思考，涵盖古今中外多部经典小说、散文、诗歌。每周文学分析与讨论。

## 课程简介

本课程是浙江大学全校通识核心课，由文学院翟业军教授主讲，2026年春夏学期共79智云课堂讲次（每周二教授主讲 + 每周四助教分组讨论）。课程围绕"文学与爱情""文学与亲情""文学与羞耻""文学与现实""文学与美食""文学与革命"及"文学与人生"七个主题展开，横跨京剧、金庸武侠、汪曾祺散文、余华小说、鲁迅《过客》、伏尼契《牛虻》等数十部中外经典文本。
