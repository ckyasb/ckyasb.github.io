# 04多电子原子及元素周期律

## 1. 氦原子的能级与光谱

氦原子 ($Z=2$) 是最简单的多电子原子，其基态电子组态为 $1s^2$。

### 1.1 能级特征与分类

由于电子自旋的存在，氦原子能级分为两套独立的系统：

* **单态 (Singlet, Parahelium, 仲氦)**: 总自旋 $S=0(\frac{1}{2}-\frac{1}{2})$ (反平行 $\uparrow\downarrow$)。
* **三重态 (Triplet, Orthohelium, 正氦)**: 总自旋 $S=1(\frac{1}{2}+\frac{1}{2})$ (平行 $\uparrow\uparrow$)。

!!! note "交换相互作用与能级差异"
    
    在相同的 $n, l$ 组态下，**三重态 ($S=1$) 的能量低于单态 ($S=0$)**。
    
    * **物理原因**: 根据泡利原理，自旋平行的电子空间波函数反对称，使得电子平均距离较远，库仑排斥势能 $U_{ee}$ 较小。

### 1.2 光谱选律

* **跃迁规则**: $\Delta S = 0$。
* **结论**: 单态和三重态之间通常不发生相互跃迁，表现为两套独立的光谱系。

??? note "亚稳态 (Metastable State)"
    * **定义**: 不能通过电偶极辐射跃迁到更低能级的激发态。
    * **氦的亚稳态**:
        * $1s2s \, ^3S_1$: 最低的三重态，由于 $\Delta S=0$ 限制，不能跃迁到基态 $1s^2 \, ^1S_0$。
        * $1s2s \, ^1S_0$: 由于跃迁选择定则 $\Delta L \neq 0$ (S到S禁戒)，也不能跃迁到基态。

## 2. 多电子原子的角动量耦合

原子中存在多个电子时，存在两种主要的相互作用竞争：**静电相互作用** (电子间库仑力) 和 **磁相互作用** (自旋-轨道耦合)。

### 2.1 L-S 耦合 (罗素-桑德斯耦合)
适用于轻元素 (低 $Z$)，此时电子间的静电相互作用远强于自旋-轨道耦合。

* **模型**:
    1.  所有电子的轨道角动量 $\vec{l}_i$ 耦合为总轨道角动量 $\vec{L}$。
    2.  所有电子的自旋角动量 $\vec{s}_i$ 耦合为总自旋角动量 $\vec{S}$。
    3.  最后 $\vec{L}$ 和 $\vec{S}$ 耦合为总角动量 $\vec{J}$。

* **原子态符号**: $n^{2S+1}L_J$

??? note "L-S 耦合的量子数计算规则"
    对于两个电子 ($l_1, l_2, s_1=1/2, s_2=1/2$):

    1.  **总轨道量子数**:
        $L = |l_1 - l_2|, |l_1 - l_2| + 1, \dots, l_1 + l_2$
    2.  **总自旋量子数**:
        $S = |s_1 - s_2|, \dots, s_1 + s_2 \implies S=0 \text{ (单态) 或 } S=1 \text{ (三重态)}$
    3.  **总角动量量子数**:
        $J = |L - S|, |L - S| + 1, \dots, L + S$

### 2.2 j-j 耦合
适用于重元素 (高 $Z$)，此时自旋-轨道耦合作用极强，超过了电子间的剩余静电相互作用。

* **模型**:
    1. 每个电子自身的 $\vec{l}_i$ 和 $\vec{s}_i$ 先耦合为 $\vec{j}_i$。
    2. 所有电子的 $\vec{j}_i$ 再耦合为总角动量 $\vec{J}$。
    3. $J = |j_1 - j_2|, |j_1 - j_2| + 1, \dots, j_1 + j_2$

!!! info "耦合比较"
    * **L-S 耦合**: $G_1(s_1, s_2)$ 和 $G_2(l_1, l_2)$ 强，适用于大多数轻原子基态。
    * **j-j 耦合**: $G_3(l_1, s_1)$ 和 $G_4(l_2, s_2)$ 强。
    * 无论哪种耦合，最终的总角动量 $J$ 的可能取值个数和数值是相同的。

## 3. 泡利不相容原理与同科电子

### 3.1 泡利原理

* **表述**: 在一个原子中，不可能有两个或两个以上的电子具有完全相同的四个量子数 ($n, l, m_l, m_s$)。
* **适用范围**: 全体费米子 (自旋为半整数的粒子)。

### 3.2 同科电子

* **定义**: 主量子数 $n$ 和轨道量子数 $l$ 均相同的电子 (即处于同一支壳层，如 $2p^2$)。
* **限制**: 由于 $n, l$ 相同，同科电子的 $m_l$ 和 $m_s$ 不能完全相同，导致可能的原子态数目少于非同科电子。

??? note "同科电子原子态的推导方法 (以 $np^2$ 为例)"
    === 对角线法
        利用 $m_l$ 和 $m_s$ 的组合列表法（或对角线法则）排除违反泡利原理的态。

        **$np^2$ ($l=1, s=1/2$) 的推导**:
        所有可能的 $(m_{l1}, m_{l2})$ 组合需满足泡利原理 (若 $m_{l1}=m_{l2}$，则必须 $m_{s1} \neq m_{s2}$)。

        1.  **$S=0$ (自旋反平行 $\uparrow\downarrow$)**: $m_{l1}$ 和 $m_{l2}$ 可以相同。
            * $M_L = m_{l1} + m_{l2}$ 可取 $2, 1, 0, -1, -2$ 等。
            * 对应 $L=2 \rightarrow ^1D_2$; $L=0 \rightarrow ^1S_0$。
        2.  **$S=1$ (自旋平行 $\uparrow\uparrow$)**: $m_{l1}$ 必须不等于 $m_{l2}$。
            * $M_L$ 最大只能是 $1+0=1$。
            * 对应 $L=1 \rightarrow ^3P_{2,1,0}$。

        **结论**: $np^2$ 的原子态为 $^1S_0, ^1D_2, ^3P_{2,1,0}$ (共5个态，而非同科 $np \cdot n'p$ 的10个态)。
    
    === 奇偶互补
        如果 $S=0$ (单态)，则 $L$ 必须是偶数 ($S, D, G \dots$)。  
        如果 $S=1$ (三重态)，则 $L$ 必须是奇数 ($P, F, H \dots$)。

## 4. 洪特定则

用于在L-S耦合情形下，确定**基态**及低激发态能级次序的经验规则。必须按顺序使用：

1. **S 最大法则**: 对于给定的电子组态，**总自旋 $S$ 最大**的项能量最低 (库仑排斥能最小)。
2. **L 最大法则**: 在 $S$ 最大的项中，**总轨道角动量 $L$ 最大**的项能量最低 (电子运动关联使得互斥能减小)。
3. **J 的次序法则 (自旋-轨道耦合)**:
    * **正常次序 (Normal)**: 当支壳层电子数 $\le$ 半满时，**$J$ 最小**的能级最低 ($J = |L-S|$)。
    * **反常/倒转次序 (Inverted)**: 当支壳层电子数 $>$ 半满时，**$J$ 最大**的能级最低 ($J = L+S$)。

!!! example "实例：确定基态"
    * **N 原子 ($2p^3$)**: 半满。
        * $S_{max} = 1/2+1/2+1/2 = 3/2$ ($^4S$)。
        * $L=0$ (半满壳层球对称)。
        * 半满时 $J$ 只有一个值 $3/2$。基态：$^4S_{3/2}$。
    * **O 原子 ($2p^4$)**: 超过半满。
        * 等效于 2 个空穴 ($2p^2$)。$S=1, L=1$ ($^3P$)。
        * 倒转次序：$J$ 取最大值 $L+S = 1+1=2$。基态：$^3P_2$。

某些特殊的竞争情况：比如$4d^8$,$5s^1$，这种情况下$4d^8$超过半满更多，$5s^1$刚好半满，反常序占主导。

## 5. 壳层结构与元素周期律

### 5.1 壳层容量

* **主壳层 ($n$)**: 最多容纳 $2n^2$ 个电子。
* **支壳层 ($l$)**: 最多容纳 $2(2l+1)$ 个电子。
    * $s$ 层: 2个; $p$ 层: 6个; $d$ 层: 10个; $f$ 层: 14个。

### 5.2 能量最低原理与填充次序

电子填充遵循 $(n, l)$ 能量规则，主要受**钻穿效应 (Penetration Effect)** 和 **屏蔽效应** 影响。

* **能级交错**: 当 $n$ 较大时，$l$ 大的轨道离心势垒大，电子难接近原子核，能量较高。
* **填充顺序**:
    $$1s \to 2s \to 2p \to 3s \to 3p \to \mathbf{4s \to 3d} \to 4p \to \mathbf{5s \to 4d} \dots$$
    *(注：$4s$ 能量低于 $3d$，因为 $4s$ 电子云能钻穿到原子核附近)*

### 5.3 朗德 g 因子与磁矩

对于L-S耦合的原子态，在外磁场中的磁矩与 $J$ 有关：

$$\vec{\mu}_J = -g_J \mu_B \vec{J}$$

??? note "朗德 g 因子公式"
    $$g_J = 1 + \frac{J(J+1) + S(S+1) - L(L+1)}{2J(J+1)}$$
    * 当 $S=0$ 时，$g_J = 1$ (纯轨道磁矩)。
    * 当 $L=0$ 时，$g_J = 2$ (纯自旋磁矩)。

### 5.4 元素周期律的物理本质

* **周期性**: 来源于最外层价电子组态的周期性重复。
* **惰性气体**: $np^6$ 满支壳层结构， $L=0, S=0, J=0$ ($^1S_0$)，电荷分布球对称，化学性质稳定。
* **幻数结构**: 电离能随 $Z$ 变化出现峰值 (Z=2, 10, 18, 36, 54, 86)，对应满壳层结构。
