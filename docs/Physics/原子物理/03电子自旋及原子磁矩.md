# 03电子自旋及原子磁矩

## 1. 电子自旋

### 1.1 背景

* **实验依据**：
    1.  反常塞曼效应。
    2.  碱金属光谱的精细结构。
电子具有内禀角动量。自旋是电子的内禀属性，是一种相对论效应。

### 1.2 自旋角动量模型
类似于轨道角动量，自旋角动量 $\vec{S}$ 服从量子化规则：

!!! summary "自旋角动量公式"
    * **自旋角动量大小**：
  
        $$S = \sqrt{s(s+1)}\hbar$$
        
        其中自旋量子数 $s = 1/2$ (对于电子)。
    * **自旋磁量子数 (z分量)**：
        
        $$S_z = m_s\hbar$$
        
        其中 $m_s = \pm \frac{1}{2}$。

---

## 2. 电子总角动量

### 2.1 LS耦合

单电子原子的总角动量 $\vec{J}$ 是轨道角动量 $\vec{L}$ 与自旋角动量 $\vec{S}$ 的矢量和。  

* **定义**：$\vec{J} = \vec{L} + \vec{S}$
* **总量子数**：$j$
* **总磁量子数**：$m_j$

!!! info "量子数取值"

    * **总角动量大小**：$J = \sqrt{j(j+1)}\hbar$
    * **z分量**：$J_z = m_j\hbar$
    * **$j$ 的取值**：$j = |l \pm s|$。由于 $s=1/2$，故 $j = l + 1/2$ 或 $j = |l - 1/2|$ (当 $l=0$ 时，只取 $j=1/2$)。
    * **$m_j$ 的取值**：$m_j = j, j-1, \dots, -j$，共有 $2j+1$ 个取值。

### 2.2 原子态符号

原子状态表示为光谱项符号：

$$n^{2s+1}L_j$$

* $n$：主量子数。
* $S, P, D, F$：代表 $l=0, 1, 2, 3$。
* $2s+1$：自旋多重度（对于单电子原子，$s=1/2$，多重度为2，即双重态）。

---

## 3. 单电子原子磁矩

### 3.1 轨道与自旋磁矩

电子运动产生磁矩，包括轨道磁矩和自旋磁矩。

* **玻尔磁子**：$\mu_B = \frac{e\hbar}{2m_e} \approx 5.788 \times 10^{-5} \text{eV/T}$。
* **轨道磁矩**：$\vec{\mu}_l = -\frac{e}{2m_e}\vec{L} = -\sqrt{l(l+1)}\mu_B$。($g_l=1$)
* **自旋磁矩**：$\vec{\mu}_s = -g_s\frac{e}{2m_e}\vec{S} \approx -2\sqrt{s(s+1)}\mu_B$。($g_s \approx 2$)

### 3.2 总磁矩与朗德g因子

由于 $g_l \neq g_s$，总磁矩 $\vec{\mu}_{total} = \vec{\mu}_l + \vec{\mu}_s$ 的方向与总角动量 $\vec{J}$ 的方向**不重合**。
在矢量模型中，$\vec{L}$ 和 $\vec{S}$ 绕 $\vec{J}$ 进动，有效的总磁矩 $\vec{\mu}_j$ 是 $\vec{\mu}_{total}$ 在 $\vec{J}$ 方向上的投影。

!!! note "为什么需要进行投影"

    总角动量J和L，S叠加的总角动量$u_total$方向并不相同，这是因为两者的权重$g_l/s$不同，$u_total$可以看作围绕J进行进动，在这个运动极快的系统下，垂直J的分量显而易见的抵消了，故我们只需要利用$g_j$来计算最终的投影即可

!!! note "总磁矩公式"

    $$\vec{\mu}_j = -g_j \frac{e}{2m_e}\vec{J}$$

    $$\mu_j = -g_j\sqrt{j(j+1)}\mu_B$$
    
    $$\mu_{jz} = -m_j g_j \mu_B$$

    $$\mu = I \cdot A$$

    其中 **朗德g因子** 为：
    
    $$g_j = 1 + \frac{j(j+1) - l(l+1) + s(s+1)}{2j(j+1)}$$

??? abstract "gj的推导（余弦定理）"

    1.  总磁矩在 $\vec{J}$ 方向的投影为有效磁矩 $\mu_j$：
        
        $$\mu_j = \mu_l \cos(\vec{L}, \vec{J}) + \mu_s \cos(\vec{S}, \vec{J})$$
    
    2.  利用余弦定理（矢量三角形 $\vec{J}=\vec{L}+\vec{S}$）：
        
        $$L^2 = J^2 + S^2 - 2JS \cos(\vec{S}, \vec{J}) \implies \cos(\vec{S}, \vec{J}) = \frac{J^2+S^2-L^2}{2JS}$$
        
        同理：
        
        $$\cos(\vec{L}, \vec{J}) = \frac{J^2+L^2-S^2}{2JL}$$
    
    3.  代入磁矩公式（注意 $\mu_l \propto L, \mu_s \propto 2S$）：
        
        $$\mu_j = \left[ L \frac{J^2+L^2-S^2}{2JL} + 2S \frac{J^2+S^2-L^2}{2JS} \right] \frac{e}{2m_e}$$
    
    4.  化简整理，并引入 $\mu_B$：
        
        $$\mu_j = \left[ 1 + \frac{J^2-L^2+S^2}{2J^2} \right] \frac{e}{2m_e}J$$
    
    5.  代入算符本征值 $J^2 \to j(j+1)$ 等，即得 $g_j$ 表达式。

## 4. 施特恩-盖拉赫实验

* **目的**：验证空间量子化。
* **原理**：原子束穿过**非均匀**磁场，受力发生偏转，如果角动量是量子化的最终的结果应当是几条分立的线。
* **受力**：

    $$F_z = \mu_{jz} \frac{\partial B}{\partial z} = -m_j g_j \mu_B \frac{\partial B}{\partial z}$$

    这是由于磁势能

    $$U = -(\mu_{j_z}) B = -\mu_j B \cos \theta = -\mu_{j_z} B = m_j g_j \mu_B B$$

    磁势能求导即得到磁力

* **结果**：对于 $s=\frac{1}{2}, l=0$ 的银原子，束流分裂为 2 条（$2j+1 = 2$），证明了角动量在磁场方向取值的量子化。

## 5. 碱金属光谱的精细结构

### 5.1 轨道自旋耦合

原子光谱的精细结构源于电子自旋磁矩与轨道运动产生的内部磁场 $\vec{B}_L$ 之间的相互作用。

* **相互作用能**：

    $$\Delta E_{LS} = -\vec{\mu}_s \cdot \vec{B}_L \propto \vec{S} \cdot \vec{L}$$

假设电子静止，原子核以速度 $\vec{v} = -\vec{v}_{electron}$ 绕电子运动。
毕奥-萨伐尔定律

$$\vec{B}_L = \frac{\mu_0}{4\pi} \frac{Ze (\vec{v} \times \vec{r})}{r^3}$$

利用轨道角动量定义 $\vec{L} = \vec{r} \times \vec{p} = m \vec{r} \times \vec{v}_{electron} = -m \vec{r} \times \vec{v}$，即 $\vec{v} \times \vec{r} = \frac{\vec{L}}{m}$。代入并利用 $c^2 = 1/(\epsilon_0 \mu_0)$，得到：

$$\vec{B}_L = \frac{Ze}{4\pi\epsilon_0 m c^2 r^3} \vec{L}$$
电子具有自旋磁矩 $\vec{\mu}_s = - \frac{e}{m} \vec{S}$（取 $g_s \approx 2$）。初步的相互作用能为 $U = -\vec{\mu}_s \cdot \vec{B}_L$。
关键修正：由于电子是在做非惯性系，这种坐标系的转动效应会导致一个**托马斯进动因子$1/2$**。
修正后为：

$$\frac{1}{2} (-\vec{\mu}_s \cdot \vec{B}_L) = \frac{1}{2} \left( \frac{e}{m}\vec{S} \right) \cdot \left( \frac{Ze}{4\pi\epsilon_0 m c^2 r^3} \vec{L} \right)$$

整理得到自旋-轨道耦合算符的标准形式：

$$H_{SO} = \frac{Ze^2}{8\pi\epsilon_0 m^2 c^2} \frac{1}{r^3} (\vec{L} \cdot \vec{S})$$

对于类氢原子波函数，这个积分有标准结果：

$$\left\langle \frac{1}{r^3} \right\rangle_{nl} = \frac{Z^3}{a_0^3 n^3 l(l+1/2)(l+1)}$$

其中 $a_0$ 是玻尔半径 $a_0 = \frac{4\pi\epsilon_0 \hbar^2}{m_e e^2} = \frac{\hbar}{\alpha m_e c}$,$\alpha$为精细结构常数$\alpha = \frac{e^2}{4\pi\epsilon_0 \hbar c} = \frac{1}{137}$


??? note "自旋-轨道耦合能量分裂推导"
    利用 $\vec{J} = \vec{L} + \vec{S}$，两边平方得：

    $$J^2 = L^2 + S^2 + 2\vec{L}\cdot\vec{S}$$
    
    因此：
    
    $$\vec{L}\cdot\vec{S} = \frac{1}{2}(J^2 - L^2 - S^2)$$
    
    求平均值（期望值）：
    
    $$\langle \vec{L}\cdot\vec{S} \rangle = \frac{\hbar^2}{2} [j(j+1) - l(l+1) - s(s+1)]$$
    
    由于 $s=1/2$， $j$ 可取 $l+1/2$ 或 $l-1/2$，导致能级分裂。
    
    * 当 $j = l + 1/2$ 时，能量较高（平行）。
    * 当 $j = l - 1/2$ 时，能量较低（反平行）。

### 5.2 能级与跃迁

* 能级修正：$E_{n,l,j} = E_{nl} + \Delta E_{LS}$。
* 光谱系：

  * 主线系 ($nP \to 3S$)：分裂为双线。
  * 锐线系 ($nS \to 3P$)：分裂为双线。
  * 漫线系 ($nD \to 3P$)：分裂为三线。

* **选择定则**：$\Delta l = \pm 1$, $\Delta j = 0, \pm 1$。

## 6. 塞曼效应

原子在弱磁场中，能级发生分裂，导致谱线分裂的现象。

### 6.1 物理机制

外磁场 $B$ 引起附加能量：

$$\Delta E = -\vec{\mu}_j \cdot \vec{B} = m_j g_j \mu_B B$$

谱线分裂频率差（洛伦兹单位 $L$）：

$$\Delta \tilde{\nu} = \frac{\Delta E}{hc} = \Delta(m_j g_j) L, \quad L = \frac{eB}{4\pi m_e c}$$

### 6.2 正常塞曼效应

* **条件**：总自旋 $J=0$ (单态)，此时 $g_j = 1$。
* **现象**：一条谱线分裂为 **3条**。
* **分裂间距**：$\Delta E = m_l \mu_B B$ （$m_l$ 为轨道磁量子数）。
* **选择定则**：$\Delta m_l = 0, \pm 1$。

### 6.3 反常塞曼效应 

* **条件**：$J \neq 0$，$g_j \neq 1$ 且上下能级 $g_j$ 可能不同。
* **现象**：谱线分裂条数多于3条。
* **公式**：

    $$\Delta \nu \propto (m_{ji} g_{ji} - m_{jf} g_{jf}) B$$

* **选择定则**：$\Delta m_j = 0, \pm 1, \Delta s =0, \Delta l =\pm 1$。

### 6.4 塞曼谱线的偏振特性

观察方向决定看到的偏振状态：

* **垂直磁场方向观察 ($\vec{B}$)**：
  * $\Delta m = 0$：线偏振光 ($\pi$ 成分)，电矢量 $\vec{E} \parallel \vec{B}$。
  * $\Delta m = \pm 1$：线偏振光 ($\sigma$ 成分)，电矢量 $\vec{E} \perp \vec{B}$。
* **平行磁场方向观察 ($\vec{B}$)**：
  * $\Delta m = 0$：**看不见** ($\pi$ 成分强度为0)。
  * $\Delta m = \pm 1$：圆偏振光 ($\sigma$ 成分)。
