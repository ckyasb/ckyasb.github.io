# 05X射线

## 2. X射线的产生机制

X射线管主要由阴极（发射电子）、阳极（靶，金属材料）和高压电源组成。其光谱由**连续谱**和**特征谱**两部分组成。

### 2.1 连续谱

* **成因**：**轫致辐射**。高速电子在靶原子核电场作用下突然减速，动能转化为辐射能。
* **宏观解释**：电子受阻减速，根据经典电动力学，带电粒子加速/减速会辐射电磁波。
* **微观解释**：电子动能连续损失，光子能量 $h\nu$ 连续变化。

!!! summary "短波限"
    * **短波限 ($\lambda_{min}$)**：当电子的所有动能一次性全部转化为一个光子时，产生最短波长。

    $$\lambda_{min} = \frac{hc}{eU} \approx \frac{12.4}{U \,(kV)} \, (\mathring{A})$$
    
    * **规律**：$\lambda_{min}$ **只与外加电压 $U$ 有关**，与靶材无关。
    * **推导**：$eU = (h\nu)_{max} = \frac{hc}{\lambda_{min}}$

### 2.2 特征谱/标识谱

* **成因**：**内层电子跃迁**。入射电子将靶原子的内层电子（K层、L层等）击出，外层电子填充空位时辐射出特定波长的光子。
* **规律**：特征峰的波长**只与靶材元素的原子序数 $Z$ 有关**，与外加电压无关（只要电压足够高以激发内层电子）。
* **标记**：
  * **K系**：电子跃迁到K层（$K_{\alpha}: L \to K$, $K_{\beta}: M \to K$）。
  * **L系**：电子跃迁到L层（$L_{\alpha}: M \to L$ 等）。

!!! abstract "莫塞莱公式"
    莫塞莱发现特征谱频率的平方根与原子序数成线性关系。

    $$\sqrt{\nu} = A (Z - \sigma)$$
    
    或者写作经验公式：
    
    $$\nu = R c (Z - \sigma)^2 \left( \frac{1}{n_1^2} - \frac{1}{n_2^2} \right)$$
    
    * $R$：里德伯常数。
    * $\sigma$：**屏蔽常数 (Screening constant)**。对于 $K_{\alpha}$ 线，$\sigma \approx 1$；对于 $L_{\alpha}$ 线，$\sigma \approx 7.4$。
    * **物理意义**：$(Z-\sigma)$ 表示跃迁电子受到的有效核电荷作用。

??? info "特征谱的精细结构与选择定则"
    由于电子自旋与轨道角动量的相互作用（LS耦合），能级发生分裂，导致光谱具有精细结构。

    **跃迁选择定则**：
    $\Delta l = \pm 1$
    $\Delta j = 0, \pm 1$
    
    **实例**：
    * $K_{\alpha}$ 线分裂为 $K_{\alpha 1}$ 和 $K_{\alpha 2}$。
    * 能级标记采用光谱项符号：$n ^{2S+1}L_j$。例如 $2p$ 态分裂为 $^2P_{3/2}$ 和 $^2P_{1/2}$。

### 2.3 俄歇d电子

* **定义**：原子内层出现空位后，释放的能量不产生X射线光子，而是将同原子的另一个外层电子激发出去，这个电子就是俄歇电子。
* **应用**：俄歇电子动能完全取决于元素本质，是表面元素分析的重要手段。
* **竞争关系**：轻元素易发射俄歇电子，重元素易发射X射线。

## 3. X射线的衍射

### 3.1 基本原理

* **条件**：晶格常数 $d$ 与 X射线波长 $\lambda$ 数量级相同，晶体可作为天然的三维光栅。
* **劳厄 (Laue)**：1912年提出晶体光栅概念。

### 3.2 布喇格方程

描述X射线在晶体表面的反射（衍射）条件。

!!! success "布喇格公式"

    $$2d \sin \theta = n \lambda \quad (n=1, 2, ...)$$

    * $d$：晶面间距。
    * $\theta$：掠射角（入射光与晶面的夹角，**注意不是与法线的夹角**）。
    * $n$：衍射级数。

### 3.3 实验方法

1. **劳厄法**：连续谱X射线入射单晶，产生劳厄斑点（对应不同晶面），用于测定晶体取向和对称性。
2. **德拜-谢乐法**：单色X射线入射多晶粉末，产生衍射环。可用于测定晶面间距 $d$。

## 4. 康普顿效应

### 4.1 现象与规律

* **现象**：X射线被物质散射后，散射光中除了原波长 $\lambda$ 的成分外，还出现了波长变长的新成分 $\lambda'$。
* **规律**：波长改变量 $\Delta \lambda$ 随散射角 $\varphi$ 增大而增大，与散射物质性质无关。

!!! note "康普顿散射公式"

    $$\Delta \lambda = \lambda' - \lambda = \lambda_c (1 - \cos \varphi)$$

    * **电子康普顿波长**：$\lambda_c = \frac{h}{m_e c} \approx 0.02426 \mathring{A}$。
    * 当 $\varphi = 90^\circ$ 时，$\Delta \lambda = \lambda_c$。
    * 当 $\varphi = 180^\circ$ 时，$\Delta \lambda_{max} = 2\lambda_c$。

### 4.2 光子模型

康普顿效应被视为**光子与静止自由电子的弹性碰撞**。

??? quote "推导"
    建立能量守恒和动量守恒方程：

    1.  **能量守恒**：
        
        $$h\nu + m_e c^2 = h\nu' + mc^2$$
        
        其中 $m_e$ 为电子静质量，$m$ 为碰撞后电子的动质量。
    
    2.  **动量守恒** (矢量形式)：
        
        $$\vec{p}_{光} = \vec{p'}_{光} + \vec{p}_{电}$$
        
        利用余弦定理：
        
        $$p_e^2 = p^2 + p'^2 - 2pp' \cos \varphi$$
        
        其中 $p = h/\lambda$, $p' = h/\lambda'$。
    
    3.  **相对论质能关系**：
        
        $$E^2 = (mc^2)^2 = p_e^2 c^2 + m_e^2 c^4$$
    
    联立上述方程，消去电子的动量和能量项，即可解得：
    
    $$\lambda' - \lambda = \frac{h}{m_e c}(1 - \cos \varphi)$$

### 4.3 几个关键问题

1. **为什么可见光不明显？**
    可见光波长 $\lambda$ 远大于 $\lambda_c$，相对改变量 $\Delta \lambda / \lambda$ 极小，难以观测。
2. **为什么有未变波长的成分（相干散射）？**
    当光子与原子核（或紧束缚的内层电子）碰撞时，相当于与质量 $M \gg m_e$ 的物体碰撞。由公式 $\Delta \lambda \propto \frac{1}{M}$，波长改变量趋近于0。
3. **康普顿轮廓**：
    谱线有展宽，是因为电子原本并非静止，而是有一定的动量分布（多普勒展宽）。

## 5. 电子对的产生与湮灭

### 5.1 电子对产生

高能光子 $\gamma$ 在原子核库仑场作用下转化为正负电子对 ($e^-, e^+$)。

* **能量阈值**：光子能量必须大于两个电子的静止能量之和。

    $$h\nu \ge 2m_e c^2 \approx 1.02 MeV$$

* **条件**：必须有原子核参与以满足动量守恒（真空中不可能发生）。

### 5.2 电子对湮灭

* **过程**：正电子与负电子相遇，转化为光子。
    $$e^- + e^+ \to 2\gamma \quad (\text{或 } 3\gamma)$$
* **守恒**：需满足动量、能量、角动量守恒。

## 6. X射线的吸收

### 6.1 吸收规律

X射线穿过物质时强度按指数衰减。

!!! summary "衰减公式"
    $$I = I_0 e^{-\mu x}$$

    * $\mu$：**线性吸收系数**，表示单位厚度吸收的几率。
    * $\mu_m = \mu / \rho$：**质量吸收系数**。
    * 公式也可写为：$I = I_0 e^{-\mu_m x_m}$，其中 $x_m$ 为质量厚度$x_m = x \cdot \rho$ 1。

### 6.2 光子与物质相互作用的总截面

吸收系数由三种效应共同贡献，其主导地位随光子能量 $h\nu$ 和物质原子序数 $Z$ 变化：

1. **光电效应 ($\sigma_{pe}$)**：
    * 光子被吸收，电子被电离。
    * 主导区域：**低能** X射线，高 $Z$ 物质。
2. **康普顿散射 ($\sigma_{C}$)**：
    * 光子被散射。
    * 主导区域：**中能** X射线。
3. **电子对产生 ($\sigma_{pair}$)**：
    * 光子转化为电子对。
    * 主导区域：**高能** ($h\nu > 1.02 MeV$)。

**总吸收系数**：

$$\mu = \mu_{光电} + \mu_{康普顿} + \mu_{电子对}$$
