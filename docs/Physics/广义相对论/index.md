# 广义相对论

**2024–2025 春夏学期 | 张欣宇 | 智云课堂 15 讲 | 教材：GR1/GR2/GR3 + 作业 ANS1-5 / HW1-6**

从等效原理和微分几何出发，建立 Einstein 场方程，研究 Schwarzschild 时空、经典检验、黑洞物理与引力波，最终触及宇宙学。
