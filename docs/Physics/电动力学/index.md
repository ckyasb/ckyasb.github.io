# 电动力学

**2024–2025 春夏学期 | 袁野 | 智云课堂 29 讲 | 教材：自编讲义 + Jackson/Zangwill/Landau**

本讲义涵盖经典电动力学的完整体系，从静电/静磁的全局与局域性质出发，经由 Maxwell 方程组，处理电磁波的传播、辐射与散射，最终进入动体电动力学和拉格朗日力学框架。
