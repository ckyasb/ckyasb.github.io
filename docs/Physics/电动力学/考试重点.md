## 必考计算类型

### 第2题（微分几何计算）核心题型

这是占半学期、必考的计算题。给一个度规，要求算出全套量：

```
度规 g_μν → Christoffel Γ^λ_μν → Riemann R^ρ_σμν → Ricci R_μν → 标量 R → Einstein G_μν
```

**必练的典型度规**：

| 度规 | 课堂/作业出处 | 关键结果 |
|:---|:---|:---|
| 二维球面 $ds^2=d\theta^2+\sin^2\theta\,d\varphi^2$ | 课堂 + HW1-3 | $R=2$ |
| **庞加莱半平面** $ds^2=(dx^2+dy^2)/y^2$ | HW2-4（必考） | $R=-2$，测地线为 $x$ 轴圆弧 |
| Schwarzschild $ds^2=-(1-2GM/r)dt^2+\cdots$ | 第5章 | 经典检验 |
| BTZ 黑洞 $ds^2=-f\,dt^2+f^{-1}dr^2+r^2d\varphi^2$ | HW5-1 | $\Lambda=-1/\ell^2$ |

??? note "庞加莱半平面——最可能考的计算题"
    老师明确说 HW2-4 庞加莱半平面"必考"。完整流程：

    1. **Christoffel**：$\Gamma^y_{yy}=\Gamma^x_{xy}=\Gamma^x_{yx}=-1/y$，$\Gamma^y_{xx}=1/y$。
    2. **Riemann**：$R_{xyxy}=-1/y^2$。
    3. **Ricci**：$R_{xx}=R_{yy}=1/y^2$。
    4. **标量**：$R=-2$（常负曲率，双曲几何）。
    5. **测地线**：$\ddot x-\frac{2}{y}\dot x\dot y=0$ → $(x-x_0)^2+y^2=1/C^2$（圆心在 $x$ 轴的圆弧）。
    6. **正交标架法**：$\theta^1=dx/y$，$\theta^2=dy/y$，$\omega^1{}_2=-dx/y$，$R_{12}=-dx\wedge dy/y^2$。

    两种方法（坐标基 + 正交标架）都要会。

## 四、高频必考点（老师反复强调的物理概念）

### 1. 多极展开（跨 9 节，最高频）

- 电势 $\propto 1/r^{2l+1}$ → **看幂次直接判定贡献阶数**（03-26 [96:15]"看到这种结构你一定要敏感"）。
- $l$ 阶电多极矩 = 全对称无迹 $l$ 阶张量，自由度恰为 $2l+1$，与球谐 $Y_{lm}$（$m=-l..l$）一一对应。
- 高阶每升一阶被 $x'/x$ 压低，是高阶小量。
- 电偶极矩只在系统总电荷 $Q=0$ 时才有绝对（不依赖原点）意义。
- 考试深度封顶二阶三阶（06-11 [42:42]）。

### 2. E、B 电磁场统一性 / 不可分割（跨 5 节）

- E 和 B 不能割裂，必须合为同一物理客体的 6 个自由度分量（03-05 [13:52]"电和磁它必须统一"）。
- 换参考系后 E、B 会混合；四维二阶微分形式 $F$ 恰好 $\binom{4}{2}=6=3E+3B$。
- E 是标准矢量场（宇称下反号），B 是赝矢量场（宇称下不反号）——故 E、B 不能简单合成同一矢量场（04-14）。

### 3. 规范自由度 / 规范变换

- $A\to A+\partial F$ 不改变物理构型（多对一冗余）。
- 纯规范部分（如张量迹 g 部分）无物理效应、$B=0$ 可整体去掉（04-16 [99:26]、06-02）。
- 引入 A 后 Bianchi 恒等式 $dF=0$ 自动满足，相当于一半 Maxwell 方程被自动解决（05-21 [36:43]）。

### 4. 对称性 + 无迹条件限制张量自由度

- 电多极子 $l$ 阶全对称无迹（$2l+1$ 自由度）；磁多极子 $(l+1)$ 阶张量前 $l$ 指标全对称无迹 + 轮换求和 = 0。
- 二阶张量三分解：对称无迹 5 + 反对称 3 + 迹 1（04-16）。
- L=2 磁四极 15 = 5（物理）+ 7（电流守恒致恒为零）+ 3（规范冗余，纯规范 $B=0$）。

### 5. 静电 / 静磁对偶

- 静电：散度非 0、旋度 0（$E=-\nabla\varphi$）；静磁：散度 0、旋度非 0（$B=\nabla\times A$）。
- 库仑规范下 A 的泊松方程与静电 φ 库仑公式同构；毕奥-萨伐尔 ↔ 库仑定律形式相似。

### 6. 光锥 / 因果性 / 推迟格林函数

- 电磁扰动只能沿光锥传播；两点关联函数仅在类光分离时非零（06-16 [05:30]）。
- 信号不超光锥、未来才可接收 → 唯一筛选推迟（retarded）格林函数。
- $\delta$ 函数把贡献限制在光锥未来点（06-09 [65:40]"非常好记，光锥上的点"）。

### 7. 辐射判据（截止线附近核心）

- 辐射场 $E,B\propto1/R$、能流 $\propto1/R^2$ 刚好抵消球面 $R^2$ → 无穷远通量非零（真辐射）。
- 类库仑场（速度场）$\propto1/R^2$，无穷远通量为零，不贡献辐射。
- **匀速运动电荷不辐射**：单质点有辐射必有加速度（$a=0$ 则辐射场为零）（06-18 [17:02]）。
- 公式中瞬时速度、加速度均取**推迟时刻 τ\***（沿光锥追踪回的真实轨迹事件点），而非测量时刻。

### 8. 守恒律形式 = 散度 + 时间微分

- 电荷守恒 $\nabla\!\cdot\!J+\partial\rho/\partial t=0$ 是原型（04-07 [87:26]"一定是一个散度与一个时间微分的关系"）。
- 所有守恒律都有类似形式；看到特定结构的微分公式要敏感其背后的守恒性（05-07 [84:30]）。

### 9. 唯一性定理

- Dirichlet（固定边界 φ）或 Neumann（固定 E 法向）条件为唯一解充分条件，边界可分段混合。
- 保证无论特解用什么等效系统求，完整问题解唯一（03-31、04-02）。

### 10. 特解 + 通解分解思路

- 特解只对付非齐次项（暂不管边界），齐次方程通解凑边界条件，最后线性代数定系数。
- 特解 → 格林函数 → 辐射；通解 → 模式 → 电磁波（03-19 [75:06]"求解电磁场运动问题时思路不变"）。

### 其他高频定性结论

- **电场线不能闭合**（由 $\oint E\!\cdot\!dl=0$）；场线密度 = 场强大小（03-12 [17:32]）。
- **位移电流 $\partial E/\partial t$ 的必要性**：运动方程须与电荷守恒自洽（对旋度方程取散度论证）（04-30 [85:54]）。
- **平面电磁波横波性**：E、B、K 两两正交且 E 与 B 同相同步；$\|B\|=\|E\|/c$；4 分量 − 1 规范 − 1 纵波（纯规范）= 2 物理自由度（05-21、05-26）。
- **电磁波多普勒与机械波本质区别**：不同观测者看电磁波速度始终不变（都是 c），变的只是频率和方向（05-26 [83:17]）。
- **静电能存储于电场中而非某个点电荷**；点电荷自能发散部分为内禀（与构型无关）可直接划掉（03-19 [41:09]）。
- **主动观点与被动观点必须严格区分**，课程约定统一采用主动观点（04-14 [48:32]）。
