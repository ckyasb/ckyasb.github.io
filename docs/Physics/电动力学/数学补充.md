## 1. 张量方法与 $\epsilon\epsilon$ 恒等式（HW3-1, HW3-2, HW3-3, HW8-1）

### 1.1 $\epsilon\epsilon$ 缩并恒等式（HW3-1）

**作业题**：(a) 推导 $\nabla\times(\mathbf{u}\times\mathbf{v})$；(b) 推导 $(\mathbf{A}\times\mathbf{B})\cdot(\mathbf{C}\times\mathbf{D})$。

??? note "用到的数学"
    **核心恒等式**：

    \\[\epsilon_{ijk}\epsilon_{ilm}=\delta_{jl}\delta_{km}-\delta_{jm}\delta_{kl}\\]

    - **(a)** $[\nabla\times(\mathbf{u}\times\mathbf{v})]_i=\epsilon_{ijk}\partial_j(\epsilon_{klm}u_lv_m)=(\delta_{il}\delta_{jm}-\delta_{im}\delta_{jl})\partial_j(u_lv_m)$，$\nabla$ 同时作用于 $\mathbf{u},\mathbf{v}$（乘积求导展开四项）
    - **(b)** $(\mathbf{A}\times\mathbf{B})_k=\epsilon_{klm}A_lB_m$，$(\mathbf{C}\times\mathbf{D})_k=\epsilon_{knp}C_nD_p$，点乘 $=\epsilon_{klm}\epsilon_{knp}A_lB_mC_nD_p=(\delta_{ln}\delta_{mp}-\delta_{lp}\delta_{mn})A_lB_mC_nD_p$

    **动机**：$\epsilon\epsilon$ 缩并是张量运算的"九九表"——所有矢量恒等式（BAC-CAB、双重叉乘、Jacobi）都由它推出。

### 1.2 边界-体积分转换（HW3-2）

**作业题**：用 Stokes 定理把 $\int_{\partial V}\mathbf{x}\times(\mathbf{F}\times d\mathbf{S})$ 化为 $V$ 内积分。

??? note "用到的数学"
    - **$\epsilon\epsilon$ 展开**：$(\mathbf{x}\times(\mathbf{F}\times d\mathbf{S}))_i=\epsilon_{ijk}x_j\epsilon_{klm}F_l\,dS_m=(\delta_{il}\delta_{jm}-\delta_{im}\delta_{jl})x_jF_l\,dS_m=x_jF_i\,dS_j-x_jF_j\,dS_i$
    - **Gauss 定理** $\int_{\partial V}T_{im}\,dS_m=\int_V\partial_m T_{im}\,dV$
    - 含 $\nabla\cdot\mathbf{x}=3$、$\partial_i x_j=\delta_{ij}$，整理得

    \\[\int_{\partial V}\mathbf{x}\times(\mathbf{F}\times d\mathbf{S})=\int_V\big[3\mathbf{F}+\mathbf{x}(\nabla\cdot\mathbf{F})-\nabla(\mathbf{x}\cdot\mathbf{F})\big]dV\\]

    **动机**：积分定理 + 张量指标的协同——"边界积分 ↔ 体积分"转换在应力张量、能动量计算中频繁出现（如角动量守恒流 HW11-1）。

### 1.3 旋转不变性（HW3-3）

**作业题**：证 $\delta_{ij}=\delta_{kl}R_{ki}R_{lj}$、$S_{ij}=R_{ji}$、$R_{ip}R_{jq}R_{kr}\epsilon_{pqr}=\epsilon_{ijk}$。

??? note "用到的数学"
    - **旋转保持长度** $|\mathbf{x}'|^2=|\mathbf{x}|^2$ → $\delta_{ij}=\delta_{kl}R_{ki}R_{lj}$（$R^TR=I$ 正交性）
    - **逆=转置** $R^{-1}=R^T\Rightarrow S_{ij}=R_{ji}$
    - **$\epsilon_{ijk}$ 是唯一三阶全反对称张量**（到标量倍数），旋转下不变，系数 $=\det R=1$
    - **$\delta_{ij}$、$\epsilon_{ijk}$ 是各向同性张量**——旋转不变

    **动机**：$\delta$、$\epsilon$ 是旋转不变的各向同性张量，是弯曲时空中 $g_{\mu\nu}$、$\epsilon_{\mu\nu\rho\sigma}$ 的平直对应。

### 1.4 全对称无迹张量投影（HW8-1）

**作业题**：四阶张量 $T_{ijkl}$（前两指标对称无迹、后两指标对称无迹），提取全对称无迹部分 $T^{(s)}_{ijkl}$。

??? note "用到的数学"
    - **指标完全对称化**（利用已有部分对称性，6 项而非 24 项置换）
    - **缩并求迹** $T^{(s)}_{aakl}$、二阶迹 $T^{(s)}_{aabb}$
    - **Kronecker $\delta$ 构造无迹抵消项**：$\delta_{ij}\delta_{kl}+\delta_{ik}\delta_{jl}+\delta_{il}\delta_{jk}$ 与 $\delta_{kl}$、$\delta_{ij}$ 的混合项

    **动机**：电磁场辐射中的多极展开（电四极/磁四极）需要全对称无迹张量——这是提取物理自由度的标准操作。

## 2. Levi-Civita 张量化（HW8-2, HW1-4）

### 2.1 $\sqrt{|g|}\epsilon_{ijk}$ 是张量（HW8-2）

**作业题**：证 $\varepsilon_{ijk}=\sqrt{|g|}\epsilon_{ijk}$ 是三阶全反对称协变张量，$\varepsilon^{ijk}=\epsilon^{ijk}/\sqrt{|g|}$ 是逆变张量。

??? note "用到的数学"
    - **度规逆 $g^{ij}$ 变换律**（矩阵形式）：$\|g'^{ij}\|=J\|g^{ij}\|J^T$，$J=\partial(u')/\partial(u)$ 为雅可比
    - **度规逆行列式变换**：$\det\|g'^{ij}\|=\det\|g^{ij}\|\cdot[\partial(u')/\partial(u)]^2$，开方得 $\sqrt{\det\|g'^{ij}\|}=\sqrt{\det\|g^{ij}\|}\cdot|\partial(u')/\partial(u)|$
    - **Levi-Civita 符号雅可比变换**（行列式定义）：$\epsilon^{lmn}(\partial u'^i/\partial u^l)(\partial u'^j/\partial u^m)(\partial u'^k/\partial u^n)=\epsilon^{ijk}\det(\partial u'/\partial u)$
    - $\sqrt{|g|}$ 提供 Jacobian 倒数 → $\sqrt{|g|}\epsilon_{ijk}$ 恰按协变张量变换；$\epsilon^{ijk}/\sqrt{|g|}$ 恰按逆变张量变换

    **动机**：$\sqrt{|g|}\,du^1\wedge du^2\wedge du^3$ 是坐标不变的体积形式——广义相对论中 $\sqrt{-g}\,d^4x$ 不变性的来源。

### 2.2 $\epsilon_{ijk}$ 在 Maxwell 方程中的应用（HW1-4）

??? note "用到的数学"
    - $B_i=\frac12\epsilon_{ijk}F_{jk}$（磁场分量从 $F_{\mu\nu}$ 提取）
    - $(\nabla\times\mathbf{E})_i=\epsilon_{ijk}\partial_jE_k$（旋度定义）
    - $\epsilon_{ijk}\epsilon_{ilm}=\delta_{jl}\delta_{km}-\delta_{jm}\delta_{kl}$（将张量方程 $\partial_{[\sigma}F_{\mu\nu]}=0$ 缩并为矢量方程）

## 3. 微分形式与外微分（HW1-4, HW2-1）

### 3.1 $dF=0$ → 齐次 Maxwell 方程（HW1-4）

**作业题**：证 Bianchi 恒等式 $dF=0$ 导致 $\nabla\cdot\mathbf{B}=0$ 与 $\partial\mathbf{B}/\partial t+\nabla\times\mathbf{E}=0$。

??? note "用到的数学"
    - **场强 2-形式** $F=dA$：$F_{\mu\nu}=\partial_\mu A_\nu-\partial_\nu A_\mu$（反对称张量）
    - **Poincaré 引理** $d^2=0$：$dF=d^2A=0$（几何恒等式，非动力学方程）
    - **分量式** $\partial_{[\sigma}F_{\mu\nu]}=0$（三指标完全反对称化）
    - 纯空间 → $\nabla\cdot\mathbf{B}=0$；含时间 → $\partial\mathbf{B}/\partial t+\nabla\times\mathbf{E}=0$

    **动机**：展示电磁学齐次方程本质是几何恒等式 $d^2=0$。注意：HW 只用 $dF=0$，**不涉及 Hodge 对偶 $d{*}F=J$**（后者是进阶内容，作业未直接调用）。

### 3.2 微分形式求体积元与面元（HW2-1）

**作业题**：用微分形式方法求球坐标体积元 $dx_1\wedge dx_2\wedge dx_3$ 与曲面面元 $d\mathbf{S}$。

??? note "用到的数学"
    - **楔积** $dx_1\wedge dx_2\wedge dx_3=J\,dr\wedge d\theta\wedge d\varphi$，$J=r^2\sin\theta$（Jacobian）
    - **面元** $dS_i=\frac12\epsilon_{ijk}(\partial_\theta x_j\partial_\varphi x_k-\partial_\varphi x_j\partial_\theta x_k)d\theta\wedge d\varphi$
    - **外微分** $d\omega=\sum_i du^i\wedge\partial_i\omega$（坐标无关的定义）

    **动机**：微分形式是处理曲面/体积元的天然语言，自动给出 Jacobian。

## 4. 正交曲线坐标系与 Lamé 系数（HW4-1, HW4-2, HW8-3）

**作业题**：坐标 $\{r,\theta,h\}$（$x_1=h^2\cos\theta/r$ 等），求方向矢量、面元、梯度/旋度/散度。

??? note "用到的数学"
    - **坐标线方向矢量** $\mathbf{e}_i=\partial\mathbf{x}/\partial q^i$，**Lamé 系数** $h_i=|\mathbf{e}_i|$，归一化 $\hat{\mathbf{e}}_i=\mathbf{e}_i/h_i$
    - **面元** $d\mathbf{S}=h_ih_j\,\hat{\mathbf{e}}_k\,dq^idq^j$（$k$ 为 $i,j$ 之外的指标）
    - **梯度** $\nabla f=\sum_i\frac{1}{h_i}\frac{\partial f}{\partial q^i}\hat{\mathbf{e}}_i$
    - **散度** $\nabla\cdot\mathbf{A}=\frac{1}{h_1h_2h_3}\sum_i\frac{\partial}{\partial q^i}(h_jh_kA_i)$
    - **旋度** $\nabla\times\mathbf{A}=\frac{1}{h_1h_2h_3}\begin{vmatrix}h_1\hat{\mathbf{e}}_1&h_2\hat{\mathbf{e}}_2&h_3\hat{\mathbf{e}}_3\\\partial_{q^1}&\partial_{q^2}&\partial_{q^3}\\h_1A_1&h_2A_2&h_3A_3\end{vmatrix}$
    - **协变/逆变分量与展开系数** $E_i=h_i\hat{E}^i$，$E^i=\hat{E}^i/h_i$（HW8-3）

    **动机**：Lamé 系数 $h_i$ 是正交曲线坐标的关键——球坐标 $(1,r,r\sin\theta)$，柱坐标 $(1,\rho,1)$。理解了它，各坐标系散度旋度公式不必死记。

## 5. 电磁场张量与 Lorentz 变换（HW10, HW12, 小测B）

### 5.1 Lorentz boost 与运动物体形状（HW10-1）

**作业题**：$B$ 系携球 $x'\cdot x'=R^2$，$B$ 相对 $A$ 以 $v=(0,0,v)$ 运动，求 $A$ 系中球的形状。

??? note "用到的数学"
    - **Lorentz boost 矩阵**（沿 $z$ 轴）：$\Lambda^0{}_0=\Lambda^3{}_3=\gamma$，$\Lambda^0{}_3=\Lambda^3{}_0=-\gamma v/c$，横向不变
    - **逆变换** $x'^3=\gamma(x^3-vt)$，代入球方程得 $A$ 系**椭球** $(x^1)^2+(x^2)^2+\gamma^2(x^3-vt)^2=R^2$（运动方向 Lorentz 收缩）

    **动机**：尺缩效应的直接体现。

### 5.2 四维速度与快度（HW10-2）

**作业题**：$v=c\tanh w$，定义固有时 $d\tau=\sqrt{-ds^2}$，构造四维速度 $u^\mu=dx^\mu/d\tau$。

??? note "用到的数学"
    - **快度-速度关系** $v=c\tanh w$（保证 $|v|<c$，类时条件 $ds^2<0$）
    - **Minkowski 度规缩并** $ds^2=g_{\mu\nu}dx^\mu dx^\nu=(c^2-v^2)dt^2<0$
    - **固有时** $d\tau=\sqrt{-ds^2}=\sqrt{c^2-v^2}\,dt$（Lorentz 标量）
    - **四维速度** $u^\mu=(\gamma c,\gamma\mathbf{v})$，$u_\mu u^\mu=c^2$（不变量）

    **动机**：四维速度是 Lorentz 矢量，$\gamma$ 因子自动处理速度合成。

### 5.3 电磁场 Lorentz 变换（HW12-1, 小测B-2）

**作业题**：平面电磁波/偏振在横向 boost 下的变换。

??? note "用到的数学"
    - **场变换** $E'_\parallel=E_\parallel$，$B'_\parallel=B_\parallel$，$E'_\perp=\gamma(E_\perp+v\times B)$，$B'_\perp=\gamma(B_\perp-v\times E/c^2)$
    - **相位 Lorentz 不变性** $k_\mu x^\mu=-\omega t+\mathbf{k}\cdot\mathbf{x}$（标量）
    - **多普勒效应** $\omega'=\gamma\omega(1-v\cos\theta/c)$（纵向）；横向 $\omega'=\gamma\omega$
    - **线偏振→椭圆偏振**：两分量不同相 → 横向 boost 后可能变椭圆偏振

    **动机**：$\mathbf{E},\mathbf{B}$ 是同一电磁场张量 $F_{\mu\nu}$ 在不同参考系的不同分量。

### 5.4 Lorentz 不变量（HW11-2,3）

??? note "用到的数学"
    - **不变量** $E^2-c^2B^2$ 与 $\mathbf{E}\cdot\mathbf{B}$（分类电磁场类型）
    - **电荷 Lorentz 不变性**：$\rho$ 增 $\gamma$ 倍、体积缩 $1/\gamma$，总 $Q$ 不变
    - **匀速电荷不辐射**：Poynting $\mathbf{S}\propto E^2\propto1/R^4$，球面通量 $\propto1/R^2\to0$

## 6. Hilbert 能动张量与规范原理（HW11-1, HW11-4, HW18）

### 6.1 电磁场角动量守恒流（HW11-1）

**作业题**：构造 $L^\mu{}_i$，证 $\partial_\mu L^\mu{}_i=0$。

??? note "用到的数学"
    - **角动量守恒流** $L^\mu{}_i=-\frac1c\epsilon_{ijk}x_jT^\mu{}_k$
    - **守恒律验证**：$\partial_\mu L^\mu{}_i=-\frac1c\epsilon_{ijk}[(\partial_\mu x_j)T^\mu{}_k+x_j(\partial_\mu T^\mu{}_k)]$
    - 第一项 $\partial_\mu x_j=\delta^\mu_j\to\epsilon_{ijk}T^j{}_k$，由 $T^{jk}$ 对称 + $\epsilon$ 反称 = 0
    - 第二项由动量守恒 $\partial_\mu T^\mu{}_k=0$ 消失

    **动机**：角动量守恒依赖 $T^{\mu\nu}$ 的**对称性**——Hilbert 能动张量天然对称，Noether 张量不对称时需 Belinfante 改进。

### 6.2 库仑规范化简（HW11-4）

**作业题**：证 $\Box\mathbf{A}=-\mu_0\mathbf{J}_{\text{旋}}$。

??? note "用到的数学"
    - **Helmholtz 分解** $\mathbf{J}=\mathbf{J}_{\text{旋}}+\mathbf{J}_{\text{源}}$（有旋无源 + 有源无旋）
    - **库仑规范** $\nabla\cdot\mathbf{A}=0$，$\nabla^2\phi=-\rho/\epsilon_0$（瞬时 Coulomb 势）
    - **$\mathbf{J}_{\text{源}}=\epsilon_0\nabla\partial_t\phi$**（由 $\nabla^2\phi=-\rho/\epsilon_0$ + $\nabla\cdot\mathbf{J}=-\partial_t\rho$ 证）
    - 有源部分被 $\phi$ 吸收 → $\Box\mathbf{A}=-\mu_0\mathbf{J}_{\text{旋}}$

    **动机**：辐射场只与电流有旋部分耦合。

### 6.3 规范原理（HW18）

**作业题**：从作用量变分推 Maxwell；局域规范不变性 → 协变导数 → 引入 $A_\mu$。

??? note "用到的数学"
    - **变分** $\delta S=\int[-\frac12F^{\mu\nu}\delta F_{\mu\nu}-j_\mu\delta A^\mu]d^4x$
    - $\delta F_{\mu\nu}=\partial_\mu\delta A_\nu-\partial_\nu\delta A_\mu$，分部积分 → $\partial_\mu F^{\mu\nu}=j^\nu$
    - **无源方程** $\partial_{[\rho}F_{\mu\nu]}=0$ 由 $F=dA$ 自动满足（$d^2=0$）
    - **协变导数** $D_\mu=(\partial_\mu+iqA_\mu)$，局域规范不变 → 引入 $A_\mu$ + 定耦合 $j_\mu A^\mu$

    **动机**：对称性决定相互作用——规范原理是构建所有基本相互作用的统一方法。

## 7. 静电能与偶极层（HW3-4）

**作业题**：球壳偶极层，两种算法 $\frac12\int\rho\phi$ vs $\frac{\epsilon_0}{2}\int|E|^2$。

??? note "用到的数学"
    - **电能两种等价公式**：$\frac12\int\rho\phi\,dV$（源积分）vs $\frac{\epsilon_0}{2}\int|E|^2\,dV$（场积分）
    - **$\delta\to0$ 极限**：理想偶极层对外屏蔽（外场为零），电能有限不发散

    **动机**：场是物理实体的证据——两种算法一致。
