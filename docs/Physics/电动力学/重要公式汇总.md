# 电动力学重要公式汇总

> 本页汇总电动力学课程全部 **核心公式**，按章节排列，便于期末复习快速查阅。考试时卷面会给出大部分公式，但需知道**每个公式解决什么问题、在什么条件下使用**。

## 1. 麦克斯韦方程组

### 微分形式（真空）

| 公式 | 名称 | 物理含义 |
|:---|:---|:---|
| $\nabla \cdot \mathbf{E} = \dfrac{\rho}{\varepsilon_0}$ | 高斯定律 | 电荷是电场的源 |
| $\nabla \times \mathbf{E} + \dfrac{\partial \mathbf{B}}{\partial t} = 0$ | 法拉第定律 | 变化磁场产生电场 |
| $\nabla \times \mathbf{B} - \varepsilon_0 \mu_0 \dfrac{\partial \mathbf{E}}{\partial t} = \mu_0 \mathbf{J}$ | 安培-麦克斯韦定律 | 电流和变化电场产生磁场 |
| $\nabla \cdot \mathbf{B} = 0$ | 高斯磁定律 | 无磁单极子 |

### 积分形式

| 公式 | 名称 |
|:---|:---|
| $\displaystyle\oint_S \mathbf{E} \cdot d\mathbf{S} = \frac{Q_{\text{int}}}{\varepsilon_0}$ | 高斯定理 |
| $\displaystyle\oint_{\partial S} \mathbf{E} \cdot d\mathbf{l} = -\frac{d}{dt}\int_S \mathbf{B} \cdot d\mathbf{S}$ | 法拉第定律 |
| $\displaystyle\oint_{\partial S} \mathbf{B} \cdot d\mathbf{l} = \mu_0 I_{\text{int}} + \varepsilon_0 \mu_0 \frac{d}{dt}\int_S \mathbf{E} \cdot d\mathbf{S}$ | 安培-麦克斯韦定律 |
| $\displaystyle\oint_S \mathbf{B} \cdot d\mathbf{S} = 0$ | 高斯磁定律 |

### 四维协变形式

| 公式 | 名称 |
|:---|:---|
| $\partial_{[\sigma} F_{\mu\nu]} = 0$ | Bianchi 恒等式（无源方程） |
| $\partial_\mu F^{\mu\nu} = \mu_0 J^\nu$ | 有源方程 |
| $\partial_\mu J^\mu = 0$ | 电荷守恒（自动满足） |
| $F_{\mu\nu} = \partial_\mu A_\nu - \partial_\nu A_\mu$ | 电磁场张量定义 |

### 洛伦兹力

$$
\mathbf{F} = q(\mathbf{E} + \mathbf{v} \times \mathbf{B}), \qquad d\mathbf{F} = (\rho \mathbf{E} + \mathbf{J} \times \mathbf{B}) \, dV
$$

## 2. 静电场

### 基本方程

| 公式 | 名称 | 条件 |
|:---|:---|:---|
| $\nabla \cdot \mathbf{E} = \dfrac{\rho}{\varepsilon_0}$ | 高斯定律（微分） | 一般 |
| $\nabla \times \mathbf{E} = 0$ | 环量定理（无旋） | 静态 |
| $\mathbf{E} = -\nabla \phi$ | 电势定义 | 静态 |
| $\nabla^2 \phi = -\dfrac{\rho}{\varepsilon_0}$ | 泊松方程 | 有电荷 |
| $\nabla^2 \phi = 0$ | 拉普拉斯方程 | 无电荷区域 |

### 库仑定律与势

| 公式 | 名称 |
|:---|:---|
| $\mathbf{E}(\mathbf{x}) = \dfrac{1}{4\pi\varepsilon_0} \displaystyle\int \dfrac{\rho(\mathbf{x}')(\mathbf{x}-\mathbf{x}')}{|\mathbf{x}-\mathbf{x}'|^3} d^3x'$ | 连续电荷的电场 |
| $\phi(\mathbf{x}) = \dfrac{1}{4\pi\varepsilon_0} \displaystyle\int \dfrac{\rho(\mathbf{x}')}{|\mathbf{x}-\mathbf{x}'|} d^3x'$ | 连续电荷的电势 |
| $\phi = \dfrac{Q}{4\pi\varepsilon_0 r}$ | 点电荷电势 |

### 静电能

| 公式 | 名称 |
|:---|:---|
| $W = \dfrac{1}{2} \displaystyle\int \rho \phi \, dV$ | 电荷系静电能（源表示） |
| $W = \dfrac{\varepsilon_0}{2} \displaystyle\int |\mathbf{E}|^2 \, dV$ | 场能表示 |
| $u = \dfrac{\varepsilon_0}{2} |\mathbf{E}|^2$ | 能量密度 |

### 格林函数

| 公式 | 名称 |
|:---|:---|
| $G(\mathbf{x}, \mathbf{x}') = \dfrac{1}{4\pi|\mathbf{x}-\mathbf{x}'|}$ | 自由空间格林函数 |
| $\nabla^2 G = -\delta^{(3)}(\mathbf{x}-\mathbf{x}')$ | 格林函数方程 |

### 唯一性定理

给定泊松方程 $\nabla^2\phi = -\rho/\varepsilon_0$，若边界 $\partial V$ 上给定：
- **Dirichlet**：$\phi\big|_{\partial V} = f$（已知电势）→ 解唯一
- **Neumann**：$\dfrac{\partial\phi}{\partial n}\big\|_{\partial V} = g$（已知法向导数）→ 解唯一（差一常数）

## 3. 多极展开

### 多极矩定义

| 阶 | 公式 | 物理量 |
|:---|:---|:---|
| $l=0$ | $Q = \displaystyle\int \rho \, dV$ | 总电荷 |
| $l=1$ | $\mathbf{p} = \displaystyle\int \rho \, \mathbf{x}' \, dV$ | 电偶极矩 |
| $l=2$ | $p_{ij} = \displaystyle\int \rho(3x'_i x'_j - r'^2\delta_{ij}) \, dV$ | 电四极矩（无迹） |

### 多极展开势

$$
\phi(\mathbf{x}) = \frac{1}{4\pi\varepsilon_0} \sum_{l=0}^{\infty} \frac{1}{|\mathbf{x}|^{l+1}} \int \rho(\mathbf{x}') P_l(\cos\theta) |\mathbf{x}'|^l \, dV'
$$

### 球谐展开

| 公式 | 名称 |
|:---|:---|
| $\phi_{\text{in}} = \displaystyle\sum_l a_l r^l P_l(\cos\theta)$ | 球内解（有限） |
| $\phi_{\text{out}} = \displaystyle\sum_l b_l r^{-(l+1)} P_l(\cos\theta)$ | 球外解（衰减） |

## 4. 静磁场

### 基本方程

| 公式 | 名称 |
|:---|:---|
| $\nabla \cdot \mathbf{B} = 0$ | 无源（无磁单极） |
| $\nabla \times \mathbf{B} = \mu_0 \mathbf{J}$ | 有旋（安培定律） |
| $\mathbf{B} = \nabla \times \mathbf{A}$ | 矢势定义 |
| $\nabla^2 \mathbf{A} + \mu_0 \mathbf{J} = 0$ | 库仑规范下矢势方程 |

### 毕奥-萨伐尔定律

$$
\mathbf{B}(\mathbf{x}) = \frac{\mu_0}{4\pi} \int \frac{\mathbf{J}(\mathbf{x}') \times (\mathbf{x}-\mathbf{x}')}{|\mathbf{x}-\mathbf{x}'|^3} d^3x'
$$

### 磁偶极矩

| 公式 | 名称 |
|:---|:---|
| $\mathbf{m} = \dfrac{1}{2} \displaystyle\oint \mathbf{x}' \times (I \, d\mathbf{l}')$ | 磁偶极矩定义 |
| $\mathbf{F} = \nabla(\mathbf{m} \cdot \mathbf{B})$ | 磁偶极子受力 |
| $\mathbf{N} = \mathbf{m} \times \mathbf{B}$ | 磁偶极子受力矩 |

## 5. 一般电磁场

### 法拉第定律（含变化磁场）

$$
\mathcal{E} = \oint_{\partial S} \mathbf{E} \cdot d\mathbf{l} = -\int_S \frac{\partial \mathbf{B}}{\partial t} \cdot d\mathbf{S}
$$

### 总电动势 = 感生 + 动生

$$
\mathcal{E} = -\int_S \frac{\partial \mathbf{B}}{\partial t} \cdot d\mathbf{S} + \oint_{\partial S} (\mathbf{v} \times \mathbf{B}) \cdot d\mathbf{l}
$$

### 电场分解

$$
\mathbf{E} = \mathbf{E}_{\text{旋}} + \mathbf{E}_{\text{源}}, \qquad \nabla \cdot \mathbf{E}_{\text{旋}} = 0,\ \nabla \times \mathbf{E}_{\text{源}} = 0
$$

## 6. 电磁场动力学性质

### 能量守恒（坡印廷定理）

| 公式 | 名称 |
|:---|:---|
| $u = \dfrac{\varepsilon_0}{2}|\mathbf{E}|^2 + \dfrac{1}{2\mu_0}|\mathbf{B}|^2$ | 能量密度 |
| $\mathbf{S} = \dfrac{1}{\mu_0}\mathbf{E} \times \mathbf{B}$ | 坡印廷矢量（能流密度） |
| $\mathbf{g} = \dfrac{1}{c^2}\mathbf{S} = \varepsilon_0 \mathbf{E} \times \mathbf{B}$ | 动量密度 |
| $\dfrac{\partial u}{\partial t} + \nabla \cdot \mathbf{S} + \mathbf{J} \cdot \mathbf{E} = 0$ | 能量守恒 |

### 动量守恒

| 公式 | 名称 |
|:---|:---|
| $\sigma_{ij} = \varepsilon_0\!\left(E_i E_j - \dfrac{1}{2}\delta_{ij}|\mathbf{E}|^2\right) + \dfrac{1}{\mu_0}\!\left(B_i B_j - \dfrac{1}{2}\delta_{ij}|\mathbf{B}|^2\right)$ | 麦克斯韦应力张量 |
| $\dfrac{\partial \mathbf{g}}{\partial t} + \nabla \cdot \mathsf{P} + (\rho\mathbf{E} + \mathbf{J}\times\mathbf{B}) = 0$ | 动量守恒 |
| $\mathbf{F} = \displaystyle\oint_{\partial V} \boldsymbol{\sigma} \cdot d\mathbf{S}$ | 应力张量求力 |

### 应力-能量张量

$$
T^{\mu\nu} = -F^{\mu\rho}F^\nu_{\ \rho} + \frac{1}{4}g^{\mu\nu}F_{\rho\sigma}F^{\rho\sigma}
$$

## 7. 电磁波

### 波动方程

| 公式 | 条件 |
|:---|:---|
| $\Box \phi = -\dfrac{\rho}{\varepsilon_0}$ | 洛伦兹规范 |
| $\Box \mathbf{A} = -\mu_0 \mathbf{J}$ | 洛伦兹规范 |
| $\Box A^\mu = 0$ | 真空无源 |

### 平面波

| 公式 | 名称 |
|:---|:---|
| $\omega = c|\mathbf{k}|$ | 真空色散关系 |
| $\mathbf{B} = \dfrac{1}{c}\hat{\mathbf{k}} \times \mathbf{E}$ | E-B 关系 |
| $|\mathbf{B}| = |\mathbf{E}|/c$ | 振幅比 |
| $k_\mu \xi^\mu = 0$ | 洛伦兹规范（横波性） |

### 洛伦兹规范与库仑规范

| 规范 | 条件 | 特点 |
|:---|:---|:---|
| 洛伦兹 | $\nabla \cdot \mathbf{A} + \dfrac{1}{c^2}\dfrac{\partial \phi}{\partial t} = 0$ | 协变，$\phi$ 与 $\mathbf{A}$ 同形式波动方程 |
| 库仑 | $\nabla \cdot \mathbf{A} = 0$ | $\phi$ 瞬时泊松，$\Box\mathbf{A} = -\mu_0\mathbf{J}_{\text{旋}}$ |

## 8. 电磁辐射

### 推迟势

$$
\phi(\mathbf{x}, t) = \frac{1}{4\pi\varepsilon_0} \int \frac{\rho(\mathbf{x}', t_r)}{|\mathbf{x}-\mathbf{x}'|} d^3x', \qquad t_r = t - \frac{|\mathbf{x}-\mathbf{x}'|}{c}
$$

### 电偶极辐射

| 公式 | 名称 |
|:---|:---|
| $\mathbf{A}^{(0)} = \dfrac{\mu_0}{4\pi} \dfrac{-i\omega \mathbf{p}}{r} e^{ikr-i\omega t}$ | 偶极辐射矢势 |
| $\mathbf{E} \propto \dfrac{k^2}{r}(\mathbf{n}\times\mathbf{p})\times\mathbf{n}$ | 辐射电场 |
| $P = \dfrac{\mu_0 \omega^4 |\mathbf{p}|^2}{12\pi c}$ | 偶极辐射总功率 |
| $\dfrac{dP}{d\Omega} \propto \sin^2\theta$ | 角分布 |

### 拉莫尔公式

$$
P = \frac{\mu_0 q^2 a^2}{6\pi c} \qquad \text{（非相对论点电荷）}
$$

## 9. 宏观介质

### 束缚电荷与束缚电流

| 公式 | 名称 |
|:---|:---|
| $\rho_{\text{bound}} = -\nabla \cdot \mathbf{P}$ | 体束缚电荷 |
| $\sigma_{\text{bound}} = \mathbf{P} \cdot \hat{\mathbf{n}}$ | 面束缚电荷 |
| $\mathbf{J}_{\text{bound}} = \nabla \times \mathbf{M}$ | 磁化电流 |
| $\mathbf{J}_{\text{pol}} = \dfrac{\partial \mathbf{P}}{\partial t}$ | 极化电流 |

### 辅助场

| 公式 | 名称 |
|:---|:---|
| $\mathbf{D} = \varepsilon_0 \mathbf{E} + \mathbf{P}$ | 电位移 |
| $\mathbf{H} = \dfrac{\mathbf{B}}{\mu_0} - \mathbf{M}$ | 磁场强度 |
| $\mathbf{D} = \varepsilon \mathbf{E}$ | 线性介质（电） |
| $\mathbf{B} = \mu \mathbf{H}$ | 线性介质（磁） |
| $\varepsilon_r = 1 + \chi_e$ | 相对介电常数 |
| $\mu_r = 1 + \chi_m$ | 相对磁导率 |

### 介质中麦克斯韦方程

| 公式 | 名称 |
|:---|:---|
| $\nabla \cdot \mathbf{D} = \rho_{\text{free}}$ | 高斯定律（仅自由电荷） |
| $\nabla \times \mathbf{H} - \dfrac{\partial \mathbf{D}}{\partial t} = \mathbf{J}_{\text{free}}$ | 安培-麦克斯韦（仅自由电流） |
| $\nabla \cdot \mathbf{B} = 0$ | 不变 |
| $\nabla \times \mathbf{E} + \dfrac{\partial \mathbf{B}}{\partial t} = 0$ | 不变 |

### 介质中波速与折射率

$$
v = \frac{1}{\sqrt{\varepsilon\mu}}, \qquad n = \frac{c}{v} = \sqrt{\varepsilon_r \mu_r}
$$

## 11. 动体电动力学

### 洛伦兹变换

| 公式 | 名称 |
|:---|:---|
| $t' = \dfrac{t - vx/c^2}{\sqrt{1-v^2/c^2}}$ | 时间变换 |
| $x' = \dfrac{x - vt}{\sqrt{1-v^2/c^2}}$ | 空间变换 |
| $u = \dfrac{u' + v}{1 + u'v/c^2}$ | 速度叠加 |

### 电磁场变换

| 公式 | 名称 |
|:---|:---|
| $E'_\parallel = E_\parallel$ | 平行不变 |
| $B'_\parallel = B_\parallel$ | 平行不变 |
| $E'_\perp = \gamma(E_\perp + \mathbf{v}\times\mathbf{B})$ | 垂直混合 |
| $B'_\perp = \gamma\!\left(B_\perp - \dfrac{1}{c^2}\mathbf{v}\times\mathbf{E}\right)$ | 垂直混合 |

### 不变量

| 公式 | 名称 |
|:---|:---|
| $E^2 - c^2 B^2$ | 洛伦兹不变量1 |
| $\mathbf{E} \cdot \mathbf{B}$ | 洛伦兹不变量2 |

## 12. 拉格朗日力学

### 作用量与变分

| 公式 | 名称 |
|:---|:---|
| $\mathcal{L} = -\dfrac{1}{4}F_{\mu\nu}F^{\mu\nu} - j_\mu A^\mu$ | 电磁场拉格朗日密度 |
| $\partial_\mu F^{\mu\nu} = j^\nu$ | 变分得有源麦克斯韦方程 |
| $\partial_{[\rho}F_{\mu\nu]} = 0$ | 自动满足（$F=dA$） |

### 规范原理

| 公式 | 名称 |
|:---|:---|
| $A_\mu \to A_\mu + \partial_\mu \Lambda$ | 规范变换 |
| $D_\mu = \partial_\mu + iqA_\mu$ | 协变导数（引入规范场） |
| $T^{\mu\nu} = -F^{\mu\rho}F^\nu_{\ \rho} + \dfrac{1}{4}g^{\mu\nu}F_{\rho\sigma}F^{\rho\sigma}$ | Hilbert 能动张量 |

## 13. 张量恒等式

| 公式 | 名称 |
|:---|:---|
| $\varepsilon_{ijk}\varepsilon_{ilm} = \delta_{jl}\delta_{km} - \delta_{jm}\delta_{kl}$ | $\varepsilon\epsilon$ 缩并 |
| $\varepsilon_{ijk}\varepsilon_{ijl} = 2\delta_{kl}$ | 缩并两对 |
| $\varepsilon_{ijk}\varepsilon_{ijk} = 6$ | 全缩并 |

| $\nabla\cdot(\nabla\times\mathbf{A}) = 0$ | 旋度的散度 |
| $\nabla\times(\nabla\phi) = 0$ | 梯度的旋度 |
