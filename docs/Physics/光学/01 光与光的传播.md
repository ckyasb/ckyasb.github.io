# 01光与光的传播

## 1. 光的本性与光谱

* **发展史与波粒二象性**：

  * **微粒说与波动说**：17世纪，牛顿提出了微粒说（光是沿直线飞行的微粒流），解释了直线传播和反射，但在解释折射时得出了错误结论（认为水中光速大于空气）。惠更斯提出了波动说，能解释反射和折射，但当时被认为无法解释直线传播。
  * **电磁说**：19世纪，托马斯·杨和菲涅耳通过干涉、衍射实验确立了波动说。麦克斯韦提出电磁理论，赫兹实验证实了电磁波的存在，光被确认为一种电磁波。
  * **波粒二象性**：20世纪初，普朗克提出量子假说，爱因斯坦通过光电效应解释了光的粒子性（光子）。现代物理学确认光具有“波粒二象性”。

* **光谱与光源**：
  * **光源分类**：分为热辐射（如太阳、白炽灯，发光与温度有关）和非热辐射（如气体放电管、激光器、萤火虫发光）。
  * **可见光范围**：波长约为 $400 \sim 760$ nm。不同波长引起不同的颜色感觉（红端波长长，紫端波长短）。
  * **频率与波长**：真空中光速 $c \approx 3 \times 10^8 \text{m/s}$。波长 $\lambda$ 与频率 $\nu$ 的关系为 $c = \lambda \nu$。
  * **光强**：光强 $I$ 比例于电场振幅的平方 $E_0^2$。
  * **光谱类型**：连续光谱（如热辐射）和线状光谱（如气体原子发射）。单色光是指具有单一波长的光（实际上总有一定频宽）。

## 2. 光的几何光学传播规律

几何光学基于波长 $\lambda \to 0$ 的极限情况，忽略衍射效应。
*   **三大实验定律**：
    1.  **直线传播定律**：在均匀介质中，光沿直线传播。影子的形成和针孔成像证明了这一点。
    2.  **反射定律**：反射光线、入射光线、法线共面；反射光线和入射光线分居法线两侧；反射角等于入射角 ($i' = i$)。
    3.  **折射定律 (斯涅耳定律)**：折射光线在入射面内，且与入射光线分居法线两侧。入射角 $i_1$ 与折射角 $i_2$ 的正弦之比为常数，即 $n_1 \sin i_1 = n_2 \sin i_2$。其中 $n$ 为折射率，定义为 $n = c/v$（$c$为真空光速，$v$为介质光速）。
*   **光路可逆性原理**：如果光线逆着原来的反射或折射方向入射，它将逆着原来的入射方向传播。
*   **全反射**：
    *   **条件**：光从光密介质（$n_1$）射向光疏介质（$n_2$），且入射角大于临界角 $i_c$。
    *   **临界角公式**：$i_c = \arcsin(n_2/n_1)$。
    *   **应用**：全反射棱镜、光导纤维（利用全反射在纤维内部传输光能）。
*   **棱镜与色散**：
    *   **偏向角**：光线经过三棱镜折射后方向改变的角度 $\delta$。存在一个**最小偏向角** $\delta_{min}$，此时光线在棱镜内对称传播（$i_1 = i_2'$）。
    *   **折射率测定公式**：利用最小偏向角可测定材料折射率：$n = \frac{\sin \frac{\alpha + \delta_{min}}{2}}{\sin \frac{\alpha}{2}}$ （$\alpha$为棱镜顶角）。
    *   **色散**：折射率 $n$ 随波长 $\lambda$ 变化的现象。正常色散介质中，波长越短，折射率越大（紫光偏折最大）。

## 3. 惠更斯原理

*   **表述**：波面上的每一点都可以看作是产生次波的波源，这些次波在下一时刻的包络面就是新的波面。
*   **应用与解释**：
    *   成功解释了光的反射和折射定律。
    *   推导出折射率与光速的关系 $n_{12} = v_1 / v_2$，并得出光在光密介质中速度较小（$v < c$）的结论，这与微粒说的推论相反（微粒说曾错误预测水中光速更快）。
    *   解释了晶体双折射现象（虽然第一章未展开，但提及了）。
*   **局限性**：在解释直进性时不够完善（忽略了衍射），不能定量计算振幅，这些需要后来的菲涅耳原理补充。

## 4. 费马原理

*   **光程 (Optical Path)**：光在介质中传播的几何路程 $l$ 与介质折射率 $n$ 的乘积，$L = nl$。它代表光在同等时间内在真空中传播的距离。对于非均匀介质，光程为积分 $\int n dl$。
*   **原理表述**：光在两点间传播的实际路径，是光程取**平稳值**（极小值、极大值或恒定值）的路径。数学表达为光程的一阶变分为零：$\delta \int n dl = 0$。
*   **意义**：费马原理是几何光学的核心原理，可以从中推导出直线传播、反射和折射定律。
    *   **物像之间的等光程性**：从物点 $Q$ 到像点 $Q'$ 的所有实际光线的光程都相等（光程为恒定值）。

## 5. 光度学基本概念

光度学是研究光强弱的学科，区别于辐射度量学，光度学考虑了人眼对不同波长光的敏感度。
*   **辐射通量 ($\Phi_e$)**：单位时间内通过某一截面的辐射能量，单位是瓦特 (W)。
*   **视见函数 ($V(\lambda)$)**：人眼对不同波长光的敏感程度。明视觉下，人眼对 $555$ nm 的绿光最敏感。光度量是辐射量以视见函数为权重的加权。
*   **光通量 ($\Phi$)**：人眼感觉到的辐射功率。
    *   单位：**流明 (lm)**。
    *   关系：对于 $555$ nm 的单色光，1 W = 683 lm。
*   **发光强度 ($I$)**：点光源在单位立体角 $d\Omega$ 内发出的光通量。
    *   定义式：$I = \frac{d\Phi}{d\Omega}$。
    *   单位：**坎德拉 (cd)**。这是国际单位制（SI）中的基本单位之一。
*   **照度 ($E$)**：单位面积上接收到的光通量。
    *   定义式：$E = \frac{d\Phi}{dS'}$。
    *   单位：**勒克斯 (lx)**，即 $1 \text{lm/m}^2$。
    *   点光源照度距离平方反比律：$E = \frac{I \cos \theta}{r^2}$。
*   **亮度 ($B$)**：发光面在视线方向单位投影面积上的发光强度。
    *   定义式：$B = \frac{dI}{dS \cos \theta}$。
    *   单位：**尼特 (nt)** 即 $\text{cd/m}^2$，或熙提 (sb)。
    *   **朗伯定律 (余弦发光体)**：理想漫反射表面或黑体辐射，其亮度 $B$ 不随方向变化，而发光强度 $I$ 随方向角的余弦变化 ($I \propto \cos \theta$)。
